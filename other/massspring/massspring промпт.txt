3. Ключевые технические решения (кратко — войдёт в бриф)
Интегратор: velocity-Verlet / semi-implicit Euler по умолчанию + оверсэмплинг 1–8×; Newmark-β как опция для жёстких сеток. Тест на сохранение энергии в CI.
Строка: два бэкенда за одним интерфейсом — MD-цепочка (богатая, поддерживает коллизии → твой «негармонический звон струн друг о друга») и FD-волновод (дешёвая, длинная).
Коллизии: penalty Hunt–Crossley (k·δⁿ + c·δⁿ·δ̇) — без залипания; spatial hash; анти-алиасинг через оверсэмплинг.
Возбуждатели = force-in + velocity-probe узлы; FM/КС/шум/волновод — генераторы силы; двунаправленная связь без алгебраических петель через ZDF.
Смычок: динамическое трение с Stribeck-кривой на оверсэмплированной частоте.
Детерминизм: фиксированный dt, сид RNG, стабильный порядок обхода — иначе пресеты «плывут».
Пресет = JSON: граф + параметры + автоматизации; запись жестов = стрим (t, nodeID/paramID, value) → редактируемые дорожки, loop/one-shot/квантизация.
Главные риски: стабильность при аудио-скорости, двунаправленная связь, CPU при больших сетках, дрейф пресетов.

Функции

Возбуждатели: force-in в узел + velocity-probe; источники: шум, Karplus-Strong,волновод, FM-банк, сэмпл, аудио-вход. Обратная связь возбудителя обязана.
Взаимодействия: смычок (трение Stribeck), столкновения строк друг с другом(Hunt–Crossley), трение, магниты, «рука» (drag мышью = сила).

Про п.8, по-человечески: плагин = AudioProcessor (в нём физический мир, работает на аудио-потоке) + окно редактора с OpenGLContext (рисует мир и ловит мышь). Финальный промпт
ПРОЕКТ: «[ИМЯ]» — физмод-синтезатор mass-spring-damper с рисуемыми резонаторами (VST3/CLAP)
Зафиксированные решения
Хост-референс: Ableton Live. SR 44.1–96k, буфер 32–128 (обяз. поддержка 32@48k).Ядро не зависит от размера блока; фиксированный dt = 1/(SR·O).
UI: JUCE 8 + juce::OpenGLContext. Канвас 2.5D: рисование в XY, колесо мыши —смещение плоскости рисования по Z (слои), камера-орбита. Порты на телахрезонаторов, связи = 3D-кабели (как ModularVST, но в пространстве). Без ImGui на старте.
Полифония: один мир-сцена; N нот → N возбудителей в одном мире.Клонирование сцен — интерфейс заложить, не реализовывать.
Модуляция MVP: velocity, modwheel, CC learn, channel aftertouch. Модель данныхmod-matrix-ready: {src, dst-param-path, depth, curve}. MPE — позже без рефактора.
Обратная связь возбудитель↔резонатор: всегда доступна. Защита: tanh-clamp силы,ZDF-решение петли, энергетический страж (адаптивное демпфирование региона прирасходимости). Макро «Coupling/Stability» в UI.
CPU: 3 тира качества (potato/normal/ultra). Гибрид: длинные струны → волноводс fractional-delay, короткие/контактные зоны → MD-цепочки с локальнымоверсемплом (activity mask); сон масс; spatial hash; SIMD (SSE/AVX).
Лицензии: пермиссивные предпочтительны; JUCE = GPLv3 или коммерч. — зафиксироватьрешение в спеке до релиза.
Функции
Резонаторы: масса, пружина (лин/нелин), демпфер, фиксация/земля, строка(2 бэкенда: MD-цепочка / волновод), мембрана-сетка, мост/жёсткий брус.Инспектор материала: m, k, c, плотность, натяжение, нелинейность.
Возбуждатели (сменные профили силы на одном force-in порту): strike, pluck,bow, magnet-pulse, шум, Karplus-Strong, волновод, FM-банк, сэмпл, аудио-вход.Velocity → интенсивность. Обратная связь с резонатора — тумблер + amount.
Взаимодействия: смычок (трение с Stribeck-кривой), столкновения тел/струн(Hunt–Crossley penalty), вязкое трение, магнит, «рука» (drag мышью = сила).
Рисование: линия → строка; замкнутая кривая → мембрана; ЗОНА ПЕРЕСЕЧЕНИЯфигур → автогенерация MD-сетки с выбранным материалом и натяжением(булевы операции Clipper2, триангуляция delaunator-cpp).
Рисуемые модуляторы: LFO-кривые, огибающие, триггер-зоны на канвасе(масса вошла в зону → событие: импульс/удар/вкл. возбудителя/смена профиля).
Запись жестов: все дёргания масс и ручек → стрим (t, nodeID/paramID, value) →редактируемый слой пресета: loop/one-shot, квантизация, скорость, сглаживание.
Пресет = JSON (версионированный), детерминизм: фиксированный порядок обхода,без unordered-контейнеров в аудиотракте, сид RNG. Undo/redo.
Ядро физики
Интегратор: velocity-Verlet (или semi-implicit Euler), O∈{1,2,4}, double вотладке → float в релизе. Контакты: Hunt–Crossley (k·δⁿ + c·δⁿ·δ̇), n∈[1.2,2],анти-chattering. Петли связей: ZDF / 1–2 итерации Ньютона, без delay-free алгебры.
CPU-бюджет (ultra): бенчмарк-патч «2 смычковые струны по 64 массы + мембрана24×24 + взаимные столкновения + 1 FM-возбудитель» ≤ [X]% ядра при 64 сэмплов@48kна среднем ноутбуке (M1 / i5-8250U). Порог приёмки: [заполни, напр. 5%].
Тесты (Catch2 в CI): дрейф энергии < ε за N сек; f0 струны = (1/2L)·√(T/μ) сошибкой < 2%; регресс-хэш WAV вывода; детерминизм (двукратный прогон — бит-в-бит).

ты описал — это не два звука и не «эффект», это одна физическая ручка. В науке о смычке это диаграмма Шелленга (Schelleng, 1973): характер звука определяется положением в пространстве {прижим F, скорость смычка v, точка β, форма кривой трения}. Скрежет и чистый бас — противоположные углы этого пространства, и всё между ними — валидные звуки. Значит, делаем макро Regime R ∈ [0..1]:

R
режим
что в физике (модель трения одна и та же)
0	скрежет	большой прижим, медленный смычок, узкая кривая спада трения, шум волоса, β у подставки → stick-slip срывы, ALF-субгармоники, широкополосный шум
1	чистый бас	малый прижим, быстрый смычок, широкая кривая, β ближе к середине → чистое движение Хельмгольца, тёплая пила

И главное: R — обычный адресуемый параметр. «Начать жёстко, потом бас, назад» = кривая R во времени. Источники: нарисованная LFO, огибающая атаки ноты (note-on → R=0 → сползает к 1 → velocity задаёт глубину скрежета), CC1/aftertouch, запись жестов (жмёшь запись, дёргаешь ручку — это и твой сценарий). Морф должен идти путём через промежуточные режимы, а не переключаться — переход через «срыв» самая выразительная зона.

ДОПОЛНЕНИЕ: Bow Morph (макро Regime)
Профиль bow = макро R∈[0..1]: 0 скрежет, 1 чистый бас. Одна модель трения (MSW),R отображается на {F_N, v_bow, v_fall, β, noise_F_N, связь с крутильными волнами}.Масштаб F_N = mult·2·Z0·v_bow (Z0 — волновое сопротивление струны), mult — окно Шелленга.
R — адресуемый параметр: mod-matrix (рис. LFO, огибающая атаки note-on с глубинойот velocity, CC, aftertouch), запись жестов, автоматизация хоста, триггер-зоны.
Скрежет = stick-slip + ALF-субгармоники + шум волоса (+ опц. крутильные моды),не отдельные «эффекты». Границы окна Шелленга — естественные крайности морфа.
Anti-alias: оценка трения на оверсемпле ≥4×, кривая C¹-гладкая (tanh-stick + exp-fall).
GUI: ручка Regime + мини-диаграмма Шелленга с курсором текущего режима голоса.
