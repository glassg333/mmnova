# PhysMod MSD Synth — Master Spec Bundle v0.1 (2026-10-08)

Подготовительный комплект для разработки плагина физмод-синтезатора (mass-spring-damper + рисуемый 2D UI + bow + коллизии струн + сменные эксайтеры + запись жестов + VST3/JUCE).

## Состав

| Файл | Назначение |
|---|---|
| `00_README.md` | Этот файл — индекс и инструкция |
| `01_MASTER_PROMPT_EN.md` | Мастер-промпт для следующей AI-сессии (EN), с `{{HOLE-XX}}` — дырами под твои детали |
| `02_SPEC_RU.md` | Полная тех-спека (RU): архитектура, физическое ядро, эксайтеры, UI, жесты, JUCE/VST3, roadmap M0–M4, риски, тесты, prior art |
| `03_RESEARCH_LINKS.md` | Карта ссылок: твои 7 ссылок (проверены) + 25+ найденных репозиториев + библиография + матрица лицензий |
| `04_OPEN_QUESTIONS_RU.md` | Чеклист недостающих деталей (варианты ответов, отвечай одной строкой) |
| `papers/` | Скачанные открытые статьи: Bilbao (гл.1+TOC), JASA-2021 коллизии (Ducceschi/Bilbao/Willemsen/Serafin), arXiv-2024 модальный синтез струн |

## Как использовать (следующий этап)

1. Открой `04_OPEN_QUESTIONS_RU.md` и ответь минимум на блоки **A** и **E** (5–7 однострочных ответов).
2. Впиши ответы в `{{HOLE-XX}}` в `01_MASTER_PROMPT_EN.md` (или оставь — AI пометит свои допущения `[ASSUMED]`).
3. Докачай вручную в `papers/` PDF из списка «Скачать вручную» в `03_RESEARCH_LINKS.md` (особенно **GENESIS/NIME — это твоя же ссылка №7**, HAL блокирует роботов, в браузере открывается).
4. Запусти новую AI-сессию: вложи `01_MASTER_PROMPT_EN.md` + `02_SPEC_RU.md` + `03_RESEARCH_LINKS.md` + `papers/`.
5. Первая задача сессии: Phase 0 (контракт) → Phase 1 (ядро `msd::core` + тесты + CLI-рендер).

## Ключевые решения уже зафиксированы

JUCE 8 / C++20 / VST3 (+CLAP-абстракция) · ядро `msd::core` без JUCE · полунеявный Эйлер с субшагами (пассивные схемы — v2) · penalty-контакты → energy-quadratisation (JASA-2021) · bow elasto-plastic с пассивностью · 2D-растеризация фигур в сетки с материалами и сшивкой пересечений · слоты эксайтеров (noise/KS/FM/audio-in/hybrid) · gesture recorder → playable preset · JSON-пресеты + APVTS-автоматизация макросов.
