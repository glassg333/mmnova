# massspring bow live v1 — «губернатор»

Своя версия DSP mass-spring смычковой струны с рисованием и GUI (tkinter).
Написана заново, чтобы убрать баги прототипов `!ptototype/1 bow live` (v9…v18):
взрыв при нуле, потеря натяжения у рисованных струн, клики, взрывы жёстких сеток.

## Запуск

```bash
python -m pip install numpy numba sounddevice
python massspring_bow_live.py          # GUI (первый старт: компиляция ядра ~10–20 с)
python massspring_bow_live.py diag     # список аудиоустройств
python massspring_bow_live.py render   # headless-демо 14 c -> bow_render.wav
```

Первый запуск уже содержит эталон-струну. Порядок игры:
**ПКМ по струне** → поставить смычок → **ПРОБЕЛ** → пошёл звук.
Ручка **R** — макро «скрежет ↔ бас» (диаграмма Шелленга: прижим/скорость/β
отображаются на одну модель трения MSW, переход всегда через промежуточные режимы).

## Управление

| Действие | Как |
|---|---|
| Нарисовать струну | кнопка **РИСОВАТЬ** (или `D`) → ЛКМ вести линию → отпустить. Концы закрепляются автоматически |
| Нарисовать «лист» | в режиме рисования **замкнуть контур** → заливка сеткой масс (ингармоничный звон) |
| Связать фигуры | просто нарисуй струну поперёк сетки/фигуры — пересечения сшиваются пружинами-связями автоматически |
| Смычок | ПКМ по струне — точка смычка; ПРОБЕЛ — вкл/выкл; слайдер β двигает вдоль струны |
| Рука | ЛКМ (вне режима рисования) — мягкий захват массы, тянуть/отпустить |
| Пин | `Alt+ЛКМ` — закрепить/освободить узел |
| Эталон-струна | `S` |
| Сброс к покою | `r` (позиции в rest, скорости в 0 — «лечит» любую свистопляску мгновенно) |
| Очистить сцену | `C` |
| Отмена рисования | ПКМ или `Esc` |

## Почему теперь не взрывается (карта фиксов)

| Баг прототипов | Причина | Фикс здесь |
|---|---|---|
| Взрыв при `tension=0` | сила смычка/молота не масштабировалась жёсткостью; явный интегратор разгонял свободные массы | сила смычка ∝ `Z0=√(T·μ)`, при k→0 сила→0; деления на натяжение нет нигде; VMAX-кламп скорости как последний рубильник |
| «Струны теряли натяжение и места» | рисованная полилиния шла в физику как есть: кривые rest-длины ≠ прямому равновесию, натяжения нет вообще (геометрическая жёсткость 2-го порядка) | 1) равномерный ресемпл по длине; 2) **преднатяжение**: `rest = dx·(1−1/κ)`, `k = κ·T0/dx` → статическое натяжение ровно T0, строй `f0=(1/2L)√(T/μ)` выполняется точно (проверено: 110.0 Гц, 163.2 при T=2.2); 3) клампы силы убраны — они «съедали» статическое натяжение (та же семья багов была и у тебя) |
| Постоянные клики | контакты без гистерезиса (chatter) + жёсткие velocity-клампы каждый подшаг | runtime-контактов нет вообще (сшивка — пружинами при создании); рука — мягкая пружина с упругим пределом; смычок — неявная бисекция |
| Взрывы жёстких сеток | фиксированный dt нарушает Куранта `ω·dt<2` при `ω=2√(k/m)` | авто-подшаги: `nsub = ⌈ω·dt/0.8⌉` до 24; при упоре — **губернатор** мягко снижает жёсткость `k·(0.8·MAXSUB/(ω·dt))²` — звук делается вялым, но никогда не расходится; в статусе видно `ГУБ x0.42` |

Стабильность проверена автотестами: зигзаг-каракуля, tension=0, T=2.2+нелинейность,
сетка 88 масс + связи, губернатор под пыткой, живые структурные операции посреди
звука — ни одного NaN/взрыва/стража.

## Ручки

- **R скрежет↔бас** — макро режима смычка (АВТО-МОРФ — 7-секундный цикл как в v9).
- **Скорость / Прижим / β / Шум волоса** — смычок; масштаб прижима нормирован на
  волновое сопротивление струны (Schelleng: `F_N = mult·Z0·v_bow`).
- **Нотка f0** — базовая частота натянутой струны (55…220 Гц) независимо от длины рисунка.
- **Натяжение (0 = верёвка)** — live-множитель T0: питч ×√(натяжение). При 0 смычок
  молчит — это физика (нет волнового сопротивления), а не баг; верёвку можно тянуть рукой.
- **Нелинейность** — жёсткая пружина (strain²), «сдувание» питча на больших амплитудах.
- **Потери ζ** — осевое демпфирование пружин `c = 2ζ√(km)` (Q ≈ 1/(2ζ)); **Воздух** —
  глобальная вязкость.
- **Жёсткость сетки** — скорость волны в листе (м/с); **Связи** — множитель пружин-связей.
- **Масштаб колебаний** — визуальное увеличение смещений (на звук не влияет).

## Техминимум (для будущего порта в C++)

- Интегратор: semi-implicit Euler, `dt = 1/(SR·nsub)`, критерий устойчивости
  `ω_eig·dt ≤ 0.8`, `ω_eig = 2√(k/m_min)` (4k/m — макс. собственное значение цепочки).
- Смычок: неявный MSW (`μ(u)=FR+(1−FR)·e^(−|u|/vf)`), 48 итераций бисекции на подшаг —
  безусловно устойчив к любому прижиму.
- Съём звука: суммы скоростей внутренних узлов, взвешенные перпендикуляром струны,
  нормировка мощности; DC-блок 25 Гц → 6 биквадов корпуса (95…1150 Гц) → tanh-лимитер.
- CPU: ~26% ядра на 1 струну (nsub=3), ~93% на сетку 211 масс + 615 пружин (nsub=3)
  на слабой VM; на десктопе — заметно ниже.
