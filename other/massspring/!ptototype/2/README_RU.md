# Этап 0 — прототип физмод-ядра (NumPy, один файл)

Офлайн-прототип будущего C++-ядра плагина. Архитектура кода сознательно 1:1
с планом порта: каждый блок файла превращается в модуль ядра без изменения
математики. Рендер проверяет три ключевых механики до строки на C++:
морф смычка (скрежет <-> бас), пила Хельмгольца, негармонический звон
двух струн друг о друга.

## Состав

| Файл | Что это |
|---|---|
| `stage0_proto.py` | весь прототип: MD-струны + смычок MSW + Hunt-Crossley |
| `bow_morph_render.wav` | рендер 10 с, 44.1 кГц стерео (L = мост A, R = мост B) |
| `helmholtz.png` | 4 панели: скрежет, пила Хельмгольца, расписание R, коллизия |

Зависимости: `numpy`, `matplotlib`. Запуск: `python3 stage0_proto.py`
(полный рендер ~35 с CPU; `--quick` — смоук-тест 2.2 с).

## Что происходит на таймлайне WAV

| Время | Событие | Что слушать |
|---|---|---|
| 0.0-1.5 c | скрежет (R=0): тяжёлый прижим, медленный смычок, бета у моста | шорох волоса, срывы, подгармоники |
| 1.5-3.0 c | морф R: 0 -> 1 | переход через «срыв» — самая выразительная зона |
| 3.0-4.5 c | чистый бас (R=1) | ровный тон A2 = 110 Гц |
| 4.5-6.0 c | морф R: 1 -> 0 | обратный морф через промежуточные режимы |
| 6.0-7.4 c | скрежет продолжается | фон |
| 7.4 c | жёсткий удар по струне B | глухой «кланк», потом негармонический звон двух струн на фоне скрежета (до конца) |

## Что подтверждено числами (полный прогон)

- f0 в фазе баса по автокорреляции: **110.5 Гц** (цель 110.0).
- Пила Хельмгольца на скорости в точке смычка: прилипание на +0.22 м/с
  (= скорости смычка), срыв до -1.35 м/с (теория: -(1/beta-2)*v_b = -1.35),
  период 9.1 мс, доля скольжения ~ 2*beta — совпадает с Макинтайром-Вудхаузом.
- RMS моста A: скрежет -20 dB, бас -9 dB; мост B при коллизии -2.6 dB.
- Стабильность: omega_max*dt = 0.247 (< 2), guard ни разу не сработал, NaN нет.
- Стоимость: 3.5 с CPU на 1 с звука в чистом NumPy (в C++ ожидается >100x).

## Главный урок (идёт в мастер-промпт как поправка к Bow Morph)

Термальная скорость v_f обязана быть **в разы меньше** скорости смычка:
рабочая точка x0 = v_bow / v_f должна лежать на ПАДАЮЩЕЙ ветви кривой трения
(x0 > 1). Первый рендер с v_f = 0.35 при v_bow = 0.22 дал равновесие на
восходящей ветви -> струна статически залипала (плоская линия вместо пилы).
Рабочие значения: v_f = 0.016 (скрежет) ... 0.030 (бас) при v_bow
0.05 ... 0.22 м/с. В C++-ядре это условие валидируется тестом: RegimeMapper
обязан гарантировать x0 > 2 для всего диапазона R.

## Ручки для подгона на слух (все в шапке stage0_proto.py)

| Ручка | Значение | Эффект |
|---|---|---|
| `REG_VB` | 0.05 -> 0.22 м/с | скорость смычка по R |
| `REG_MULT` | 14 -> 4.5 | прижим F_s = mult*2*Z0*v_bow (окно Шелленга) |
| `REG_VF` | 0.016 -> 0.030 м/с | ширина кривой трения (держать << v_bow) |
| `REG_BETA` | 0.065 -> 0.14 | точка смычка от моста |
| `KD` | 0.25 | кинетический пол (хвост трения при скольжении) |
| `NOISE_MAX` | 0.35 | глубина шума волоса при R=0 |
| `R_SCHED` | (0,0)(1.5,0)(3,1)(4.5,1)(6,0) | сценарий морфа |
| `KC`, `CHI`, `GAP`, `STRIKE_V` | 1.2e5, 0.35, 3.5 мм, 4.5 м/с | жёсткость/демпф контакта, зазор, сила удара |
| `SIGMA_AIR`, `ETA_CD` | 0.3, 0.01 | затухание струн |

Параметры — стартовые из масштабных соображений (прижим нормирован на
волновое сопротивление Z0). Подгон диапазонов на слух — и есть смысл Этапа 0.

## Карта переноса numpy -> C++ (Фаза 1)

| В прототипе | В ядре C++ |
|---|---|
| `make_string()` | `msd::StringChain` (k, m, cd, концы-земля) |
| основной цикл, сегменты, интегратор | `msd::World::processBlock()` (semi-implicit Euler) |
| неявная ветка трения (`abs(u) < vf`) | `bow::MSWContact::apply()` — полу-неявный stick |
| явная ветка (`abs(u) >= vf`) | `bow::MSWContact` slip-режим |
| `regime`-массивы (`REG_*`) | `bow::RegimeMapper` + guard x0 > 2 |
| блок контакта (`KC`, `NEXP`) | `collide::HuntCrossley` |
| `recA/recB` (мостовые силы) | аудиовыход плагина |
| guards (NaN, V_GUARD) | энергетический страж v0 |

Тесты Catch2 при порте: дрейф энергии, f0 = (1/2L)*sqrt(T/mu) < 2% ошибки,
бит-в-бит детерминизм двух прогонов, регресс-хэш WAV.

## Три вопроса после прослушивания

1. Скрежет достаточно грязный, или хочется злее? (злее = добавить в морф
   крутильные волны струны — дают «дроблёный» призвук)
2. Бас не «пластиковый»? (если да — увеличить N и/или добавить резонанс
   волоса смычка 1-3 кГц)
3. Привязывать ли скрежет к атаке ноты автоматически (velocity -> глубина
   скрежета, сползание к басу огибающей) — или только ручной/записанный морф?
