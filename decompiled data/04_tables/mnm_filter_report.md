## 2. 2-pole SVF multimode (kernel `func_0004A8`, `P:$5D3-$5FA`)

Это основной **резонансный multimode-фильтр** голоса (FILT-страница).


| Параметр | Значение |
|---|---|
| Адрес кода | `P:$05D3 – $05FA` (post-voice, после `jsr (r1)`) |
| Цикл | `do #<$8` × 2 (8 итераций × 2 канала = **16 сэмплов/блок**) |
| Константа `x0` | `$F528BD` = **−0.084747577** (знаковая q.23) |
| Константа `x1` | `$4A4DF0` = **+0.581161499** (знаковая q.23) |
| Состояние A-bank | `X:$71+n*3, n=0..7` (stride 3, 8 стерео-сэмплов) |
| Состояние B-bank | `X:$73+n*3, n=0..7` |
| Коэффициенты (per-voice) | загружаются из `V-$18` (6 слов) в `Y:$91+` / `Y:$d1+` |
| Mod register m4 | `$FFFFFF` (linear, без wrap) |
| Mod register n4 | `$FFFFFE` = −2 (для `y:(r4)+n4` backward step) |
| Голосовой state block | `V = Y:$528 + voice*$100` (256 слов/голос, 6 голосов) |

### 2.1. Точная раскадровка одной итерации (P:$5DA-$5E1)

```text
; Вход: y0, y1 — чередующиеся сэмплы; x0=$F528BD, x1=$4A4DF0
; Аккумуляторы a, b — фильтр-состояния (lp/bp/hp) для текущего сэмпла
mpy  y0,x0,a    a,x:(r1)+n1    y:(r4)+,y1   ; a = y0*x0   ; старый a→state
mpy  x0,y1,b    b,x:(r2)+n2                  ; b = x0*y1   ; старый b→state
mac  y1,x1,a    y:(r4)+,y0                  ; a += y1*x1
mac  x1,y0,b    y1,x:(r1)+                  ; b += x1*y0  ; store y1→state
mac  x1,y0,a    y:(r4)+,y1                  ; a += x1*y0
mac  y1,x1,b    y0,x:(r2)+                  ; b += y1*x1  ; store y0→state
mac  x0,y1,a    y:(r4)+n4,y0                ; a += x0*y1  ; r4−2 (n4=-2)
mac  y0,x0,b    y:(r4)+,y0                  ; b += y0*x0
move a,x:(r1)+n1                            ; сохранить a в state
move b,x:(r2)+n2                            ; сохранить b в state
```

Итоговая формула (per сэмпл): `a = 2·x0·y0 + 2·x1·y1`, `b = 2·x0·y0 + 2·x1·y1` (свёртка 4 входов).
Здесь `y0, y1` — чередующиеся сэмплы (вход + предыдущее состояние),
`x0 = -0.0847476, x1 = +0.5811615` — фиксированные scalers (одинаковые для всех TONE).
TONE/Q/MODE подаются через `Y:$91+` (предзаполнение перед циклом).

## 3. Cascaded HP+LP Base-Width (kernel `P:$A5F-$ABF`)

Три последовательных 1-полюсных IIR-фильтра (по 16 сэмплов/блок):

| # | Параметр | Таблица | Формула | Роль |
|---|---|---|---|---|
| 1 | `V+$16` (BASE) | кривая 1 [0..127] | `a = (1-k)·a + k·input` | HP на BASE |
| 2 | `V+$16+V+$17` (BASE+WIDTH) | кривая 1 [0..127] | `a = (1-k)·a + k·input` | LP на BASE+WIDTH |
| 3 | `V-$8d >> 17` | кривая 2 [129..256] via `x:(r2+$144b48)` | `a = (1-k)·a + k·input` | доп. фильтр (mode) |
