 Кнопка MATRIX (теперь рядом с LOAD BANK) — внизу открывается синее окно в стиле SE-1X/Omega CODE: слева контроллеры, посередине LFO/ENV3/XMOD/волны, справа env DLY/DYN + PAN 1–4. Всё редактируемое, 
 пишется в тот же слот (A при MORPH≤50%, иначе B), морфится и автоматизируется как остальные байты.
 
 Из скрина осталась неотображённой верхняя строка «голосовые» параметры (uni/voice/prior/vmod/trg, octav, tune, category) — они в банке есть и морфятся, 
 но в UI их не вывожу, пока движком не используются; если хочешь — выведу их в extend отдельным блоком «для полноты», скажи.
 
 
 Автопанорама одного голоса — это ОРИГИНАЛ
Прямо из мануала, PAGE 15 «PAN POSITIONS IN A MULTI»: «The Multi preset stores its own Pan Position, Pan Rate, and Pan Depth for each voice».
 То есть у каждого голоса свой осциллятор панорамы со своей скоростью — они фазой разъезжаются, и один голос действительно может гулять один. 
 «Все вместе гуляют» — когда Rate у голосов совпадает (в Multi можно выставить одинаковые P1–P4 RATE, у нас это ручки в GLOBAL-окне). Так что: 
 гуляет по отдельности = честный оригинал, гуляют вместе = тоже оригинал (одинаковые rates). Наша реализация: синус 0.02–8 Гц на голос + позиция + depth, ровно по этой спецификации.

2. Ручки — драг переделан заново
Круговой драг r11 заменён линейным аккумулятором (dx−dy): тянется в любом направлении — вверх, вниз, влево, вправо, по диагонали; 120 px = полный ход, 1 px ≈ 1 байт. Попап и арка на месте. Надеюсь, на этот раз «крутится куда тянешь».

3. AUX-карта и TYPE — теперь щёлкается прямо из Ableton
AUX-карта и раньше зависела от TYPE: она слышна только когда TYPE = AUX1 (у большинства патчей TYPE 0…4 — потому и «ничего не переключает»). В r14 добавил Filter Type как параметр хоста (AudioParameterChoice: SEM LP…AUX2) — щёлкай TYPE из Ableton/клипа, байт и параметр синкятся в обе стороны. Тест: патч → TYPE=AUX1 → крутить AUX1 Card (OB SVF/OB-X/TB303).

4. ANODAZED — это он сам, экстремальный патч
Его байты: GLIDE_FLAGS 68 (ON+legato), GLIDE_TIME 127 (максимум), CUTOFF 0 (фильтр закрыт, открывает только контур), FILT_TYPE = BR (вилка), EXT_IN 64, DYN2 127. Тот самый «фейзинг» из скрина BLEND — он и есть замысел звука, щелчки не от латча. Заодно реализовал [MDE] по мануалу: bit2 = legato (как раньше), без bit2 = regular — glide на каждом триггере.

Что вернули из r10 и почему это главное:

Питч — ровно как в r10: FREQ − 32 (оба осциллятора). В r15/r16 этот сдвиг сняли по фабричной статистике — и весь звук ушёл на 32 полутона вверх. Это и есть «звучит очень тонко», «октавы сбиты», «слишком фильтрован» — один баг объяснял все три жалобы. Измерено: FREQ=32 / OCT=MID / A4 = 440.085 Гц (было ~2034), FREQ=44 = 880.17, FREQ=20 = 220.58.

Морф @50%: xfade 30 → 120 мс. Измерение одиночного прыжка через 50% (+12 st, SEM→MINI): max/base = 1.00 — транзиент «клика» убрался. Если в банке морф «подрастает» по уровню — это реальный уровень патча B, не артефакт (в r10 там был резкий скачок).

AUX2 «взрывался» — нашёл настоящую причину: не резонанс, а численный расход SVF при f/sr ≥ 0.30 (проверено сеткой: 0.25 — стабильно при любом Q, 0.30+ = inf даже на Q=0.5). HP-стадия на HPF вправо уходила в inf → полный клип. Фикс: кламп частоты SVF 0.24·sr + AGC 1/(1+2.5·res²) + Q HP мягче. Измерено: res=127 peak 1.000 → 0.018, inf нет.
