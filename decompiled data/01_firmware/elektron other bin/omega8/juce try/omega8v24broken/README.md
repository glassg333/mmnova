# Omega8 — VST3-версия синтезатора Studio Electronics Omega 8 / Omega CODE

Папка проекта (для репозитория `glassg333/mmnova` — положить как `omega8/`).
JUCE + Visual Studio (Windows). Ключевая задача — **запуск оригинальных патчей
(SE 176 байт) из фабричных банков `.syx`/`.mid`**: формат декомпилирован
статистическим анализом банков и сверен со скриншотом редактора Omega/CODE
(78/78 проверенных значений совпали с патчем REVELATION).

## Сборка

### Вариант A — ваш билдер (рекомендую, как у Monomachine Nova)
1. Папку `omega8` (с этим `Omega8.jucer`) положить в `E:\mm\`.
2. Перетащить папку на `JUCE\juce + vs builder\build_vst3.bat`
   (или запустить bat без аргументов и выбрать папку).
   Билдер сам: переключит модули на `useGlobalPath=1`, сделает
   `Projucer --resave`, соберёт Release x64 и скопирует .vst3 в
   `C:\Program Files\Common Files\VST3\!build test`.
3. Схема .jucer снята 1:1 с рабочего `Monomachine Nova Synth 1.9.9`
   (корень `<JUCERPROJECT>`, те же модули, включая
   `juce_audio_plugin_client` и `juce_audio_processors_headless`,
   экспортёр VS2022 x64 `/utf-8`) — см. `docs/BUILD_SCHEME_RU.md`.

### Вариант B — Projucer руками
1. Открыть `Omega8.jucer` в Projucer (`C:\JUCE\Projucer.exe`).
2. File → Save and Open in IDE → VS2022 → Release x64.
3. VST3: `Builds/VisualStudio2022/x64/Release/VST3/`.

### Вариант C — CMake (запасной)
```
cmake -B build -G "Visual Studio 17 2022" -DJUCE_DIR=C:/JUCE
cmake --build build --config Release
```

## Что работает
- **Загрузка оригинальных банков**: `.syx` и SMF `.mid` (только SysEx-потоки,
  размер кадра 8+128×176). Фабричный банк A встроен как ресурс — плагин
  стартует уже с 128 патчами; кнопка `LOAD BANK .syx/.mid` загружает любой
  другой (B, RAM-дампы, пользовательские).
- **Мгновенное переключение патчей на лету**: параметры **Preset A** и
  **Preset B** (0–127, автоматизируемые, ступенчатые) — крутятся из DAW.
- **Морф/переключение пресета — автоматизируемый параметр `Patch Morph A→B`**
  (0–100%): посимвольная интерполяция всех 160 байт параметров (причём
  в т.ч. линейно, не «скачком») — можно рисовать энкодером в DAW.
- 8 стерео-голосов с «летающей» панорамой (per-voice rate/pos/depth —
  массивы байтов 136/144/152), 2 LFO + пан-LFO, 3 огибающие, XMOD,
  матрица 24 destinations (как в мануале), фильтры:
  `SEM LP/BP/HP/BR`, `MINI` (лестница Moog), `AUX1` (Oberheim SVF),
  `AUX2` (CS80: HP hpf/hpr + LP).
- Арпеджиатор (автоматизируемый: on/off, rate, pattern, octaves).
- Пресеты/морф автоматизируемы; state DAW сохраняет (с путём банка).

## Карта байтов (декодировано; `Source/OmegaPatch.h`)
Подтверждены редактором (conf=3): LFO1 rate 8 / depth 10–12 / dest 13–15,
LFO2 21 / 23–25 / 26–28, OSC1/2 freq 30/31, PWM 34/35, level 37/38/noise 39,
XMOD dpth/dest 41/42, TYPE 43 (0=SEM LP,1=BP,2=HP,3=BR,4=MINI,5=OBER,6=CS80),
CUTOFF 44, RESO 45, TRACK 46, ENV1 AMT 47, env1 49–53, env2 54–58, env3
59–63 (A,D,Dk2,S,R), env3 matrix dest 64–66 / amt 67–69, EXT IN 76,
HPR 79, WIN 80, контроллеры 86–109 (modwhl, dynamics, bender, pressure,
cont1, cont2 — cont2 со знаком: храним = отобр.+64), DYN 112–114,
pan 136/144/152 (8×rate, pos, depth), имя 160–175, GLIDE time 0 / flags 1.
Сильные (conf=2): OCTAVE 2 (нibble: 64=MID, шаг 16 = октава), ENV3 AMT 3,
SUB 4, PRIOR 7, VOLUME 32, HPF 40, OSC2 FINE 78, MASTER TUNE 77.
Неизвестные (остались сырыми, на поведение влияют нейтрально): 6,17,18,33,36,
70–73,75,81–85,110,111,134 — байты загружаются/сохраняются как есть.

## Известные ограничения v1
- Стадия `Dk2` (вторая затухающая стадия огибающей) хранится, но в DSP пока
  не участвует (A/D/S/R участвуют) — нужен аппаратный сверочный тест.
- Источники cont1/cont2 замаплены на CC16/CC17; приоритет (LOW/HIGH/LAST) и
  режимы multi-trigger — декодированы, влияют минимально.
- Кнопка сравнения/редактирования страниц (как на железе) — только просмотр
  значений; звуковые параметры читаются из морф-патча.

## Как пользоваться (rev r5)

### LCD (синий экран, колонка Programmer)
- **Строка 1** — имя патча, который сейчас правят ручки (только печатный ASCII; битые байты вырезаются — «иероглифы» больше не появятся).
- **Строка 2** — `A:007  B:003  MORPH:45%`:
  - `A:007` — номер патча в слоте **A** (показывает 1..128),
  - `B:003` — номер патча в слоте **B**,
  - `MORPH` — позиция морфа A→B в %.

### Переключение патчей на лету (как в оригинале)
- Кнопки `<` `>` у строк **PATCH A** / **PATCH B** — шаг по слоту вверх/вниз. Мгновенно, можно во время звучания ноты.
- Выпадающий список `-- patch --` — быстрый выбор патча в **слот A**.
- В DAW автоматизируются параметры **Preset A** / **Preset B** (значение 0..127 = патчи 1..128).
- Program change из хоста тоже уходит в слот A (128 программ).

### Морфинг A→B
- Ползунок **MORPH A > B** = автоматизируемый параметр **Patch Morph A->B**.
- 0% = слот A, 100% = слот B, между — пообайтовая интерполяция всех параметров патча.
- Рецепты:
  - **переключение без щелчка**: два патча в A и B + короткий MORPH-автомейшн 0→100% (или просто кнопки `< >` — сглаживания r5 гасят клики);
  - **морф-свипы**: держите связку A/B и ведите MORPH целевой нотой/фейдером — автоматизация пишется сэмпл-в-сэмпл;
  - **аккорд ↔ арп**: включите **START/STOP** арпа — та же связка звучит пунктиром; выкл — снова аккорды.

### Ручки
- Ручки редактируют **тот слот, к которому ближе морф**: MORPH ≤ 50% → слот A, иначе → слот B. На дисплее — реальные байты этого слота.
- Правьте A с MORPH=0, B с MORPH=100%.
- Изменение слышно сразу (применение ≈1 аудиоблок ≈ 5–10 мс).
- Правки байтов живут до выгрузки плагина; чтобы закрепить — сохраните банк и грузите через **LOAD BANK .syx/.mid**.

### Арпеджиатор
- **START/STOP**, **RATE** (шаги/с), паттерн `UP/DOWN/UP-DN/RND`, **1–4 OCT**.
- Держите аккорд — арп его разбирает; отпустите — арп замолкает.

### Что чинит r5 (звук)
- **DC offset** — DC-блокер ~12 Гц на выходе (как выходной конденсатор в железе): патчи со смещением больше не уводят/не глушат сигнал.
- **Щелчки при морфинге и переключении** — сглажены громкость (6 мс), cutoff/резонанс (4 мс), панорама (1 мс) + 4 мс микро-кроссфейд на смене волны/фильтра/XMOD.
- **«Молчащие» патчи** — NaN/Inf внутри фильтров сбрасываются со стабилизацией: раньше «яд» от одного голоса делал незвукучим весь вывод.
- Ручки перестали сбрасываться (не дёргаются во время вращения, диапазон 0..127).

### Если что-то не так
1. В логе сборки должна быть строка `omega8 build rev r5-20260929` — нет = собраны старые файлы.
2. Пришлите: номер патча (`A:xxx`), что слышно/не слышно (осциллограф/спектр приветствуются), хвост лога.

## r6 — матрица модуляций (extend window)

Кнопка **MATRIX** (рядом с LOAD BANK) открывает нижнее окно в стиле синего
LCD у SE-1X / Omega CODE (скрин `UI/OMEGACODE.jpg`):

- **CONTROLLERS** — матрица источников `modwhl, dynamics, bender, pressure,
  cont1, cont2`: 2 назначения (dropdown 25 позиций) + 2 глубины на строку.
- **LFO1 / LFO2 / ENV3** — по 3 dest-дропдауна на источник (как в оригинале,
  до этого dest были только текстом); у ENV3 ещё 3 глубины (E3 A1..A3),
  у LFO — волна SIN/SQR (W1/W2).
- **XMOD** — назначение FREQ / PW / CUTOFF.
- **ENV DLY / DYN** — задержки о-envelope (DLY1..3, теперь реально работают:
  в движок подключена стадия Delay перед Attack) и dynamics (DYN1..3,
  DYN2 = velocity→VCA работает, 1/3 — байты банка для полноты/морфа).
- **PAN 1–4** — pos / rate / dpth по 4 голосам (это и есть «летающая панорама»:
  движок читает kArrPos/Rate/Depth, раньше ручек не было).
- **Волны OSC1 (tri/saw/pwm)** и **GLIDE** теперь кликабельны как на железе
  (биты WAVE_BITS / GLIDE_FLAGS).

Что НЕ работает намеренно (движок не читает эти байты, показываем только
работающее): unison/voice/prior/vmod/trg, mode/quun, glissando, auto,
OSC2 sync mode, category, win, MASTER TUNE (заглушка).

- **Сверка списков назначений с мануалом omegaCODE (стр.17–18,24) и декодом:**

  MODWHEEL/DYNAMICS/PRESSURE и с ENVELOPE 3 (verified: ENV3 dest 16 == LF1R).
  Пары осцилляторов на месте (FRE1/FRE2, LEV1/LEV2, PW1/PW2, 1&2F/1&2P).
  Для LFO мануал additionally упоминает VOL — байтовый код не декодирован,
  пункт не добавлен (не гадаем). XMOD: FREQ/PW/CUTOFF — на скрине "=Vcf" ✓.
- **cont1/cont2 SOURCE-дропдауны** (MODW/TRAK на скрине) НЕ реализованы:
  байты 81–85 имеют conf=0 в карте — без подтверждения не пишем.
- Реализовано только то, что подтверждено мануалом/декодом —
  категории банков (MINI/OBLP/OBBR/OBHP) — это бейджи редактора,
  байтовый код категории у нас не декодирован — не показываем.

## r14 — тишина/плавание громкости, свободный драг ручек, TYPE в Ableton (звук superseded by r15)

- **Почему было тихо и «плавало»:** байт VOLUME (offset 32) на фабричных патчах
  распределён 49..88 (mode 60–64, mean 64 — проверено на всех 512), а старая
  кривая `1.4*(v/127)^2` даёт на типовом патче 0.36 (−9 дБ). Хуже: громкость
  бралась из ГЛОБАЛЬНОГО патча — при браузинге пресетов в Ableton уровень
  прыгал прямо под играющими нотами. **Фикс:** громкость каждого голоса из
  **его** патча (`v.pg.VOLUME`), кривая `min(1, 0.5*(v/64)^2)` (mode64 → 0.5).
- **AGC смягчён:** MINI 1.6→0.9, AUX 1.0→0.6, прочие 0.6→0.4 (вместе с новой
  кривой общий уровень вырос ~×1.7 без клиппинга; soft-clip r8 остаётся).
- **Ручки:** круговой драг r11 заменён линейным аккумулятором `(dx−dy)`:
  тянется в любую сторону (вверх/вниз/влево/вправо/диагональ), 120px = полный
  ход, попап и арка на месте.
- **Filter Type — параметр хоста** (`AudioParameterChoice`): TYPE (SEM LP… AUX2)
  щёлкается прямо из Ableton — AUX-карта слышна без панели; байт и параметр
  синхронизируются в обе стороны (галочки/комбо ↔ хост).
- **[MDE] glide по мануалу:** bit2 флагов = legato (только между зажатыми,
  как раньше); без bit2 = regular — glide на КАЖДОМ триггере.
- Ответ на баг-репорт: AUX-карта слышна только при TYPE=AUX1 (батл-тест теперь
  из Ableton); ANODAZED = GLIDE_FLAGS 68 (legato) + GLIDE_TIME 127 + CUTOFF 0 +
  FILT_TYPE BR + EXT_IN 64 — экстремальный фабричный патч, не баг щелчка.

## r15 — возврат характера r10, восстановление pitch-center, панель по оригиналу

- **Звук:** по обратной связи r14 был слишком громким/менее чистым. В r15 возвращена
  кривая r10 `1.4*(VOLUME/127)^2`, per-voice latch оставлен, чтобы пресетный браузинг
  не менял уровень уже звучащих нот. Статическая gain-компенсация r11/r14 снята;
  soft-clip r8 пока оставлен. Это намеренно консервативное возвращение к варианту,
  который пользователь счёл ближе к оригиналу.
- **Pitch:** восстановлено центрирование OSC1/OSC2 FREQ вокруг raw=32 (формула r10).
  r11 убрал `-32`, то есть каждый осциллятор получал ровно **+32 полутона** относительно
  r10; на верхнем регистре это могло звучать как другой патч и сильнее алиасить.
  Для новых голосов glide больше не стартует от дефолтных 440 Hz; bit2 GLIDE_FLAGS
  не трактуется без подтверждения. Исправлен и MIDI pitch wheel: значение 8192 теперь
  центр (0 semis); прежний делитель без вычитания центра принимал его за +2 semitones.
  По скрину редактора REVELATION FREQ 24/36 сохраняет интервал 12 полутонов.
  Абсолютное соответствие MIDI-ноте ещё нужно сверить тюнером на нейтральном патче —
  формула raw-32 восстановлена как regression fix к r10.
- **Лицевая панель:** секции и пропорции перестроены по предоставленному OmegaCODEeditor
  screenshot; элементы начинаются ниже полосы заголовков, ручки центрируются в ячейках,
  подписи не заезжают на следующий ряд. ADSR на главной панели снова A/D/S/R;
  DKY2 (Decay 2) и остальные расширенные параметры остаются в GLOBAL.
- **GLOBAL без наложения:** закрытые матричные комбо и ручки теперь скрываются, а не
  остаются поверх основной панели после resize. Ручки отправляют change-notification,
  поэтому движение записывает байт в патч; SUB_WAVE ограничен корректным enum 0..6.
- **Фильтры:** семь строк `SEM LP/BP/HP/BR`, `MINI LP`, `AUX1`, `AUX2` на лицевой панели
  теперь активные кнопки с большими hit-area и синхронизируются с параметром Ableton.
  AUX1 Card имеет три **реализованные аппроксимации** (`OB SVF`, `OB-X`, `TB-303`),
  это не исчерпывающий список аппаратных карт.
- **Английские подписи:** стрелки заменены ASCII-кнопками `< > ^ v`, видимые названия
  фильтров и волн — английские; OCT/TUNE подписаны понятнее (точная DSP-реализация
  случайной расстройки TUNE пока не подтверждена); полная таблица —
  `docs/ENGLISH_LABELS_R15.md`. Исходники не содержат японских символов в видимых
  строках; если такие глифы всё ещё видны в установленном плагине, нужен скрин именно
  его окна (в исходном GUI они отсутствуют).
- **AUX по мануалу:** manual перечисляет SEM/MINI и дополнительные 303/2600/Juno-Jupiter/
  CS-80 варианты, CS-80 относится к AUX2. Три пункта AUX1 в текущем DSP — только те
  три модели, которые реально подключены; неподдерживаемые карты не выдаются за оригинал.
- **Важно:** проект не компилировался в этой среде (сборка запрещена по репо-ограничению).
  Проверены текстовые якоря, символьный баланс, parameter IDs, кликабельные callback и
  содержимое архива. В MSBuild должен появиться `omega8 build rev r15-20260929`.

## r16 — фильтры без «затычек», истинный DC, live BLEND (2026-09-29)

`omega8 build rev r16-20260929`. Подробности и измерения — `docs/CHANGELOG_R16.md`.

- **Фильтры:** MINI → **Moog24** (референс MoogPop; ObVarLadder-«шум» при высоком reso
  убрался — это был его входной tanh, а не DC); AUX1 card0 → **OB-Xa 24** (4-полюсная
  лестница + Xpander, референс `OB-XaFilter multimode/`); **CS-80 (AUX2)** — честная
  SVF-лестница: старый HP one-pole «хак» (`a·x/2`) пропускал DC — теперь DC HP-стадии = 0.
  SEM (Svf) и TB-303 (Wurtz) без изменений — по измерениям DC-чистые.
  Подписи карт: `OB-Xa 24 / OB-X 12 / TB-303`.
- **Истинный DC offset:** мастер 1-полюс 12 Гц (−6 дБ/окт) → 2-й порядок 10 Гц
  (−12 дБ/окт) + NaN-reset. Измерено standalone (res=max): все r16-фильтры |DC| ≤ 2e-4,
  самовозбуждение DC=0; e2E по factory-банку max|DC| на выходе = 1e-4 (v15: 7e-4).
  Диодная пара OB-X 12 — референс OB-Xd, сохранена (её −2.5e-3 снимается мастер-HP,
  характер дисторшна не искажаем).
- **PITCH (поправка к r15):** FREQ = **raw**, как r11..r14. Factory-банк: FREQ1 везде
  0..63 (29 патчей raw=0!) — при `raw−32` это 11 Гц на ноте 36 = тишина; при raw
  66 основных патчей = +2 октавы, как на оригинале (A/B тюнером: FREQ 32/32 + OCT MID
  → +2 окт). Это же объясняет «DS offset»: патчи v15 стояли на 2.67 октавы ниже —
  фундаменты 20–60 Гц + резонанс = гул.
- **BLEND («стал работать хуже»):** причина — байт-lerp портил ENUM-байты (FILT_TYPE,
  WAVE, LFO/ENV3-dest, PAN, OCT…) + latch r11 замораживал старые параметры. Теперь
  `Patch::lerp` со списком enum-байтов (снэп на t≥0.5, как исходный BLEND-меню),
  движок получает lerp-патч каждый аудио-блок — морф live; per-voice xfade 30 мс.
- **В r17:** CC98/99 → BLEND из хоста (сейчас крутится параметром `morph`),
  проверка уровней резонансных патчей (AGC).
- **Проверено:** standalone-сборка движка (без JUCE) + e2E-прогон factory-банка
  (128 патчей загружаются, звук есть, DC ≤ 1e-4, NaN нет). Компиляция в этой среде
  не запускалась — сборка только вашим билдером (запрет репо).

## r17 — честный SEM (Oberheim 12 dB), мульти-банки, CC98/99, раскладка ручек (2026-09-30)

`omega8 build rev r17-20260930`. Подробности и измерения — `docs/CHANGELOG_R17.md`.

- **SEM = Oberheim 12 dB лестница** (мануал: SEM = 12 dB Oberheim LP/BP/HP/BR; MINI = Moog 24 dB).
  Новый struct `Oberheim12`: 4× BZT one-pole (TPT), K-фидбэк через σ, входной буст (1+K),
  нормализация α₀ = 1/(1+K·G⁴), входной tanh — **бит-в-бит порт референса**
  `omega8_decode_for_agents/external_filters/OberhVar.h` (A/B-сверка по 33 точкам АЧХ, t17g).
  K = 4·res (референсное отображение r 1..10 → K 0..4); prewarp `g = tan(π·f/fs)`.
  Режимы по замеру АЧХ: LP = s4, BP = s2−s3 (DC=0), HP = u−s4 (DC=0),
  BR = x−s1+s2−s3+s4 (нотч на cutoff, DC = x).
  Характер: «мягкий» Oberheim — reso крутит скос и низкие средов, без Moog-воя
  (мануал: самоколебания характерны для НЕ-SEM фильтров).
- **Мульти-банки** (`Omega8FactoryMulti.syx`, 128×80 B): раньше — молчаливый отказ
  («краш» был воспринят как краш; OOB не было). Теперь `loadBank` парсит мульти:
  каждый слот = **первый активный part (0x7F = пустой) текущего банка** — best effort:
  другие ROM-банки в VST не грузятся, так что part-ссылки на них не резолвятся.
  Громкость/панорама/имя — из part-записи; имя пишется прямым memcpy
  (`setName()` делает `raw.fill(' ')` — затирает 160 байт параметров).
  Пустой слот = тихий плейсхолдер. LCD 4 с: `BANK LOADED: N patches` /
  `MULTI: first part per slot (8-part ref)` / `LOAD FAILED: not an Omega 8 bank`.
- **CC98/99 из хоста** (в мануале не описаны → best effort): CC98 = BLEND (morph),
  CC99 = preset A. Raw-store в APVTS — без дребезга, аудио-тред safe.
- **Раскладка редактора по оригинальной панели:** на физической панели только
  VOLUME + GLIDE (референсный набор — CODE-панель). 10 ручек, которых на оригинальной
  панели нет (FINE, TUNE, EXT IN, SUB, HPF, HPR, LFO1 D2/D3, LFO2 D2/D3), перенесены
  в нижнюю GLOBAL-полосу extend-окна.
- **Глифы в тултипах попуапов:** попуап ручки теперь показывает `TITLE значение`
  (чистый ASCII, int) через textFromValueFunction — японские иероглифы были в старых
  сборках (≤r10, %/кракозябры) или фолбэком шрифта Windows; в r17 попуап — только ASCII.
- **OSC2 («второй осциллятор не работает»):** заводской дизайн — в factory-банках
  OSC2 LEVEL = 0 и WAVE2 = 0x40 (tri). Осциллятор 2 декодируется и звучит,
  как только поднять ручку OSC2 LEV (sub-осциллятор — на тумблере SUB). r17: тултип
  на OSC2 LEV это объясняет — раньше выглядело как мёртвая ручка.
- **Проверено:** standalone-тесты (t17..t17i: АЧХ/DC/самоколебания/NaN всех режимов,
  бит-в-бит сверка с референсом, нотч BR, парсинг мульти 1:1 с hex) + e2E r17 vs r16:
  SEM-патчи (F=0) — новый тембр (rms 0.03–0.08, peak ≤ 0.77, |DC| ≤ 4e-5);
  **все не-SEM патчи идентичны r16 поцифрово** (изменение изолировано в SEM).
  Компиляция JUCE в этой среде не запускалась (запрет репо) — сборка вашим билдером;
  проверка ревизии: `findstr /c:"r17-20260930" Source\PluginProcessor.h`.
