# Omega8 — VST3-версия синтезатора Studio Electronics Omega 8 / Omega CODE

Папка проекта (для репозитория `glassg333/mmnova` — положить как `omega8/`).
JUCE + Visual Studio (Windows). Ключевая задача — **запуск оригинальных патчей
(SE 176 байт) из фабричных банков `.syx`/`.mid`**: формат декомпилирован
статистическим анализом банков и сверен со скриншотом редактора Omega/CODE
(78/78 проверенных значений совпали с патчем REVELATION).

## Сборка

### Вариант A — ваш билдер (рекомендую, как у Monomachine Nova)
1. Папку `omega8` (с этим `Omega8.jucer`) положить в `E:\mm\`.
2. Перетащить папку на `JUCE\juce + vs builder\build_vst3.bat`
   (или запустить bat без аргументов и выбрать папку).
   Билдер сам: переключит модули на `useGlobalPath=1`, сделает
   `Projucer --resave`, соберёт Release x64 и скопирует .vst3 в
   `C:\Program Files\Common Files\VST3\!build test`.
3. Схема .jucer снята 1:1 с рабочего `Monomachine Nova Synth 1.9.9`
   (корень `<JUCERPROJECT>`, те же модули, включая
   `juce_audio_plugin_client` и `juce_audio_processors_headless`,
   экспортёр VS2022 x64 `/utf-8`) — см. `docs/BUILD_SCHEME_RU.md`.

### Вариант B — Projucer руками
1. Открыть `Omega8.jucer` в Projucer (`C:\JUCE\Projucer.exe`).
2. File → Save and Open in IDE → VS2022 → Release x64.
3. VST3: `Builds/VisualStudio2022/x64/Release/VST3/`.

### Вариант C — CMake (запасной)
```
cmake -B build -G "Visual Studio 17 2022" -DJUCE_DIR=C:/JUCE
cmake --build build --config Release
```

## Что работает
- **Загрузка оригинальных банков**: `.syx` и SMF `.mid` (только SysEx-потоки,
  размер кадра 8+128×176). Фабричный банк A встроен как ресурс — плагин
  стартует уже с 128 патчами; кнопка `LOAD BANK .syx/.mid` загружает любой
  другой (B, RAM-дампы, пользовательские).
- **Мгновенное переключение патчей на лету**: параметры **Preset A** и
  **Preset B** (0–127, автоматизируемые, ступенчатые) — крутятся из DAW.
- **Морф/переключение пресета — автоматизируемый параметр `Patch Morph A→B`**
  (0–100%): посимвольная интерполяция всех 160 байт параметров (причём
  в т.ч. линейно, не «скачком») — можно рисовать энкодером в DAW.
- 8 стерео-голосов с «летающей» панорамой (per-voice rate/pos/depth —
  массивы байтов 136/144/152), 2 LFO + пан-LFO, 3 огибающие, XMOD,
  матрица 24 destinations (как в мануале), фильтры:
  `SEM LP/BP/HP/BR`, `MINI` (лестница Moog), `AUX1` (Oberheim SVF),
  `AUX2` (CS80: HP hpf/hpr + LP).
- Арпеджиатор (автоматизируемый: on/off, rate, pattern, octaves).
- Пресеты/морф автоматизируемы; state DAW сохраняет (с путём банка).

## Карта байтов (декодировано; `Source/OmegaPatch.h`)
Подтверждены редактором (conf=3): LFO1 rate 8 / depth 10–12 / dest 13–15,
LFO2 21 / 23–25 / 26–28, OSC1/2 freq 30/31, PWM 34/35, level 37/38/noise 39,
XMOD dpth/dest 41/42, TYPE 43 (0=SEM LP,1=BP,2=HP,3=BR,4=MINI,5=OBER,6=CS80),
CUTOFF 44, RESO 45, TRACK 46, ENV1 AMT 47, env1 49–53, env2 54–58, env3
59–63 (A,D,Dk2,S,R), env3 matrix dest 64–66 / amt 67–69, EXT IN 76,
HPR 79, WIN 80, контроллеры 86–109 (modwhl, dynamics, bender, pressure,
cont1, cont2 — cont2 со знаком: храним = отобр.+64), DYN 112–114,
pan 136/144/152 (8×rate, pos, depth), имя 160–175, GLIDE time 0 / flags 1.
Сильные (conf=2): OCTAVE 2 (нibble: 64=MID, шаг 16 = октава), ENV3 AMT 3,
SUB 4, PRIOR 7, VOLUME 32, HPF 40, OSC2 FINE 78, MASTER TUNE 77.
Неизвестные (остались сырыми, на поведение влияют нейтрально): 6,17,18,33,36,
70–73,75,81–85,110,111,134 — байты загружаются/сохраняются как есть.

## Известные ограничения v1
- Стадия `Dk2` (вторая затухающая стадия огибающей) хранится, но в DSP пока
  не участвует (A/D/S/R участвуют) — нужен аппаратный сверочный тест.
- Источники cont1/cont2 замаплены на CC16/CC17; приоритет (LOW/HIGH/LAST) и
  режимы multi-trigger — декодированы, влияют минимально.
- Кнопка сравнения/редактирования страниц (как на железе) — только просмотр
  значений; звуковые параметры читаются из морф-патча.

## Как пользоваться (rev r5)

### LCD (синий экран, колонка Programmer)
- **Строка 1** — имя патча, который сейчас правят ручки (только печатный ASCII; битые байты вырезаются — «иероглифы» больше не появятся).
- **Строка 2** — `A:007  B:003  MORPH:45%`:
  - `A:007` — номер патча в слоте **A** (показывает 1..128),
  - `B:003` — номер патча в слоте **B**,
  - `MORPH` — позиция морфа A→B в %.

### Переключение патчей на лету (как в оригинале)
- Кнопки `<` `>` у строк **PATCH A** / **PATCH B** — шаг по слоту вверх/вниз. Мгновенно, можно во время звучания ноты.
- Выпадающий список `-- patch --` — быстрый выбор патча в **слот A**.
- В DAW автоматизируются параметры **Preset A** / **Preset B** (значение 0..127 = патчи 1..128).
- Program change из хоста тоже уходит в слот A (128 программ).

### Морфинг A→B
- Ползунок **MORPH A > B** = автоматизируемый параметр **Patch Morph A->B**.
- 0% = слот A, 100% = слот B, между — пообайтовая интерполяция всех параметров патча.
- Рецепты:
  - **переключение без щелчка**: два патча в A и B + короткий MORPH-автомейшн 0→100% (или просто кнопки `< >` — сглаживания r5 гасят клики);
  - **морф-свипы**: держите связку A/B и ведите MORPH целевой нотой/фейдером — автоматизация пишется сэмпл-в-сэмпл;
  - **аккорд ↔ арп**: включите **START/STOP** арпа — та же связка звучит пунктиром; выкл — снова аккорды.

### Ручки
- Ручки редактируют **тот слот, к которому ближе морф**: MORPH ≤ 50% → слот A, иначе → слот B. На дисплее — реальные байты этого слота.
- Правьте A с MORPH=0, B с MORPH=100%.
- Изменение слышно сразу (применение ≈1 аудиоблок ≈ 5–10 мс).
- Правки байтов живут до выгрузки плагина; чтобы закрепить — сохраните банк и грузите через **LOAD BANK .syx/.mid**.

### Арпеджиатор
- **START/STOP**, **RATE** (шаги/с), паттерн `UP/DOWN/UP-DN/RND`, **1–4 OCT**.
- Держите аккорд — арп его разбирает; отпустите — арп замолкает.

### Что чинит r5 (звук)
- **DC offset** — DC-блокер ~12 Гц на выходе (как выходной конденсатор в железе): патчи со смещением больше не уводят/не глушат сигнал.
- **Щелчки при морфинге и переключении** — сглажены громкость (6 мс), cutoff/резонанс (4 мс), панорама (1 мс) + 4 мс микро-кроссфейд на смене волны/фильтра/XMOD.
- **«Молчащие» патчи** — NaN/Inf внутри фильтров сбрасываются со стабилизацией: раньше «яд» от одного голоса делал незвукучим весь вывод.
- Ручки перестали сбрасываться (не дёргаются во время вращения, диапазон 0..127).

### Если что-то не так
1. В логе сборки должна быть строка `omega8 build rev r5-20260929` — нет = собраны старые файлы.
2. Пришлите: номер патча (`A:xxx`), что слышно/не слышно (осциллограф/спектр приветствуются), хвост лога.

## r6 — матрица модуляций (extend window)

Кнопка **MATRIX** (рядом с LOAD BANK) открывает нижнее окно в стиле синего
LCD у SE-1X / Omega CODE (скрин `UI/OMEGACODE.jpg`):

- **CONTROLLERS** — матрица источников `modwhl, dynamics, bender, pressure,
  cont1, cont2`: 2 назначения (dropdown 25 позиций) + 2 глубины на строку.
- **LFO1 / LFO2 / ENV3** — по 3 dest-дропдауна на источник (как в оригинале,
  до этого dest были только текстом); у ENV3 ещё 3 глубины (E3 A1..A3),
  у LFO — волна SIN/SQR (W1/W2).
- **XMOD** — назначение FREQ / PW / CUTOFF.
- **ENV DLY / DYN** — задержки о-envelope (DLY1..3, теперь реально работают:
  в движок подключена стадия Delay перед Attack) и dynamics (DYN1..3,
  DYN2 = velocity→VCA работает, 1/3 — байты банка для полноты/морфа).
- **PAN 1–4** — pos / rate / dpth по 4 голосам (это и есть «летающая панорама»:
  движок читает kArrPos/Rate/Depth, раньше ручек не было).
- **Волны OSC1 (tri/saw/pwm)** и **GLIDE** теперь кликабельны как на железе
  (биты WAVE_BITS / GLIDE_FLAGS).

Что НЕ работает намеренно (движок не читает эти байты, показываем только
работающее): unison/voice/prior/vmod/trg, mode/quun, glissando, auto,
OSC2 sync mode, category, win, MASTER TUNE (заглушка).

## r7 — GLOBAL, чёрная тема, LCD BLEND (сверка с мануалом/скринами)

- **Кнопка MATRIX → GLOBAL** — как на железе (Programmer Global switch).
- **Чёрная тема** по скрину `UI/черный омега8.jpg` / `matrix patch blender/7.jpg`:
  панель, ручки, кнопки, LCD (чёрный экран, тёплый белый текст), extend-окно чёрное.
- **LCD в стиле оригинала**: при морфе >0% — `BLEND: A007+B003 … 45%`
  (как `BLEND: D001+D041 15%` на скрине blender), иначе `PATCH A007 B003` + имя.
- **Сверка списков назначений с мануалом omegaCODE (стр.17–18,24) и декодом:**
  CONT_DEST из `work/omega8_map.json` = [OFF, FRE1, FRE2, 1&2F, LEV1, LEV2, PW1,
  PW2, 1&2P, FILT, RESO, LEVN, XMOD, EA1, EA3, EXT, LF1R, LF2R, LF1D, LF2D,
  1&2D, 1&2R, PAND, PANR, PAN] — дословно совпадает с ручным списком
  MODWHEEL/DYNAMICS/PRESSURE и с ENVELOPE 3 (verified: ENV3 dest 16 == LF1R).
  Пары осцилляторов на месте (FRE1/FRE2, LEV1/LEV2, PW1/PW2, 1&2F/1&2P).
  Для LFO мануал additionally упоминает VOL — байтовый код не декодирован,
  пункт не добавлен (не гадаем). XMOD: FREQ/PW/CUTOFF — на скрине "=Vcf" ✓.
- **cont1/cont2 SOURCE-дропдауны** (MODW/TRAK на скрине) НЕ реализованы:
  байты 81–85 имеют conf=0 в карте — без подтверждения не пишем.
- Реализовано только то, что подтверждено мануалом/декодом —
  категории банков (MINI/OBLP/OBBR/OBHP) — это бейджи редактора,
  байтовый код категории у нас не декодирован — не показываем.
