**Метод:** текст-ориентированный эмулятор DSP56300 поверх верифицированного дизассемблера

## 1. ГЛАВНЫЙ РЕЗУЛЬТАТ: рабочий бит-точный эмулятор

`dsp_emu.py` исполняет дизассемблерный листинг как программу. 20/20 юнит-тестов
(`test_dsp_emu.py`). Ядро фильтра `$04A8–$0B4C` исполняется от начала до конца
(4351 шаг на блок 16 сэмплов) с загруженными таблицами из образа P-памяти.
Машины исполняются из диспетчера (GND-SIN проверен, 69 слов за кадр).

### Верифицированная семантика инструкций (закрывает открытый вопрос №1 итерации 11)

| Семантика | Значение | Доказательство |
|---|---|---|
| **MAC/MPY** | произведение 24×24 **сдвигается влево на 1** (дробный режим) | размер таблицы div1: индекс = BASE·1199 при BASE=0.5 → 599 только при `<<1`; иначе таблица задействована наполовину |
| **DIV** | **ОДИН шаг** невосстанавливающего деления: (1) сдвиг D1:D0 влево на 1; (2) знак D1 == знак S → вычитание S, иначе сложение; (3) бит частного (знак нового D1 == знак S) → в младший бит D0. 24 инструкции `div` = полное деление D1/S в формате 24.24: **D1 = частное, D0 = дробная часть** | все 7 мест `div` в ядре (`$0588`, `$0653`, `$067D`, `$0723`, `$0744`, `$07A4`, `$0ADB`) — идиома `move #N,a; andi #$fe,ccr; do #24; div` |
| **8-бит imm → аккумулятор** | значение попадает в **A1/B1** (не в A2): `move #$8,a` = делимое 8 в 24.24 | идиома деления `$079D`: 8/y0 — разумное время задержки только при делимом в D1 |
| **Параллельные переносы** | чтение регистров/памяти ДО ALU-операции (конвейерное сохранение): `mac y0,x0,a a,x:(r1)+` сохраняет ПРЕДЫДУЩЕЕ a | структура FIR-ядра func_000340 |
| **DO** | занимает 2 слова; тело = [pc+2 .. ext_addr] включительно | `do #<$10,>$34f` — тело `$345–$34E`, rts на `$34F` вне тела |
| **ASR/ASL с переносом** | `asr b #$1,a` = B>>=1 на месте + параллельный перенос `#$1→A1`; счётчик-немедленное = класс `0Cxxxx` | декодирование класса 2E (imm в битах 15–8) + контекст |
| **MACSU/MPYSU** | S1 — знаковое, S2 — беззнаковое | интерполяция EQ: `mpysu x1,y0,b` с дробью x1 = a0 (беззнаковое) |
| **L-память** | A→L: A1→X-половина, A0→Y-половина; `ba/ab` = пара аккумуляторов: X→B1, Y→A1 (`ba`) | сохранение/восстановление 48-бит аккумуляторов в ядре |
| **BTST на a/b** | тест бита n в **B1** (главной 24-бит части) | биты MODE (`btst #$b,b`) всегда в B1 |
| **След. адрес** | следующий адрес инструкции = следующий ЛИСТИНГОВАННЫЙ адрес (2-словные инструкции с ext word) | прогон всего ядра |

## 2. Измеренный путь коэффициента (закрывает вопрос №2 итерации 11 частично)

Прогон `$04A8→$05A1` при свипе BASE (эксперимент A, `06_measured/exp_A.json`):

```
Y:$04 = −c1/2 · (1 + 64·t·Δ)          (коэффициент 1-й стадии, знак — соглашение ядра)
c1   = X[$141CA7 + idx],  idx = (BASE·$4AF·2)>>24      # индекс 0..1199
Δ    = div2[WDTH] − div1[BASE]        # $144446[WDTH·$80·2>>24] − $143F95[idx]
t    = a0 после DIV-петли = 2^24 / mean,  mean = (div1+div2)/2   # малая поправка
Y:$05 = t·Δ·64                          # ширино-модулированная пара
Y:$06 = width1[WDTH]  ($1444C6)         # +Δf
Y:$07 = width2[WDTH]  ($144546)         # −Δf
```

Замеры (BASE-свип, WDTH=0): Y04 = −0.500009 (BASE=0) → −0.496491 (64) →
−0.410283 (96) → −0.095743 (112) → +0.238730 (120) → +0.491516 (127).
Y06/Y07 = точно width1/width2[0] = 0.003792/0.003550 ✓ совпадение с таблицами.

## 3. Фейзер: измеренный конвейер фазы (закрывает вопрос №3 итерации 11)

Прогон proc `$144E9A` (эксперименты `06_measured/phaser_lfo_rate.json`,
`06_measured/phaser_states.json`):

| Ячейка (кадр машины r6 = P+$28) | Роль | Измерено |
|---|---|---|
| **X:(r6+$11) + X:(r6+$12)** — 48-бит (X = старшее) | **аккумулятор фазы LFO** | дельта/блок по старшему слову: SPD=1..96 → −1; 112 → −2; 127 → −2.5 (дробная часть накапливается в младшем слове). Фаза считает ВНИЗ. Период LFO при SPD=127 ≈ 2^24/2.5 блоков ≈ 1.2 с |
| **X/Y:(r6+$1D)** — 48-бит | **указатель чтения линии задержки** (CNTR-управляемый) | дельта не зависит от SPD ✓ |
| **Y:(r6+$21)** | счётчик fade-in (wet=0 первые 128 блоков) | инкремент +1/блок до $80 ✓ подтверждено |
| **Y:(r6+$23)** | однополюсное сглаживание DEP | 0xAC → 0x73 за блок ✓ |
| вход | **X:(r0)+** — r0 задаётся ядром перед jsr (указатель буфера входа) | `$144EA8: move x:(r0)+,x1` |
| выход | **y:(r7)+**, r7 = $100 (Y:$100–$11F) | `$144D02/07/08` у машин; GND-SIN пишет туда же |
| шина | машины также пишут **L:$00–$0F** (второй выход, r1=0 у GND-SIN) | `$144CEA: add a,b b,l:(r1)+` |
| линия задержки фейзера | внешняя SRAM **X:$114000 + track·$2000** | сбрасывается в 0 при загрузке |

## 4. Исправления карты страницы голоса (дополнение к 03_voice_page)

- Внутри фильтровой секции r6 = **W − $28** (W = y:$123) — доказано `lua (r6-$28),r6` на `$013D` перед `jmp func_0004a8`.
- Следовательно **TRIG = y:(r6_f+$28) = y:$123+0** — ячейка, обнуляемая на `$0148` (`move x0,y:(r6)`).
- Кадр машины: r6_m = W = P+$28 ⇒ машинные параметры **P+$2C..$33**, состояние машин — **L-пары P+$38..$4E** (напр. фаза GND-SIN = L:(P+$3A/$3C)).
- Выход машины = **Y:$100+** (r7 = $100 устанавливает ядро на `$0102`), вход FX-машин = **X:(r0)+**.
- Параметры страницы — 16-бит значения в старшей половине слова (<<16): `asr #$10` повсеместно.
- Ячейка **y:(r6_f+$FB)** = слово машины, передаваемое в фильтр (последнее слово выходного буфера) — читается на `$056B`.

## 5. Что осталось открытым (для итерации 13)

1. Сквозной звуковой тракт фильтра: коэффициенты дошли до ячеек (свип BASE/WDTH
   работает), но параметр→выход гейтится состоянием, которое пишут машины/секвенсор
   (ячейки слота X:(r6−$21)/−$20, нота, VOL). Нужен запуск с заполненным слотом
   (нота ON) — каркас уже готов (`track_harness.py`).
2. Точная формула масштаба INP/MIX фейзера на выходе (выход 0 при wet-gate —
   вероятна ещё одна ступень нормировки).
3. Бит-точная симуляция MAC-конвейера func_000340/000397 теперь ВОЗМОЖНА на
   эмуляторе — осталось подать сигнал с заполненным слотом и снять импульсный
   отклик (каркас в `measure_fr.py`).
