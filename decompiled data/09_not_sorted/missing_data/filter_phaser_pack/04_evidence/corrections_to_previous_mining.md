- X:$14A000 (sine 8192) и X:$14A800 (cos 8192) — LFO-квадратура, P:$144ED4/$144ED6.
Ссылок на $141900/$141980/$141A00/$141B18/$142F06/$143546 из кода фейзера — НОЛЬ.

Реальные владельцы (все ссылки из ЯДРА, секция энвелопов/фильтра):

## 2. «div_table_1 (107 слов)» — на самом деле 1201 слово

Границы по ссылкам: div_table_1 = $143F95…$144445 (1201 слово), индекс = BASE×$4AF>>24
(0..1199) — P:$0576 `mpyi #>$4af,x0,a; move a,r0` + P:$057D `x:(r0+$143f95)`.
107 непрерывных ненулевых слов v4 — артефакт парсера HI08-потока.
Содержимое: 0.001150 → 0.926179, монотонно, сглаженно — коэффициент среза SVF.

## 3. «FXDYN_attack_table/$1444C6» — это WIDTH-таблицы ФИЛЬТРА

P:$0595–$0597 (ядро, вычисление коэффициента фильтра):
`y0 = x:(r2+$1444c6); y1 = x:(r2+$144546)`, r2 = WIDTH×$80>>24 (0..127).
- $1444C6: +0.003792 → +0.189188 (растёт) — положительная ветка
- $144546: +0.003550 → −0.181846 (падает через 0) — отрицательная ветка
Они дают ±дельту коэффициента от WIDTH (ширина полосы). FX-DYNAMIX использует
СОСЕДНИЕ адреса ($144746+), но имя «FXDYN_attack» для $1444C6 неверно.

## 4. Резонанс фильтра — таблицы найдены (главный запрос итерации)

- HPQ (оффсет страницы $12): P:$08FA `x0 = y:(r6+$12); mpyri #>$80` → индекс HPQ>>1:
  - $1448C6 (128w): 0.500000 → 0.032195 (демпфирование SVF; HPQ=0 → 0.5, HPQ=127 → 0.032)
  - $144946 (128w): 0.007812 → 0.120422 (линейный фидбек-гейн резонанса)
- LPQ (оффсет $13): P:$0985 `a = y:(r6+$13) + $8000; asr #10` → индекс:
  - $144BC9 (128w): 0.003906 → 0.484375 (линейно, шаг 1/256 — фидбек LP-резонанса)
- Гейн-компенсация резонанса считается в ядре P:$0916–$092D (по y0/y1 из $1448C6/$144946,
  возведения в квадрат P:$0F53–$0F58-паттерн, клипы $7FFFA4).

## 5. Хорус-фильтр ($144AC7) — роль уточнена

$144AC7 (258 слов, 0.002211→0.910894) используется:
1) хорус: LP в цепи обратной связи (P:$1477AC–$1477C8, LP>>16 индекс) — как было известно;
2) ЯДРО: DBAS/DWID-тон-фильтр track-delay (P:$0A5F/0A86) и как таблица скорости
   однополюсной рампы BOFS/WOFS-модуляции фильтра (P:$0A5D+).
Это НЕ «фильтр машины» — трековый фильтр строится на SVF-таблицах ($143F95, $144446,
$1444C6/$144546, $141CA7, $142158) + резонансных ($1448C6/$144946/$144BC9). Требование
«фильтр двойной, с энвелоупами, с известным резонансом» закрыто именно ими.

## 6. Состояние 48-битных (X+Y пар) величин — читать как L-память

Паттерн `move x:(r6+$1d),b / move y:(r6+$1d),b0` и `move b,l:(r2)` по всему коду:
48-битные аккумуляторы хранятся парами X-слово + Y-слово по одному адресу.
Фейзер: L:$FF (скретч), l:(r2)=L:$1F (состояние аллпасс-ступени), $25/$26 (LFO-фаза).
Не трактовать X- и Y-половины как независимые переменные.

## 7. «$141A98 big block» — внутренняя структура

$141A98…$1448C5 (11822 слова) — непрерывная зона таблиц, внутри:
- $141A98: таблица 1600 слов для второй SVF-стадии (индекс min(x,$63F)) —
  пары ($141A98+i) и ($142158+i) интерполируются линейно (P:$0629–$0636)
- $141CA7: 1201 слово — коэффициент 2-й стадии от BASE-env (1.0 → −0.977)
- $142158: 1600 слов — партнёр (0.000259 → 0.994163)
- $142F06: 384 слова — EQ/интерп
- $143546: 128, $1435C6: 1600 (EQ-пик/шелф), $143C06: 911 (гейн-рампа)
- $143F95: 1201 (div1), $144446: 128 (div2), $1444C6/$144546: 128+128 (width ±)
- $1448C6/$144946: 128+128 (HPQ), $144AC7: 258 (LP one-pole), $144B48: 128, $144BC9: 128 (LPQ)
Пакет содержит каждую с точными границами + текстовые дампы + анализ формы.
