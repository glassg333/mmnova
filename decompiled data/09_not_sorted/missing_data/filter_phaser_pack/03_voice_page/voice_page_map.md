Метод: дизассемблирование ядра DSP1 (P:$0000–$0B4D) + машин (P:$100000+) с трассировкой
обращений r6 = база страницы голоса (y:$123 = текущая страница, шаг $100 слов на трек;
3 трека на DSP, DSP1 = треки 0–2, DSP2 = треки 3–5).

## ГЛАВНОЕ: структура страницы голоса ($100 слов на трек)

Страницы: трек 0 = Y:$0400, трек 1 = Y:$0500, трек 2 = Y:$0600 (указатель в y:$123,
счётчик трека в y:$124 — доказано кодом P:$000163–$00016C: `y:$123 += $100; y:$124 += 1`,
и P:$000100–$000106: `r1 = y:$124; r0 = y:(r1+$120)`).

ПРЕДЫДУЩАЯ КАРТА ИЗ ДОКУМЕНТАЦИИ (Y:$0500 = SYNTH_A, Y:$0508 = AMP_ATK, ...) БЫЛА ВЕРНА
ТОЛЬКО ДЛЯ ТРЕКА 1 И ТОЛЬКО КАК АБСОЛЮТНЫЕ АДРЕСА. Реальная семантика — ОФСЕТЫ от базы
страницы, и она другая:

| Оффсет | Параметр | Доказательство (P-адрес инструкции) |
|--------|----------|-------------------------------------|
| $00 | AMP ATK (attack) | P:$08A0: `a = y:(r6+$0); asr #10; r4 = a` → индекс таблицы атаки $141800 |
| $01 | AMP HOLD | P:$08B0: стадия 1 энвелопа читает y:(r6+$1), зажим `cmp #>$10000` |
| $02 | AMP DEC (decay) | P:$08C6: стадия 2 читает y:(r6+$2) → индекс таблицы затухания $141880 |
| $03 | AMP REL (release) | P:$08CA: стадия 3 читает y:(r6+$3); при стадии 4 константа $20 |
| $04 | машинный параметр 0 | фейзер: P:$144EFA `y:(r6+$4)` = CNTR; хорус: DEL |
| $05 | машинный параметр 1 | фейзер: P:$144F0C `y:(r6+$5)` = DEP |
| $06 | машинный параметр 2 | фейзер: P:$144EB4/145057 `y:(r6+$6)` = SPD |
| $07 | машинный параметр 3 | фейзер: P:$145027 `y:(r6+$7)` = MIX (та же формула, что у хоруса $1477CF) |
| $08 | машинный параметр 4 | фейзер: P:$144FBE `y:(r6+$8)` = FB |
| $09 | машинный параметр 5 | фейзер: P:$144EC9 `y:(r6+$9)` = WID |
| $0A | машинный параметр 6 | (у большинства машин "---") |
| $0B | машинный параметр 7 | фейзер: P:$144EA6 `y:(r6+$b)` = INP (входит как INP²·4) |
| $0C | AMP DIST (distortion) | P:$097C: `x:(r6-$1c)` после `lua (r6+$28),r6` = оффсет $C → диспетч дисторшна `jmp (r0)` |
| $0D | AMP VOL | (чтения в секции гейна P:$0807+) |
| $0E | AMP PAN | P:$053E: `y:(r6+$e) + $C00000` → панорамные гейны (±0.75 поворот) |
| $0F (X!) | стерео-флаг | P:$05A9/05E8/08FD: `x:(r6+$f)`, бит 0 = канал моно (пропуск 2-го канала) |
| $10 | FILT BASE | P:$056D: `b = y:(r6+$10)` → вход вычисления коэффициента среза (таблица $143F95) |
| $11 | FILT WDTH | P:$0578: `y0 = y:(r6+$11); ×$80` → индекс таблиц $144446/$1444C6/$144546 |
| $12 | FILT HPQ | P:$08FA: `x0 = y:(r6+$12); ×$80` → индекс (HPQ>>1) таблиц резонанса $1448C6/$144946 |
| $13 | FILT LPQ | P:$0985: `a = y:(r6+$13) + $8000; asr #10` → индекс таблицы $144BC9 (LP-резонанс) |
| $14 | DELAY-MOD DEPTH (глубина, биполярная) | **ИТЕРАЦИЯ 15: переатрибутировано!** P:$0A22 (знак → выбор банка), P:$0AB7–$0ABE: (P+$14−$400000)² — глубина² delay-модуляции. НЕ фильтровый env (доказано бит-точно, 08_env_verdict/) |
| $15 | DELAY-MOD FB (обратная связь интегратора) | **ИТЕРАЦИЯ 15** P:$0ABF; KILL-гейт P:$0AC0–$0AC4: при фазе AMP-env == 4 (X:P+$D8) → 0. НЕ фильтровый env |
| $16 | DELAY RAMP RATE 1 | **ИТЕРАЦИЯ 15** P:$0A5D–$0A63: скорость однополюсной рампы 1 ($144AC7), стейт P+$D4, цель = аудио-шина. НЕ фильтровый env |
| $17 | DELAY RAMP RATE 2 | **ИТЕРАЦИЯ 15** P:$0A84–$0A92: скорость рампы 2 = (P+$17+P+$16)>>16, стейт P+$D5, кривая $144B48. НЕ фильтровый env |
| $18–$1F | EFFX: EQF EQG SRR DTIM DSND DFB DBAS DWID | EQ-секция P:$0789–$0859; delay-секция P:$0939+ |
| $23 | TEMPO (хост) | P:$08B4 (HOLD×TEMPO), P:$0994 (DTIM×TEMPO×$791FD0) |
| $28 | TRIG_EVENT (0=idle,1=note on,2=note off,3=kill) | P:$088E–$089C энвелопа; подтверждает карту v10 (+0x28) |

ВНИМАНИЕ: для FX-машин (хорус/фейзер/фленджер/реверб) оффсеты $10–$26 используются как
СОБСТВЕННЫЕ ячейки состояния (инициализируются в init-рутинах): напр. фейзер:
$10 = база delay-буфера, $11/$12 = 48-бит фаза/состояние, $1D = 48-бит указатель чтения,
$20/$21 = fade-in счётчик, $22 = сглаженный DEP, $24 = сглаженный WID, $25/$26 = 48-бит LFO-фаза.
Поэтому нельзя читать оффсеты $10+ у FX-машин как «параметры фильтра».

## Состояние (та же страница, старшие оффсеты)

- X-страница (x:(r6+..)): стерео-флаг $F, состояния машин, состояния каскадов фильтра
  (P:$05C5–$05CD копируют 3 L-слова из страница+$C4–$C6 в Y:$91/Y:$D1 скретч перед SVF).
- Y-страница: энвелоп-фазы в страница+$BF–$C0 (r7−$23/−$22 при r7 = r6+$E2),
  резонансные состояния L:$80–$8A (X+Y пары, P:$0927–$092D), коэфф. рампы L:$90–$A0.

| $05A2–$06C0 | СВФ-каскад 1: 2× oversample halfband (константы $F528BD/$4A4DF0) + process |

| $0789–$0859 | 1-полосный EQ (таблицы $143546/$1435C6) |

## ИТЕРАЦИЯ 13 — ИСПРАВЛЕНИЯ (бит-точная эмуляция, 06_amp_env/)

1. **r6 варьирует по секциям!** Вход трека и машинный вызов: r6 = y:$123 = P+$28
   (машина читает свои параметры/состояние как r6+$04..$26 → P+$2C..$4E);
   после `lua (r6-$28),r6` (P:$013D) весь фильтровый конвейер $04A8–$0B4C идёт
   с r6 = P. Таблица выше смешивала обе базы: «машинные параметры $04–$0B» —
   это оффсеты МАШИННОГО r6 (= P+$2C..$33), а не страницы.
2. **AMP-энвелоп**: уровень = `Y[P+$D7]`, фаза = `X[P+$D8]`, счётчик HOLD =
   `Y[P+$D8]` (r7 = P+$FA в $088E–$08D7; старая карта считала r7 = P+$E2 →
   ошибочные $BF/$C0). Полная реконструкция — 06_amp_env/.
3. **AMP-страница идёт последовательно**: $00 ATK, $01 HOLD, $02 DEC, $03 REL,
   $04 DIST, $05 VOL, $06 PAN, $07 PORT.
   - VOL = **$05** — доказано гейн-путём: `gain ∝ level·VOL²` (P:$08DF–$08E4,
     чтение y:(r6+$5) при r6 = P).
   - PAN-угол = **$06** → индекс sin/cos $14A000/$14A800 (P:$08DB–$08EB).
   - DIST = **$04** (порядок страницы AMP); ЧТЕНИЕ `y:(r6+$c)` в P:$0509 —
     это отдельная теневая ячейка P+$0C (драйв-энвелоп: атака через $141800);
     диспетч рутины дисторшна — УКАЗАТЕЛЬ в `X[P+$0C]`, 0 = выкл (P:$097B–$0980,
     `tst a; beq; move a,r0; jmp (r0)` — прыжок по значению ячейки!).
4. **Ячейка $0D** (чтение P:$052B, таблица $141A00) — скорость спада драйва;
   НЕ VOL. **$0E/$0F** — балансные гейны (P:$053E: ±0.75 узел); X[P+$0F] бит0 =
   моно-флаг (подтверждено).
5. **EQ-секция** P:$0789–$0859 читает `y:(r6+$4)` (EQF-путь? — совпадает с DIST
   страницы AMP: секция = дисторшн/EQ-гибрид, уточнение — итерация 14) и
   `x:(r6+$b)` (EQG-raw, делитель). Строку «$18–$1F EFFX» считать НЕ подтверждённой
   для EQ; доказанные чтения $18–$1F: только DBAS $1F (P:$0B1E) в delay-секции.
6. **Мастер-выход** фрейма: 16 L-слов на `y:(r6)+` при r6=0 → Y:$0000–$001F
   (P:$0B41–$0B49), + X-сторона через r1/r3 (OS-буферы, указатели x:$FF/x:$2C9 —
   в эмуляторе пиновать, иначе ходят в страницу!). Мастер-вход = L:$10–$1F.
7. **Шина машин** L:$0000–$000F = межмашинный маршрут (пишет машина, читает
   вход следующей), выход машины на фильтр = **Y:$100–$121** (копируется на
   X:$97–$A1/X:$D7–$E1 стадией P:$04F5, r7 сбрасывается в $100 на P:$013E).
   ВНИМАНИЕ: X:$100–$121 = ячейки состояний SVF-каскада — НЕ трогать!
