# Трековый фильтр Monomachine — реконструкция алгоритма по машинному коду DSP56300

OS 1.32B, ядро DSP1. Все адреса — P-память программы, если не указано иное.
Модель: **двойной резонансный фильтр** = каскад 1 (нерезонансная пара HP→LP, 2×oversample)
+ каскад 2 (резонансный SVF с раздельными HPQ/LPQ), с **собственным энвелопом** (ATK/DEC/
BOFS/WOFS) и **известным резонансом** (таблицы HPQ/LPQ извлечены).

```
   BASE, WDTH, HPQ, LPQ, ATK, DEC, BOFS, WOFS  (страница голоса $10–$17)
        │
        ▼
[1] ЭНВЕЛОП ФИЛЬТРА (P:$0960–$0B49, значения прошлого блока входят в [2])
        env BASE±(ATK/DEC-рампа · BOFS), env WDTH±(··· · WOFS)
        рампы скорости — однополюсные через таблицу $144AC7 (258 слов)
        + амплитудная кривая env через $144B48 (128 слов)
        bipolar: BOFS−$400000 → знак (P:$0AB7: sub #>$400000; abs; asl)
        «Decatime»-защита: при малом DEC Y-гейн гасится (P:$0AC0–$0AC4)
        ▼
[2] КАСКАД 1: вычисление коэффициентов (P:$0537–$05A1)
        idx = (BASE_env) · $4AF >> 24            (P:$0576, 0..1199)
        widx = WDTH_env · $80 >> 24              (P:$057A, 0..127)
        c1 = div1[BASE][idx]                     $143F95, 1201 слов (0.00115→0.926)
        c2 = div2[WDTH][widx]                    $144446, 128 слов (0.033→1.0)

        (линейная интерполяция между div1[BASE] и div2[WDTH] —

          обрабатывает 8-словные подблоки двумя фазами (P:$05D8 / P:$05EF — L/R)

        HPQ → damping = tblHPQ[HPQ>>1]           $1448C6: 0.500→0.0322
        HPQ → fbGain  = tblHPQ2[HPQ>>1]          $144946: 0.0078→0.1204
        LPQ → fbGainLP = tblLPQ[LPQ]             $144BC9: 0.0039→0.4844

          (коэфф. и состояния в L:$80–$8A — 48-бит X+Y пары),
          вход сглаживается однополюсно (macr-паттерн P:$039A–$03A6)
```

## Энвелопы: AMP (общий) и FILTER (собственный)

### Стейт-машина AMP-энвелопа (P:$088E–$08D7) — эталон логики
```
триг: TRIG_EVENT = 1 → стадия 0 (ATK); 2 → 3 (REL); 3 → 4 (fast REL, константа $20)
стадия 0 ATK:  phase += env_shape_A[ATK]        ($141800, ATK>>10; ATK=0 → шаг 0.5/блок)
               конец таблицы (флаг EC) → стадия 1
стадия 1 HOLD: phase += 1; если phase > HOLD·TEMPO·$791FD0·2 → стадия 2   (P:$08B4–$08C1)
стадия 2 DEC:  acc = −acc · env_shape_B[DEC]    ($141880; |множитель| 0.8977→0.99997)
стадия 3/4 REL: acc = −acc · env_shape_B[REL];  стадия 4: индекс = $20 (фикс. быстрый)
```

### FILTER-энвелоп (P:$0960–$0B49) — механизм модуляции среза
- Глубины BOFS/WOFS ($16/$17) bipolar: вычитается $400000 (=0.5), знак → направление
  модуляции (P:$0A22–$0A28: `sub #>$400000,a; bmi …`, выбор r0/r1-банков $40/$62).
- Скорость рампы: однополюсная рекурсия x[n] = x[n]−tbl[i]·(x[n]−target), tbl = $144AC7
  (индекс = BOFS/2 → i = (BOFS>>16)·2, P:$0A5D–$0A63), 16 сэмплов на блок (do #10×2).
- Смешение в коэффициент: ramp_state·env_value·кривая $144B48 (P:$0AA9: `x:(r2+$144b48)`,
  r2 = (state>>11)&$3FFF) → модифицирует срез каскада 1 в СЛЕДУЮЩЕМ блоке (значение
  переносится через x:(r7−$3) / страница+$D9, P:$0552→$056B).
- DEC ($15) управляет спадом env-фазы (P:$0ABF), «decatime»-гейт P:$0AC0–$0AC4.

## Формулы для порта (проверяемые)

```cpp
// срез каскада 1 (на блок, до процесса):
int   idx  = (int)(baseEnv * 1199.0 / 2147483648.0);   // baseEnv = 24-bit слово
float frac = baseEnv * 1199.0 / 2147483648.0 - idx;
float c1   = div1[idx] + (div1[idx+1] - div1[idx]) * frac;   // линейная интерполяция
int   widx = widthEnv * 127.0 / 2147483648.0;
float c2   = div2[widx];
float f    = 0.5f * (c1 + c2);                                // P:$0583: (div1+div2)/2
float df   = c2 - c1;
f += (float)(frac * df * 64.0 / 8388608.0);                   // P:$058E–$0591
f -= width1[widx] * (1.0f + f);                               // P:$0592–$0593: a = −w1·(x+1)
// резонанс каскада 2:
float dampHP = hpqTbl [hpq >> 1];      // 0.5 … 0.032
float fbHP   = hpq2Tbl[hpq >> 1];      // 0.0078 … 0.1204
float fbLP   = lpqTbl [lpq];           // 0.0039 … 0.4844
// halfband FIR (2× oversample):
constexpr float HB[4] = { -0.08623f, 0.58066f, 0.58066f, -0.08623f }; // $F528BD/$4A4DF0
```

## Что доказано инструкциями, а что — реконструкция с высокой уверенностью

ДОКАЗАНО (адреса в тексте): структура двойного каскада; все параметр-пути $10–$17;
все формулы индексации; halfband-константы и их FIR-структура; резонансные таблицы и
их индексация; стейт-машина энвелопов; панорамный узел ±0.75; INP²-масштабы (FX).

РЕКОНСТРУКЦИЯ (высокая уверенность, но помечено): точная рекурсия SVF-ядра func_000340
по MAC-конвейеру (соответствует Chamberlin SVF: `LP += f·BP; BP += f·LP − damp·BP`,
демпфер = $1448C6-таблица) и точный порядок halfband-фаз; масштаб 2×oversample.

ПРОВЕРКА: прогон div1 через sin-подгонку даёт f ≈ 2·sin(π·fc/fs) с fc ≈ 15 Гц…18 кГц —
согласуется с ручкой BASE 0–127; сумма halfband-тапов 0.9889 (−0.097 дБ), ноль на
Найквисте — признак корректного дециматора.
