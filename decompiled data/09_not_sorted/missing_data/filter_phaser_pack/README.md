## НОВОЕ В ИТЕРАЦИИ 14 (см. 01_filter/svf_recursion_proven.md и 07_svf_fit/)

1. ✅ **Ф1 ЗАКРЫТ — точные рекурсии обоих ядер доказаны бит-в-бит**:
   - `func_000397` — это НЕ классический SVF, а **сканер 8 дробных тапов задержки**
     (резонанс = гребёнка тапов!): `out = x_mid·(1+y0) − y0·x_prev + округление`;
     тапы = пары (позиция, дробь) L:$80–$90, кольцевой буфер через заворот
     24-битного адреса. Доказательство: 8/8 вызовов бит-точны.
   - `func_000340` — гибрид симметричного FIR + SVF-обратной связи; коэффициенты
     ходят по **модуль-4 кольцу** (M4=$000003, Y:$04–$07); B-состояние =
     `(x1·y0 + y1·a_prev) << 2`. Доказательство: 0 расхождений по инструкциям
     и памяти за 2 кадра.
2. ✅ **Критический фикс эмулятора**: `move a1/b1,aN-подрегистры → rN/x0/y:(rN)+`
   дважды извлекали часть аккумулятора (писали 0 вместо A1/B1). Все прогонные
   инструменты пересмотрены; 27/27 юнит-тестов.
3. ✅ Обнаружено: GND-SIN синтезируется самим ядром ($08D8–$08F9, шаг осциллятора
   = param1²) — объясняет «тишину» ранних прогонов и даёт живой тест-сигнал
   (svf_live.py).
4. Фильтр ≈97%: остались Ф2 (масштаб env→срез) и Ф3 (роли EQ-таблиц) —
   04_evidence/what_is_missing_for_full_port.md.

## ЧТО ЗАКРЫТО (главные запросы)

1. **ФИЛЬТР — двойной, с энвелоупами, с известным резонансом.**
   - Двойной = каскад 1 (пара HP→LP, 2×oversample, halfband-константы из кода
     `$F528BD/$4A4DF0`) + каскад 2 (резонансный SVF, func_000397, per-sample рампы).
   - Энвелоупы: полная стейт-машина AMP (P:$088E, ATK/HOLD/DEC/REL, таблицы $141800/$141880)
     и собственный FILTER-энвелоп (BOFS/WOFS-рампы через таблицу $144AC7, кривая $144B48,
     bipolar-глубины $14–$17).
   - Резонанс ИЗВЛЕЧЁН: HPQ → `$1448C6` (демпфирование 0.500→0.0322) + `$144946`
     (фидбек 0.0078→0.1204); LPQ → `$144BC9` (0.0039→0.4844, шаг 1/256).
   - Срез: BASE → `$143F95` (1201 слово! не 107, как считали в v4), WIDTH → `$144446`
     + width-пары `$1444C6`/`$144546`; вторая стадия → `$141CA7`/`$142158`.
2. **ФЕЙЗЕР.** Полный дизассембл машины (437 слов) + реконструкция: модулируемая
   линия задержки (кольца $1000 слов ×2 канала), 2 аллпасс-ступени, кубическое ядро
   (веса −1/6, −1/3, +1, +1/6), квадратурный LFO из 8K sin/cos-таблиц, все константы
   ($9566, $28F5C, $FFFC03, $410410, $7EB852, $5A8241, $7FFFA4…), формулы MIX
   (dry·(1−MIX)+wet·MIX — та же, что у хоруса) и fade-in 128 блоков.

## Как использовать

1. **БЫСТРЫЙ ПУТЬ (JUCE):** взять `09_juce_port/` — готовые заголовки + скелет
   плагина + тесты; README_JUCE.md — пошаговая интеграция.
2. Взять `.bin` таблиц из `01_filter/tables/` (3 байта/слово, big-endian, signed 24-bit
   fraction = word/2^23). `.txt`-дампы — для сверки глазами.
3. Собрать порт по `monomachine_track_filter.hpp` / `monomachine_phaser.hpp`:
   пути параметров, индексации и константы верифицированы; помечено TODO-SIM там, где
   нужна побитовая симуляция MAC-конвейера (см. разделы «Что доказано / что реконструировано»).
4. Сверять с листингами в `01_filter/disasm_*` и `02_phaser/disasm_*` — каждый шаг
   реконструкции снабжён P-адресом инструкции.
