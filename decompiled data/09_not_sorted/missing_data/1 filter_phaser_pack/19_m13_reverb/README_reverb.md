# m13 FX-REVERB — полный структурный разбор (итерация 26)

**Дата:** 2026-09-23. Метод: дизасм `code_full.asm` ($14538E–$14561B) + бит-точный
прогон PROC на эмуляторе (`exp26_m13_reverb.py`, здесь же).

## 1. Идентификация и границы

| Элемент | Адрес |
|---|---|
| INIT (при смене машины) | `$14538E` – `$1453DA` (`rts $1453DB`) |
| CONF | `$1453DB` = `rts` (пустой) |
| PROC | `$1453DC` – `$14561A` (`rts $14561B`) |
| Таблица аллпасс-коэффициентов и модулей | P:`$14561C` – `$14562B` (16 слов) |
| Таблица выходных коэффициентов MIXER (по DEC) | P:`$14562C` – `$1457AB` (128×3 слова, шаг индекса 2) |
| «Тихая» запись DAMP-таблицы (fade-in не закончился) | P:`$1457AC` – `$1457B1` (нули) |
| DAMP-таблица (коэффициенты демпфирования) | P:`$1457B2` – … (записи по 3 слова, шаг индекса 2) |

Вызов машины: `jsr (r2)` c r6 = страница машины = P+$28 (как у m18).

## 2. Параметры (дескриптор OS `FX-REVERB`, coldfire_main.bin 0x588b5)

Дескриптор: `DEC DAMP GATE MIX HP LP --- INP`, дефолты
`40 02 7f 20 00 7f 00 40` (hex). Ячейки страницы: r6+$4..$B = P+$2C..$33.

| Ручка | Ячейка | Куда попадает в DSP |
|---|---|---|
| DEC | r6+$4 | (а) коэффициент аллпасс-лестницы g = map(DEC); (б) индекс записи таблицы выходных коэффициентов $14562C (шаг 2) |
| DAMP | r6+$5 | индекс записи DAMP-таблицы $1457B2 (шаг 2) → коэффициенты one-pole гребёнок 1–4 |
| GATE | r6+$6 | скорость гейта: `rate = max($F4240, (GATE<<16)² >> 11)` при `(GATE<<16)²>>11 > $FA0`, иначе $F4240 (1e6) |
| MIX | r6+$7 | выходной микш: `out = 2·(MIX·wet + (1−MIX)·INP²·dry)` |
| HP | r6+$8 | индекс в таблицу $144AC7 (та же LP-рампа фильтра!) → 2-полюсный HP на wet |
| LP | r6+$9 | индекс в таблицу $144AC7 → 2-полюсный LP на wet |
| — | r6+$A | не читается |
| INP | r6+$B | входной гейн: банк входа масштабируется на INP², dry-путь тоже INP² |

## 3. INIT — карта банков задержки

База банков: `x0 = $114000 + track·$2000` (тот же трек-банк, что у m18/хоруса).
INIT пишет 17 указателей в ячейки страницы и обнуляет стейты:

**p5 = r6+$33..$38 — указатели ЧТЕНИЯ (старейшие слова колец):**
`base+$0000, +$1000, +$2000, +$2800, +$3000, +$C00`

**p4 = r6+$39..$3E — указатели ЗАПИСИ (новейшие):**
`base+$0A67, +$198F, +$2713, +$2E55, +$3577, +$0E65`

→ **6 гребёнок, задержки = запись−чтение:**

| # | задержка, слов | мс @44.1k | кольцо (m1 из таблицы $145621+) |
|---|---|---|---|
| 1 | $A67 = 2663 | 60.4 | $A76 |
| 2 | $98F = 2447 | 55.5 | $99E |
| 3 | $713 = 1811 | 41.1 | $722 |
| 4 | $655 = 1621 | 36.8 | $664 |
| 5 | $577 = 1399 | 31.7 | $7FF |
| 6 | $265 = 613 | 13.9 | $3FF |

(кольца 5–6 намеренно больше задержки — в них живёт LFO-модуляция чтения).

**p7 = r6+$3F..$43 — указатели 5 аллпассов:** `base+$19C0, +$1A00, +$1A80, +$1B00, +$1C00`.

Прочее INIT: `y:(r6+$25) = $F4240` (1e6, база скорости гейта),
`y:(r6+$32) = $14A000` (указатель sin-таблицы LFO), стейты r6+$20/$26-$2B/$47/$48 = 0.

## 4. Таблица $14561C — аллпассы и модули колец

Слова 0–4 — коэффициенты 5 аллпассов (знакочередующаяся лестница):
`−0.96308, +0.94779, −0.92235, +0.88759, −0.83655`
Слова 5–9 — модули (размер кольца −1) аллпассов: `$2E, $42, $64, $94, $DE`
(47/67/101/149/223 слов → задержки ≈ 46/66/100/148/222 слов = 1.04/1.50/2.27/3.36/5.03 мс).
Слова 10–15 — модули колец 1–6 (`$A76 $99E $722 $664 $7FF $3FF` — совпадают
с немедленными значениями в PROC ✓).

Коэффициент аллпасса, реально входящий в лестницу: **x1 = g·fade·coef[k]**,
где `g = b1( (DEC<<16)·$66666·2 + $59999A )` ≈ 0.25 при DEC=64 (растёт с DEC),
`fade` — гейн fade-in.

## 5. Таблицы DAMP и DEC

**DAMP ($1457B2, запись = 3 слова, индекс = DAMP>>1):** коэффициенты
one-pole сглаживания гребёнок 1–4 (чем больше DAMP, тем сильнее демпфирование):

| DAMP | c1 | c2 | c3 |
|---|---|---|---|
| 0 | 0.999683 | 0.999708 | 0.999784 |
| 4 | 0.935295 | 0.940384 | 0.955528 |
| 8 | 0.875053 | 0.884578 | 0.913229 |

Квод: секция k читает слово 3·idx+k, поэтому 4-я секция берёт первое слово
СЛЕДУЮЩЕЙ записи (квирк индексации, задокументирован).

**DEC ($14562C, запись = 3 слова, индекс = DEC>>1):** коэффициенты выходного
микшера (компенсация wet-гейна при росте decay): rec0 = 0.2492/0.2712/0.3479,
rec63 = 0.5769/0.5937/0.6556. Микшер читает слова [0],[1],[2],[3],[5] от базы
записи (4 слота X:$20-$23 с m3=4, поэтому фактически используются [0],[5],[3],[1]).

## 6. Структура PROC (блок = 16 сэмплов)

1. **Fade-in (256 блоков):** счётчик r6+$48++; пока < $100 выходной гейн
   fade = 0, потом 1.0. При отсутствии fade DAMP-указатель = $1457AC (нули).
2. **Вход:** 16+ слов c шины (r0), гейн INP², с промежуточными `asl` —
   результат в Y:$00–$0F (внутренний Y-банк).
3. **Гребёнки 1–4** (`m1 = $A76/$99E/$722/$664`, чтение от p5 вперёд,
   2 чтения на сэмпл): one-pole `a += c·(ring − a)` по очередным словам кольца,
   c = DAMP-коэффициент; стейты a/a0 в r6+$26..$29 / r6+$2C..$2F; выход —
   банки Y:$20–$2F / $30–$3F / $40–$4F / $50–$5F.
4. **Гребёнки 5–6** (`m1 = $7FF/$3FF`): то же + **LFO-модуляция позиции
   чтения**: фаза = адрес в sin-таблице ($14A000, кольцо m4=$1FFF, шаг +16
   слов/блок → период 512 блока = 8192 сэмпла = **5.38 Гц**); `n1 = sin>>21`
   (±3 слова сдвиг тапа), дробная часть → два коэффициента
   `c·(1−frac)`, `c·frac` (m3=1, X:$00/$01) → интерполяция чтения.
5. **5 аллпассов:** цепочка через Y:$00–$0F in-place (стадия k читает то, что
   написала стадия k−1; вход цепочки — входной банк из п.2). Коэффициент
   стадии = g·fade·coef[k]; запись в кольца x:(r1)+ (p7), модули из $145621+.
6. **Микшер гребёнок:** сумма 6 банков Y:$20–$7F с циклическими коэффициентами
   X:$20–$23 (таблица DEC, m3=4), `asl` ×2 → wet в X:$00–$1F (2 канала).
7. **Гейт:** пик-детектор `maxm a,b` (утечка 0.9993/сэмпл, y0 = $7FEF9E) минус
   порог r6+$1F; гейт-гейн: рампа вверх `+$147AE/сэмпл` или вниз `×$7EB852
   (0.9885)/сэмпл` (rep #10), применяется к wet (X:$00-$0F ← X·Y-гейн).
8. **HP/LP:** 2-полюсные секции (стейты r6+$18–$1D / $14–$17), коэффициенты
   из таблицы $144AC7 по индексам HP/LP — та же таблица, что у тона-фильтра
   голоса (итог итерации 1!). Порядок: HP → LP, стерео (a/b = L/R).
9. **Выход:** `out[k] = 2·(MIX·wet[k] + (1−MIX)·INP²·dry[k])` → Y:$100+ (16 слов).

## 7. Эмулятор: правки и измерения

- В `dsp_emu.py` реализованы **REP** (исполнение следующей инструкции N раз;
  семантика N-исполнений подтверждена INIT: `rep #6` чистит ровно 6 ячеек
  $26–$2B) и **MAX/MAXM** (знаковый максимум: s>d → d←s, иначе s←d). Регрессия
  27/27 зелёная.
- `exp26_m13_reverb.py`: INIT бит-в-бит пишет все 17 указателей (см. JSON
  `init_pointers`: $1159C0/$115A00/… = base+$19C0+…); dry-путь точен
  (импульс 0.5, MIX=32 → 0.375).
- Замеры: первое эхо появляется на блоке 41 (короткая гребёнка, 613 слов =
  38.3 блока + FIR/аллпасс ✓ совпадает с картой задержек).

## 8. Открытый вопрос (приоритет итерации 27)

**Wet-путь в харнесе расходится:** на блоке 41 (первое возвращение эха) выход
резко уходит в полный масштаб (RMS по сырым словам 2.4–3.4e7 = все 16 сэмплов
у упоров), затем затухает в ноль к блоку ~82. Статический разбор стабилен
(все коэффициенты < 1), поэтому наиболее вероятная причина — параллел-мув баг
эмулятора на одной из форм, специфичных для m13 (класс ошибки итерации 25:
неверная часть аккумулятора/порядок защёлки в `mac … a,y:(r4)` /
`mac x1,x0,a x:(r1)+,x1`). План: снять сетку A/B против пост-инструкционных
снапшотов (методика 18_m18_final), найти инструкцию, починить, снять ИР и
хвосты по DEC/DAMP бит-точно.

## 9. Ответы на вопросы сессии

- **«к ревербу»** — сделано: топология = 6 гребёнок (13.9–60.4 мс) + 5

  таблице фильтра + микш; все таблицы извлечены, все ручки DEC/DAMP/GATE/
  MIX/HP/LP/INP разведены по ячейкам и функциям.
- Остаток до 100% формально — бит-точная верификация wet-пути (см. §8).
