## ГЛАВНАЯ ПОПРАВКА (аннулирует часть итераций 18–20)

Секция ядра $064E–$0859 («F3»: кривые $143C06/$1447C6, мастер-таблица $143546/$1435C6,
тон-лерп $141A98/$142158/$142F06) **НЕ читает ручку DIST**. Замер эмулятором: в момент
чтений $065A/$0685/$07A6/$079F/$06C2 регистр **r6 = $400 = база страницы голоса**,
т.е. секция читает `y:(r6+$4)` = **МАШИННЫЙ ПАРАМЕТР 0** (1-я ручка машины), а
`x:(r6+$b)` = X-сторона слота $0B (машинный стейт), `x:(r6+$f)` = стерео-флаг.
Именование «DIST-кривая» в F3_table_readers.md (итер. 18–20) и в ответе итерации 20
было ошибочным — см. раздел «Кому на самом деле принадлежат кривые».

Настоящий DIST = слот **x:(page+$0C)** (X-сторона!), UI AMP-страница ручка 5 = CC 60
(страница UI ≠ порядок слотов памяти; карта слотов — 03_voice_page/voice_page_map.md:
$00–$03 env, $04–$0B машинные параметры 0–7, $0C DIST, $0D VOL, $0E PAN).

## Доказанный механизм DIST (всё в листинге)

1. **Инициализация**: ядро $0000C9–$0000DB (старт, r6 = y:$123 = база страницы):
   `move #$0,x0; move x0,x:(r6-$1c)` → DIST-слот = 0 («нет обработчика»).
2. **Диспетч**: $097B–$0980, ПОСЛЕ секции резонанса ($0904–$0910) и ДО стадии-2
   ($0A5D–$0B4C):
   ```
   097B: lua (r6+$28),r6        ; r6 = page+$28
   097C: move x:(r6-$1c),a      ; a = x:(page+$0C) = DIST-слот
   097D: tst a
   097E: beq $0981              ; DIST=0 → чистый путь
   097F: move a,r0
   0980: jmp  (r0)              ; DIST≠0 → ПРЫЖОК НА АДРЕС ОБРАБОТЧИКА В СЛОТЕ
   ```
   Слот хранит **24-битный P-адрес обработчика** (не значение ручки!) — адрес
   ставит хост (ColdFire) при назначении машины/патча. Позиция в тракте:
   **после фильтра/резонанса, до стадии-2**; кадр уже стадии-2:
   $0982–$0984: `n6=$15C; lua (r6)+n6,r7` → r7 = page+$15C ($55C для page $400).
3. **Эпилог**: обработчик обязан завершиться `jmp $000981` (`lua (r6-$28),r6` —
   восстановление r6). Поиск по всему дизасму даёт РОВНО ОДИН такой переход в
   машинной области: **$145CCD**.
4. **Найденный обработчик** [$145C48–$145CCE] (SWAVE-семейство):
   - prologue: рампа-ограничитель y:(r6+$34) — fade-in 64 блоков (анти-щелчок),
     стейты y:$32/$33 = f(param5 y:(r6+$9)·$066666 + param6·$79999A);
   - тело: 8+8-членная взвешенная mac-структура (DO $8, вес $40) над шинами
     X:$00–$0F / X:$10–$1F, глобальная y:$C4, банки X:$30–$3F/$80–$90;
   - хвост: `jmp $000981`.
5. **Вторичное использование слота**: код области m10/m11 ($146A1B–$146A30)
   работает с (x:$C, y:$C) как с 48-битной L-парой (normf/div + func_0003e0) и
   рядом читает VOL y:(r6+$d) (закон add #$10 / cmp #$98). Инициализация-очистка
   машин (напр. $1464FC–$146501) пишет 0 в обе стороны.

## Что известно о секции амплитуды в итоге

- **DIST = хук «вставь свой обработчик после фильтра»**: сама ручка (CC 60) живёт
  у хоста; в DSP-слот попадает адрес per-machine/per-алгоритм обработчика. Значит
  «дисторшн» на Monomachine — это не одна кривая, а **семейство машинных
  обработчиков** в области $144000+, вызываемых диспатчем. Найден один полный
  (SWAVE-семейство, $145C48); остальные — та же схема (поиск `jmp $000981` /
  аналогичных эпилогов).
- Для порта: emulate = «если слот≠0 → вызвать обработчик между резонансом и
  стадией-2», для чистого синтеза без DIST слот = 0 и тракт линейный.

## Кому на самом деле принадлежат кривые из F3 (поправка)

- $143C06 (экспонента ×1.081/шаг, +0.677 дБ/шаг) и $1447C6 (спад к √2/4 с
  масштабом p0²·0.98316+0.01574) индексируются **машинным параметром 0**
  (`y:(r6+$4)`, индекс = 2·knob, чётные входы 256-словных интерливнутых пар).
- Мастер-таблица **$143546..$143C05 = 1728 слов**, `$1435C6 = $143546 + $80`
  (вторая база). Читатели: ядро $07D9 (индекс y:$4DA) и $0860 (индекс x:$4D9,
  потребление (1.0 − tbl)·½), машины **m4 SWAVE-SAW ($145A52), m5 SWAVE-PULS
  ($147347), m14 SWAVE-ENS ($145C31), m17 FX-RINGMOD ($1479E5)** — все с тем же
  паттерном (индекс из своих параметров, кламп [0,$63F]) → таблица = кривые
  тембра/волны (16 полос × 108 слов), общая для SYN-машин и ядра.
- Индексные слоты секции НЕ внешние и не ColdFire: r7 катается стеком внутри
  секции ($4DC → $4E6 → $4EE → $4F3), и все три чтения садятся на два
  физических слота кадра:
  - **x:$4D9** — пишет блок $0537–$0556 (`a1→x:(r7-$3)` при r7=$4DC):
    idx = f(param4·16−128 (y:(r6+$8)), |PAN_L+$C00000|, x:(r7-$1), биты 9/11
    y:(r6+$25)), кламп [0,$700]; читается как (r7−$0D) тон-стеком $06CD и как
    (r7−$1A) читателем $0857;
  - **y:$4DA** — пишет $056C (`b1→y:(r7-$2)`, PAN-R-ветвь $055C–$056A);
    читается как (r7−$14) читателем $07D4.
- Сглаживание индекса — one-pole на L-слоте (x/y:$4C1 = (r7−$25)) с усреднением
  (state+new)/2 ($06EF–$06F6) — анти-зиппер.

## Итерация 23 (2026-09-22): драйв-энвелоп DIST снят бит-в-бит; элемент JUCE собран

Метод: бит-точный эмулятор, машина m14 SWAVE-ENS (её CONF сама вооружает слот:
`$145C44: move #>$145c48,x0; move x0,x:(r6-$1c)` — каждый кадр, т.к. ядро
вызывает CONF на $00FB–$00FF ЕЖЕКАДРОВО и обнуляет слот на $0000DB).

### Драйв-энвелоп P:$04FF–$0536 — замеры

- Атака: step = tblA[$141800][DIST_raw] **бит-в-бит** для DIST ∈ {16,32,64,96,127}
  (0x10CFEA / 0x46A98 / 0x4E05 / 0x560 / 0x65 за кадр; DIST=0 → 0x400000).
- Wrap атаки: level+inc ≥ 1.0 → a1 = −1.0 (0x800000 знаковый), фаза := 1.
- HOLD = 1 кадр, причём `bra $052B` ($0528) падает в DEC **в том же кадре**:
  порог счётчика = 0·tempo·… = 0 (x0 = 0 от `clr a`), выход безусловный.
- DEC: level −= tblE[$141A00][idx]; `clr b ifmi` клампит в 0 → wrap'нутый
  −1.0 умирает мгновенно (0.5 → −1.0 → 0 замерено).
- Индекс DEC: y:(page+$0D) перезаписывается ядром в кадре — замер: VOL=127 →
  **16129 = 127²** (VOL²!) → idx = (VOL²+$7FFF)>>16 = 0 → шаг tblE[0] = 1/64.
- Ретриг: y:(page+$20)==1 → сброс уровня/фазы/счётчика ($0500–$0505).

### Тимбр-индекс $0537–$0556 — знак через a1-срез (важно!)

Все промежуточные произведения входят в следующий множитель через a1
(младшие 24 бита, знаковые). При panTerm=0: |0+$C00000| = 0.75 в 56-битном
акк., но a1 = 0xC00000 = **−0.5**; квадрат 0.25; asl#2 → 1.0 → a1 = **−1.0**.
Итог: idx = −$80 − drive·1792 — ОТРИЦАТЕЛЬНЫЙ, скользит вниз с драйвом.
**Верификация**: кадр 70, DIST=64, drive = 1418083 → формула −303−128 = −431,
эмулятор x:(P+$D9) = 0xFFFE51 = −431. Бит-в-бит. Верхний кламп $700
подтверждён (tfr x1,a ifge), нижнего нет — отрицательные индексы уходят в
таблицу как есть.

### Контракт слота — дополнения

- CONF вызывается ядром ЕЖЕКАДРОВО ($00FB–$00FF, r6 = y:$123 = P+$28), а не
  только при смене машины; INIT — при смене (бит 7 ячейки TRIG y:(P+$28)).
- Обработчику нужны стейты своего CONF (кольцо y:(r6+$36), x:(r6+$30/$31)):
  принудительный jmp в $145C48 без CONF ведёт по мусорному указателю.
- ХАРНЕС-ЛОВУШКИ (исправлены, важны для всех будущих замеров):
  1) x:$2C3 = источник r5 → пишется в X:$FF ($04F6) → при 0 мастер-микш
     работает в ФИДБЕК-режиме (выход экспоненциально умирает ~15 кадров) —
     подтверждена сноска итер. 22; надо ставить x:$2C3 = адрес вне X:$00-$1F;
  2) снимок xmem содержит X:$40B = $FFFECF (мусор) — убивает тракт; в
     рабочем харнесе X:(P+$0B) = 64 (EQG-делитель);
  3) бит 7 ячейки TRIG (y:(P+$28)) — флаг «машина сменилась» для INIT.
