# Stage-2 tail (P:$0AD1–$0B4C) — bit-exact reconstruction

**Итерация 22.** Последний непрозрачный участок фильтрового конвейера разобран
поблочно и верифицирован **слово-в-слово** на бит-точном эмуляторе:
`verify: OK=8296 BAD=0` (16 конфигураций × 2–4 кадра, включая 4 кадра со
взятой веткой skip и 4 контрольных). После этого блока DSP-алгоритм фильтра
считается покрытым на 100 % (см. `04_evidence/what_is_missing_for_full_port.md`).

Модель: `exp22_model.py::model_tail(s0, b7, b8, ext)` — закрытая форма,
принимающая три среза состояния (в `$0AD1`, после копии, перед микшем) и
воспроизводящая каждое слово записи/чтения эмулятора. Снимки:
`exp22_snap.json.gz` (естественный путь), `exp22_skip.json.gz` (skip-путь,
форс L:P+$CF и глобального счётчика Y:$C4).

## Контекст

Хвост исполняется после стадии 2 (резонатор/фидбек, `P:$0A5D–$0AD0`, итер. 18)
и перед `jmp func_000143` (возврат в ядро кадра). Регистры кадра: r6 = база
страницы голоса P ($400), r7 = P+$15C. Листинг: `disasm_tail_P0AD1-0B4C.txt`.

## T1 — DIV-блок ($0AD1–$0AE9): обратная величина длины дела

```
b   = (L:P+$CF asr 2)                    ; 48-бит состояние длины дела
y0  = b0(b)                              ; делитель S = младшее слово
a   = $000001_000000                     ; делимое 1.0 в 24.24
24 × div y0,a                          ; невосстанавливающее деление
b1  = a0                                 ; частное Q ≈ 2^24/S
b   = b asr 17                           ; (Q·2^24 | старший хвост) >> 17
a   = ((y1:y0) · Y:$C4) asr 1            ; mpyuu + dmac su: умножение на
                                         ; глобальный счётчик хоста Y:$C4
ifeq: b = 0                              ; clr b ifeq — гвард A==0 (Y:$C4==0!)
b   = b − a
если b ≥ $10<<24 → bge $0B1E             ; SKIP: T2/T3/T4 не исполняются
```

Смысл: `L:P+$CF` — текущая длина дела в 24.24; Q = 1/длина; результат
масштабируется счётчиком хоста `Y:$C4`. Ветвь skip срабатывает, когда
«обратная длина» велика — т.е. дело короче порога: тогда интеграция тапов,
вызов func_397 и публикация выхода пропускаются целиком, исполняются только
DWID-рампа (T5) и мастер-микш (T6). Порог: с Y:$C4 = 0.5 skip наступает при
S = (L:P+$CF asr 2).y ≤ 4. При S = 0 — гвард деления на ноль эмулятора
(a = $FFFFFF…), затем `clr b ifeq` … нет: при S=0 частное = $FFFFFF, но при
Y:$C4 ≠ 0 произведение даёт b > порога — см. exp22_tail_skip.py.

Верифицировано обе ветви: 4 кадра skip (pcf = $10/$8, YC4 = 0.5) и 4 кадра
естественного пути.

## T2 — интеграция фаз тапов ($0AEA–$0B0B) → L:$90–$A0

```
a += $40<<24                  ; add #>$40,a — базовый сдвиг индекса
b   = tfr y0,b; asr b; x0 = b1  ; x0 = полшага (b1 после asr)
b   = move a0,b; lsr b          ; b1 = младшая часть частного+сдвига
17 × do (тело $0AF8–$0AFA):
    a,l:(r1)                    ; X:(r1) ← a1, Y:(r1) ← a0 (перекрывается)
    add y,a                     ; a += y1:y0  (шаг = полный 48-бит y)
    add x0,b; b1,y:(r1)+        ; Y:(r1) ← b1 (пре-ALU); b += x0
    and x1,b                    ; b1 &= $7FFFFF (маска дроби), b0 = 0
```

Результат: банк тапов `L:$90–$A0` (17 пар) — X-половина = целая позиция тапа,
Y-половина = дробь интерполяции для func_000397. Шаг интеграции = частное
деления T1 (`y1:y0`), т.е. позиции тапов разъезжаются пропорционально
1/длине дела — гребёнка «дышит» вместе с делэем.

**Важно про DO-тело**: дизассемблер печатает `do …,>$afb`, но фактическое
тело = [$0AF8..$0AFA] — напечатанный адрес на 1 больше последней инструкции
тела (сырое слово расширения = $0AFA). Инструкция `$0AFB`
(`move y:(r7-$91),x0`) вне цикла. Это правило верно для всех DO в листингах
пака: тело = [pc+2 .. printed−1].

### Де-зиппер ротация ($0AFB–$0B0A)

```
X:$40 ← Y:P+$CB ; X:$51 ← X:P+$CB ; Y:P+$CB ← X:$50 ; X:P+$CB ← X:$61
```
Классическая перестановка слотов кадра — история для анти-зиппер
интерполяции следующего кадра (см. итерацию 15).

## T3 — вызов func_000397 ($0B0B–$0B13)

`r0 = a1` (после `lsr b a1,r0`), `n0 = n1 = $10`, `y0 = Y:$90`, `r4 = $91`,
`r3 = $70`, затем `jsr func_000397`. Сама функция доказана бит-в-бит в
итерации 14 (`07_svf_fit/svf_fit.py`); здесь она вызывается с банком тапов
T2. Замеченные побочные эффекты вызова (важно для модели хвоста): перепись
кольца `X:$70–$82` (в новый X:$70 попадает вход дела) и запись 16 слов
выхода секции дела в `Y:$00–$0F`. В модели хвоста func_397 — чёрный ящик с
этими двумя эффектами, взятыми из среза b7.

## T4 — публикация выхода в хостовое кольцо ($0B14–$0B1D)

```
r0 = $71; r4 = X:$C5; m2 = m4 = $3FFF
a = X:(r0)+; b = X:(r0)+         ; предзагрузка (X:$71, X:$72)
8 × do (тело $0B1C–$0B1D):
    move x:(r0)+,a  a,y:(r4)+
    move x:(r0)+,b  b,y:(r4)+
```
Из-за конвейерного лага (источник параллельного переноса — пре-ALU значение)
16 сохранений = `X:$71, X:$72, …, X:$80` **по порядку** — простое копирование
кольца выхода секции дела в хостовое кольцо по указателю `X:$C5` с
модульным окном $4000 (m4 = $3FFF; эмулятор: base = ptr & ~$3FFF, обход окна
без заворота в 0 для выровненных указателей — в снимках X:$C5 = $4000, т.е.
запись в Y:$4000–$400F). Это тот самый «мастер-выход машины», который хост
затем микширует.

## T5 — DWID-рампа без_zipпера ($0B1E–$0B32)

```
x0 = Y:(r6+$1F)                  ; DWID (машийный параметр, CC-страница EFX)
a = DWID²; y0 = Y:$4FF (env); b = env²
a = env²·DWID²
Y:(r7−$5D) = Y:$4FF ← a1         ; новое состояние = (env·DWID)²
a −= env                         ; delta = (env·DWID)² − env
b = env; y0 = $10; x0 = a1(a)    ; x0 = delta (пре-ALU)
a = env; b += mpy($80000, delta) ; b = env + delta/16
step = mpy($10, delta)
8 × do (тело $0B31–$0B32):
    a,y:(r5)+ ; mac y0,x0,a      ; чётные: env + k·step
    b,y:(r5)+ ; mac y0,x0,b      ; нечётные: env + delta/16 + k·step
```
16 значений `Y:$10–$1F` — внутритактная рампа модуляции (микш T6 читает их
как mod[k]); полшага сдвиг между a- и b-цепочками убирает зиппер-шум.
DWID = 0 → delta = −env → рампа съезжает к нулю (проверено в сетке).

## T6 — мастер-микш ($0B33–$0B49)

Указатели: `r4 = $20` (банк L2 Y:$20–$3F), `r5 = $10` (L:$10–$1F =
пары (X: банк «прошлого кадра», Y: mod-рампа T5)), `r2 = 0` (аудио-шина
X:$00–$0F), `r3 = X:$2C9` (эхо-кольцо), `r1 = X:$FF` (кольцо мастер-выхода),
`r6 = 0` (мастер-выход Y:$0000–$001F), m2 = m4 = $FFFFFF.

Тело цикла `$0B43–$0B48` (16 итераций; `$0B49 move r3,x:>$2c9` — после
цикла, в снапшот b9 ещё не попавший):

```
outs[0]    = (Xpre[0] + L2[1])·mod[0]                 ; затравка из аудио-шины
outs[2k]   = (fb[k] + L2[2k+1])·mod[k]   , k = 1..15
outs[2k+1] = (Xpre[$10+k] + L2[2k])·mod[k]           ; Xpre = шина до микша
fb[k] = outs[k]     если кольцо выхода (r1 = X:$FF = 0) накрывает X:(k)
      = Xpre[k]     в реальной машине (X:$FF указывает вне X:$00–$1F)
echo[k]   = asr1(outs[2k]_56 + outs[2k+1]_56)  → X:(r3)+
Y:$0000+$k ← outs[k]; X:(X:$FF)+k ← outs[k]
X:$2C9 ← r3 (после цикла)
```

**Ключевое открытие**: в харнесе X:$FF = 0 — кольцо мастер-выхода совпадает с
аудио-шиной X:$00–$1F, поэтому микш читает СВОИ же выходы через
`x:(r2)+,x1` → обратная связь `outs[2k] = (outs[k] + L2[2k+1])·mod[k]`
(отсюда экспоненциальные хвосты в Y:$0010–$001F снимков). В реальной машине
хост держит X:$FF вне окна X:$00–$1F, и в микш идёт чистая аудио-шина —
обе ветви покрыты формулой `fb[k]`.

`L2` (Y:$20–$3F) = банк выхода секции дела (стадия 2, итерация 18);
X:$10–$1F до микша = остатки таповых позиций прошлого кадра (в сетке — нули).

## Верификация

```
python exp22_model.py     # OK=8296 BAD=0 (bge-skip frames: 4)
```
Покрытие: 12 конфигураций (ATK/DEC/BOFS/WOFS × DWID) × 4 кадра естественного
пути + 2 skip-конфигурации × 2 кадра + 2 контроля (форс без skip) × 2 кадра.
Проверяются: банк тапов X/Y:$90–$A0, ротация P+$CB, копия Y:$4000+,
DWID-рампа Y:$10–$1F и Y:$4FF, мастер-выход X/Y:$0000–$001F, эхо X:$300+,
указатель X:$2C9.

Инструменты: `exp22_tail.py` (сбор срезов), `exp22_tail_skip.py` (skip-ветвь),
`exp22_diag2.py` (watch-проба блоков).
