## Как использовать

1. **БЫСТРЫЙ ПУТЬ (JUCE):** взять `09_juce_port/` — готовые заголовки + скелет
   плагина + тесты; README_JUCE.md — пошаговая интеграция.
2. Взять `.bin` таблиц из `01_filter/tables/` (3 байта/слово, big-endian, signed 24-bit
   fraction = word/2^23). `.txt`-дампы — для сверки глазами.
3. Собрать порт по `monomachine_track_filter.hpp` / `monomachine_phaser.hpp`:
   пути параметров, индексации и константы верифицированы; помечено TODO-SIM там, где
   нужна побитовая симуляция MAC-конвейера (см. разделы «Что доказано / что реконструировано»).
4. Сверять с листингами в `01_filter/disasm_*` и `02_phaser/disasm_*` — каждый шаг
   реконструкции снабжён P-адресом инструкции.

## ИТЕРАЦИЯ 17 — сверка с мануалами/интернетом: гипотеза энвелопа ПОДТВЕРЖДЕНА

Пользователь предположил, что фильтр «берёт основную энвелоуп от ампа». Сверка с
официальной MIDI CC-картой, мануалом и сообществом (tarekith, Elektronauts, gearspace)
+ бит-точные прогоны (10_manual_crosscheck/) дали:

- FLT page = BAS/WDTH/HPQ/LPQ/**ATK/DEC/BOFS/WOFS** (CC 72–79 → страница $10–$17,
  чтения доказаны трассой абсолютных адресов).
- У фильтра СВОЯ AD-энвелопа (ATK=$14, DEC=$15), общий триггер с AMP-env и
  KILL-гейт по фазе 4 AMP-env; назначения: base ← BOFS($16), width ← WOFS+BOFS
  ($17+$16) через кривые $144AC7 — в точности «LP — раб, следует за HP» (tarekith).
- Носитель модуляции измерен бит-точно: банк фидбек-коэффициентов X:$40–$5E
  (WOFS=127 → +0.573, BOFS=127 → 0.000, baseline 0.004–0.116) + стейты P+$D4/$D5.
- Статический SVF-каскад (BASE/WDTH) env-free — переподтверждён трижды.
- Поправка: Y:$04–$07 дважды используемы (кольцо коэффициентов ↔ мастер-выход).
- Новые лиды: ADSR-машина $04A8–$04F4 (Y:$04FF, трек 0; раскладка $18–$1F — H1/H2);
  кейтрекинг на CPU; секция $0789–$0859 читает DIST ($04).
