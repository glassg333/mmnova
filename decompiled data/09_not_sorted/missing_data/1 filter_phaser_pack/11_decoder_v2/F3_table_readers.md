## Схема секции $0789–$0859 (DIST/EQ-гибрид)

```
EQG (P+$0B) ──► DIV×24 ──► 1/EQG (y1)
DIST (P+$04) ─► индекс $100 ──► $1447C6[DIST], DIST²-масштаб
банки X:$72-$93 ──► DO $22 × mpy(1/EQG) ──► Y:$70-$91 / Y:$B0-$D1 (×$80 swap)
y:(r7-$14) ──► clamp $6A3 ──► $143546[idx]·(1/EQG) ──► макросы ×8 → Y:$4+ (гейн)
```

## Вывод для порта

1. «EQ» в MonoMachine — это не Biquad-EQ, а **таблицы-кривые + гейн**
   (waveshaper/тон-стек), входящие в DIST/EQ-гибрид после каскада-1 и
   резонатора. Для чистого фильтра (без DIST/EQ) таблицы НЕ нужны —
   что и требовалось доказать для порта фильтра.
2. Для полного бита-в-бит эмуляции тракта нужны: $143C06 (258+ секторов
   DIST-кривой), $1447C6, $143546 (≥1680), $141A98/$142158/$142F06 (lerp-пары)
   — все уже в 01_filter/tables/ (кроме $1447C6 — добавить в итер. 19).
3. P+$0B = EQG (raw divisor, подтверждено $079F), P+$04 = DIST — карта
   страницы сверена с кодом.

## Открытым остаётся

- Источник y:(r7-$14) (индекс $143546) — вероятно, огибающая/энергия сигнала.
- $1435C6 машинные читатели (4 машины) — общая кривая, разбор итер. 19.
- Точная по-сэмпловая топология секции (где именно сатурируется аккумулятор — clamp $7FFFA4) и аудио-позиция DIST/EQ относительно фильтра (программно секция $064E–$0859 стоит до фильтровых блоков, но фактический порядок шин не трассировался).

## Итерация 20: кривые измерены (exp20_dist_curves.py)

Индексация уточнена по листингу: путь DIST: `move y:(r6+$4),a` → `asl a` →
`mpyi #>$100` → `move a,rN`. asl удваивает дробь, mpyi #>$100 = умножение на 2⁻¹⁶,
итого rN = 2·knob (0..254). Обе кривые — 256-словные **интерливнутые пары**;
используются чётные входы (knob 0..127). Никаких «секторов по $100» нет.

**$143C06 (драйв-гейн), чётная ветвь:** строго геометрическая прогрессия,
рост ×1.081 за шаг ручки (= +0.677 дБ/шаг) по ВСЕЙ длине (замерено на k=0,10,30,60,100,120:
отношение соседних чётных входов 1.081–1.082). Диапазон: 380/2²³ (−87.2 дБ) при DIST=0 →
7335429/2²³ (−0.77 дБ) при DIST=127. Нечётная ветвь = та же кривая ×1.04 (+0.34 дБ)
— вторая версия коэффициента (канал/полоса). **DIST = экспоненциальный гейн-драйв**, а не
табличный waveshaper по сигналу: сатурация даётся переполнением аккумулятора (guard $7FFFA4
на lerp-значении и арифметикой секции), кривая задаёт только величину драйва.

**$1447C6 (компенсация/масштаб на EQ-банки):** убывает от $7FFFFF (1.0) до ровно
**√2/4 = 0x2D413D = 1/(2√2) ≈ −9.03 дБ** с плато примерно от середины ручки;
чётная/нечётная ветви совпадают с k≥1 (odd[0] = 8380847 чуть ниже). С масштабом
0.98316·DIST² + 0.01574 итоговый коэффициент растёт ~квадратично и насыщается:
0.0157 (DIST=0) → 0.353 (DIST=127).

P_143C06_kernel_tbl_143C06.* уже был (911 слов = кривая + хвост до $143F95).

**Статус DIST (AMP-страница, ручка 5, CC 60):** карта параметра сверена (итер. 17),
обе кривые извлечены и охарактеризованы (итер. 20), читатели разобраны. Остаток —
три пункта из «Открытым остаётся» выше.
