## Полный PROC m18 ($145045–$14513F), блок за блоком

Голова ($145045–$14509B) разобрана в итерации 22 (14_m18_phaser/): банки входа
`Y:$00–$0F / Y:$10–$1F = input·INP²·4` (INP = параметр 7), фаза LFO
(48-бит `x:(r6+$11/$12)`, шаг = SPD²·$9566 за блок, счёт ВНИЗ от $80:00000000),
one-pole индекса `y:(r6+$1B)` (k=$28F5C, цель = параметр 5 WID) с выборкой
квадратуры из $14A000 (sin) / $14A800 (cos), де-зиппер рампы X/Y:$E0–$EF.

Хвост (итерация 24, листинг 02_phaser/disasm_m18_real_phaser…, строки 87–176):

1. **$14509C–$1450A4 — one-pole CNTR**: `s18 (48-бит x/y:(r6+$18)) += $28F5C·P0 − $28F5C·s18_hi`
   ($FD70A4 = −$28F5C). k = $28F5C/$800000 = 0.0199 ≈ 1/50 за блок. Параметр 0 = CNTR.
   Замер (проба A, exp24f): s18 стартует 0 и сходится к значению, зависящему только
   от P0; при P0=0 остаётся 0.
2. **$1450A6–$1450AF — one-pole DEP**: тот же коэффициент, цель = параметр 1 (DEP),
   стейт `s19 (r6+$19)`. Замер: симметрично CNTR (проба A: p1=127 даёт ту же
   траекторию в s19, что p0=127 в s18).
3. **$1450B0–$1450C5 — квадратичная форма + рампа X:$E0–$EF**:
   `v = s19·(s19 − 1.5)` (v(s) = s² − 1.5s, минимум −0.5625 при s=0.75, v(0)=v(1)=0);
   стейт `y:(r6+$1A)` ← v; дельта Δ = v_new − v_old; 16-шаговая рампа
   `X:$E0+k = v_old + (k+1)·Δ·0.5` (де-зиппер).
4. **$1450C6–$1450D4 — банк модуляции**: `X:$00+k = s_k·ramp[k] + c`, где s_k =
   X:$20+k (стейты ротатора), ramp[k] = X:$E0+k, c = состояние s19 (конвейерное).
5. **$1450D5–$1450E6 — one-pole FB + рампа Y:$90–$9F**: `s13 = (P4 − 0.5)·2`
   (параметр 4 = FB, центровка ±1), стейт `y:(r6+$13)`; рампа
   `Y:$90+k = s13_old + (k+1)·Δ·0.5` (де-зиппер FB).
6. **$1450E7–$145128 — ДВУХПРОХОДНЫЙ 16-СТУПЕНЧАТЫЙ ВРАЩАТЕЛЬ** (ядро фейзера):
   - `do #$2` — два прохода (вход x:(r0)+ — 17 слов за проход, 34 всего;
     банк результата r3 = $60 для прохода 1, $70 для прохода 2);
   - перед проходом: копия 7 L-пар стейтов `r6+$1E..$24` → X/Y:$20–$26
     (персистентные состояния ротатора, пишутся обратно после прохода);
   - 16 итераций развёрнутой mac-цепи: комплексное вращение
     `a = ramp·s + rampQ·q; b = ramp·s − rampQ·q` (s ← X:$20+k каскадно, q ← Y-банк),
     выход b-цепи → X:$60–$6F (проход 1) / X:$70–$7F (проход 2);
   - последний шаг умножает на константу `$5A8241` (≈ 0.70706 = cos 45°) —
     фиксированный поворот финальной ступени;
7. **$145129–$14513E — финальный микш (параметр 3 = MIX)**:
   `x0 = y:(r6+$7)`; `x1 = $7FFFFF − x0 = 1 − MIX`;
   чётный выход `a = (1−M)·dry_even[k] + M·wet1[k]` (dry = Y:$00–$0F, wet1 = X:$60–$6F);
   нечётный выход `b = (1−M)·wet2[k] + M·dry_odd[k]` (wet2 = X:$70–$7F, dry = Y:$10–$1F
   — стерео-перекрёст). Запись парами `a/b → y:(r7)+` → Y:$100–$11F.
   Замер (проба B): MIX плавно кроссфейдит, экстремумы соответствуют формуле.
8. **$14513F — `rts`**.

## LFO фейзера — сводка (ответ на «лфо фейзера точнее»)

- **Форма-носитель**: квадратура sin/cos, таблицы $14A000/$14A800 по 8192 слова =
  один период; индекс = сглаженный one-pole (k=1/50) от параметра 5 (WID) × $800.
  WID — «ширина/форма» вращателя, НЕ скорость.
- **Скорость**: параметр 2 (SPD) → шаг фазы = **SPD²·$9566 за блок** (48-бит фаза
  x:(r6+$11/$12), счёт вниз, старт $80:00000000). Закон SPD² подтверждён дважды
  (итер. 22 прямым замером фазы; итер. 24 — по частоте выхода).
- **Частота (замер итер. 24, DC-вход, блок = 16 сэмплов @ 44.1 кГц)**:
  SPD=16 → период 4.8 блока = **576.55 Гц**; формула `f ≈ 576.55·(SPD/16)² Гц`:
  SPD=4 → 36 Гц, SPD=8 → 144 Гц, SPD=12 → 324 Гц. Выше ~SPD 22 (≈1.1 кГц) модуляция
  уходит в аудио-диапазон и алиасит — штатное поведение машины (metallic/PM-звук).
- **Глубина**: параметр 1 (DEP) через one-pole s19 и квадратичную форму v = s²−1.5s
  (мягкое насыщение по краям ручки) → амплитуда вращения.
- **Центр**: параметр 0 (CNTR) через one-pole s18 — статический угол вращателя
  (замер ИР итер. 22: CNTR 32/64/96 → первый тап 0.5562/0.5802/0.6029).
- **Рампы**: 16-шаговые де-зиппер рампы на каждую модуляционную координату
  (X:$E0–$EF — CNTR/DEP-форма; Y:$90–$9F — FB) — модуляция пересчитывается
  по-сэмплово внутри блока.

## Хелпер $14514D–$14538C: 3-фазный шейпер на кривых ядра

Функция (r7 → x:$FF, как у PROC) ведёт собственный конверт по **кривым ядра**:
фаза 0 — атака `tbl[$141980][P4>>16]` (параметр 4), фаза 1 — `tbl[$141900][P5>>16]`
со счётчиком +$20, фаза 2 — спад `tbl[$141A00][P6>>16]` с `clr ifmi`. Стейты
y:(r6+$10/$11/$12). Это тот же набор кривых, что у AMP/EFX-конвертов ядра
($141800–$141B18) — переиспользование подтверждено.
