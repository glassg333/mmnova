# PHASER (m18) LFO — окончательный референс (итерация 29)

**Статус: все четыре вопроса («источник / форма / скорость / глубина») закрыты
измерениями на бит-точной модели `18_m18_final/exp25_model.py` (верифицирована
OK=38400 BAD=0 против эмулятора).** Файл измерений: `exp29_lfo_rate.py` /
`exp29_lfo_rate.json` (в этой папке). Все числа ниже — на ИСПРАВЛЕННОМ
эмуляторе (фикс DO-цикла, итерация 25); устаревшие числа итераций 22/24
помечены явно.

## 1. Источник сигнала

LFO фейзера — **чисто внутренний осциллятор PROC m18**, никаких внешних входов:

- код: `$145057–$145069` внутри PROC m18 (`$145045–$14513F`);
- состояние — 24-битная пара `x:(r6+$11)` / `x:(r6+$12)` (компоненты a/b
  фазора; r6 = страница FX + $28, т.е. на страницу EFFX не заходит);
- инициализация: `move #$80,x0` в INIT машины — фазор стартует с
  **a = $000080 (128 LSB ≈ 1.53e-5), b = 0**;
- **free-running**: фаза живёт в стейте машины, не синхронизируется ни с
  темпом, ни с нотами/голосами, ни с датчиком позиции; отдельного «источника
  LFO» в ядре нет — каждый экземпляр m18 крутит свой;
- ВАЖНОЕ УТОЧНЕНИЕ к итерациям 19–24: квадратурные таблицы
  **$14A000/$14A800 — НЕ носитель LFO-формы**. Осциллятор — численное
  вращение (интегрирование), таблицы читаются только в WID-пути
  (стерео-ширина, §4). Форма/скорость LFO от их содержания НЕ зависят
  (проверено: модель с любыми таблицами даёт идентичную траекторию фазора).

## 2. Форма волны

**Квадратурный фазор (a = cos-компонента, b = sin-компонента) — синусоида**,
полученная численным вращением, а не чтением таблицы. На каждый 16-сэмпловый
блок выполняется 16 итераций (по одной на сэмпл), значения пишутся в
X:$20–$2F (b-цепь) / Y:$20–$2F (a-цепь) и потребляются в том же блоке
стадией боковых полос ($14508B).

Точная рекуррентность (инструкция-в-инструкцию, с учётом задержки защёлки x1):

```
θ        = step·2⁻²³ (радиан/сэмпл),  step = a1(mul(a1(mul(SPD<<16,SPD<<16)),$9566))
b_k = b_{k−1} − θ·a_{k−2}        (mac -x1,x0,b:  x1 = a, задержанное на 2 шага!)
a_k = a_{k−1} + θ·b_{k−1}        (mac y0,x0,a:   y0 = b, задержанное на 1 шаг)
```

Это рекуррентность 3-го порядка (x1 отстаёт на ДВА индекса). Её корни:
**λ = 1 ± iθ + θ²/2 → |λ| = √(1+2θ²)**. Отсюда два следствия, оба подтверждены
замерами (exp29_lfo_rate.json, совпадение с теорией ≤0.1% на всех SPD):

1. **скорость вращения** ω = arg λ ≈ θ (точнее atan2(θ, 1+θ²/2));
2. **амплитуда растёт**: ln|λ| = θ² за сэмпл — фазор не стационарен,
   а экспоненциально «раскачивается» из стартовых 128 LSB (см. §4).

Вращение идёт **в сторону уменьшения фазы** (b' = b − θa: при a=1, b=0
компонента b уходит в минус) — согласуется с «счёт ВНИЗ» итерации 24.

Квантование: состояние хранится 24-битными словами (усечение acc на границе
блока). При стартовой амплитуде 128 LSB фазовый шум квантования (~1 LSB на
фон 128 LSB) даёт заметную диффузию фазы (~1 радиан за период при SPD=8) —
реальное поведение железа, фазор «самоочищается» по мере роста амплитуды.

## 3. Скорость (rate) — ИСПРАВЛЕНО

**Рабочая формула:**

```
f_LFO = step · 2⁻²³ · fs / 2π   [Гц],  fs = 44100, 16 сэмплов/блок
      ≈ SPD²/512 Гц  (SPD = 0..127 → 0 .. 31.5 Гц)
период ≈ 512/SPD² секунд
```

Замер на модели (фаза анврапом, окно 60%; совпадение с теорией ≤0.005%):

| SPD | step | f, Гц (замер) | f, Гц (теория) | период, блоков | период, с |
|-----|------|---------------|----------------|----------------|-----------|
| 8   | 149  | 0.12467       | 0.12467        | 22108.8        | 8.02      |
| 16  | 597  | 0.49951       | 0.49951        | 5517.9         | 2.00      |
| 32  | 2390 | 1.99971       | 1.99971        | 1378.3         | 0.50      |
| 64  | 9561 | 7.99965       | 7.99967        | 344.5          | 0.125     |
| 100 | 23343| 19.53084      | 19.53105       | 141.1          | 0.0512    |
| 127 | 37650| 31.50081      | 31.50169       | 87.5           | 0.0317    |

Закон f ∝ SPD² подтверждён отношениями: f(16)/f(8) = 4.007, f(64)/f(16) =
16.015, f(127)/f(100) = 1.613 (теория 1.6129 = 127²/100²).

**ЗАМЕНА УСТАРЕВШИХ ЧИСЕЛ (артефакты однопроходного эмулятора, итерации
22/24):** «576.55 Гц при SPD=16», «f ≈ 576.55·(SPD/16)² Гц», «выше ~SPD 22 —
аудио-рейт с алиасингом» — НЕВЕРНЫ. Реальный диапазон LFO — саб-аудио
0…31.5 Гц, алиасинга нет; 31.5 Гц @SPD=127 — верхняя граница штатного
музыкального диапазона качания. Множитель $9566 — константа фейзера
(у хоруса m15 $956, у фленджера m19 $9566, у m33 $4AB3 — см.
12_lfo_shapes/README_lfo_shapes.md).

## 4. Глубина (modulation depth) — два независимых пути

### 4a. Модуляция КОЭФФИЦИЕНТА лестницы (главный путь)

```
CNTR (парам. 0) → one-pole s18 (k=$28F5C) → c = 2·(s18−0.5)      [статика]
DEP  (парам. 1) → one-pole s19 (k=$28F5C) → v = s19·(−(|c|+1))   [глубина]
→ V-рампа Y-путь (перезаписывает квад-рампу cos в X:$E0–$EF)
фазор (Sc, Qc) → боковые полосы: a_bank = XE·Sc + YE·Qc;
                                b_bank = XE·Sc − YE·Qc
→ mod[i] = (a|b)_bank[i]·V[i%16] + c  → коэффициент allpass-ступеней
```

- отклонение коэффициента от статики c равно **|v|·|фазор|** (вращение
  сохраняет норму фазора; замер: mod_dev = 1.66e-5 при |фазор| = 1.66e-5,
  |VR| ≈ 0.99 — совпадение точное);
- |v| ≤ 2 (максимум при CNTR=0/127, DEP=127); реально глубина определяется
  не только DEP, а **произведением DEP на растущий фазор** — см. §5;
- CNTR сдвигает рабочий коэффициент (светлее/темнее), DEP задаёт размах.

### 4b. Стерео-ширина (WID, парам. 5)

one-pole (k=$28F5C) → индекс `s_wid·$800>>24` (0..2047) → таблицы
$14A000 (sin) / $14A800 (cos = sin+2048 слов, четверть оборота) →
16-шаговые рампы X/Y:$E0–$EF → знак при b_bank/a_bank = L/R расщепление
боковых полос. WID — «ширина/поворот» стерео-образа, на скорость и общую
глубину модуляции коэффициента НЕ влияет. Содержимое таблиц по-прежнему
восстановлено только гипотетически (полный период синуса, 8192 слов; их
заливает ColdFire, в дампе P-памяти их нет) — на LFO-выводы не влияет.

## 5. Поведение амплитуды: встроенный soft-start и предел

Фазор стартует с 128 LSB (1.53e-5) и растёт **ln|λ| = θ² за сэмпл**
(замер совпал с теорией 0.5·ln(1+2θ²) на всех SPD в пределах ошибки окна):

| SPD | рост, 1/блок | e-fold | модуляция ≥0.01 (|v|≈1) | модуляция ≥0.1 | до полного масштаба (обёртка) |
|-----|--------------|--------|--------------------------|----------------|-------------------------------|
| 8   | 5.27e-9      | 1.9 с  | 1.6 ч                    | 1.8 ч          | 8.8 суток                     |
| 16  | 7.88e-8      | 126 мс | 12.4 мин                 | 13.9 мин       | 14.2 ч                        |
| 32  | 1.26e-6      | 7.9 мс | 46 с                     | 52 с           | 53 мин                        |
| 64  | 2.01e-5      | 0.5 мс | 3.5 с                    | 3.9 с          | 3.3 мин                       |
| 100 | 1.20e-4      | 83 мкс | 0.6 с                    | 0.7 с          | 33.5 с                        |
| 127 | 3.12e-4      | 32 мкс | 0.24 с                   | 0.27 с         | 12.9 с                        |

Практический вывод: у m18 **нет стационарной глубины** — это софт-старт:
после смены машины/ноты (INIT перезасеивает фазор в $80) качание набирает
глубину тем быстрее, чем выше SPD (скорость роста ∝ SPD⁴). После достижения
полного масштаба 24-битное хранение фазора обёртывается по модулю 2 —
вращение перестаёт быть чистым (фазор «складывается»), модуляция становится
нерегулярной; при максимальном SPD это наступает через ~13 с непрерывной
работы. Для порта: если нужна «чистая» синусоида — считайте фазор в double
без роста (или клампьте амплитуду), но бит-точность с железом требует
воспроизвести именно это поведение (`exp25_model.py`, шаг 2).
