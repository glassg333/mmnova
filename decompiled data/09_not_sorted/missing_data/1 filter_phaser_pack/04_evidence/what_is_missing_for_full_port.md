## ФИЛЬТР — DSP-алгоритм: 100% (ЗАКРЫТ в итерации 22)

### НОВОЕ в итерации 22 — хвост стадии 2 ($0AD1–$0B4C) доказан бит-в-бит
Модель `13_stage2_tail/exp22_model.py::model_tail` воспроизводит эмулятор
слово-в-слово: **verify: OK=8296 BAD=0** (12 конфигураций × 4 кадра +
skip-ветвь + контроли). Блоки:
- T1 DIV: Q = 1/(L:P+$CF asr 2), продукт с глобальным счётчиком Y:$C4,
  гвард `clr b ifeq`, ветвь skip при Q·(1−YC4) ≥ $10<<24 (короткое дело →
  интеграция/func397/копия пропускаются, DWID-рампа и микш остаются);
- T2 интеграция тапов → L:$90–$A0 (шаг = частное T1 — гребёнка «дышит»
  вместе с делэем) + де-зиппер ротация P+$CB;
- T3 вызов func_000397 (доказан в итер. 14) с банком тапов T2;
- T4 копия X:$71–$80 → Y:(X:$C5)+ (модульное окно $4000) — публикация
  выхода машины хосту;
- T5 DWID-рампа Y:$10–$1F без зиппера (a/b-цепочки, полшага сдвиг),
  состояние (env·DWID)² → Y:$4FF;
- T6 мастер-микш: outs[2k] = (fb[k]+L2[2k+1])·mod[k],
  outs[2k+1] = (Xpre[$10+k]+L2[2k])·mod[k], эхо = asr1(сумма) → X:(X:$2C9)+;
  fb[k] = outs[k] при X:$FF=0 (фидбек в харнесе) или чистая аудио-шина в
  реальной машине — обе ветви в формуле.
Питфолл документирован: напечатанный конец DO = последняя инструкция тела +1.

## DIST — элемент готов (итерация 23)
Драйв-энвелоп P:$04FF-$0536 снят бит-в-бит (атака = tblA[DIST], wrap, HOLD 1
кадр + fallthrough в DEC, DEC tblE[idx] c клампом ifmi, ретриг y:(P+$20));
формула тимбр-индекса $0537-$0556 сверена с эмулятором бит-в-бит (−431);
контракт слота обработчика (CONF-вооружение каждый кадр, фейд-ин 64).
JUCE: 09_juce_port/Source/mnm_dist.h (12/12 тестов). Осталось (опционально):
по-сэмповое тело обработчика $145C48 (вращатель/кольцо 1024/веса) и полный
список «машина → обработчик» (живёт у ColdFire; искать по эпилогу jmp $000981).

## Итерация 27 (20_coldfire_clock/) — часы, страницы, роутинг на host

1. Карта трамплинов: тактовый модуль ROM $2676E0–$267F82 → RAM $1000088–$1000929;

2. Темп-движок $267ABA: интеграторы $29C04C+t*12+i*4, модуль $F23FA = 2·63²·125
   (сдвиговая декомпозиция), округление $791FD = $F23FA>>1; выход d4<<((7·x)>>7+6)
   → слот+$14; фазы $2BFC58+t*$66+i*$22 (+$00 фаза, +$0C инкремент, +$14 выход),

4. Сборщик страниц $267DEE: флаги $29C014+t*4, глайд entry+$7C = (цель+3·стейт)>>2

## Итерация 28 (21_echo_kernel_routing/) — ядро DSP: роутинг эха

1. **ПОПРАВКА к итерации 24**: DSND и DBAS ЧИТАЮТСЯ ядром DSP. Глайндвижок
   $000262–$0002EA: `y:(r6-$0C)` = P+$1C (DSND) на $000284, `y:(r6-$0A)` =
   P+$1E (DBAS) на $0002C8; r6 = страница+$28 (Y:$123 = $528, страницы
   Y:$500/$600/$700); X:$500-$52F = X-тень страницы. Причина промаха-24: скан
   смещений от базы страницы вместо смещений от r6.
2. Глайндвижок: цели P+$22/P+$29 (стеи X:$502/X:$507), 48-бит акк-умуляторы
   (X:$504:X$505 / X:$508:X$509), скорости = frac(T[idx]·P$2A>>8), idxA = DSND>>16,
   idxB = P+$07>>16, T = Y:$1449C6 (извлечена: [1]=$010F79 … [127]=$A; [128..255]
   — вторая кривая $0→$7FFFFF). Больше DSND → медленнее глайнд.
3. Позиция X:$501 = accB + P+$26 + $B000·DBAS − $5800 + accA, кламп [0,$5800];
   декод как 22-битный float: len = X:$140000[X:$501&$7FF] >> 10 << (X:$501>>11);
   a = len·$1D22A>>3 → аргумент PROC машины (длина stage-2 задержки).
   X:$140000 = 2048-словная мантисса 0.5→1.0 (извлечена из образа SRAM).
4. Эхо-шина: X:$2C9 (запись мастер-микша $000B33–$000B4B, 16 слов/голос),
   X:$2CA (цель DMA4-блока хоста 47 слов → X:$2FC, команда $000259), X:$2CB
   (старт шины, чтение обратно в банки $0001C2–$0001E1). DMA4 = ESSI0 RX
   (DSR4=$FFFFB8, DCR4=$CA5140, 32 слова/кадр) + ренарм на хост-блок.
5. Роутер спецификаций $242058 расшифрован: $7001FA+t·12+j = группа,
   $700242+t·12+j = смещение, $70028A+t·12+j = третий байт; $2403D4(d3=track,
   d2=группа, a1=смещение); г2/3/4 → $1000A14+(группа·8+track·52+смещение)·4 —
   одно слово страницы на один указатель (поправка к README-27). Значения
   спецификаций — рантайм-стейт ОС (сеттеры $2427B4/$242968), в ROM их нет.
6. Хост-чтение из DSP: CVR $06/$86, адрес = *($259114)+1 = X:$701 → слово $27
   staging ($24828E DSP2 / $248204 DSP1).
7. ОСТАЛОСЬ для полного порта эха: (а) путь DFB (P+$1D) на DSP — чтение не
   найдено (возможно через мод-банк X:$00-$1F или хост); (б) семантика 47-словного
   блока X:$2FC; (в) содержимое X:$701; (г) UI-имена P+$07/P+$22/P+$26/P+$29;
   (д) значения спецификаций ОС (рантайм-дамп или трассировка $212xxx).
