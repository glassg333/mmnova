# AMP-энвелоп трека Monomachine — ПОЛНАЯ реконструкция (бит-точная верификация)

Итерация 13. OS 1.32B, ядро DSP1. Всё ниже исполнено и измерено на бит-точном
эмуляторе (`05_emulator/dsp_emu.py`) на РЕАЛЬНОМ коде ядра: трек-фрейм $0100–$0B4C,
машина подменена инжекцией тест-сигнала в буфер выхода машины Y:$100–$121.

## Где живёт энвелоп

**Стейт-машина: P:$088E–$08D7** (вызывается 1 раз на блок = 16 сэмплов, 44100 Гц
→ 1 кадр = 0.3629 мс).

Ячейки состояния (r6 = база страницы трека P = $400/$500/$600; r7 = P+$FA внутри
энвелопа):

| Ячейка | Роль | Доказательство |
|---|---|---|
| `Y[P+$D7]` | УРОВЕНЬ (аккумулятор, 24-bit) | `P:$08A3/08A7/08D3/08D7: y:(r7-$23)` |
| `X[P+$D8]` | ФАЗА: 0=ATK 1=HOLD 2=DEC 3=REL 4=KILL | `P:$0893/089C/08AB/08C3: x:(r7-$22)` |
| `Y[P+$D8]` | Счётчик HOLD (сеется в 1 при конце атаки) | `P:$08AC/08B7/08BF` |
| `Y[P+$28]` | TRIG_EVENT вход: 1=note-on 2=note-off 3=kill | `P:$088E` |

Параметры (страница AMP, идут ПОСЛЕДОВАТЕЛЬНО):

| Страница | Параметр | Использование |
|---|---|---|
| $00 | ATK | индекс таблицы атаки: `idx = ATK>>16` (raw 0..127) |
| $01 | HOLD | порог счётчика с темп-масштабом |
| $02 | DEC | индекс таблицы затухания |
| $03 | REL | индекс таблицы затухания (релиз) |
| $04 | DIST | (драйв: атака драйва через $141800[DIST], P:$0509; диспетч рутины дисторшна — указатель в `X[P+$0C]`, 0=выкл, P:$097C–$0980) |
| $05 | VOL | гейн: `gain ∝ level·VOL²` (P:$08DF–$08E4) — СТЕПЕННАЯ кривая |
| $06 | PAN | угол панорамы → sin/cos-таблицы $14A000/$14A800 (P:$08DB–$08EB) |

⚠️ Исправления против voice_page_map итерации 11: VOL = **$05** (не $0D), PAN-угол =
**$06**; ячейки $0D/$0E/$0F читаются другими секциями (баланс/гейн-компенсация
P:$053E–$0551). Уровень/фаза энвелопа = **P+$D7/P+$D8** (не $BF/$C0 — старая карта
считала r7 = P+$E2, реально r7 = P+$FA).

## Алгоритм (точный, по инструкциям)

```
TRIG = Y[P+$28]:
  trig=1 → phase(X) := 0            (уровень НЕ сбрасывается!)
  trig=2 → phase := 3 (REL)         (P:$0896)
  trig=3 → phase := 4 (KILL)        (P:$089A)

ФАЗА 0 — ATK (P:$08A0–$08AD):
  inc = tblA[$141800][ATK_raw]      # ATK_raw = (Y[P+$00] >> 16), 0..127
  level += inc                      # add y0,a
  store level                       # move a,y: → a1, младшие 24 бита акк.
  if EXTENSION flag clear → дальше атакуем
  else (level+inc ≥ 1.0, акк. переполнился):
      level := wrapped (≈ −1.0 !!! 24-битный wrap, ЗНАК МЕНЯЕТСЯ)
      phase := 1; counter(Y) := 1

ФАЗА 1 — HOLD (P:$08AE–$08C5):
  t0 = max(0, HOLD_raw·2^16 − $10000)      # P:$08B1–$08B3: HOLD=1 ≡ 0
  threshold = t0 · TEMPO · $791FD0 · 2      # P:$08B4–$08BB, TEMPO=Y[P+$23]
  counter += 1
  if counter > threshold → phase := 2

ФАЗА 2 — DEC (P:$08C6–$08C9): rate_raw = DEC_raw  (Y[P+$02])
ФАЗА 3 — REL (P:$08CA):       rate_raw = REL_raw  (Y[P+$03])
ФАЗА 4 — KILL (P:$08CC–$08CD): rate_raw = $20 (32)
  ОБЩИЙ ШАГ (P:$08CE–$08D7):
  idx = rnd((rate_raw + $7FFF) >> 16)       # = rate_raw для 0..127; для $20 → 1
  level = −level · tblB[$141880][idx]       # mpy -x1,y0,a ; tblB < 0!
```

### Тонкости, доказанные эмуляцией

1. **Wrap атаки**: `move a,y:` сохраняет a1 (биты 47–24 аккумулятора). При
   переходе через 1.0 старший бит уходит в расширение → a1 = −0.999… (ОТРИЦАТЕЛЬНЫЙ).
   Уровень реально проходит через −1.0.
2. **Первый шаг затухания**: `mpy -x1,y0,a` при level = −1.0: отрицание −1.0 в
   24-битном фракте переполняется обратно в −1.0, произведение
   (−1.0)·(−0.999…) = +0.999… — уровень СНОВА становится положительным и дальше
   затухает к нулю с положительным знаком. Итог: **|level| = огибающая**, знак —
   внутренняя кухня.
3. **KILL**: индекс $20 после `add #$7FFF; asr #16; rnd` округляется до **1** →
   множитель tblB[1] = 0.904016/кадр (−60 дБ за 44 кадра ≈ 16 мс).
4. **DEC=127 (tblB[127] = −1.0)**: уровень заморожен навсегда (∞).
5. **Ретриггер (trig=1 во время DEC/REL)**: уровень НЕ сбрасывается — атака
   продолжается с текущего уровня: из отрицательной зоны уровень лезет ВВЕРХ
   через 0 к +1.0. Амплитуда (|level|) при этом ПАДАЕТ к нулю и снова растёт
   (дип-к-тишине-и-повторная-атака) — родное поведение оригинала.

## Гейн-путь (как уровень становится амплитудой)

`P:$08D8–$08FA` → per-sample гейны `Y:$20–$2F (L)` / `Y:$30–$3F (R)`, применяются
в резонансном SVF-цикле `P:$0904–$0910 / func_000397`:

- **цель гейна** = |level| · VOL² · панорамный множитель (sin/cos из $14A000/$14A800,
  угол из PAN=$06) + балансные поправки P:$053E–$0551 (±0.75 узел);
- **де-зиппер**: однополюсное сглаживание к цели, коэффициент ≈ 0.094/кадр
  (3/32): выход на цель за ~28 кадров (~10 мс) — сглаживает и смену знака уровня
  при wrap'е (щелчка нет);
- **внутриблочный рамп**: 16 значений гейна на блок линейно растут
  (mac-накопление в do-цикле, P:$08F6–$08F9) — интерполяция между блоками,
  ступенчатых артефактов нет.

## C++ эталон порта

```cpp
// Monomachine track AMP envelope, 1 unit = 1 block of 16 samples @ 44100
struct AmpEnv {
    static constexpr float TBL_A[128] = { /* P_141800_env_shape_tbl_A.bin */ };
    static constexpr float TBL_B[128] = { /* P_141880_env_shape_tbl_B.bin (отрицательные!) */ };
    int   phase = 0;         // 0 ATK 1 HOLD 2 DEC 3 REL 4 KILL
    float level = 0.0f;      // хранит ЗНАКОВЫЙ level (см. п.1-2 тонкостей)
    int   counter = 0;

    void trig(int t) {       // 1=on 2=off 3=kill
        if (t == 1) phase = 0;
        else if (t >= 2) phase = (t == 3) ? 4 : 3;
    }
    float tick(int atkRaw, int holdRaw, int decRaw, int relRaw, int tempo) {
        switch (phase) {
        case 0: level += TBL_A[atkRaw];
            if (level >= 1.0f) { level -= 2.0f; phase = 1; counter = 1; } // 24-bit wrap
            break;
        case 1: { float t0 = std::max(0, (holdRaw << 16) - 0x10000) / 8388608.0f;
                  float thr = t0 * tempo * 0.472732f * 2.0f;             // $791FD0/2^24
                  if (++counter > thr) phase = 2; } break;
        case 2: level = -level * TBL_B[decRaw]; break;
        case 3: level = -level * TBL_B[relRaw]; break;
        case 4: level = -level * TBL_B[1]; break;   // $20 → rnd → idx 1
        }
        return std::abs(level);      // гейн = |level|·VOL²·panLaw
    }
};
```

## Метод верификации

Харнес `06_amp_env/amp_env_measure.py` (бит-точный прогон реального трек-фрейма):
триггер → наблюдение Y[P+$D7]/X[P+$D8] покадрово; мастер-выход Y:$0000–$001F —
амплитудная кривая. Свипы ATK×10 / DEC×11 / REL×5 / HOLD×5 / KILL / RETRIG —
`06_amp_env/amp_env_sweep.json`. Измеренные приращения совпали с таблицами
бит-в-бит (например ATK=32: шаг = $046A98 = tblA[32] точно).
