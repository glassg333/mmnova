## Что добавлено нового (чего не было)

1. **`dsp/MnMAmpDist.h`** — реальный DIST из P:$079F-$07D1: x0=max(0,2D−1),
   k=0.9837891·x0²+0.0162109, усиление 4k, клип ±1.0, кривая привода 1.0→√2/4.
   Уточнено: `c` теперь корректно берётся по индексу 0..128 (у старого
   `MnMDistReal.h` был выход за границы таблицы при idx>128 — UB!).
2. **`dsp/MnMFilter24.h`** — фильтр с прошивочным путём коэффициента:
   индекс = BASE·$800−$80 + env·4·$700·|BOFS−0.5|² ± мод + WDTH·$800
   (P:$0537-$056A), кламп $6A3=1699, коэффициент из kCutoffTable1728
   (P:$143546), сглаживание дельты с округлением до 1/256 (P:$056D-0572),
   Q-интерполятор по трём банкам (P:$0629-0649), 2 SVF-петли ×8×2 кадров.
3. **`dsp/MnMVoiceChain.h`** — СКВОЗНАЯ post-voice цепочка: машина → AMP env →
   DIST → фильтр (со связкой drive→срез) → пан/громкость → выход. Этого блока
   раньше не было.
4. **`dsp/MnmKernelTables.h`** — 17 таблиц дословно (около 6000 слов), включая
   НОВЫЕ: kCutDiv1201 (P:$143F95), kCutMod128 (P:$144446), kCutDivA/B128
   (P:$1444C6/$144546), kQBaseCurve48 (P:$141CA7), kPanTable256×2
   (P:$143C06/$143D06). Якоря байт-в-байт проверены.
5. **Новый факт**: `dsp1_pmem.bin` отображается на P-адреса напрямую
   (слово №addr == P:$addr). Раньше считали `addr−0x100000` — из-за этого
   у части дампов были нули.
