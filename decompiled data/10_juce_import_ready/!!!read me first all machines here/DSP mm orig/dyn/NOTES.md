# FX-DYNAMIX (m16) — NOTES (компрессор)

Листинг: `03_listings/machines_page_A/16_FX-DYN_full.txt`
(init $1477DE / config $1477E5 / proc $1477E6, срез $1477DE-$14789D, 149 слов).
Майнинг: `scripts/exp_m16_dyn.py` (эмулятор DSP56300).

## Диагноз текущего порта

В 1.7.11 машина 16 — generic-динамика (не прошивка). Прошивочный DYNAMIX —
полноценный компрессор с лог-доменом и ROM-таблицами баллистики.

## Слот-карта (выведена из кода proc, дескриптор обрезан)

p0=ATK, p1=REL, p2=THRESH, p3=MIX, p4=RATIO, p5=OUT, p6=ENV, p7=INP
(машинный параметр i = r6+$4+i).

## Законы (адреса листинга — см. шапку MnmDynExact.hpp)

- INP: 4·(k/127)² ($1477EA-$1477F1).
- Детектор: потсэмпловый max квадратур L²/R² (mpy + maxm, $1477FA-$147802)
  → X:$61.. — пиковый follower.
- Огибающая: one-pole на 48-бит стейте $15, коэффициент из ROM-таблицы
  X:$1446C6 по индексу ENV×128 ($147803-$147816).
- Лог-домен: clb/normf нормализация; мантисса×512 → лог-кривая X:$1444C6
  (512 слов, РЕАЛЬНЫЙ дамп); экспонента → второй-region таблица ($14781D-$14782B).
- THRESH: p2·$D00000·2 + $320000·2 в лог-единицах ($14782C-$147831). Ниже
  порога — линейно (эмулятор: out = 0.52·amp до amp≈0.7 на дефолтах).
- RATIO: наклон = ($40 + p4·$C04000)·2 — ОТРИЦАТЕЛЬНЫЙ (gain падает с
  перебором порога) ($147833-$14783A). Эмулятор: gain $0177B3 → $000433 при
  p4 0→127 на amp=0.9.
- Гейн: кламп + asr #$7 + rnd → экспонента 2^x через ROM X:$140000 (та же
  2048-таблица, что питч FM/BBOX) со знаковым динамическим сдвигом
  ($14783B-$147849).
- Баллистика: ATK/REL коэффициенты из ROM X:$1446C6 / X:$144746
  (attack 1581119→9125, release 173380→3014, k=0 самый быстрый); выбор
  attack/release сравнением target vs current ($147862-$147871).
- MIX: wet·(127−k)/127 + dry·k/127 ($147883-$147889).
- OUT: сухой путь = OUT²·$7F8000·2 + $8000·2 ($147887-$14788F).

## Честные границы

- [РЕКОНСТР.]: точная 48-бит парность стейтов (x:$11/y:$11, x:$15/y:$15) —
  восстановлена по порядку move; законы подтверждены эмулятором.
- Знаковый заворот лог-кривой на горячем входе (мантиссная таблица переходит
  через ноль на индексе 256) — поведение прошивки, сохранено (реальная
  таблица в MnmDynExactTables.hpp).

## A/B

DSP MODE → FX → режим `ex` на машине 16 (DYN): mnm = generic, ex = прошивка
(пиковый детектор + лог-домен + ROM-баллистика).
