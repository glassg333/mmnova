# МОДУЛЬ: Track Delay + EFX envelope (P:$0939–$0B4C) — Monomachine OS 1.32B

Файлы:
- `MnmTrackDelay.hpp` — ядро (бит-точный порт)
- `mnm_trackdelay_tables.h` — ROM-таблицы DSP1 (извлечены из dsp1_pmem.bin)
- `test_mnm_trackdelay.cpp` — тест (сравнение с эталонными векторами)

## Что это

Пер-трековая стадия эха/EFX из DSP1-ядра. НЕ машина: в прошивке машины-дилея
НЕТ («DLY» = 0 вхождений; m32 = DPRO-DDRW, m33 = DPRO-DENS — атрибуция старых
листингов была ошибочна). Настоящий дилей — глобальная стадия тракта, исполняется
для каждого трека в хвосте пост-цепочки ядра.

## Разметка блоков (все верифицированы слово-в-слово на эмуляторе)

| Блок | Адрес | Что делает | Верификация |
|------|-------|------------|-------------|
| EFX envelope | $04A8–$04F5 | ATK=tblA[EQF], DEC=tblB[EQG], SUS=SRR², REL=tblB[DTIM] | iter 24 (exp24_echo) |
| Длина: цель | $0985–$09A9 | gate T1[LPQ·64]·TEMPO·$791FD0·32 ≥ $4000 → target = P$2A·T2[LPQ·64]·$21D10 | iter 24+26 |
| Длина: глайд | $09CB–$09EE | L += 0.1·(target−L)/кадр ($0CCCCD/$733333, словесно lo-unsigned/hi-signed) | exp24e: α=0.1 байт-в-байт |
| Позиция чтения | $09AB–$09C9 | слюв к (write−length), кламп ±4 слова/кадр (tape-style retune) | iter 24 |
| Копии банков | $09FA–$0A35 | указатели L:$C2/$C4/$C5; Y:$0000+→X:$62–$83, Y:$4000+→X:$40–$61; свап по знаку (FILT ATK−0.5) | данная сессия |
| Гребёнка тапов | $0AEA–$0B13 | 17 тапов L:$90–$A0 (шаг = 1/длины, «дышит» с делэем) + func_000397 | iter 22 T1/T2/T3 |

| Мастер-микш | $0B33–$0B49 | outs = (bus + L2)·mod[k]; echo[k] = asr1(outs[2k]+outs[2k+1]) → X:(X:$2C9)+ | iter 22 T6 |
| СТАДИЯ-2 (ФИЛЬТР ФИДБЕК-ЛУПА) | $0A5D–$0AD0 | три вращающиеся цепочки L1/L2/L3 + DP | iter 18 (384/384) |

## ОТВЕТ НА ВОПРОС ПРО ФИЛЬТР ФИДБЕК-ЛУПА — ДА, НАЙДЕН

Это **стадия-2** ($0A5D–$0AD0). Кольцо эха замыкается через неё:

```
шина X:$00–$1F → L1 → L2 → L3 → DP(глубина) → гребёнка 17 тапов → func_397
   ↑                                                              ↓
   └────────── возврат из кольца Y:$0000+/$4000+ (копии $09FA) ←──┘
```

Коэффициенты:
- c1 = LP[$144AC7][BOFS] — «EFX Delay FLT Base» ($51E; ColdFire пишет в ячейку
  $516, ядро читает её как индекс кривой)
- c2 = LP[$144AC7][WOFS+BOFS] — «Delay FLT Width» ($51F→$517): «LP — раб, следует
  за HP» (цитата мануала — в коде это буквальный индекс Base+Width)
- c3 = $144B48[(длина)>>17] — временная рампа: резонанс «едет» вместе с длиной
- DP: depth = (2·|ATK−0.5|)², KILL-гейт при фазе 4 AMP-конверта

Официальные имена ручек подтверждены MIDI-спекой (mn_midi.csv): CC86 = «EFX Delay
FLT Base», CC87 = «EFX Delay FLT Width».

## Сюрпризы прошивки (важно для порта)

1. **SRR ($51A) — НЕ биткраш в DSP1-ядре.** Прочтения $51A в ядре: ТОЛЬКО EFX-
   конверт ($04C9/$04DE): SUS = SRR². Замер с реальной машиной (GND-SIN) на
   полном фрейме: выход идентичен при SRR=0/64/127 (exp41_srr_test). «Биткраш»-
   поведение на железе — следствие SUS=0: эхо глохнет после DEC (это и есть
   слышимый эффект ручки в эхо-пути).
2. **DSND ($51C), DFB ($51D), DBAS ($51E) ядром НЕ читаются.** Send/feedback
   применяет ColdFire-микшер; база длины приходит готовой в хост-ячейку P$2A.
   Формула DTIM/DBAS/TEMPO→P$2A в DSP-прошивке ОТСУТСТВУЕТ (это main OS).
3. **DTIM ($51B)** в ядре читается только как индекс кривой RELEASE EFX-конверта.
4. Таблицы $144BC9/$144C49 = T1[i]=(i+1)/256 и T2[i]=1/(i+1) (исправление
   итерации 24: это НЕ нотные деления).

## Контракт модуля

```cpp
mnm::td::TrackDelayCore core;
mnm::td::TrackDelayCore::Params p;
p.eqf/eqg/srr/dtim = значение<<16;      // $518-$51B
p.dsnd/dfb/dbas/dwid = значение<<16;    // $51C-$51F (dsnd/dfb/dbas — прозрачно)
p.filtAtk/filtDec = <<16;               // $514/$515 (DP depth + свап банков)
p.bofs/wofs = <<16;                     // $516/$517 (фильтр фидбек-лупа)
p.lpq = <<16;                           // $513 (индекс гейта/таблиц длины)
core.tempo = BPM<<16;                   // $523
core.lenHost/lenHostHi = P$2A (48-бит); // хостовая длина (из DTIM/BAS/TEMPO)
core.hostC4 = Y:$C4; core.outBase = X:$FF; core.echoPtr = X:$2C9;

core.processFrame(p, bus32, outL, outR, echo16);
```

bus32 = 32 слова (L0..L15, R0..R15) — шина трека после машин/фильтра/AMP
(в прошивке это X:$0000–$001F на входе $0B33).

## Что осталось хост-стороны (вне DSP-дампа, задокументировано)

- формула P$2A (ColdFire: DTIM/DBAS/TEMPO → длина в словах) — лид №3 итерации 26;
- точка возврата DFB-суммы в кольцо (хост-микшер).
