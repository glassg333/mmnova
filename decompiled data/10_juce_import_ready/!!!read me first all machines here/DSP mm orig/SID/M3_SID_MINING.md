## Машина
- INIT $14636F: обнуление $19/$1B-$1F; Y:($1A) = $19B5 (LFSR-семя)
- CONFIG $14637A: PWRS(Y:$6) ≥ 0.5 → Y:($19) = 0
- PROC $146382, один 16-сэмпловый кадр

## Расшифровка блоков
1. **Частота** ($146382-90): A>>15 → a0; macuu $FD9FB3; lsr#5; asl#4 → шаг;
   обновление Y:($16) только если WAVE(Y:$7) < $666666 (0.4).
2. **Машинная волна** ($146391-C2): индекс = (MFRQ>>6 + $400)>>11 & $7FF читает
   X:$140000+idx — это страница machine-wave (в железе загружается хостом
   ColdFire во время работы, в ОС отсутствует!). Значение масштабируется
   $20B40 и mpyuu $FD9FB3 → вклад в фазовый инкремент (y0).
   В MSRC ≥ 0.5 вклад = $2000×MFRQ + $800.
3. **Фазовый пробег** ($1463C3-E4): две 48-бит фазовые цепочки Y:($17)/($18),
   191 шаг (MOD ≥ 0.5, с гашением переноса bclr #0,b2 / clr a ifcs) или
   192 шага (MOD < 0.5, цепочки a/b меняются местами в накопителях).
   Промежуточные фазы пишутся в X:$00-$BF / Y:$00-$BF (m0/m4 = $BF → 192 слова).
4. **Вейвформ** ($1463E5-DD): бит 21 MOD → $146493 (взвешенное чтение буфера);
   иначе WAVE(Y:$7): < 0.1 → $1464C0 LFSR (rol/eor x1=$658100, семена $1A/$24,
   запись через n4=+4 — каждое 4-е слово!); ≥ 0.1 → $14647D (треугольник:
   abs; sub $40(=0x400000 imm8<<16); asl — 96 пар). Ветви $146474/$1464A1/$1464DE
   НЕДОСТИЖИМЫ: цепочка bcs монотонна (первый `bcs $14647D` ловит всё ≥ 0.1;
   «остаток» < 0.1 не может пройти пороги 0.2/0.3/0.4) — мёртвый код прошивки.
5. **Фильтр** ($1463FB-46B): 10-словное колесо коэффициентов на Y:$F0+
   (m5=$9 → кольцо из 10, шаг n5=+2; с $14644B шаг становится +1 — «y:(r5)+»),
   состояния $1B-$1F зеркалируются в X:$F0-$F6 (r1/r2/r3 = $F0/$F2/$F4),
   x1 = $6186, макрос macr = mac + округление. 16 итераций → 32 слова выхода
   Y:(r7)+ = 16 сэмплов × (L,R) (пары одинаковые).
6. **Восстановление** ($146461-46A): $1B-$1F из X:$F0-$F4.
