## MnmReverb.hpp — что верифицировано

Бит-в-бит совпадает с эмулятором оригинального ROM на всех фреймах до момента
первого возврата LFO-гребёнок (vf38+):
- входная стадия `2·INP²·(bus[2k]+bus[2k+1])`
- 5 аллпассов (47/67/101/149/223), обратная связь `fade·(0.35+0.05·DEC)·coef_i`
- гребёнки 1–4: one-pole демпфирование (DAMP-таблица)
- матрица 4 секций (DEC-таблица, ротация коэффициентов по k mod 4)
- запись в линии `line += matrix + allpass·$155556`
- гейт-конверт (утечка 0.99884/0.000127, рампа атаки $147AE·16 / спада ·$7EB852,
  кламп на 1.0 через Data Limit Checking)
- wet = matrix·gate_ramp
- HP/LP-секции ($144AC7[HP], $144AC7[LP])
- финальный микс `4·(MIX·wet + (1−MIX)·INP²·dry)`, dry = bus[k] последовательно

Расходится (vf38+, ≈20% слов): точный тайминг/амплитуда возврата гребёнок 5/6
(LFO-интерполированный тап: `tap = rd + (sin>>21)`, `frac = (sin<<2)&$FFFF`).
Первый кандидат для следующей сессии: сверка по-семпловой истории аллпасс-выхода
(Y:$0-$1F на момент записи в линию, $145553-$145562).

## Фиксы эмулятора DSP56300 (эта сессия — КРИТИЧНЫ ДЛЯ ВСЕХ МАШИН)

1. **Modulo addressing для не-степенных-2 длин** (`upd_r`): старая формула
   `((r&m)+Δ)%(m+1)` работала только для масок 2^k−1. Реверб использует длины
   47/67/101/149/223/2679/2447/1827/1637 — теперь корректное правило пересечения
   границы буфера (линейный проход base..base+m с заворотом на краях).
2. **Data Limit Checking** (FM §5.4.1.2): запись аккумулятора в память/x0/x1/y0/y1
   сатурируется до $7FFFFF/$800000. Без этого гейт-рампа реверба уходила в
   пилообразный самозахват вместо клампа на 1.0.
3. **8-битный immediate в MOVE** (`#$xx` без маркеров `>`/`<`):
   - в data-регистры (x0/x1/y0/y1/части/память) — **левое выравнивание** `xx<<16`
     (доказательство: `move #$40,y1` = 0.5 в HP-фильтре реверба);
   - в аккумуляторы A/B — **raw** (доказательство: див-идиома ядра P:$07A0
     `move #$8,a; 24× div y0,a` требует делимое = 8);
   - в R/M/N — **raw** (`move #$10,n4` = шаг LFO).
   ALU-immediate (cmp/add) — raw.

## Очередь машин (порядок ТЗ)

m13 REVERB (1257 сл.) → m1 GND-SIN (159) → m2 GND-NOIS (193) → m3 SID-6581 (323)
→ m4 SWAVE-SAW (322, unison UNIL/UNIW/UNIX + SUB1/SUB2) → m5 SWAVE-PULS (338,
unison + PW/PWAD/PWRS) → m14 SWAVE-ENS (462, PCH2/3/4 + CHRL/CHRW) →
m6 DPRO-WAVE (258) → m11 VO-6 (2267, формантный VOC1/VOC2/VOIC/CONS/CLEN/CVOL —
замена 3 грубых bandpass в порту).
