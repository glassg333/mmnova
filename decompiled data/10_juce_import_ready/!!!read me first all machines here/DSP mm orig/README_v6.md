# DSP_New v6 — FX-REVERB (m13) бит-точное ядро + GND-машины + статус SWAVE

Дата: 2026-09-25. Источник: OS 1.32B, DSP1 P-memory (репозиторий mmnova,
`decompiled data`). Всё автономно: каждый модуль = отдельная папка,
интеграции в структуру плагина нет — добавление построчное по README.

## Состав поставки

|-------|-----|----------|

## ШАГ 1 — файлы (без правок сборки)

Скопировать папки целиком (например, в `Source/DSP_New/`):
- `reverb/` — 4 hpp + NOTES.md
- `gndsin/`, `gndnois/` — по одному hpp

Таблицы не требуют внешних файлов: DEC/DAMP/FIRPool/Sin уже в hpp
(извлечены из dsp1_pmem.bin скриптами, прикладываются дословно).

## ШАГ 2 — FX-REVERB (m13): режим "ex" в `Source/NovaDSP.h`

Ветка `id == 13` сейчас = generic `juce::Reverb`. Заменить на:

```cpp
#include "DSP_New/reverb/MnmRevExact.hpp"
// в классе машины:
mnmrev::RevExact revEx;
bool revExArmed = false;
```

Контракт ядра:
- `setParams(dec, damp, gate, mix, hp, lp, inp)` — 0..127, слоты DEC DAMP GATE MIX HP LP INP;
- `process(const int32_t* in, int32_t* out)` — **блоки по 32 сэмпла** (24-bit);
  при хостовом буфере не кратном 32 — накопительный буфер;
- `reset()` — после смены пресета/машины.
- ПАРАМЕТР GATE в 1.32B слышимо инертен (см. reverb/NOTES.md) — передавать как есть.

Рекомендация: включать ядро флагом `ex` (как в шагах v1-v3) для A/B
против generic-juce, ветку 13 не переписывать до проверки.

## ШАГ 3 — GND-SIN (m1) / GND-NOIS (m2): режимы "ex"

```cpp
#include "DSP_New/gndsin/MnmGndSinExact.hpp"
mngnd::GndSinExact sinEx;    // reset() + process(pitch48, out32)
// pitch48 — 48-битное слово питча кернела (a1:a0), как передаёт диспетчер.
// Выход: 32 слова = 16 сэмплов, каждый записан дважды (L/R паттерн ROM).
```

m2: `mngnd::GndNoisExact` — `reset()` + `process(out32)`; LFSR бит-точен,
tilt-цепочка — черновая (см. комментарии в hpp).

## Что изменилось в инструментарии (для следующих сессий)

- `dsp_emu.py::upd_r` исправлен: modulo для не-степенных длин (кольца реверба
  $A76/…) — base = r & ~(next_pow2(m+1)-1). Прежняя формула теряла бит 20 и
  схлопывала указатели ≥ $100000. Степенные кольца (флейнджер/хорус) — без изменений.
- Эксплореры exp70-exp78: полная расшифровка m13 (таблицы DEC/DAMP/ER,
  warmup 256 блоков, «мёртвые» записи гейта, аддитивная инжекция W·1/3).

## Открытое (бэклог)

- m2 tilt-FIR довести до бит-точности (структура из листинга есть).
- m4/m5/m6/m14 (SWAVE): законы расшифрованы, ядра — 1-2 сессии (SWAVE_STATUS.md).
- m3 SID-6581, m11 VO-6 (формантный синтез) — 2-3 сессии.
- m32 DDRW / m33 DENS (это НЕ «FX-DLY/FX-EXT», см. machine_map_fix).
