# FX-RINGMOD m17 — режим "ex" (прошивочное ядро RingCore)

## Что здесь
- `MnmRing.hpp` — `monomachine::mnm::RingCore`, восстановлен из листинга
  машины 17 (P:$14789E-$147B37, `03_listings/machines_page_A/17_FX-RING_full.txt`)
  и проверен прогонами в эмуляторе (`exp_m17_ring.py`). Файл без изменений
  из поставки `mmnova_ringmod_m17_2026-09-24.tar.gz`.

## Прошивочные законы (все с адресами)
- **Несущая**: частота приходит в регистре A на входе PROC ($1478C7) —
  кейтрек от ноты дорожки; наклон 0.18565 ≈ 8192/44100 единиц фазы на
  сэмпл; кламп 0x4074 = 16500 Гц. Ручки TUNE на машине НЕТ: слот 2 в
  дескрипторе = `---` (fx_descriptors_region.bin @0x370) — «TUNE» был
  изобретением старого порта.
- **INP**: 4·(INP/127)² (единица @64) — квадратичный закон входа ($147A2A).
- **Веса источников**: WAVE = (127−2·WAVE), кламп 0; EXT = 127−EXT.
- **Два источника несущей**: хелпер func_0003D3 с семенами ±0.707 и LUT
  со смещением −0x800; WAVE-морф синус → квадратура.
- **Шины L/R в квадратуре** (отводы ±2048 слова таблицы $14A000).
- **MIX**: сглаживание однополюсником (r6+$54), out = dry·(1−MIX)+wet·MIX.

## Слоты (дескриптор m17)
`WAVE, EXT, ---, MIX, ---, ---, ---, INP` — слот 2 на железе не используется,
несущая кейтрекается.

## Отличия от текущего generic (MonomachineRingMod 1.7.11)
- Несущая: generic — 440·2^((pitch−69)/12) от выдуманной ручки TUNE;
  прошивка — кейтрек ноты дорожки + кламп 16500 Гц.
- Вход: generic — линейный; прошивка — 4·(INP/127)².
- WAVE: generic — sin/квадрат/треугольник «примерно»; прошивка — морф
  синус→квадратура через LUT с квадратурными шинами L/R.
- MIX: generic — мгновенный; прошивка — сглаженный однополюсником.

## Тест
`g++ -std=c++17 -O2 -I ringmod -o t tests/test_mnm_ring.cpp && ./t`
→ `ALL RING CORE SANITY CHECKS PASSED` (частота 999.5→1000, кламп
16499.9/16500, INP=0 → тишина, EXT=127 → кольцо соседним каналом, MIX=0 → dry).

## Примечание про ручку TUNE
В режиме "ex" слот 2 игнорируется ядром (несущая кейтрекается). Правка
описания ручки в `machine_definitions.hpp` (TUNE → "---") — OPTIONAL,
в шаге 12 консолидированных патчнотов помечена как необязательная: если
хочется сохранить идентичность UI между режимами, описание можно не трогать.
