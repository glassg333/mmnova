# FM-машины m8/m9/m10 — режим "ex" (точные законы OS 1.32B)

## Что здесь
- `MnmFmExact.hpp` — голос `FmCoreExact` (контракт API 1:1 с `MnmFm.hpp::FmCore`),
  поверх восстановленной топологии движка использует **бит-точные законы ручек**
  итераций 27–28 (`mnm_fm_exact.hpp`).
- `mnm_fm_exact.hpp` — сами законы (namespace `mnm_fm`), каждая константа
  цитирует адрес прошивки. Источник: `filter_phaser_pack/22_fm_machines`,
  верифицировано на бит-точном эмуляторе DSP56300 (fm_harness + 24-блочные
  прогоны m8/m9/m10).

## Бит-точные законы (БИТ-В-БИТ)
| Узел | Закон | Адрес |
|---|---|---|
| Таблица отношений | 24 значения, ratio = raw/2^19 (1/32…8) | P:$141A80 |
| Индекс таблицы | n = ((K·2^16+$8000)·24)>>24 | P:$145D36/DAA |
| Скрытый ×2 | ratio1 умножается на 2×finmult (канал мод-1) | P:$145DB6 `asl b` |
| 1FIN | finmult = 1+(K−64)/256 | P:$145DAE |
| Уровни | (K/64)² wrap mod 2^24 СО ЗНАКОМ (ноль ~K=90.5, инверсия выше) | P:$145DFB-$145E17 |
| Друп env | 1−((K−64)/128)⁴ при K≥64 | P:$1460AC |
| Шейпер | G = (K−64)/16 при K≥64 (гейт 64) | P:$145D8C-$145DA0 |
| 1FB | фидбек = sin_prev·K·32 единиц таблицы (8192=цикл) | P:$145DC1/$146270 |
| Квантизатор фазы | carrier += (mix>>12) единиц/сэмпл | семейство $145E48 |
| TUNE | униполярный +683·K/128 шагов $140000 (2048/октава) = 0…+397 центов | ядро $02C0-$02C9 |
| DYN 1FRQ | непрерывный K/2^19·2, кламп $7FFFFF | P:$1461E3 |
| DYN 2FRQ | (K/128)²·4 | P:$14625D-$14626A |
| DYN 1VEN | CONF-инициализация рекурсии $2C = 4·(1VEN−64)/128·1VOL (только <64) | P:$1461AB-$1461B7 |
| DYN LP | фиксированный коэффициент 64/2^23 на всех мод-путях | P:$146233/$146297/$1462D3 |

## Границы честности
- **[РЕКОНСТР.]**: размещение first-difference/шейпера внутри выборки, TONE как
  выходная однополюсная стадия (в прошивке LP стоит в мод-пути), отсутствие
  стерео-ротаторов в моноварианте — тот же уровень допущений, что у текущего
  mnm-ядра 1.7.11.
- **DYN (m10)**: по трём независимым доказательствам итерации 28 кросс-FM
  структурно неслышим (d(фазы) несущей идентичен при mods 0/MAX; корреляция
  выходов 1.0000 по экстремумам всех ручек; LP $40 + >>12 ⇒ mix>>12 ≡ 0) —
  слышимый выход = чистая синусоида несущей. Законы сохранены для полной
  бит-точности internals.
- Прошивочный выход FM = ±16 слов (гейн добирает AMP-стадия ядра $04A8);
  в плагине уровень нормирован к линии — множитель не применяется (на тембр
  законов не влияет).

## Что это исправляет против mnm (MnmFm.hpp 1.7.11)
1. Отношения были на выдуманной 32-значной шкале с плавающей синусоидой —
   теперь родная 24-значная таблица + точный индекс.
2. Уровни были линейными 0..1 — теперь квадратичные с wrap-через-знак
   (пропадание нуля ~90.5 и инверсия тембра выше — фирменный характер).
3. Пропадал скрытый ×2 модулятора-1 и точный 1FIN — октавное смещение тембра.
4. 1FB был линейным 0..4 — теперь K·32 табличных единиц (до ~0.5 цикла).
5. TUNE был биполярным ±2 полутона — теперь униполярный 0…+397 центов.
6. DYN: непрерывные отношения заменены на точные законы (1FRQ/2FRQ).
