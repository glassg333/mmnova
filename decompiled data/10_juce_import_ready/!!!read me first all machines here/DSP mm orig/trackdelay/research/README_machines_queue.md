# МАЙНИНГ-ДОСЬЕ: машины очереди (m13, m1, m2, m3, m4, m5, m14, m6, m11)
## Monomachine OS 1.32B, DSP1. Формат: файл-описание для поочерёдного применения.

Источник: `03_listings/machines_page_A/*.txt` (дизасм dsp56k, верифицирован 100%),
`05_descriptors/all_machine_descriptors.json` (имена ручек из ColdFire OS),
блоки ядра — из `11_decoder_v2/`, `11_stage2_model/`, `13_stage2_tail/`,
`17_delay_echo/` (пака filter_phaser_pack, итерации 11–28).

Общий контракт машин: PROC(r6 = V = страница машины = Y:$123 трека) вызывается
на каждый 16-сэмпловый блок; A = 48-бит фазовый инкремент (экспонента, см.
KERNEL_VOICE_CHAIN.md §3.3); вход шины r0; выход — 34 слова на стек Y:(r7)+
(чётные→окно L X:$97–$A7, нечётные→окно R X:$D7–$E7 через $04FC).
Параметры машины = V+$04..$0B (SYNTH A–H), значения <<16 (0..127 → 0..$7F0000).

## m13 FX-REVERB — 1257 слов, структура 100% (итерация 26)

- INIT $14538E–$1453DA, CONF = rts, PROC $1453DC–$14561B; таблицы $14562C (DEC),
  $1457B2 (DAMP), $147AE/рампы гейта.
- Параметры (r6+$4..$B): DEC DAMP GATE MIX HP LP --- INP.
- Топология: 6 гребёнок (2663/2447/1811/1621/1399/613 слов = 60.4/55.5/41.1/
  36.8/31.7/13.9 мс) + 5 аллпассов (46/66/100/148/222; k = −0.963…−0.837) +
  LFO (sin $14A000, 5.38 Гц, ±3 слова) на гребёнках 5–6.
- Законы: DEC → g аллпассов + индекс $14562C; DAMP → индекс $1457B2 (one-pole
  гребёнок 1–4); GATE → скорость max($F4240,(GATE<<16)²>>11); MIX/INP →
  out = 2·(MIX·wet + (1−MIX)·INP²·dry); HP/LP → индексы $144AC7.
- Fade-in 256 блоков (счётчик r6+$48, гейн r6+$47).
- ОСТАТОК: бит-точная верификация wet-пути. В итерации 26 выход «упирался в
  упор на первом эхе, блок 41» — подозрение на параллел-мув баг эмулятора
  (класс ошибки итерации 25: store параллельного переноса берёт pre-ALU
  значение). РЕЦЕПТ: в 05_emulator/dsp_emu.py::commit_writes проверить, что
  при dual-move «a,x:(r2)+ y:(r4)+,a» источник читается ДО ALU этой же
  инструкции. После фикса прогнать exp26 сетку A/B снапшотов (README_reverb §8).

## m1 GND-SIN — 159 слов ($144CC9–$144D99)

- INIT: X:(V+$10) = $14A000 (база синус-таблицы 8192), Y:(V+$10) = 0.
- PROC $144CD0: фазовый инкремент A × $17C6F9 (= 0.18625) — собственный масштаб;
  фаза в L:(V+$10) (X-старшая/Y-младшая), маска $1FFF (8192 записей/период);
  16 значений $14A000+фаза пишутся в X/Y:$0000–$000F (scratch таблица указателей);
  интерполяция 2 точек (mpysu/macsu, do #<$8) → 16 сэмплов a/b (L/R);
  pushing a,a,b,b → Y:(r7)+.
- ХВОСТ ($144D21–$144D4D): 2-модовый выходной резонатор. Коэффициенты
  мода A: $1E454E/$5B75B8; мода B: $0CFCE3/$2BC9CA (переключение по
  y:(r6+$5)?? — порог в $144E5B-подобных ветках; стейты y:(r6+$14/$15/$1c/$1d)).
  Выход = 4-матрица (mac y0,x0 / mac -y0,x0 …) с x0 = $40 — wet/dry кросс.
- Параметры: только TUNE (V+$0B). SIMPLest машина — эталон для теста тракта.

## m2 GND-NOIS — 193 слова ($144D9A–$144E80)

- INIT: Y:(V+$10) = $A (seed), Y:(V+$11) = 1 (инкремент).
- PROC $144DA2: генератор шума — 16-шаговая аддитивная цепочка
  (b += x1; x1 = b1; …) с сохранением 16 значений в X:$6–$15 (кольцо, m-рег) —
  детерминированный PRBS-подобный шум, seed/step в V+$10/$11.
- Ladder: таблица коэффициентов в коде по r2 = $144E7A (10 слов пар);
  5 полюсов × 2 канала (do #<$10, макро-цепи mac y0,x0 …) — состояния
  V+$12/$13/$14 (L) и V+$15/$16/$17 (R); выход morph по V+$4 (ST) между
  двумя режимами ($144E26–$144E3C: bpl/asl ветка, $400000 = порог 0.5).
- Финал ($144E50–$144E71): кросс-матрица a/b c y0 = 64+64·V+$4, выбор ветки
  по V+$6 (STON) ≥ $400000; запись в Y:(r7)+ (16+16).
- Параметры: ST (V+$4), RED (V+$5), STON (V+$6), TUNE (V+$0B).

## m3 SID-6581 — 323 слова ($14636F–$1464FB + хвост в 10_FM-DYN_full)

- Атрибуция исправлена (итерация 27/28): секция $14636F–$1464FB («5-позиционный
  селектор 1VEN» в листинге 10_FM-DYN) = КОД m3 SID: селектор $1463E8 читает
  WAVE-страницу SID; дескриптор: слоты m3 = $14636F/$14637A/$146382.
- Параметры: PW, PWAD, PWRS, WAVE, MOD, MSRC, MFRQ, TUNE.
- Структура: классика SID 6581: пилообразный/треугольный/импульсный осц +
  PW (скважность), ADSR-подобный PWAD/PWRS (attack/decay ширины импульса? —
  PWAD = PW attack, PWRS = PW release — см. селектор $1463E8), WAVE-селектор,
  ring-mod от MSRC/MFRQ.
- ПОРТ: осцилл-ядро = фазовый аккумулятор (маска 8192 от $14A000-подобных
  таблиц) + 5-позиционный селектор $1463E8. Требует отдельной сессии на
  полную транскрипцию (323 слова, таблицы в $14636F–$1464FB).

## m4 SWAVE-SAW — 322 слова ($145932–$145AB4). «Пила» = wavetable-сканер

- Параметры: UNIL, UNIW, UNIX, ---, SUBX, SUB1, SUB2, TUNE.
- Таблицы: X:$140000 (2048 — питч-волна 0.5·2^(i/2048)) и X:$1407FF (2048 —
  пилообразная волна скана); константы: $17C6F9 (0.18625 — масштаб инкремента),
  $56982B, $7EB852, $17A6, шаги $1407FF-скана.
- Структура PROC $14594A:
  1) y:(V+$5) → mpyri $80 / $40 = ДВА фазовых инкремента (unison detune L/R!);
  2) два do #<$2 блока ($145982–$145992, $145994+) — чтение таблиц
     X:($101BFB/101CFB/101B7B/101C7B)+r0 (окна модуляции питча pre-voice!)
     через mpysu/dmac — интерполяция фаз 2 голосов unison;
  3) скан волны: $1459A6+: X:$140000/$1407FF, индекс = фаза>>11 (маска $7FF),
     кросс-интерполяция пар (r3+n3/r2+n2) — движение по волне;
  4) unison-зона $145A06–$145A42: состояния V+$1A/$1B/$1C (накопители фаз
     3 голосов: UNIL/UNIW/UNIX = level/width/mix модуляции фазы), чтения
     V+$2D/$2E/$2F — скейлы; V+$1F/$22 — фидеры;
  5) SUB-осцилляторы: SUBX (V+$9 — кроссфейд суб), SUB1/SUB2 (V+$A/$B —
     инкременты суб-голосов = /2 /4 от основного — октава/квинта суб);
  6) суммирование 3 unison-голосов + 2 суб → пуш в Y:(r7)+.
- ЗАКОН UNISON (из кода): UNIL = расстройка уровней пары, UNIW = ширина
  detune (добавка к фазовому инкременту, $80/$40 масштабы), UNIX = кросс-
  микс 2-го голоса.

## m5 SWAVE-PULS — 338 слов. Импульс + unison

- Параметры: UNIL, UNIW, SUB1, SUB2, PW, PWAD, PWRS, TUNE.
- Ядро: фаза (V+$14/$15 пары) + сравнение с PW-порогом → биполярный импульс;
  PWAD/PWRS = авто-модуляция ширины (attack/release кривые — константы
  $F8F5C3/$7D70A4/$333333/$2B1100 — рампы ширины); unison — та же схема, что
  m4 (два инкремента из TUNE, mpyri $80/$40); SUB1/SUB2 = суб-импульсы.
- Константы $400000/$200000 = пороги компаратора (±0.25/0.5) — форма пульса.

## m14 SWAVE-ENS — 462 слова. 4-голосый ансамбль + хорус

- Параметры: PCH2, PCH3, PCH4, WAVE, PW, CHRL, CHRW, TUNE.
- Голоса 2–4: собственные фазовые аккумуляторы (V+$18+ зона), инкременты =
  основной инкремент × (1 + PCH2/3/4 detune-кривая); WAVE = выбор волны
  (таблицы X:$140000+), PW для импульсной волны.
- Хорус: CHRL (level), CHRW (width) — модуляция задержки голосов по синусу
  $14A000 (квадратура — константы $56982B/$7F5C29/$F62183 = рампы глубины);
  микс 4 голосов + хорус → выход.
- Константы: $200000 (0.25 — порог PW), $FFFE70/$FE4226 (−0.0086/−0.123 —
  one-pole коэффициенты хорус-модуляции).

## m6 DPRO-WAVE — 258 слов. Wavetable + sync

- Параметры: WAVE, WP, WPM, WPRS, SYNC, SFRQ, ---, TUNE.
- WAVE = номер волны (банк таблиц), WP = позиция скана, WPM = скорость скана,
  WPRS = сброс скана, SYNC = жесткий синхронный сброс фазы от SFRQ
  (sync-частота): фаза ≥ SFRQ-порог → сброс (классический osc-sync).
- Константы: $F9F156/$EE4BAF/$C652AD/$939958/$9023EC — рампы скана;
  $555555 = 1/3 (ширина сегмента волны).

## m11 VO-6 — 2267 слов ($1464FC–$1469BF+). Формантный синтез (вокодер)

- Параметры: VOC1, VOC2, V-SW, VOIC, CONS, CLEN, CVOL, TUNE.
- Самая большая машина. Таблицы-форманты: 4 банка P:$1001D1/$1007F1/$100E11/
  $101431 (по 1568 слов) — читаются кодом $146F9D–$1470EB (KERNEL_VOICE_CHAIN §7).
- Замена «3 грубых bandpass» в текущем порту: реальная структура =
  формантный банк: VOC1/VOC2 = центральные частоты двух формант (индексы
  банков), VOIC = голос/глухой микс (voiced = пилообразный источник от
  питча; unvoiced = шум m2-генератора), CONS = доля консонансов (шумовой
  кроссфейд), CLEN = длина формантной рампы, CVOL = громкость голоса.
- 20 чтений r6+$6 (V-SW) и 12 чтений r6+$A (CONS) — селектор волны/источника
  и консонансный микс — самые «живые» ручки.
- ПОРТ: batч-транскрипция 2267 слов — 2 полные сессии. Скелет: 2 формантных
  банпаса (biquad из банков) + питч-источник + шумовой источник + микс.

## Приоритет применения другим агентом

1. m13: починить параллел-мув в эмуляторе → бит-точная верификация wet-пути
   (рецепт выше) → машина закрывается на 100%.
2. m4/m5: порты осцилляторов (структура описана, таблицы на месте) — самый
   быстрый способ закрыть «пилы/пульс».
3. m14: ансамбль = 3 копии осциллятора m4 + хорус — после m4.
4. m1/m2: транскрипция по досье (машины маленькие, 1–2 часа).
5. m3/m6: средние, 1 сессия каждая.
6. m11: скелет формантного банка + gradual-верификация (2 сессии).

## Клетки-ловушки (общие для всех машин)

- r6 в PROC = V (машиная страница). V+$04–$0B = параметры; V+$10+ = стейты
  машины (сохраняются между блоками); V-$28+ = страница AMP/FILT (ядро).
- Выход машин: ТОЛЬКО через y:(r7)+ pushes — 34 слова (16 L + 16 R + 2).
  Чётные слова стека → X:$97-$A7, нечётные → X:$D7-$E7 (распределение на $04FC).
- Таблицы X:$140000/$140800/$14A000: $140000 = питч-волна (2048),
  $14A000 = синус 8192 (восстановлен, в bin-дампе отсутствует).
- Питч: A на входе = экспоненциальный инкремент фазы; фазовые аккумуляторы
  машин — 48-бит L-пары (X=hi, Y=lo).
