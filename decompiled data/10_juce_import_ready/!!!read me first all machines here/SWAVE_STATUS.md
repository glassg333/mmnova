# SWAVE-семейство (m4 SAW / m5 PULS / m6 WAVE / m14 ENS) — статус декодирования

Дата: 2026-09-25. Листинги: `04_SWAVE-SAW_full.txt` (322), `05_SWAVE-PULS_full.txt`
(338), `06_DPRO-WAVE_full.txt` (258), `14_SWAVE-ENS_full.txt` (462).

## Что уже добыто (T1, из листингов)

- **Коэффициент питча осцилляторов**: константа `$17A6` / `$56982B`
  (пара у $14595F-$145961 в m4) — та же схема «дробное приращение фазы
  из питча кернела», что у GND-SIN (`$17C6F9`).
- **Вейвтейбл ROM**: указатель `$140000` (r3) + `$1407FF` (r2) — маска
  таблицы `$7FF` (2048 слов); чтение `x:(r3+n3)` / `x:(r2+n2)` с индексами
  из фазы. Главная таблица: `04_tables/P_101a7b_SWAVE_wavetable_main.bin`.
- **Unison (4 голоса)**: таблицы развёртки PCH2/PCH3/PCH4/PCH5
  (`P_101afb/b7b/bfb/cfb`, по 128 слов, значения в долях октавы — например
  PCH2[0..15] = 0.125, 0.132433, 0.140308, 0.148651, …). В proc читаются как
  `x:(r0+$101bfb)`, `x:(r0+$101cfb)`, `x:(r0+$101b7b)`, `x:(r0+$101c7b)` —
  голоса 2/3/4 (+5) добавляются к базовому голосу, индекс = нота
  (таблица пер-нотной расстройки, 128 нот).
  m14 ENS: 4-голосный ансамбль PCH2/3/4 + хорус CHRL/CHRW.
- **Unison-параметры**: UNIL (уровни голосов), UNIW (ширина/детюн),
  UNIX (распределение) — читаются как y:(r6+$5) с масштабами `$80`/`$40`
  (`mpyri #>$80 / #>$40`, $145976-$145979).
- **Инициализация m4**: 48 слов состояний обнуляются (rep #$30 / rep #$f),
  x:$C/$F = 0, y:(r6+$27) = $88, y:(r6+$2d) = $80, указатели таблиц
  $14A000 (x:(r6+$d), x:(r6+$10)).
- **Выход**: l:(r4)+/l:(r5)+ — 48-бит пары (L/R каналы, стерео-раскладка
  голосов unison по L/R).

## Что осталось до ядра (оценка: 1 сессия на m4+m5, 1 на m14+m6)

1. Полная трасса proc m4 в эмуляторе (как exp70-78 для реверба): свипы
   UNIW/UNIX/PTCH → законы голосов.
2. Интерполяция вейвтейбла (линейная, таблица 2048) и SUM1/SUB1/SUB2
   (суб-осцилляторы) — ветки $1459A2+.
3. m5 PULS: PW/PWAD/PWRS — ширина пульса и его модуляция, скважность.
4. m14 ENS: хорус CHRL/CHRW (та же LFO-машина, что у m15 chorus — уже
   добыта в v3) поверх 4 голосов.
5. m6 WAVE: DPRO-вариант — таблица `$101d7b` (DPRO_wavetable_ref).

## SID-6581 m3 (323 слова) — статус

Листинг: `03_SID_full.txt`. Структура типовая: 3 осциллятора (пила/квадрат/
треугольник/шум по коммутации), кольцевая модуляция, огибающая ADSR.
Расшифровка коммутаций waveform = ветвления по y:(r6+$n) — 1 сессия.

## VO-6 m11 (2267 слов — крупнейшая машина) — статус

Формантный синтез: VOC1/VOC2 (два формантных банка), VOIC (гласный выбор),
CONS/CLEN (согласная/длина), CVOL (уровень). В порту NovaDSP.h сейчас
3 грубых bandpass. Требует: карту формантных таблиц (P:$1001d1 dispatch,
P:$1007f1 table2 — уже в 04_tables), трассу вокального цикла,
2-3 сессии (уровня реверба).

ПРИМЕЧАНИЕ: m1 GND-SIN ядро готово на 95% (инкремент/рампа/фаза бит-точны,
интерполяция — известная дельта, см. NOTES в MnmGndSinExact.hpp).
m2 GND-NOIS: LFSR бит-точен (проверено эмулятором), tilt-FIR — черновик.
