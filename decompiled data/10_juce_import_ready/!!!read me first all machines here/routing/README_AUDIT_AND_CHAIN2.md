## 0.1 ПОЧЕМУ РАНЬШЕ «НЕ СХОДИЛОСЬ» (три бага тест-харнеса, ядро было верно)

1. Poke-протокол: пробелы из frames.txt ('X'/'Y') шли в wr() как есть, а wr()
   сравнивает с МАЛЕНЬКИМ 'x' → ВСЕ X-покы писались в Y-память.
2. Парсер expected.txt: после разбора ячеек снапшота поток оставался в
   std::hex → номер кадра следующего SNAP читался как HEX ("SNAP 16" → 22).
   Поэтому «расхождение f22» было сравнением кадра 22 со снапшотом кадра 16.
3. Память: init.txt — РАЗРЕЖЕННЫЙ дамп (только ненулевые ячейки). Эталон же
   работает с ПОЛНЫМ образом RAM (load_xy_memory: dsp1_xmem/ymem.bin, включая
   нулевые ячейки x:2C0-2C9 и X-страницу трека x:400+). Теперь каждый датасет
   несёт полный образ: full_x.bin/full_y.bin (exp65_dump_fullmem.py).
«X-зеркало 381 ячейки» из итерации 62 было артефактом бага №1, а не семантикой.

## 2. КАРТА ТРАКА (канон, порядок исполнения ядра = OS 1.32B, P:$02EC–$0B4C)

Вход цепи: $0132 (r6 = P, r7 = $100, r5 = X:$2C3). Выход: Y:$00–$1F + мастер-шина.

| PC | Секция (имя по мануалу) |
|---|---|
| $04A8–$04F4 | машина-ADSR (только трек 0, ячейки $18–$1B) |
| $04F5–$04FE | копия выхода машины Y:$100–$121 → X:$97+/X:$D7+ |
| $04FF–$0536 | DIST драйв-энвелоп (tblA[$141800], tblE[$141A00], VOL²-индекс) |
| $0537–$05A0 | кольцо коэфф. фильтра: BASE − Y:(P+$D9) + тимбр-индекс → $143F95/$144446/$141CA7/DIV24 |
| $05A1/$05B5 | каскад 1 func_000340 (L/R, моно-флаг X:(P+$F).0) |
| $05BB–$05FE | 2× оверсэмпл halfband ($F528BD/$4A4DF0) → X:$71+ |
| $05FF–$06C1 | F3-L: тон P+$D6, EQG Y:(P+$0B), билинейный лерп $141A98/$142158/$142F06, (state+new)/2, кривая $143C06 × param0 |

| $0904–$0910 | per-sample гейн → шина X:$00–$1F |

EQ = $0789–$0859; FILTER = каскад1+HPQ; DISTORTION = F3-тембр + слот-обработчик;

## 4.1 ОБЁРТКА ДЛЯ ИМПОРТА (MnmTrackChain.hpp)

JUCE-независимый C++17 класс на ядре:
- load(dir) — chain_program.lst + full_x.bin/full_y.bin
- setSlot(m) / runMachineInit() — слот машины как в ОС
- сеттеры верифицированных ячеек страницы (DIST/VOL/PAN/BASE/WDTH/HPQ/LQP,
  AMP и FILTER env, TEMPO, machine params $2C-$33, EQG, mono, слот-хендлер)
- trigger()/clearTrigger() — TRIG-ячейка Y:P+$28 (бит0 триггер, бит7 CONF)
- processFrame(out[32]) — преамбула $00CF-$0100 → машина $0100-$02EB →
  тракт $02EC-$0B4C; возвращает мастер-шину Y:$00-$1F
Тест: test_mnm_trackchain.cpp — BIT-EXACT на D_real через публичный API.
