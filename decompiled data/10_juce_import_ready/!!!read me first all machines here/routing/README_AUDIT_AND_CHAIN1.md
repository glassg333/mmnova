## 2. КАРТА ТРАКА (канон, порядок исполнения ядра = OS 1.32B, P:$02EC–$0B4C)

Соответствие мануалу: HEADROOM for DIST = гейн-компенсация $0859+oversample-хедрум;
EQ = $0789–$0859; FILTER = каскад1+HPQ; DISTORTION = F3-тембр + слот-обработчик;
AMP ENVELOPE = $088E; VOLUME/PAN = $08D8; SRR/DELAY = $0939+ (SRR-крутилка рядом,
см. pack 10); LEVEL = мастер-микш. Порядок ядра ≺ порядок мануала — расхождений
с monomachine_manual_OS1.32 нет, «неверный роутинг» = отсутствие секций в старом порте.

## 3. ОРАКУЛ (work/chain_oracle/)

 Ground truth = сам код прошивки в бит-точном эмуляторе (dsp_emu.py, 27/27 семантики).
 3 датасета × 32 кадра: A_neutral (m1), B_hot (m1, DIST=96/RES/ENV), C_m14_handler
 (m14 + форс-arm слота $145C48 + INIT-стейт). Каждый: init.txt (память+регистры
 до кадра 0), frames.txt (покадровые pokes+инжекция синуса), expected.txt
 (выходы Y:$00–$1F + снапшоты памяти кадров 0/8/16/31), boundaries.json
 (16 границ секций, кадр 16). Протокол кадра: $00CF–$0100 (преамбула, CONF) →
 $0100–$02EB (машина; jsr (r1) на $02EB НЕ исполняется — граница) → инжекция →
 $02EC–$0B4C. Таблицы: tables_x.bin/tables_y.bin ($100000–$14C800; X≠Y!).

## 4. ЯДРО C++ (MnmDspCore.hpp + test_mnm_chain.cpp)

1:1 порт семантики эталонного эмулятора: 56-бит акк., параллельные переносы с
pre-ALU латчем, сатурация, DO/REP, DIV, tcc, бит-опы, L-память, imm8-правила.
Статус: пошаговая трасса регистров (A/B/x0/x1/y0/y1/r0–r7/sr) идентична эталону
4259/4365 шагов кадра 0 датасета A (97.6%); логи записей в контрольные ячейки
(X:$80/$81/$90/$FF/$2C3) идентичны 53/53. Остаток: 381 ячейка низкой памяти
кадра 0 — X-зеркало Y-записей в одном пути стора (func_000365/37C l-store /
y-store район) + как следствие хвост гребёнки. Диагностика доведена до
конкретного района, исправление — первая задача следующей итерации. Это честный
статус: «бит-в-бит» объявляется только при 100% диффе, которого здесь ещё нет.
