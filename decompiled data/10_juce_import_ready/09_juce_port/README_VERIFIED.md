# README_VERIFIED.md — 09_dsp_models_verified (v2)

Папка содержит **намеренные whitelist-копии** верифицированного содержимого (дубликаты
по sha256 сделаны осознанно, чтобы пак был самодостаточным при отдельном копировании).

- `09_juce_port/Source/` — порт DSP-ядра для JUCE. Верификация: побайтовая сверка выходов
  с `dsp1_pmem.bin` + смоук-тест (см. `10_juce_import_ready/01_CORE_VERIFIED/TEST_REPORT.txt`).
  Уровень: T0-результат. Перепроверять не нужно.
- `22_fm_machines/mnm_fm_exact.hpp` — точные законы FM-машин MNM:
  ratio = $141A80/2^19; уровни операторов (K/64)² с wrap; друп 1−((K−64)/128)⁴;
  шейпер G=(K−64)/16; фидбек FB=K·32; скрытый ×2 для op1; 1FIN = 1+(K−64)/256;
  питч $140000 = 2048 шагов/октаву; TUNE = +683·K/128.
  Уровень: T0-результат (итерации 27–28, численная верификация на harness).
  Примечание: в `12_mining_archive/filter_phaser_pack/mnm_fm_exact.hpp` лежит та же версия
  (хэш совпадает) — единый источник истины.
