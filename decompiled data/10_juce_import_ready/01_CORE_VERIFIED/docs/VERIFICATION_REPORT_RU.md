1. **KERNEL_CHAIN_RU.md §4 (DIST): формула и скейлинг неверны.**
   - Написано: `k = 0.985461·D² + 0.016230`, `idx = D·$100>>23`, `D в 0..~0.5`.

     (не 0.985461), аргумент — **(2D−1)**, а не D; при скейле 0..0.5
     **дисторшн полностью мёртв** (x0=0 на всём диапазоне — проверено

2. **KERNEL_CHAIN_RU.md §5: «X:$143F95 (107 сл.)»** — неверно. Таблица занимает
   **1201 слово** ($143F95..$144445), индекс = coef·$4AF ∈ 0..1200, и она

3. **В доке пропущены две таблицы-делителя**: $1444C6 и $144546 (по $80 w,
   читаются P:$0595/0597 вместе с $144446).

   в float с ошибкой; fc/q-формулы выдуманы (в прошивке — табличный срез
   $143546, clamp 1699, верх 0.907354 ≈ 6610 Гц); «$F528BD — damping» —
   по сути это тапы 4-точечного интерполяционного FIR (сумма 2·(0.5805−0.0846)

5. **DistortionSaturationBlock.h ("2 try")**: дисторшн сведён к «SR.SM hard clip

## 3. НОВОЕ, ЧЕГО РАНЬШЕ НЕ БЫЛО (главное за сегодня)

### 3.1 DIST: точный вход в активную зону и знаковая ловушка $800000
`add #>$800000` — это **−1.0**, а не +1.0 (Q1.23!). Поэтому:

    x0 = max(0, 2·D − 1)      ; D = Y:(V-$24), Q1.23
    idx = floor(x0·256) ∈ 0..255
    c  = DRIVE[$1447C6 + idx]          ; 129 уникальных, дальше flat
    k  = 0.9837891·x0² + 0.0162109     ; k(D=0.5)=0.0162 ... k(D=1.0)=1.0000

- D ≤ 0.5 → x0 = 0 → ступень пассивна (c=1.0, k=0.0162). **Рабочая зона ручки —
  D ∈ (0.5..1.0].** Экспериментально (риг, свип): при D=0.5/0.626/0.752/0.878
  пики выхода 0.032/0.157/0.532/1.0(клип) — закон **gain = 4.000·k** (3 точки
  дают ровно 4.0), жёсткий клип ±1.0 при 4k ≥ 2.
- Кривая привода заканчивается значением **0.3535534 = √2/4** (не «0.35»).
- Значение **c подаётся в путь коэффициента фильтра** (P:$07D5-07DB: произведение
  с TBL среза $143546) — дисторшн связан с фильтром: больше drive → меньше c →
  темнее срез. Раньше это нигде не было отмечено.
- V-$1D (деление P:$079F) на усиление не влияет (свип 0.03125..0.5 — выход
  идентичен); читается из X-пространства (X:$50B), при 0 деление даёт ~1.0.
  Роль — на ColdFire-стороне, статус OPEN.

### 3.3 AMP-таблицы: точные законы
- ATK: геометрия ×0.9198/шаг (ATK[1]=0.4599), ATK[0]=0.5, ATK[127]=1.2e-5.
- DEC: −0.8977 … −1.0000; DEC[127] = −1.0 = «заморозка» огибающей.
- Обе таблицы общие для decay и release; release без сустейн-пола.

### 3.4 SVF-петля P:$05D3-05FA: структура
8 итераций на блок, двухканальная (HP-петля P:$05D5-05E4, LP-петля P:$05EE-05FA
с включением по биту 0 из X:(V-$19), P:$05E9 `brset`), состояния с шагом +3
(X:$71/$73, X:$B1/$B3 — интерливинг под 4-tap интерполяцию), поток данных
Y:$91+ (r4). Константы x0/x1 = тапы FIR. Точная разводка «кто вход/кто Q» в
потоке Y:$91 — остаётся OPEN (как и в доке §7), но теперь известна структура
петли и точки записи состояний.

### 3.5 Cutoff-таблица $143546 — свойства
1700 записей, монотонная 0.000403..0.907354, верхняя запись соответствует
**fc = 6610 Гц** (2·sin(π·fc/fs) = 0.907354). «Темнота» Monomachine — свойство
таблицы, подтверждено. Вторая база $1435C6 = та же таблица со сдвигом +$80.
