## Что проверено в ходе добычи

### Поиск инициализаций runtime-таблиц в coldfire_main.bin (425 858 байт)

- **Дизассемблировано:** 5686 инструкций через capstone m68k (режим M68K_030, ближайший к ColdFire V4)
- **Найдено immediates с runtime-адресами:** 0 (ноль)
- **Вывод:** ColdFire main НЕ содержит прямых ссылок на runtime-адреса DSP
- **Гипотеза:** инициализация выполняется либо через косвенную адресацию (через таблицу указателей в RAM), либо в boot ROM (BIN 0x0-0x3D40)

### Поиск BE32/LE24 констант в оригинальном BIN (8 388 608 байт)

- **boot ROM (BIN 0x0-0x4000):** 11 HI08-записей, 0 для runtime-targets
- **sec1_DSP1 (BIN 0x286EC-0x2A5B2):** 0 HI08-записей
- **sec2_DSP2 (BIN 0x2A5B2-0x2C421):** 0 HI08-записей
- **sec3_common (BIN 0x2C421-0x75BA2):** 6 HI08-записей, 0 для runtime-targets
- **Вывод:** runtime-таблицы НЕ хранятся в готовом виде в BIN-файле прошивки

### Поиск сигнатур таблиц (pitch-wavetable, sine, LFO speed, kernel curve)

- **pitch-wavetable (сигнатура wt[0]=0x400000, wt[1]≈0x400163):** 0 кандидатов в coldfire_main.bin
- **sine 8K (сигнатура sine[0]=0, sine[1]≈0x006488, sine[2048]=0x7FFFFF):** 0 кандидатов
- **LFO speed (геометрическая прогрессия ratio 0.919846):** 0 кандидатов
- **Вывод:** runtime-таблицы генерируются кодом при старте, не хранятся в готовом виде

## Как использовать

### Для bit-accurate эмулятора аудио-движка

Используйте таблицы из `recovered/` напрямую (33 файла). Для pitch-wavetable и sine используйте math-recovered версии (X_140000, X_14A000, X_14A800) — они побайтно совпадают с заводскими.

### Для эмулятора LFO

Используйте `runtime/Y_141800_LFO_speed_table.bin` (теоретическая). Коэффициент 0.919846 даёт близкие к заводским значения, но не точные. Для точного восстановления:
1. Снять дамп Y:$141800 (128 слов × 3 байта) с живого Monomachine через HI08-монитор
2. Или реверснуть функцию инициализации в coldfire_main.bin (поиск обращений к Y:$141800 через XREF к строкам или структурам данных)

### Для эмулятора реверба

`zero_in_image/P_123ef5_FXREV_decay_table.bin` и `P_133191_FXREV_damp_table.bin` содержат нули. Без реальных значений алгоритм реверба (листинг 1257 строк, точный) не будет звучать правильно. Нужен либо дамп с железа сразу после factory reset, либо реверс ColdFire init.
