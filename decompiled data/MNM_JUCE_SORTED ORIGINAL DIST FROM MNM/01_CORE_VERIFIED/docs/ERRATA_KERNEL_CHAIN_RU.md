# ERRATA к KERNEL_CHAIN_RU.md (справка, ошибки в исходном документе)

Этот документ лежит рядом с `KERNEL_CHAIN_RU.md` для контекста. Правильные
значения — в `VERIFICATION_REPORT_RU.md` (тот же каталог) и в коде `dsp/`.

1. §4 DIST: формула `k = 0.985461·D² + 0.016230` со скейлом D 0..0.5 — НЕВЕРНА.
   Верно: `x0 = max(0, 2D−1)`, `k = 0.9837891·x0² + 0.0162109` (P:$07B3/07B5).
   При D ≤ 0.5 дисторшн пассивен (x0=0).
2. §5: «X:$143F95 = 107 слов» — НЕВЕРНО. Таблица занимает 1201 слово
   ($143F95..$144445), рядом $141CA7 (48 слов Q-base) — в доке отсутствовала.
3. Пропущенные таблицы: $1444C6, $144546 (по 128 слов) и парные $143C06/$143D06
   (по 256 слов, путь ширины/пан-кривых).
4. «Release = вычитание» — НЕВЕРНО, release мультипликативный (P:$04ED).
5. «Дисторшн = bset #$14,sr» — неполно: это только финальный клип; характер
   создаёт k-ступень P:$07A6-07D1 (см. MnMAmpDist.h).
6. §атрибутация V-$1C/V-$1B как «LFO SPD/MULT» — НЕВЕРНА, это
   FilterAttack/FilterDecay (подтверждено формулой биполярной центровки
   |V-$1A + $C00000|·$700 для BOFS/WOFS, P:$053E-054B).
