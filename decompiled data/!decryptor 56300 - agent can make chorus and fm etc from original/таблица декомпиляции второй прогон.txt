🎯 Что РЕАЛЬНО нужно сделать для полного воспроизведения
Приоритет 1 (критично для портирования):
Лучший дизассемблер DSP56300 — текущий не парсит dual-move параллельные инструкции (группы 0000/0001). Без этого kernel AMP/FILT/EFFX/LFO код непонятен. Варианты: mot dsp56300-gdb, IDA Pro + плагин, или допилить scripts/dis56300.py.
Декодирование кривых параметров (32 байта curve data в дескрипторе) — без этого SPD=64 не переводится в конкретную частоту LFO в Гц. Метод: A/B-сравнение с железом — записать звук при разных значениях параметра, измерить частоту, восстановить функцию.
Приоритет 2 (важно):
Реверс ColdFire main (425KB) — там MIDI→pitch, modulation matrix routing, UI logic. ColdFire MCF5206e дизассемблируется capstone (уже есть scripts/cf_disasm.py), но нужен анализ.
Voice state layout — нужно понять, какие X/Y:(r6+offset) соответствуют каким параметрам. Метод: поставить известные значения параметров, прочитать состояние через MIDI sysex, сопоставить.
Приоритет 3 (опционально):
Извлечь оставшиеся ~30 маленьких таблиц в P:$101A7B–$104210 и P:$104210–$1134C5. Это wavetables для VO-6, DPRO, SID — они есть в образе, просто не названы.
Глубокий анализ reverb (1263 строки) и VO-6 (2273 строки) — это самые сложные машины, требуют часового анализа каждой.
