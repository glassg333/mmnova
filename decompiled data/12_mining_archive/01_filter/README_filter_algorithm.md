# Трековый фильтр Monomachine — реконструкция алгоритма по машинному коду DSP56300

OS 1.32B, ядро DSP1. Все адреса — P-память программы, если не указано иное.
Модель: **двойной резонансный фильтр** = каскад 1 (нерезонансная пара HP→LP, 2×oversample)
+ каскад 2 (резонансный сканер тапов с раздельными HPQ/LPQ).

**ИТЕРАЦИЯ 15 — ВАЖНОЕ ИСПРАВЛЕНИЕ**: собственного энвелопа у фильтра НЕТ
(бит-точное доказательство — 08_env_verdict/). Параметры P+$14–$17, ранее
считавшиеся «FILT ATK/DEC/BOFS/WOFS», — это delay-модуляция трека. Движение
фильтра на реальной машине обеспечивает CPU (LFO/мод-матрица), записывая
слова BASE/WDTH/HPQ/LPQ между кадрами DSP.


## Энвелопы: AMP (единственный) и «ложный FILTER»

**ИТЕРАЦИЯ 15**: раздел «FILTER-энвелоп (P:$0960–$0B49)» ниже — ИСТОРИЧЕСКАЯ
ОШИБКА итераций ≤14. Секция $0939–$0B49 = track delay + delay-модуляция;
P+$14–$17 = глубина/ОС/скорости рамп ДЕЛАЯ. Полное доказательство:
08_env_verdict/README_env_verdict.md.

### Стейт-машина AMP-энвелопа (P:$088E–$08D7) — эталон логики
```
триг: TRIG_EVENT = 1 → стадия 0 (ATK); 2 → 3 (REL); 3 → 4 (fast REL, константа $20)
стадия 0 ATK:  phase += env_shape_A[ATK]        ($141800, ATK>>10; ATK=0 → шаг 0.5/блок)
               конец таблицы (флаг EC) → стадия 1
стадия 1 HOLD: phase += 1; если phase > HOLD·TEMPO·$791FD0·2 → стадия 2   (P:$08B4–$08C1)
стадия 2 DEC:  acc = −acc · env_shape_B[DEC]    ($141880; |множитель| 0.8977→0.99997)
стадия 3/4 REL: acc = −acc · env_shape_B[REL];  стадия 4: индекс = $20 (фикс. быстрый)
```

### «FILTER-энвелоп» (P:$0960–$0B49) — ПЕРЕатрибутировано в итерации 15
- Глубина P+$14 bipolar (вычитается $400000, знак → выбор банков $40/$62, P:$0A22);
  глубина² = (P+$14−0.5)² (P:$0AB7–$0ABE).
- P+$15 — обратная связь интегратора модуляции (P:$0ABF), KILL-гейт: фаза AMP-env
  == 4 (X:P+$D8) → 0 (P:$0AC0–$0AC4).
- Скорости рамп: однополюсная рекурсия x[n] = x[n]−tbl[i]·(x[n]−target), tbl = $144AC7
  (rate 1 = P+$16>>16, P:$0A5D–$0A63; rate 2 = (P+$17+P+$16)>>16, P:$0A84–$0A92),
  стейты P+$D4/$D5, кривая $144B48 (P:$0AA9).
- Интегратор X:$40–$5E: Σ(audio·P+$15 + ramp·depth²) → коэффициенты delay-обратной
  связи; банк тапов ДЕЛАЯ L:$92–$9F (P:$0AF8/$0AF9); рампа времени делаЯ Y:$10–$1F.
- К срезу фильтра НИКАКОГО отношения не имеет (бит-точное доказательство).

## Формулы для порта (проверяемые)

```cpp
// срез каскада 1 (на блок, до процесса); baseWord = СЛОВО ПАРАМЕТРА BASE (P+$10, Q23),
// env-членов НЕТ — доказано бит-точно (итерация 15, 08_env_verdict/):
int   idx  = (int)(baseWord * 1199.0 / 8388608.0);      // baseWord = 24-bit Q23 слово
float frac = baseWord * 1199.0 / 8388608.0 - idx;
float c1   = div1[idx] + (div1[idx+1] - div1[idx]) * frac;   // линейная интерполяция
int   widx = widthWord * 127.0 / 8388608.0;
float c2   = div2[widx];
float f    = 0.5f * (c1 + c2);                                // P:$0583: (div1+div2)/2
float df   = c2 - c1;
f += (float)(frac * df * 64.0 / 8388608.0);                   // P:$058E–$0591
f -= width1[widx] * (1.0f + f);                               // P:$0592–$0593: a = −w1·(x+1)
// резонанс каскада 2:
float dampHP = hpqTbl [hpq >> 1];      // 0.5 … 0.032
float fbHP   = hpq2Tbl[hpq >> 1];      // 0.0078 … 0.1204
float fbLP   = lpqTbl [lpq];           // 0.0039 … 0.4844
// halfband FIR (2× oversample):
constexpr float HB[4] = { -0.08623f, 0.58066f, 0.58066f, -0.08623f }; // $F528BD/$4A4DF0
```

## Что доказано инструкциями, а что — реконструкция с высокой уверенностью

ДОКАЗАНО (адреса в тексте): структура двойного каскада; все параметр-пути $10–$13;
все формулы индексации; halfband-константы и их FIR-структура; резонансные таблицы и
их индексация; стейт-машина AMP-энвелопа; панорамный узел ±0.75; INP²-масштабы (FX).

ДОКАЗАНО БИТ-В-БИТ (итерация 14, svf_recursion_proven.md): точные рекурсии
func_000340 (гибрид FIR+SVF, модуль-4 кольцо коэффициентов M4=$000003) и
func_000397 (сканер 8 дробных тапов задержки). Резонанс каскада 2 — гребёнка
тапов, а не классический SVF.

ДОКАЗАНО БИТ-В-БИТ (итерация 15, 08_env_verdict/): у фильтра НЕТ энвелопа;
P+$14–$17 — delay-модуляция; путь P:$056B–$0572 — идентичность (a ← BASE);
кольцо коэффициентов и банк тапов L:$80–$91 не зависят от P+$14–$17.

РЕКОНСТРУКЦИЯ (высокая уверенность, но помечено): точный порядок halfband-фаз
вызывающего кода; масштаб 2×oversample.

ПРОВЕРКА: прогон div1 через sin-подгонку даёт f ≈ 2·sin(π·fc/fs) с fc ≈ 15 Гц…18 кГц —
согласуется с ручкой BASE 0–127; сумма halfband-тапов 0.9889 (−0.097 дБ), ноль на
Найквисте — признак корректного дециматора.
