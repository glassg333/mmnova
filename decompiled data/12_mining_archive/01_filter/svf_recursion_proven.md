# Точная рекурсия SVF-ядер — ДОКАЗАНО бит-в-бит (итерация 14)

Дата: 2026-09-21. Метод: трассировка реального ядра в бит-точном эмуляторе DSP56300
(после критического фикса `move a1,rN` — см. ниже), затем чистая Python-реимплементация
обоих ядер и сверка КАЖДОЙ инструкции и КАЖДОГО слова памяти против эмулятора.

Статус: **Ф1 ЗАКРЫТ.** Скрипты доказательства: `07_svf_fit/` (svf_fit.py, svf_fit340.py).

## 0. Критический фикс эмулятора (влияет на все прошлые прогоны)

В `dsp_emu.py` источники-подрегистры аккумулятора (`a0/a1/a2/b0/b1/b2`) защёлкивались
УЖЕ извлечёнными (24 бита), а `commit_writes` извлекал их повторно → `move a1,rN`,
`move b1,y:(rN)+`, `move a1,x0` и т.п. писали `0` вместо A1/B1.

Последствия фикса, обнаруженные трассировкой:
- `$0928: move a1,r0` (выбор тапа) давал r0=0 вместо реального указателя;
- `$0902: move a1,r5` (индекс резонансных таблиц $1448C6/$144946) давал 0 → таблицы
  всегда читались с индекса 0;
- записи `b1,y:(r1)+` (рампы коэффициентов L:$80–$90) писали 0.

После фикса: 27/27 юнит-тестов эмулятора (включая 6 новых регрессионных).

## 1. func_000397 — СКАНЕР МНОГОТАПОВОЙ ЗАДЕРЖКИ (не SVF!)

**Роль переопределена.** Это не резонансный SVF, а 8-таповый сканер линии задержки
с дробной интерполяцией. Вызывается 4 раза за блок: $0938 (резонансная секция),
$0978/$0A5A/$0B13 (delay-секция трека: DTIM/DSND/DFB/DBAS/DWID).

### Структура данных
- **L:$80–$90** (17 пар X+Y, заполняются вызывающим кодом P:$092B–$092D):
  - X-часть = ЦЕЛОЧИСЛЕННАЯ ПОЗИЦИЯ ТАПА (указатель в кольцевой буфер истории);
  - Y-часть = ДРОБНАЯ ЧАСТЬ ТАПА (коэффициент интерполяции).
  Прогрессия строится 48-битным сложением: `a += y` на слот (шаг = env-производное
  значение) — доказано прогоном: при DBAS/DSND=0 позиции = 0,1,2,…,$10; при живом
  сигнале тапы ушли в $27–$32 (кольцо вокруг указателя записи).
- **Кольцевой буфер** = вся 24-битная X-память: указатели тапов могут уходить в
  $FFFFxx и «заворачиваться» через $FFFFFF → $000000. Чтения по адресам вне образа
  эмулятор возвращает 0; на реальном железе регион $FFFF00+ либо зеркалит начало
  X-RAM, либо буфер физически лежит у вершины адресного пространства (открытый
  вопрос по карте памяти DSP56303, НЕ влияет на форму рекурсии).
- **r4 = $81…$88** — обход пар тапов: `x:(r4)` → позиция, `y:(r4)+` → дробь.

### Рекурсия (на сэмпл, 8 итераций, ДВЕ фазы a/b = два шины)

Фаза A (по указателю r0), фаза B (по r1); на каждой итерации r0/r1 перезагружаются
из X:(r4), дробь y0 = Y:(r4). Для каждой фазы:

```
acc  = -x_prev * y0                      ; mpy  (48-бит, дробный, <<1)
acc += x_mid                             ; add  (выравнивание A1)
acc += round(x_mid * y0)                 ; macr
out  = acc                               ; сохраняется в X:(r2)+ / X:(r3)+
```

Математически (в дробных 1.23):

```
out = x_mid * (1 + y0) - x_prev * y0      ; + округление macr
    = x_mid + y0 * (x_mid - x_prev)
```

— **линейная интерполяция дробного тапа** (экстраполяция на y0 вперёд от x_mid к
x_prev). Порядок чтений в фазе: x_prev = X:(p), x_mid = X:(p+n0), затем X:(p+n0+1),
X:(p+n0+1); во 2-й фазе — то же от r1 c n1. Выходы пишутся последовательно в
X:$22…$32 (шина a) и X:$34…$44 (шина b) — по 17 значений на вызов.

**Доказательство:** 8/8 вызовов (4 сайта × 2 кадра) воспроизведены бит-в-бит:
инструкции, аккумуляторы A/B (56 бит) и вся память $00–$FF совпали.

## 2. func_000340 — ГИБРИД СИММЕТРИЧНОГО FIR + SVF-ОБРАТНОЙ СВЯЗИ (каскад 1)

Вызывается из P:$05A1/$05B5 (L/R фазы 2×oversample-конвейера), 16 итераций за вызов.

### Структура данных
- **r0** = поток входных сэмплов (X:$96+ — аудио машины, записано стадией $04F5 в
  X:$96–$A6/$D6–$E6), ходит +1/-1/+1 (симметричный FIR-доступ).
- **r1** = пинг-понг состояний X:$93/$94 (+$95): чтение состояния, запись a/b.
- **r4** = Y:$04–$07, **M4 = $000003 — модуль-4 кольцо коэффициентов** (!):
  Y:$04 = f (срез), Y:$05–$07 = остальные коэффициенты (ширина/демпфирование).
- Выходы: `Y:(r1)+2` = b_old (рампа состояний B), `X:(r1)-` = a_old.

### Рекурсия (на итерацию; y0/y1 = коэффициенты из мод-4 кольца)

```
; вход: a = предыдущий x0 (tfr-выравнивание), b = состояние B (после <<2)
1) a += y0 * x0                    ; $345  \ симметричный FIR-тап
2) a += y0 * x0                    ; $346  / (двойной mac = ×2)
3) a += y1 * x1                    ; $347   SVF-обратная связь (состояние x1)
4) a -= x0' * y1                   ; $348   (x0' = X:(r1) — состояние SVF)
5) a -= y0 * x0''                  ; $349
6) a -= y0 * x0''                  ; $34A   (снова двойной)
7) b  = x1 * y0                    ; $34B   (mpy — СБРОС b)
8) a  = x0_next ; y0 = a_prev      ; $34C   (tfr: a = сырой вход!)
9) b += y1 * y0_prev_a             ; $34D   (y0 = ЗНАЧЕНИЕ ПРЕДЫДУЩЕГО a!)
10) b <<= 2                        ; $34E
```

Ключевые факты:
- аккумулятор A между итерациями = просто следующий входной сэмпл ($34C tfr):
  SVF-коррекция НЕ накапливается в A — она уходит в сохраняемые a_old/b_old;
- B — «медленное» состояние: b = (x1·y0 + y1·a_prev) << 2, сбрасывается каждый
  сэмпл mpy-ем и растёт сдвигом — классическая пара «быстрый вход / интегратор»;
- x1 = X:(r0-1) — симметричный FIR-доступ (тот же сэмпл, что и x0, но по другую
  сторону интерполяционной фазы halfband-конвейера вызывающего кода).

**Доказательство:** 2/2 кадра — 0 расхождений по инструкциям (163 контрольные точки
A/B на кадр) и 0 расхождений по памяти $00–$FF против эмулятора.

## 3. Что это меняет в общей схеме фильтра

```
машина (аудио 34 слова) ──$04F5──> X:$96–$A6 / X:$D6–$E6 (история)
                                        │
[каскад 1] P:$0537–$06C0: коэффициенты (div1/div2/width, exp_A.json) →
           func_000340 ×2 (L/R) в halfband 2×oversample — гибрид FIR+SVF
                                        │
[EQ]       P:$0789–$0859 (1 полоса, EQF/EQG)
                                        │
[AMP env]  P:$088E–$08D7 (готово, 06_amp_env/)
                                        │
[резонанс] P:$0859–$0938: HPQ → damping $1448C6 / fb $144946, LPQ → fb $144BC9;
           L:$80–$90 = прогрессия тапов (шаг от env) → func_000397 (тап-сканер)
                                        │
[delay]    P:$0939–$0B49: тот же сканер ×3 вызова + фильтр-энвелоп ($144AC7/$144B48)
```

«Резонанс» каскада 2 реализован НЕ классическим SVF-фидбеком, а **гребёнкой
дробных тапов** с коэффициентами из HPQ/LPQ-таблиц — темброво это даёт тот же
резонансный пик, но порт должен повторять именно гребёнку.

## 4. Как воспроизвести доказательство

```bash
cd 07_svf_fit

```

(2.5 МБ) не включены в пак — регенерируются svf_trace.py.
