# Пересборка образов DSP из оригинальной прошивки (секции 1/2/3, HI08-поток)
# Формат: 24-бит BE слова, как в эталонных образах репозитория

DSP1 P: 1343588 слов, non-zero 110836, несовпадений с эталоном 0 -> dsp1_pmem_from_firmware.bin
DSP1 X: 1044 слов, non-zero 68, несовпадений с эталоном 0 -> dsp1_xmem_from_firmware.bin
DSP1 Y: 1076 слов, non-zero 755, несовпадений с эталоном 0 -> dsp1_ymem_from_firmware.bin
DSP2 P: 1343588 слов, non-zero 110767, несовпадений с эталоном 0 -> dsp2_pmem_from_firmware.bin
DSP2 X: 1044 слов, non-zero 69, несовпадений с эталоном 0 -> dsp2_xmem_from_firmware.bin
DSP2 Y: 1279 слов, non-zero 755, несовпадений с эталоном 0 -> dsp2_ymem_from_firmware.bin

Несовпадений 0 => образы восстановлены из прошивки бит-в-бит.
