# m18 — настоящий PHASER ($145036–$14538D): первый разбор (итерация 22)

Диспетчер: INIT = `$145036`, CONF = `$145044` (rts), PROC = `$145045`,
выход PROC = `rts` на `$14538D`. Листинг: `disasm_m18_real_phaser_P145036-14538D.txt`.
Харнес: `m18_harness.py` (запуск PROC напрямую, как phaser_harness.py итер. 2).

## Контракт вызова (подтверждён прогонами)

- `r6 = P+$28 = $428` — страница FX-машины (ядро держит r6 = y:$123 = $528,
  lua (r6-$28)... для FX-страницы $428 — совпадает с итер. 2);
- параметры: `y:(r6+$04..$0B)` — 8 слотов (хост пишет напрямую в Y:$42C–$433,
  ядро их НЕ копирует — проверено watch на $428–$46F за кадр);
- вход: `x:(r0)+` — r0 = указатель ядра на входной буфер (в харнесе X:$200),
  PROC читает 34 слова;
- выход: `y:(r7)+`, r7 = $100 → Y:$100–$11F, запись ПАРАМИ `l:(r7)`-стиля:
  `$14513D` пишет чётные слоты (сигнал), `$14513E` — нечётные (ноль!).

## Что разобрано в листинге (голова PROC, $145045–$14509B)

1. **Банки масштабированного входа** ($145049–$145056):
   `Y:$00–$0F = input[0,2,4,…30]·INP²·4`, `Y:$10–$1F = input[1,3,5,…31]·INP²·4`,
   где INP = параметр 7 (`y:(r6+$B)`), возведение в квадрат — `mpy x0,x0`,
   масштаб ×4 — `asl #$2`. Замер: вход 0.5, INP=64 → Y:$00 = 0.50000;
   INP=127 → 1.96887; INP=0 → 0. Параметры 0–6 на банк НЕ влияют.
2. **Фаза LFO** ($145057–$145069): шаг = `SPD²·$9566` (SPD = параметр 2,
   `y:(r6+$6)`) — та же константа, что у фленджера m19 (×16 хоруса).
   Leapfrog-квадратура на 16 ячеек X:$20–$2F / Y:$20–$2F (тот же код семьи,
   `mac -x1,x0,b`/`mac y0,x0,a`, bset/bclr #$14 sr). 48-бит фаза `x:(r6+$11/$12)`
   стартует с $80:00000000 (INIT) и считает ВНИЗ.
   Замер шага за блок: SPD=16 → −1, 32 → −1, 64 → −3, 127 → −10 (младшее слово).
3. **Сглаженный индекс LFO** ($14506A–$145078): one-pole k=$28F5C на
   `y:(r6+$1B)`, цель = параметр 5 (`y:(r6+$9)`); индекс ×$800 → выборка
   квадратуры из таблиц `$14A000` (sin) / `$14A800` (cos) — носитель формы.
4. **Де-зиппер рампы LFO** ($14507A–$145088): дельты квадратуры против
   состояний `y:(r6+$1C/$1D)`; 16-шаговые рампы `X:$E0–$EF` и `Y:$E0–$EF`
   (`mac y0,x0,a`/`mac x0,y1,b`, шаг ×8) — по-сэмпловые позиции модуляции.
5. **Ротатор-лесница** ($145089–$14509B): 16 итераций, состояние = те же банки
   X:$20–$2F / Y:$20–$2F (читаются до записи — персистентны между блоками):
   `a_k = ramp·s_k + rampQ·q_k`, `b_k = ramp·s_k − rampQ·q_k`,
   где s_k = X:$20+k, q_k = Y:$20+k, ramp/rampQ = рампы X/Y:$E0+k.
   a-цепь пишется обратно в X:$20+k (каскад), b-цепь — в X:$30–$3F
   (квадратурный выход). Это КОМПЛЕКСНЫЙ ВРАЩАТЕЛЬ на 16 ступеней, а не
   классический аллпасс — фейзер Monomachine построен на вращателях.

## Замеры

1. **Импульсный отклик** (SPD=0, INP=100, FB=40): `ir = [0.5562, 0, 0.0578, 0,
   0.0423, 0, 0.0396, 0, …]` — нечётные сэмплы выхода = 0 (структура парной
   записи), хвост ~8 ненулевых тапов на блок; коэффициент напрямую зависит от
   параметра 0 (CNTR): 32 → 0.5562/0.0578/…, 64 → 0.5802/0.1004/…,
   96 → 0.6029/0.1381/… DEP при SPD=0 не влияет (глубина живёт только через
   модуляцию) ✓.
2. **Фаза LFO**: счёт вниз от $80:00000000, шаг за блок −1/−1/−3/−10 при
   SPD = 16/32/64/127 (закон SPD² подтверждён).
3. **Банк масштаба**: Y:$00 = input·INP²·4 (INP = параметр 7), чёт/нечёт
   разнос по Y:$00–$0F / Y:$10–$1F.
4. Нотчи на 2048-точечном DFT ИР при SPD=0 не выражены (<0.05) — ожидаемо:
   без модуляции ротаторы стоят на статических углах; острота нотчей зависит
   от длины колец $722/$664 (хвост, не разобран).
