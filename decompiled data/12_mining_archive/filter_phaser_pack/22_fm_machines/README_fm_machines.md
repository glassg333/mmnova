# 22_fm_machines — Бит-точная перепроверка FM-машин (m8/m9/m10)

Дата: 2026-09-23 (итерация 27). Метод: полный листинг + бит-точный эмулятор
(05_emulator/dsp_emu.py) + прямые замеры внутренних ячеек. Все законы даны
для слова параметра = knob<<16 (0..127 → $000000..$7F0000).

Машины и точки входа (диспетчер $10016B/$10018D/$1001AF, индексы = номер машины):

| машина | имя (OS) | INIT | CONF | PROC | rts PROC |
|---|---|---|---|---|---|
| m8 | FM+ STAT | $145D12 | $145D1D | $145D21 | $145EC8 |
| m9 | FM+ PAR | $145EC9 | $145ED4 | $145EDB | $14619C |
| m10 | FM+ DYN | $14619D | $1461A8 | $1461C1 | **$14636E** (не $146473! хвост = хелперы шейпера) |

Контракт: r6 = P+$28 ($428), r7 = $100, m0..m7 = $FFFFFF, A = питч-слово
(конверсия ядра $02DD–$02EA). Параметры y:(r6+$4..$B) = P+$2C..$33.
Выход: 32 слова Y:$100–$11F = 16 L/R-пар (a,a,b,b-дублирование пар).

## 1. Общая архитектура (все три машины)

Трёх-операторный ФМ «через производные» — то, чего нет ни в одном учебнике:

1. **Каждый модулятор** = синус (таблица X:$14A000, 8192 слов/цикл, фаза
   маскируется `and #$1fff`, адрес = $14A000+idx) → **первая разность**
   (`d[i] = s[i] − s[i−1]`, стейт на странице) → **однополюсный LP**
   (коэффициент = $144AC7[TONE] у STAT/PAR; у DYN — фиксированный #$40,
   см. §5) → **пик-шейпер** `y[i] = d[i] + G·d[i−1]`, G = 16·max(0, K−64)
   (в словах: G = 16·(K_word − $400000)>>24, K = ручка-гейт ≥64).
2. **Микс модуляторов** (с уровнями-ручками) → буфер X:$80–$9F.
3. **Несущая**: фаза b += inc (с плавным glide-рампом Δinc/32 на блок),
   затем **пост-сэмпловая ФМ**: `b += mix[i]>>12`, чтение синуса
   с линейной интерполяцией (дробь фазы = pre-mask b0!) → X:$E0–$FF.
4. **Два квадратурных ротатора** (константы $0CFCE3/$2BC9CA и $4E63DF/$6F0F12)
   → стерео-детюн/панорама; микс ×0.5 пар соседних сэмплов → 16 значений →
   a,a,b,b → 32 слова выхода.

**Важно про и/and**: `and #$1fff,b` на аккумуляторе очищает b0 (дробь фазы)
каждую итерацию, НО адресная дробь для интерполяции берётся из ПРЕ-mask
копии (l:(r1)+ до and). Приращение фазы — целое число табличных единиц
на итерацию (питч квантован на ~5.4 Гц/канал, ниже §6).

## 2. Ручка TUNE (последний парам, r6+$B) — работает через ЯДРО, не машину

PROC/CONF/INIT ни одной из трёх машин TUNE не читают. Ядро $0262/$02C0–$02C9:
`TUNE → x:$1`; питч = slew1 + slew2 + **TUNE·683** + P+$26 + P+$1E·$B000 − $5800
(клэмп 0..$5800). Масштаб таблицы питча $140000 = 2048 единиц/октава
(проверено: tbl[1024]/tbl[0] = 1.4142 = 600 центов).

**Закон TUNE: +683/128 = 5.336 единиц/шаг = +3.127 цента/шаг, униполярно
0…+397 центов (knob 0 = 0 центов, knob 64 = +200 центов, knob 127 = +397).**
JUCE, центрирующий TUNE на 64 (±), ошибается вдвое и по знаку диапазона.

## 3. FM+ STAT (m8) — полная карта ручек

Параметры: 1FRQ 1FIN 1ENV 1FB 2FRQ 2VOL TONE TUNE.

### 3.1 Отношения (таблица $141A80, 24 записи)

Индекс: `n = ((K_word + $8000)·24) >> 24 = floor((K+0.5)·3/32)`
— границы подтверждены свипом (края на 11, 21, 32, 43, 53, 64, 75, 85, 96, 107, 117).

Сырые слова (шестнадцатеричное, отношение = raw/2^19 — подтверждено
спектрометрией боковых полос: 2FRQ=48 → f_mod = 689 Гц = 0.25·f_car):

```
004000 008000 010000 018000 020000 028000 030000 040000
050000 060000 070000 080000 0A0000 0C0000 0E0000 100000
140000 180000 1C0000 200000 280000 300000 380000 400000
= 1/32 1/16 1/8 3/16 1/4 5/16 3/8 1/2 5/8 3/4 7/8 1 5/4 3/2 7/4 2 5/2 3 7/2 4 5 6 7 8
```

- **модулятор 2** (2FRQ): f2 = f_car · raw/2^19 (без 1FIN);
- **модулятор 1** (1FRQ): f1 = f_car · raw/2^19 · finmult · 2 — у него есть
  множитель ×2 (`asl b`, $145DB6) и 1FIN.

### 3.2 1FIN — точный множитель отношения модулятора 1

```
finmult = 1 + (FIN − 64)/256     (0.750 … 1.2461)
```
($145DAE–$145DB7: sub $400000, asr#2, add $400000 — код однозначен).
JUCE-версия совпадает. **Но** в JUCE finmult применён к ratio1 БЕЗ ×2 —
из-за этого все отношения модулятора 1 вдвое занижены.

### 3.3 1ENV — уровень оператора 1 с ПЕРЕПОЛНЕНИЕМ-ЧЕРЕЗ-ЗНАК

```
level_word = (ENV²·2048) mod 2^24, трактуется как signed 1.23
droop      = 1 − ((ENV−64)/128)^4   при ENV ≥ 64, иначе 1
level      = level_word · droop     (может быть ОТРИЦАТЕЛЬНЫМ)
```
Эквивалентно: level = ((ENV/64)² mod 2, sign-wrapped) · droop.
Замеры (mix_max): 16→0.0516, 32→0.2065, 48→0.4646, 64→0.8259 (= (k/64)²·0.826);
80→0.2676 (= |−0.4375|·0.61 — знак перевёрнут!), 96→0.1524, 127→0.0359.
**Нули/инверсии выше 64: около ENV≈90.5 (×2.0 → 0) и ENV≈128 — звук
оператора 1 проваливается и инвертируется. Это прошивочная особенность,
её нет в JUCE (там линейный/квадратичный уровень без wrap).**

CONF каждый кадр сбрасывает env-стейт (r6+$2A) в $7FFFFF → «ENV» — не
огибающая во времени, а статическая кривая уровня (у PAR так же, стейты $32/$33/$34).

### 3.4 1FB — фидбек модулятора 1

```
feedback (табличных единиц фазы) = sin_{i−1} · 1FB·32
```
(asr #$11 от слова → knob·32; максимум 127·32 = 4064 ед. = 0.496 цикла —
вплоть до шума). Одно-сэмпловый фидбек, аккумулируется в фазе модулятора
(r6+$1C/$1D). Замер fb_accum: 32→−0.00012 (предск. −0.000122) ✓.

### 3.5 2VOL — ТРИ роли (главный источник «не той» громкости/тембра)

1. **Гейт**: 2VOL < 64 → вклад оператора 2 = РОВНО ноль
   ($145D8C–$145D95: y1 = max(0, 2VOL−$400000)).
2. **Уровень**: тот же wrap-закон, что 1ENV: ((2VOL/64)² mod 2 signed)·…
   (без droop! droop только у 1ENV/2ENV/3ENV-стейтов).
3. **Пик-шейпер** при ≥64: d[i] + (2VOL−64)/16·d[i−1] — резонансный подъём
   производной модулятора 2 (макс. коэффициент 63/16 ≈ 3.94).

JUCE использует 2VOL/127 как линейный уровень модулятора — это неверно
втройне (нет гейта, нет wrap, нет шейпера).

### 3.6 TONE

`n2 = TONE>>16` (прямая ручка 0..127) → коэффициент однополюсника $144AC7[n]
на КАЖДОЙ производной модулятора (у STAT — 2 LP: стейты $28/$29;
у PAR — 4: $2B/$2C/$2D + пост-микс $2E?? — см. пакет 09_juce_port, таблица
$144AC7 уже извлечена). Замер: TONE=0 → коэфф 0.00221 → mix 0.00013;
TONE=127 → 0.90969 → 0.0484 ✓.

## 4. FM+ PAR (m9)

Параметры: 1FRQ 1ENV 2FRQ 2ENV 3FRQ 3ENV TONE TUNE.

- Три параллельных модулятора → один микс → одна несущая. Отношения всех
  трёх — по таблице §3.1 (1FRQ/2FRQ/3FRQ = r6+$4/$6/$8), БЕЗ ×2 и без 1FIN
  (множителей finmult в PAR нет — листинг $145EE3–$145EF6 не содержит
  asl-пары $145DB5–$145DB6).
- 1ENV/2ENV/3ENV = гейт(≥64) + wrap-уровень + пик-шейпер КАЖДОГО модулятора
  + env-стейт с droop (стейты $32/$33/$34, CONF сбрасывает все три в $7FFFFF).
- TONE LP: на каждый дифф + дополнительный на микс (стейт $2B) — итого
  4 каскада одного коэффициента $144AC7[TONE].
- TUNE — как в §2.

## 5. FM+ DYN (m10) — декодировано ~80%, 2 открытых вопроса

Параметры: 1FRQ 1FEN 1VOL 1VEN 2FRQ 2ENV 2FB TUNE (TONE НЕТ).

Доказано кодом (листинг + CONF $1461A8–$1461C0):

1. **1FRQ — НЕПРЕРЫВНОЕ отношение** (не таблица!): f1 = f_car · (1FRQ/2^23)·2,
   клэмп 1FRQ ≤ $7FFFFF ($1461E3–$1461E7). JUCE-версия exp2 — неверна.
2. **2FRQ — квадратичное непрерывное отношение**: f2 = f_car · (2FRQ/128)²·4
   ($14625D–$14626A: mpy x0,x0; asl#2; mpy на L:$5).
3. **2FB** — тот же фидбек, что STAT 1FB: sin·2FB·32.
4. **1FEN — ЧМ модулятора 1 через рекурсию вейвтейбла**: n1 = 128 − |1FEN−64|·2;
   r6+$2E ← −table$141880[n1]·r6+$2E; приращение += r6+$2E>>12.
   Таблица $141880 = ТА ЖЕ, что decay-скорости AMP-огибающей (убывающая,
   $8D1897…$800000 = −0.102…−1.0).
5. **1VEN** — НЕ селектор шейпера! (итерация 28: код $14636F+ = машина m3 SID;
   селектор $1463E5–$1463F9 читает y:(r6+$7) СТРАНИЦЫ SID = ручку WAVE).
   В m10 1VEN задаёт CONF-инициализацию рекурсии стейта $2C:
   $2C = 4·(1VEN−64)·1VOL при 1VEN<64, иначе 0 ($1461AB–$1461B7), и скорость
   её знакопеременного затухания через n1 = 128−|1VEN−64|·2 в таблицу $141880
   ($14623C–$146248, шаг — раз в блок). $2C добавляется к 1VOL² перед ×4
   в уровне модулятора 1.
6. **1VOL** — гейт ≥64 + уровень (как 2VOL у STAT) шейпера модулятора 1.
7. **2ENV** — уровень+droop оператора 2 (стейт $2D). (Скорость «вращения
   192-буфера» $1463B8–$1463E4 — это SID, не m10.)
8. **Фиксированные LP** вместо TONE: коэффициент #$40 = 64/2^23 — см. §9.

### Открытые вопросы DYN — ЗАКРЫТЫ в итерации 28 (см. §9)

- **(а) LP #$40** — коэффициент действительно 64/2^23 (1.23), τ≈1.49 с;
  слышимого пути мимо LP НЕТ: микс→>>12 даёт ровно 0. Кросс-FM у m10
  структурно неслышим (доказано замерами).
- **(б) «буфер → 5 шейперов → выход»** — этот код принадлежит машине m3 SID
  (границы по таблице диспетчера: m3 = $14636F/$14637A/$146382,
  m11 = $1464FC/$14653C/$1469BF); к m10 отношения не имеет.

## 6. Питч-цепь и абсолютная частота — статус

- Машина: приращение несущей inc_48 = 2·A·$0BE37C (замер L:$5 бит-в-бит),
  фаза += inc_48 за итерацию; **инкремент в табличных единицах = целая часть**
  (and #$1fff сбрасывает дробь аккумулятора — семантика DSP56300: AND на
  аккумуляторе действует на A1, A0=0) → питч квантован ~1 ед./итерацию.
- f_канала = inc · 44100/8192 = inc · 5.383 Гц (32 итерации/блок = 16 L + 16 R,
  блок = 16 кадров @44.1к). Спектральное подтверждение: боковые полосы
  f_mod = (raw/2^19)·f_car при f_car = 2756.25 Гц (inc=185 → 1 цикл/блок).
- Ядро: питч = slew1+slew2+TUNE·683+…−$5800 (клэмп 0..$5800); таблица
  $140000 = 2048/октава; конверсия $02DD–$02EA → A.
- **Открытый вопрос №2**: стыковка «нота → Гц» даёт систематическое
  расхождение ×1.118 (−2 полутона) между конверсией ядра и машинным
  инкрементом в нашей интерпретации масштаба аккумуляторов (5.47 vs 1.47
  представления, семантика dmac-выравнивания). Это НЕ влияет на законы
  ручек выше (все они относительные и замерены независимо), но абсолютная
  калибровка «нота→Гц» требует отдельной итерации (28) с дизассемблерной
  верификацией mpysu/dmac на эталонных парах.

## 9. Итерация 28 — границы машин по таблице диспетчера и финал по DYN

Дата: 2026-09-24. Метод: побайтовое чтение таблиц диспетчера ядра
($10016B/$10018D/$1001AF — это ДАННЫЕ, декомпилятор показывал их как код),
пошаговая трасса PROC (exp28_dyn_reach.py), замеры каскадов и фаз
(exp28_dyn_levels.py, инлайн-пробы).

### 9.1 Границы машин (исправление карты итерации 27)

Таблицы диспетчера индексируются ядром напрямую: `y:$124 → r0;
r1 = x:(r0+$1001af)` ($0000F6–$0000FF) — machine N → table[N]. Записи:

| idx | INIT | CONF | PROC | машина (OS) |
|---|---|---|---|---|
| 3 | $14636F | $14637A | $146382 | **SID** (SID-6581) |
| 8 | $145D12 | $145D1D | $145D21 | FM-STAT ✓ |
| 9 | $145EC9 | $145ED4 | $145EDB | FM-PAR ✓ |
| 10 | $14619D | $1461A8 | $1461C1 | **FM-DYN** ✓ |
| 11 | $1464FC | $14653C | $1469BF | VO-6 |

Файл листинга `10_FM-DYN_full.txt` содержит чужой хвост: код $14636F–$1464FB —
это **m3 SID** (совпадает с заголовком 03_SID_full.txt), $1464FC+ — **m11 VO-6**.
Все «шейперы/192-буфер/скорость вращения» из §5 итерации 27 — код SID.
Трасса PROC m10 (все 1VEN/2FRQ-варианты, 2273 шага/блок): в зону $14636F+
исполнение НЕ попадает ни разу (0 шагов), rts всегда $14636E.

### 9.2 DYN: три экспериментальных доказательства

1. **Фазовый ход несущей инвариантен к мод-ручкам.** d(фаза)/блок несущей =
   2208 ед. (A=11776) при mods ZERO и при mods MAX (1VOL=127, 2ENV=127,
   2FB=127) — побитно совпадает на всех блоках. mix>>12 ≡ 0.
2. **Выход не зависит ни от одной ручки.** Корреляция 24-блоковых выходов
   базового набора с 1FRQ=127 / 2FRQ=127+2FB=127 / 1VEN=0+1VOL=0 / 1FEN=0 /
   2ENV=0 / all-zero: **corr = 1.0000 во всех случаях**, max|out| = 16 слов.
3. **2FB работает**, но только на самом модуляторе 2: d(фаза mod2)/блок =
   2192±3 (дрожание от фидбека sin·2FB·32 в фазу) против ровно 2208 при
   2FB=0. Неслышимо (путь модулятора заглушен LP).

Механика глушения: LP с коэффициентом #$40 = 64/2^23 (τ≈1.49 с при 88200
итер/с) стоит на всех трёх путях (мод-1 $146233, мод-2 $146297, микс $1462D3);
стеди-стейт LP ≈ 1.2e-4·уровень; после сдвига >>12 вклад в фазу < 1 единицы
таблицы ⇒ ровно 0. 1FEN-смещение ($2E>>12) входит в инкремент МОДУЛЯТОРА 1
($1461DE–$1461EB), а не в L:$5 несущей — тоже неслышимо.

### 9.3 Масштаб выхода семейства (снятая «аномалия»)

Выходная стадия m10 «×64/2^23 + пара-сумма + asr» — НЕ ошибка: у STAT та же
константа #$40 на $145EB3. Все три FM-машины выдают на Y:$100–$11F слова
порядка ±16 (замер: m8=16–17, m9=16–17, m10=16) — единый семейный масштаб;
усиление делает AMP-стадия ядра ($04A8, r7=$100 → r6=P-страница).

### 9.4 Итоговая модель FM-DYN (бит-точная)

Слышимый результат: **чистая синусоида несущей** (питч = A, стерео-детюн
квадратурными ротаторами, пара-сумма ×64/2^23) при ЛЮБЫХ положениях ручек.
Внутренние законы (отношения 1FRQ/2FRQ, уровни-обёртки, фидбек 2FB,
рекурсии 1FEN/1VEN) исполняются бит-в-бит, но их аудио-пути заглушены
фиксированным LP. Это свойство самой прошивки (все машины и адреса
верифицированы на эмуляторе), а не дыра модели: харнес не вносит ни гейна,
ни потерь (m8/m9 через тот же харнес дают здоровые спектры). Для JUCE-порта
DYN достаточно несущей + ротаторов; законы молчащих internals сохранены в
mnm_fm_exact.hpp для полноты.

### 9.5 Статус питч-цепи ×1.118 (открыт, не влияет на ручки)

Абсолютная калибровка «нота → Гц» (стык конверсии ядра $02DD–$02EA и
машинного инкремента) остаётся с систематикой ×1.118; требует эталонной
пары (реальное железо) или полной верификации семантики mpysu/dmac/
представления аккумулятора. На все законы ручек и на выводы §9 не влияет.
