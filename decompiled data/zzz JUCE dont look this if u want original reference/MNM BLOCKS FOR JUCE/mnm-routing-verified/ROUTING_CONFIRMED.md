## 2. РОУТИНГ БУФЕРОВ с адресами                              [A]
источник: 3 mnmdsp_reference/dsp/MnmRouting.h + docs/ROUTING_RU.md

  Буферы X:$2C0..$2C3 = { $160, $1C0, $220, $280 }   (DSP1)
    buf0/1/2 = выходы 3 треков текущего прохода
    buf3     = внешний вход (codec ADC)

  Выбор входа   P:$0113-$0131, флаги X:$2C4
    bit4  -> буфер 3 (EXT)
    bit12 -> буфер 0
    bit13 -> буфер 1
    иначе -> буфер 2

  Заливка EXT   P:$02ED-$031D  (bit6/7, пинг-понг X:$100/$120)
  Запись выхода P:$0143-$0218
    бит установлен -> ПЕРЕЗАПИСЬ func_0001ec  (INSERT)
    бит сброшен    -> ДОБАВЛЕНИЕ func_0001e2  (параллельно)
  Сумма в микс  func_0001A3, P:$01AD-$01C1 : buf0+buf1+buf2 -> buf0

  "6 треков, а сосед один": голоса идут по 3 за проход, выбрать можно
  только буфер своего прохода. Больше трёх источников железо не даёт.

  "100% wet" = роутинг, а не MIX: FX читает буфер соседа и перезаписывает
  тот же буфер -> стоит инлайном, сухой заменяется. Особого режима
  соседа в коде машин НЕТ.

## 3. INP и MIX                                               [A]
  INP  P:$14768B-$147698   gain = INP^2, x4 на произведении в 56-бит
       32 -> -12 дБ ; 64 -> 0 дБ ; 127 -> +12 дБ    квадратичный закон

  MIX  P:$1477CB-$1477DD   a = $7FFFFF - MIX ; out = a*dry + MIX*wet
       одинаково у CHORUS/REVERB/DYNAMIX/PHASER/FLANGER/RINGMOD, MIX = p3
       дефолты: 127 у CHORUS/DYNAMIX/PHASER/FLANGER, 32 у REVERB

## 6. НО: HPQ/LPQ не в машинном дескрипторе                   [B]

Машинные дескрипторы = только SYNT-страница (8 ручек машины).
HPQ/LPQ/BOFS/WOFS = общая FILT-страница, одна на все машины.

Значит есть ОТДЕЛЬНЫЙ блок дескрипторов страниц (AMP/FILT/EFFX/LFO).
Косвенно: PAGE_TEMPLATES.txt помечен "verified from ColdFire main" —
автор его откуда-то прочитал. Искать рядом с 0x57FC5.
