# MMNova OS 1.32B -> JUCE. Честный статус.

## Правило этого архива
Здесь лежит ТОЛЬКО то, что подтверждено реальным дизассемблером или
реальным hex-дампом. Приближения в виде C++ сюда не положены — вместо
них лежит тулкит, которым их можно добить локально.

## ТИР A (можно брать как есть)
- MnMChorus.h        — FX-CHORUS P:$147661-$1477DE, прочитан целиком (382 слова)
- MnMGndSin.h        — GND-SIN P:$144CC9-$144D4D, прочитан целиком (159 слов)
                       + литеральный 2-полюсник P:$144D21 ($1E454E / $5B75B8)
- MnMFixed.h         — арифметика DSP56303 (Q23, 56-бит, sat24 = bset #$14,sr)
- MnMTablesA.h       — таблицы из 04_tables/*.txt (реальный hex, не выдумка)
- MnMDescriptors.cpp — 23 дескриптора машин из ColdFire 0x57FC5

## ТИР B / C (кода НЕТ — есть рецепт)
Смотри mmnova_slice.py и PORT_PLAN.md. Я прочитал меньше 40% кода этих
машин, поэтому писать "точный порт" было бы враньём.

## Что было ошибкой в прошлых попытках (1 try / 2 try)
1. Приближения подавались как "точный порт" с authoritative-комментариями.
2. В "2 try" в референс просочились правки из промптов плагина
   (изгиб decay 150%, переименование RETRO->MNM, кастомный BBOX).
   Эталон прошивки таких вещей не содержит. Здесь их нет.
3. FX-REVERB в "1 try" использовал константы Freeverb (1116/1188/1277/1356),
   а в прошивке P:$1453A8 стоят $0A67/$098F/$0713/$0655. Это разный звук.
