# Канонический роутинг Monomachine SFX-60 OS 1.32B

Цепочка подтверждена тремя независимыми источниками:

1. Слуховой тест через эмуляцию:
   synth -> dist -> srr -> filt -> eq -> env -> dsnd

2. CHANGELOG monomachine-lab 0.1.4:
   "Kept the original machine, distortion/SRR, filter, EQ, AMP and delay routines"

3. Файл дескрипторов ColdFire (PAGE_TEMPLATES.txt):
   Каждая машина проходит через общие страницы AMP / FILT / EFFX.

## Раскладка страниц в тракте:

[1] SYNT page: 8 параметров выбранной машины (P:$14xxxx)
    Генерирует сырой осциллятор блоками по 16 кадров @ 44.1 кГц.

[2] AMP page (ручка 5, DIST):
    Умножение на множитель headroom (-64..+63). Клип делается в ALU
    насыщением SR.SM (bset #$14,sr) на +-1.0 Q23.

[3] EFFX page (ручка 3, SRR):
    Sample Rate Reduction. Децимация сэмпл-рейта (кранч).

[4] FILT page (ручки 1..8):
    24 dB multi-mode SVF (две петли P:$05D3-$05FA).
    HPQ (ручка 3) и LPQ (ручка 4) независимо управляют резонансом секций.
    Модулятор: огибающая ATK/DEC через BOFS/WOFS двигает срез.

[5] EFFX page (ручки 1..2, EQF / EQG):
    1-полосный параметрический эквалайзер. Стоит ПОСЛЕ фильтра,
    подравнивая отфильтрованный спектр.

[6] AMP page (ручки 1..4, AHDR + ручки 6..7, VOL/PAN):
    Огибающая глушит сигнал. Тишина в паузе ноты.

[7] EFFX page (ручка 5, DSND -> ручки 4,6..8, DTIM/DFB/DBAS/DWID):
    Посыл в кольцевой буфер дилея X:$114000. Эхо продолжает звучать
    после отпускания клавиши.
