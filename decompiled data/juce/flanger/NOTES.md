# FX-FLANGER (m19) — NOTES

Листинг: `03_listings/machines_page_A/19_FX-FLA_full.txt`
(init $144E81 / config $144E99 / proc $144E9A, срез $144E81-$145035, 345 слов).
Майнинг: `scripts/exp_m19_fla.py` (эмулятор DSP56300).

## Диагноз текущего порта

В 1.7.11 машина 19 рендерится generic-флейнджером (`NovaDSP.h: id==19 →
flanger.setParameters(...)`) — не прошивка: нет ROM-таблицы, LFO-интегратора,
знакового FB, ROM-законов ручек.

## Выведенные законы (все с адресами листинга — см. шапку MnmFlaExact.hpp)

| Ручка | Закон | Адрес |
|---|---|---|
| DEL (p0) | target = floor(1021·k/128) − 3 слова (0.07..18.6 мс @44.1к), сглаживание one-pole $28F5C/$FD70A4 | $144E8D-$144E91, $144EFE-$144F09 |
| DEP (p1) | сглаженный стейт $22; рампа тапа = (del+2)<<10 × dep | $144F0A-$144F1B |
| WID (p2) | WID² × $9566 → ширина окна интерполятора | $144EB4-$144EB9 |
| MIX (p3) | out = wet·(127−k)/127 + dry·k/127 | $145027-$145034 |
| FB (p4) | (k−64)/127 × 2.01168, ЗНАКОВЫЙ; comb-возврат buf[tap] += fb·read | $144FBE-$144FC8, $144FD3-$144FE2 |
| SPD (p5) | LFO-интегратор phase += SPD·$28F5C·2 − phase·$028F5C·2 | $144EC8-$144ECF |
| INP (p7) | 4·(k/127)² | $144EA6-$144EAB |

- Линия задержки: ДВА кольцевых буфера 4096 слов (L=X, R=Y, 48-бит L: доступ),
  тап читается линейной интерполяцией (asr #$4 / mpy·asr #$a).
- Стерео: R-канал = инвертированный LFO × $5A8241 (0.7071) → декорреляция.
- Квадратура: X:$14A000 / X:$14A800 (+2048), рампа по кадру из прошлого блока.
- Фейд-ин: первые 128 кадров мокрый путь растёт (счётчик y:$21).
- Квантование ROM-таблицы (полусинус, пик 0x7FFFFF) — в MnmFlaExactTables.hpp.

## Честные границы

- [РЕКОНСТР.]: 32-итерационный windowed-синтез ($144F8F-$144FA1) с таблицей
  из 10 коэффициентов ($144F73-$144F8D: 11/12, 1/2, 10/12, 1/2, 1, 3/2, 1/2,
  1, 2/12, 11/12) — структура и коэффициенты 1:1, 48-битная обвязка
  восстановлена; и WID-интегратор (x:$11/x:$12, bset #$14).
- Остальное — законы из листинга + эмуляторные свипы.

## A/B

DSP MODE → FX → режим `ex` на машине 19 (FLA): mnm = generic, ex = прошивка.
Ожидаемо: иная кривая DEL (0.07-18.6 мс с one-pole сглаживанием), знаковый FB
(ниже центра — инверсия), ROM-интерполятор вместо generic.
