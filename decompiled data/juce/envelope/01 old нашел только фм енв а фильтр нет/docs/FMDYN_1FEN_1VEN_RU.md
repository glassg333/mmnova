# FM+ DYN (m10): КОНВЕРТЫ 1FEN / 1VEN / 2ENV — ПОЛНАЯ РАСШИФРОВКА

**Дата:** 2026-10-01. Пак 11. Источник: листинг 10_FM-DYN_full.txt
($14619D–$14636E) + бит-в-бит порт MnmFmDyn.hpp (пак 3; оракул — эмулятор
OS 1.32B, 16 наборов ручек × 16 блоков). Адреса — комментарии-обоснование.

Терминология: «резонанс», не «резонатор». m10 — машина трека; её конверты
крутят параметры FM-голоса на машинной странице (r6 = V-страница), они НЕ
относятся к трековому фильтру и НЕ являются «кусками env2» (env2 — общий код
кадра, r6 = $400; у них общие только таблицы шагов $141880).

---

## 1. КАРТА РУЧЕК (слова CONF кладёт как K<<16 в V+$04..$0B)

| Слово | Ручка | Роль в голосе |
|---|---|---|
| V+$4 | 1FRQ | частотное отношение модулятора 1 (clamp $7FFFFF) |
| **V+$5** | **1FEN** | конверт отклонения скорости модулятора 1 |
| V+$6 | 1VOL | громкость/глубина модулятора 1 |
| **V+$7** | **1VEN** | конверт гейна пик-шейпера модулятора 1 |
| V+$8 | 2FRQ | частотное отношение модулятора 2 (квадратичное) |
| **V+$9** | **2ENV** | droop-конверт уровня модулятора 2 |
| V+$A | 2FB | фидбек (воблит адрес чтения LUT модулятора 2) |

ЗАМЕЧАНИЕ: в таблице пака 10 1VEN был приписан к V+$6 — по листингу
($14623C читает V+$7) и порту 1VEN = V+$7, V+$6 = 1VOL. Здесь исправлено.

## 2. INIT (P:$14619D)

Обнуляются машинные стейты V+$11..$2A; в V+$10/$14/$18 (48-битные фазовые
аккумуляторы модуляторов и карриера) пишется база синус-таблицы $14A000.

## 3. CONF (P:$1461A8–$1461C0) — стартовые значения конвертов

- `V+$2D = $7FFFFF` — droop-стейт уровня модулятора 2 = полный.
- **Старт 1VEN-стейта V+$2C:** `a = 1VEN − 0.5`; `b = a · 1VOL`;
  если 1VEN < 0.5 → a = b; **V+$2C = a << 2**.
  То есть: при 1VEN ≥ 64 старт = 4·(1VEN−0.5); при 1VEN < 64
  старт = 4·(1VEN−0.5)·1VOL (учёт громкости).
- **Старт 1FEN-стейта V+$2E:** `b = 1FEN − 0.5`; если < 0 → b/2 (asr);
  **V+$2E = sign(b)·b·|b|** — квадрат с сохранением знака
  (1FEN ≥ 64 → +(1FEN−0.5)²; 1FEN < 64 → −(0.5−1FEN)²/2).

CONF вызывается при настройке машины — каждый новый голос стартует с этих
значений (это и есть «где начинают»).

## 4. 1FEN — КОНВЕРТ СКОРОСТИ МОДУЛЯТОРА 1 ($1461CE–$1461E0)

Каждый кадр PROC:

```
idx = 128 − 2·|1FEN − 64|                ; asr#$f от (K−64)<<16, abs, 128−…
level(V+$2E) = level · (−SHAPE_B[idx])   ; mpy -x1,x0, таблица $141880
inc1 = 4·ratio1·carrierInc + (level >> 12)   ; asr#$c, add b,a → L:$5-путь
```

- **Индекс-парабола:** центр ручки (K=64) → idx=128 (медленнее всего),
  края (K=0/127±) → idx=0..2 (быстрый спад).
- Таблица $141880: idx=0 → ×0.8977/кадр (−60 дБ ≈ 64 кадра = 23.2 мс);
  idx=64 → ×0.99852 (≈1.69 с); idx=126 (K=63/65) → ×1.000015 — лёгкий РОСТ;
  idx=127 → ×1.0 (заморозка).
- **Краевой случай K=64:** idx=128 читает ПЕРВОЕ СЛОВО СЛЕДУЮЩЕЙ таблицы
  $141900 (= +1) → множитель −1 → инверсия знака уровня каждый кадр; но при
  K=64 стартовый уровень = 0 (CONF) → всегда 0. Звуковой эффект — нулевой.
- **Куда идёт:** смещение инкремента фазы модулятора 1 = level>>12. 1FEN —
  это «спадающее отклонение» высоты модулятора от карьера: нота стартует с
  отклонением (квадрат ручки) и плавно съезжает к чистому соотношению 1FRQ.
- **Где начинают/чем кончают:** старт = CONF-значение sign(b)·b·|b|;
  конец → асимптота 0 (скорость по параболе ручки). Условия перезапуска —
  новый CONF (нота/смена параметров).

## 5. 1VEN — КОНВЕРТ ГЕЙНА ПИК-ШЕЙПЕРА ($14623A–$146262)

Каждый кадр PROC:

```
idx = 128 − 2·|1VEN − 64|                ; та же парабола, та же таблица
level(V+$2C) = level · (−SHAPE_B[idx])
gate = max(0, 1VOL + level − 0.5)        ; $146249–$14624F
shape: y[i] = (y[i]·gate)<<4 + y[i−1]    ; пик-шейпер, стейт V+$20, in-place Y:$80
level1 = (1VOL² + level) << 2            ; $14629E–$1462A9 — уровень модулятора 1
```

- Старт = CONF-значение 4·(1VEN−0.5) (или ×1VOL при 1VEN<64).
- Конец → 0: гейт = max(0, 1VOL−0.5), уровень = (1VOL²)<<2 — «сухое»
  статическое состояние машины.
- Смысл: 1VEN временами ДОБАЛЯЕТ громкость и перегиб модулятора 1 сразу после
  ноты (атака ярче), затем спадает к статике. При 1VEN=64 старт 0 → конверт
  выключен.

## 6. 2ENV — DROOP УРОВНЯ МОДУЛЯТОРА 2 ($1462AA–$1462C2)

```
если 2ENV ≥ 0.5:
    x = (2ENV − 0.5)²                    ; mpy x0,x0
    droop = $7FFFFF − x²                 ; mac −x0,x0 → A = $7FFFFF − x·x
    state(V+$2D) = state · droop         ; каждый кадр
level2 = state · ((2ENV)² << 2)
```

- Старт state = $7FFFFF (CONF), уровень модулятора 2 = полный.
- Чем больше 2ENV, тем быстрее droop-множитель уменьшается → хвост модулятора
  2 затухает («dynamic» характер машины). При 2ENV < 64 droop-ветка не
  исполняется — state остаётся полным.
- CONF перезаписывает state обратно в $7FFFFF при новой ноте/настройке.

## 7. СВОДКА «СТАРТ / КОНЕЦ / УСЛОВИЯ» (кадр = 0.3628 мс)

| Конверт | Старт (CONF) | Каждый кадр | Конец | Условия |
|---|---|---|---|---|
| 1FEN (V+$2E) | sign(b)·b·\|b\|, b=1FEN−0.5 | ×(−SHAPE_B[128−2\|K−64\|]) | →0 (асимптота) | сброс новым CONF |
| 1VEN (V+$2C) | 4·(1VEN−0.5) [·1VOL если <64] | ×(−SHAPE_B[128−2\|K−64\|]) | →0 | сброс новым CONF |
| 2ENV (V+$2D) | $7FFFFF | ×($7FFFFF−x²), x=((2ENV−0.5)²) при 2ENV≥0.5 | →0 при 2ENV>64 | 2ENV<64: без спада |
