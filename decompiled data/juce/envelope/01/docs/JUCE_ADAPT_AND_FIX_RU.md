## 1. ЧТО КЛАСТЬ В JUCE-ПРОЕКТ (карта модулей по пакам)

| Файл | Откуда | Роль | Статус |
|---|---|---|---|
| `MnmAmpEnv.hpp` + `MnmAmpEnvTables.h` | пак 7 | ENV 1: AMP-конверт (ATK/HOLD/DEC/REL, TRIG 1/2/3) + гейн-путь VOL²·sin/cos + рамп | бит-в-бит |
| `MnmEnv2.hpp` + `MnmEnv2Tables.h` | пак 10 | ENV 2: конверт глубины модуляции тапов делэя | бит-в-бит 6120/0 |

Правила интеграции:

- **Модель времени:** конверты тикают РАЗ В КАДР = 16 сэмплов @ 44.1 кГц
  (0.3628 мс). В `processBlock` дели буфер на 16-сэмпловые кадры: сначала
  `tick()` конвертов, потом 16 сэмплов аудио. Бит-точность гарантируется
  только при 44.1 кГц; на другой частоте пересчитывай время и помни, что
  таблицы шагов остаются прошивочными.
- **Слова параметров:** ручки приходят в модули как сырые слова `K<<16`
  (0..127). Не нормализуй во float до передачи в бит-точные модули.
- **Триггеры:** TRIG-слово AMP-конверта: 1 = note-on (уровень НЕ сбрасывается —
  нативный ретригер!), 2 = note-off (→ REL), 3 = kill (→ фаза 4, ×0.904016).
- **KILL-гейт резонанса:** после тика AMP-конверта передай его слово фазы в
  стадию 2: фаза 4 → множитель затухания резонанса = 0 ($0AC0–$0AC4) — хвост
  резонанса глохнет мгновенно при снятии ноты. Это гейт, не ручка.
- **env2:** по умолчанию уровень = 1.0 (модуляция тапов = просто DWID²);
  ячейки $418–$41B скрыты от UI/MIDI в прошивке — выставляй их только если
  делаешь расширение, и помни: единственный потребитель — рампа тапов делэя,
  НЕ фильтр.
- **Порядок тракта в кадре** (как в прошивке, пак 8): машина → env2 → копия
  истории → стадия 1 (срез) → EQ → AMP-конверт → гейн → HPQ/LPQ-резонанс →
  делэй → стадия 2 (резонанс) → хвост (MnmTail) → выход/эхо-шина.
- Каркас-обёртка для voice:

```cpp
struct MnmEnvStack {                       // минимальный конвертный стек
    mnmfm::MnmAmpEnv  amp;
    mnmenv2::MnmEnv2  env2;                // (пак 10)
    mnmtail::TailIn0  tin{};               // наполнение из кадра
    // … стадия 2 / хвост по мере подключения
    void noteOn()  { amp.trig(1); }
    void noteOff() { amp.trig(2); }
    void kill()    { amp.trig(3); }        // фаза 4 → KILL резонанса
};
```

## 2. ВОСЕМЬ ТИПОВ ПОЛОМОК В СТАРЫХ ПРОЕКТАХ И ЭТАЛОННЫЕ ЗАМЕНЫ

Все замены — `juce/MnmEnvLegacyFix.h` (smoke: ALL OK; T5 совпадает с
MnmTail.hpp бит-в-бит на сетке 200×200). Автопоиск — `LegacyEnvFixer.py`.

| # | Поломка | Замена |
|---|---|---|
| B1 | Термин «резонатор» в коде/доках | «резонанс» / «блок резонанса» |
| B2 | Стадия 2 «кормит» тапы делэя | связи нет (exp68); удалить запись L2→тапы |
| B3 | BOFS/WOFS перепутаны с DBAS/DWID | kCellFilterBOFS/$416,$417 vs kCellDelayDBAS/$41E,$41F |
| B4 | env2 подключён к фильтру («второй фильтр») | env2 → рампа тапов делэя ($0B1E); дефолт 1.0; kEnv2DefaultLevel |
| B5 | Нет KILL-гейта: резонанс висит после note-off | `stage2DecayMultiplier(phase, dec)`: phase==4 → 0 |
| B6 | Атака с заворотом int (клац/инверсия) | `ampAttackStep`: сатурация $7FFFFF + фаза HOLD |
| B7 | REL/DEC/KILL одним множителем | `decayIdxFromRateWord`: REL/DEC слова свои; KILL = raw $20 → idx 1 |
| B8 | ADSR на DBAS/DWID | её нет: `dwidRamp16` = T5 (env·DWID)², анти-зиппер |
| B9 | Пинг-понг внутри DSP | посыл МОНО (T6); сторону двигает знак DSND на хосте |

Запуск линтера:

```bash
python3 juce/LegacyEnvFixer.py /path/to/old_project            # критично/warn
python3 juce/LegacyEnvFixer.py /path/to/old_project --md-terms # + терминология
```

Линтер возвращает 1, если найдены critical-находки (B2/B3/B4/B8). Правки кода
делай руками по таблице — автоматический патч чужих деревьев намеренно не
выполняется.
