# ВСЕ КОНВЕРТЫ MONOMACHINE OS 1.32B — ENV 1 / ENV 2 / ENV 3 + FM-машины

**Дата:** 2026-10-01. Пак 11. Источник: OS 1.32B, DSP1 (P-память), дизасм +
бит-в-бит верификация (паки 3/5/7/8/10/11).
Терминология: «резонанс» / «блок резонанса» / «резонансный хвост» — НЕ «резонатор».

Кадр конвертов = один проход кадра голоса = 16 сэмплов @ 44.1 кГц = **0.3628 мс**.
Все уровни — 24-битные слова Q1.23 (полный уровень $7FFFFF = 1.0).
Конвертные таблицы ОБЩИЕ: атака $141800 (SHAPE_A), спад/релиз $141880 (SHAPE_B).

## 1. ENV 1 — AMP-КОНВЕРТ (VEN)

Код P:$088E–$08D7, бит-в-бит порт MnmAmpEnv.hpp (пак 7; верификация task 43).

### Ячейки

| Слово | Смысл | Диапазон |
|---|---|---|
| P+$00 | ATK (скорость атаки, индекс $141800) | 0..127 (слово K<<16) |
| P+$01 | HOLD (длительность удержания, от темпа) | 0..127 |
| P+$02 | DEC (множитель спада, индекс $141880) | 0..127 |
| P+$03 | REL (множитель релиза) | 0..127 |
| P+$28 | TRIG: 1=note-on, 2=note-off, 3=kill | — |
| P+$05/$06 | VOL / PAN | 0..127 |

### Фазы (числа — из таблиц прошивки)

- **TRIG=1 (нота-он): фаза := 0 (ATK), уровень НЕ сбрасывается** (нативный
  ретригер с подхвата).
- **Фаза 0 ATK:** `level += SHAPE_A[ATK]`. K=0 → +0.5/кадр (полный за 2 кадра
  ≈ 0.73 мс); K=64 → +0.00238 (≈152 мс); K=127 → +0.000012 (≈30 секунд).
  Сумма вышла за 24 бита (флаг E) → **дата-лимитер пишет $7FFFFF** (не −1.0!),
  фаза := 1 (HOLD), счётчик := 1.
- **Фаза 1 HOLD:** порог = ((HOLD·tempo)>>23 · $791FD0 · 4); счётчик++ пока
  (счётчик<<24) ≤ порога, потом фаза := 2. HOLD=0 → 1 кадр.
- **Фаза 2 DEC:** `level = −level·SHAPE_B[DEC]` (таблица отрицательная, спад
  положительного уровня). K=0 → ×0.8977/кадр (−60 дБ ≈ 64 кадра = 23.2 мс);
  K=64 → ×0.99852 (−60 дБ ≈ 4669 кадров ≈ 1.69 с); **K=127 → ×1.0 — заморозка**.
- **TRIG=2 (нота-off): фаза := 3 (REL)** — та же арифметика со словом REL.
- **TRIG=3 (kill): фаза := 4 (KILL)** — фиксированное слово скорости $20 →
  индекс 1 → **×0.904016/кадр** (−60 дБ ≈ 68 кадров ≈ 25 мс) — «штатное»
  быстрое гашение без ручки.
- Уровень < 1 LSB → тишина; уровень хранится как есть (ретригер подхватывает).

### Выход

Гейн-путь P:$08D8–$08FA: v = level·VOL²; L = v·cos[panIdx+1], R = v·sin[panIdx]
(база $14A801 — сдвиг +1, поэтому PAN 0 = жёстко влево); 16-сэмпловый линейный
рамп на канал от предыдущей цели (анти-клик).

### РОЛЬ В KILL ХВОСТА РЕЗОНАНСА (главное)

Слово фазы AMP-конверта читается в кадре: **фаза == 4 → множитель интегратора
блока резонанса = 0 ($0AC0–$0AC4) — резонансный хвост глохнет мгновенно**.
Это гейт-вход от AMP-конверта, а НЕ отдельная ручка и НЕ «энвелоуп фильтра».
Эхо при этом НЕ трогается (эхо и фильтр — два разных блока, exp68).

## 2. ENV 2 — КОНВЕРТ ГЛУБИНЫ МОДУЛЯЦИИ ТАПОВ ДЕЛЭЯ

Полный пословный разбор, кадр ячеек и верификация — ENV2_RAZBOR_RU.md (пак 10).
Здесь — выжимка для полноты слота.

- Код P:$04A8–$04F4, исполняется для любой синт-машины (skip при Y:$124≠0 —
  FX-слоты без env2). r6 = $400, ячейки Y:$418–$41B скрыты от UI/MIDI.
- Гейт-форсаж: хост пишет номер фазы в Y:$421 — машина прыгает на 1 кадр.
- Фазы: 0/прочее → level = $7FFFFF (по умолчанию модуляция = DWID²);
  1 атака level += SHAPE_A[$418>>16]; E-флаг → $7FFFFF и фаза 4;
  4 спад level ×(−SHAPE_B[$419>>16]) до (sustain)²; 5 сустейн level = ($41A)²;
  2 релиз level ×(−SHAPE_B[$41B>>16]) без конца.
- **Выход Y:$4FF имеет РОВНО ОДНОГО потребителя** — $0B1E–$0B22:
  рампы тапов делэя Y:$10–$1F ← (env·DWID)². К фильтру env2 не подключена.
- Верификация: 489 кейсов / 2040 кадров, **6120/0** [100% ENV2 BIT-EXACT].
- Числа атак/спада — те же ряды, что в ENV 1 (общие таблицы).

## 3. ENV 3 — DIST DRIVE-ENV (P:$04FF–$0536) — полный стат. разбор (новое, пак 11)

Конверт «драйва» DIST-обработчика, который диспетчер вставляет в слот делэя
(канон: модулирует delay-время; атрибуция итерации 52). Вот его машина пословно:

### Ячейки

| Ячейка | Роль |
|---|---|
| P+$0C | ATK — индекс таблицы атаки $141800 (слово K<<16) |
| P+$0D | DEC — индекс вычитающей таблицы спада **$141A00** (округление (K+$7FFF)>>16) |
| P+$20 | триггер хоста: запись 1 → полный сброс (фаза 0, уровень 0), самоочистка |
| P+$23 | TEMPO — слово темпа (в фазе HOLD; для DIST множитель всегда 0) |
| скретч Y:(r7−$1) | фаза (0=атака, 1=hold, 2=спад) |
| скретч X:(r7−$1) | уровень (24 бита) |
| скретч X:(r7−$2) | счётчик фазы hold |

### Фазы (по листингу $04FF–$0536)

- **Триггер ($04FF–$0505):** хост пишет 1 в P+$20 → фаза := 0, уровень := 0,
  P+$20 самоочищается. Дальше исполнение падает в фазу 0 этого же кадра.
- **Фаза 0 АТАКА ($0509–$0516):** `level += SHAPE_A[ATK>>16]` ($141800).
  Переход в HOLD происходит по **переполнению** (E-флаг): пока переполнения
  нет, ветка `bec` ($0510) уходит на сохранение уровня БЕЗ смены фазы; когда
  сумма выходит за 24 бита — дата-лимитер сатурирует $7FFFFF, фаза := 1,
  счётчик := 1 (та же схема, что в AMP/env2: атака кончается переполнением). Времена — как в ENV 1:
  ATK=0 → 2 кадра (0.73 мс); ATK=64 → ≈152 мс; ATK=127 → ≈30 с.
- **Фаза 1 HOLD ($0517–$052A):** порог считается от TEMPO (P+$23), но
  множитель `mpy y0,x0` здесь всегда 0 (`clr a; move a,x0`) → порог 0 →
  **HOLD длится 1 кадр** — у DIST-конверта эффективная форма AD.
- **Фаза 2 СПАД ($052B–$0536):** `level −= TBL_E[(DEC+$7FFF)>>16]` — таблица
  **$141A00, вычитающая** (не множитель!): idx=0 → −0.015625/кадр (полный спад
  за 64 кадра ≈ 23.2 мс); idx=64 → −0.000421 (≈2375 кадров ≈ 862 мс);
  **idx=127 → −0 — уровень не убывает (вечный)**. Отрицательный уровень
  клампится в 0 (`clr b ifmi`).
- Уровень живёт в скретче X:(r7−$1); читается кодом DIST-слота (полный трейс
  потребителей — в очереди портов, на атрибуцию не влияет).

**Итог ENV 3:** старт — с 0 по триггеру хоста (P+$20=1); атака — таблица $141800
до сатурации $7FFFFF; HOLD — 1 кадр; спад — вычитающий $141A00 до 0;
KILL-гейта стадии 2 у него нет (он гейтится только своим триггером).

## 4. FM-КОНВЕРТЫ (кратко; полный разбор — FMDYN_1FEN_1VEN_RU.md)

- **FM+ STAT (m8):** 1ENV (V+$6) — уровень оператора 1: значение <64 — оператор
  молчит; level = 1ENV²·(droop-сглаживание, стейт V+$2A, CONF кладёт $7FFFFF).
  Это ручка тембра с огранкой, НЕ конверт времени.
- **FM+ PAR (m9):** 1ENV/2ENV/3ENV (V+$5/$7/$9) — уровни трёх операторов:
  G = max(0, ENV−64), та же огранка на 64.
- **FM+ DYN (m10):** единственная из FM-троицы с конвертным кодом —
  1FEN ($1461CE, из V+$5) и 1VEN ($14623A, из V+$7): каждый кадр
  `state ×(−SHAPE_B[128 − 2·|K−64|])` — индекс параболой вокруг 64.
  2ENV (V+$9) — droop-множитель уровня модулятора 2.
  ЗАМЕЧАНИЕ К ПАКУ 10: там индекс записан как 128 − |K−64|; по листингу/порту
  (asr #$f от слова K<<16) индекс = **128 − 2·|K−64|**. Краевой случай K=64:
  индекс 128 → чтение первого слова СЛЕДУЮЩЕЙ таблицы $141900 (слово +1 →
  инверсия знака множителя), но при K=64 стартовый уровень = 0 → всегда 0.

Это машинные уровни/тембр операторов FM-голоса (страница r6 = V-страница
машины), НЕ трековый фильтр и НЕ env2 (та — общий код кадра, r6 = $400).

## 5. ГДЕ ЧТО ЛОМАЕТСЯ В СТАРЫХ ПРОЕКТАХ (см. JUCE_ADAPT_AND_FIX_RU.md)

1. Конверт на срезе фильтра — среза его НЕ имеет (env-free, 4 доказательства).
2. Стадия 2 «кормит» делэй — связи нет (exp68).
3. BOFS/WOFS перепутаны с DBAS/DWID ($416/$417 vs $41E/$41F).
4. env2 подключён к фильтру / назван «вторым фильтром» — не он.
5. Нет KILL-гейта фазы 4 — резонансный хвост висит после снятия ноты.
6. Атака без data-limiter — заворот в отрицательные вместо сатурации $7FFFFF.
7. REL/DEC/KILL одним множителем — в прошивке три разных слова (+ фикс $20).
8. ADSR на DBAS/DWID — её нет; есть T5-рампа (env2·DWID)² с анти-зиппером.

Эталонные замены — juce/MnmEnvLegacyFix.h (smoke: ALL OK, T5 совпадает с
MnmTail.hpp бит-в-бит). Линтер — juce/LegacyEnvFixer.py.
