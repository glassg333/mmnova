ПАК 11 — ENV 1/2/3 + FM+ DYN (1FEN/1VEN) + ХВОСТ $0AD1–$0B4C В C++ + JUCE-АДАПТАЦИЯ
Monomachine OS 1.32B, DSP1. Дата: 2026-10-01.

ОТВЕТЫ НА ЗАПРОС «да давай и env 1 2 3 … все энвелоупы распиши подробно и сделай
джус адаптацию … и фикса старых проектов где энвелоупы были сломаны»
---------------------------------------------------------------------------------
1) FM+ DYN 1FEN/1VEN расшифрованы ЦЕЛИКОМ (docs/FMDYN_1FEN_1VEN_RU.md):
   1FEN = конверт отклонения скорости модулятора 1 (стейт V+$2E, смещение
   инкремента = level>>12); 1VEN = конверт гейна пик-шейпера + добавка к
   уровню мод-1 (стейт V+$2C); 2ENV = droop-множитель уровня мод-2 (V+$2D).
   Каждый кадр: state ×(−SHAPE_B[128 − 2·|K−64|]) — парабола индекса вокруг 64.
   Поправка к паку 10: индекс = 128 − 2·|K−64| (а не 128 − |K−64|);
   1VEN = V+$7 (V+$6 = 1VOL). Исправление объяснено и не влияет на выводы пака 10.
2) Хвост $0AD1–$0B4C перенесён в C++ (dsp/mnm/MnmTail.hpp) и верифицирован:
   verify: OK=8296 BAD=0 [100% TAIL BIT-EXACT] — ожидания взяты из снапшотов
   эмулятора OS 1.32B (exp22_snap/exp22_skip), 56 кадров, skip-ветвь покрыта.
3) ENV 1/2/3 расписаны подробно с числами (docs/ENV123_RAZBOR_RU.md):
   ENV1 = AMP-конверт (фазы ATK/HOLD/DEC/REL/KILL, таблицы $141800/$141880,
   TRIG 1/2/3, KILL-гейт резонанса при фазе 4 — $0AC0–$0AC4);
   ENV2 = конверт модуляции тапов делэя (пак 10, 6120/0 — сводка);
   ENV3 = DIST drive-env ($04FF–$0536) — НОВЫЙ пословный разбор: ATK $141800
   до сатурации, HOLD 1 кадр, спад ВЫЧИТАЮЩЕЙ таблицей $141A00 (DEC=0 → 23.2 мс,
   DEC=127 → вечный), триггер P+$20=1.
4) JUCE-адаптация + фиксер (docs/JUCE_ADAPT_AND_FIX_RU.md, juce/):
   карта модулей по пакам, правила времени (кадр 16 сэмплов), TRIG-слова,
   порядок тракта; 9 типов поломок старых проектов B1–B9 с эталонными
   заменами (juce/MnmEnvLegacyFix.h, smoke ALL OK) и линтером
   (juce/LegacyEnvFixer.py).

ТЕРМИНОЛОГИЯ
------------
Пишем «резонанс» / «блок резонанса» / «резонансный хвост». AMP-конверт при
фазе 4 гасит затухание резонанса ($0AC0–$0AC4) = KILL хвоста при снятии ноты;
это гейт-вход, не отдельная ручка. Эхо и фильтр — два РАЗНЫХ блока (exp68).
