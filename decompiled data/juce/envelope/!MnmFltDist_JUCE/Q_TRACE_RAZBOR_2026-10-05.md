## 2. ТОПОЛОГИЯ Q-СТУПЕНИ (полный кадр, program order)

1. $04F5–$04FD: машина-шина → потоки X:$97–$A7 (движок A) и X:$D7–$E7 (B).
2. $0537–$056C: закон тона (порт: mnm_tone_index.h) → X:$4D9/Y:$4DA.
3. $0573–$059A: кольцо из Y:$410/$411 → Y:$04–$07 (порт: mnm_filter_ring.h,
   бит-в-бит mnm_17). Y:$04–$07 = ПЕРВЫЕ слова банка Y:$04–$33 (16×3 коэффа).
4. $05A1/$05B5: каскад func_000340, кольцо mod-4 (порт: mnm_cascade340.h,
   бит-в-бит). Выход → X:$95+.
5. $05C3–$05FA: halfband-глей: банки Y:$91+/$D1+ (сид прошлого кадра) →
   два полублока do #<$8 (константы $F528BD/$4A4DF0) → потоки X:$71+/X:$73+.
6. $05FF–$0649: LPQ-интерполяция (вес):
   b = idx·$FFFDF3 + sat(idx−$5BF)·$FFE666 + sat(idx−$63F)·$FFA666
   (HPQ-ветка $06E1–$06ED: третий член $FFD99A);
   a = Y:$40B; b += poly·a; b += a·$FFF912; clamp;
   сид: state = (state + b)/2 [$061F–$0628, r7-$1E];
   x1 = дробь, r0/r1 = целая строка.
7. $0629–$0649: интерполяция пар (kQPairA/B/C) по (строка, дробь) →
   коэффициент → Y:$1E/$1D [$0648/$0649]; второй проход → Y:$1C [$0665].
8. $0654–$06B9: трансформ-блоки (2×do #<$8): развёртка коэффициентов по банку
   Y:$04–$33 (писатели $0692/$069E/$069F/$06B8).
9. $06BF: jsr func_000350 — биквад A: r0=r1=$74 (поток IN-PLACE X:$74/Y:$74+),
   r4=$4 → банк Y:$04+ шаг (+1,+1,−2) … линейная прогулка 16×3;
   семена a/b со стека r7; a-ветка → l:(r1)+ (в поток), b-ветка → x1 (ОС).
10. $06C2/$06C3: jset #0,X:$40F → пропуск движка B (гейт владельца).
11. $06CA: jsr func_000350 — биквад B: r0=r1=$B4 (in-place X:$B4/Y:$B4+).
12. $06CD–$0719: HPQ-интерполяция (тот же закон, ячейка Y:$40A, сид r7-$25)
    → коэффициенты $0718/$0719/$072C.
13. $0718–$0779: трансформы → банк; $0788/$0799: jsr func_000365 ×2
    (следующая ступень потоков); далее $07BF/$07F4/$07F8 → $0820–$0890
    (гейн EQ $0857, порт в mnm_tone_index.h) → резонанс $08E9+ → T5/T6.

## 3. ЗАКОН Q-ДРОБИ (сид → свежие q), измерено

Дробь (x1 после сида) при одном кадре инжекции, idx-ветка $63F:
  LPQ=0   → x1 = $000000
  LPQ=64  → x1 = $800000   (= (0 + $1000000)/2: цель = слово ручки <<17)
  LPQ=127 → x1 = $EE0000
Целевая дробь ≈ (слово_ручки << 17)/$1000000, ограниченная полиномом
idx-членов; кадр-за-кадром state → цель (однополюсник 1/2). Отсюда разные
значения при повторном прогоне (сид) — владелец прав.
