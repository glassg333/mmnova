# MnmFltDist — JUCE-порт тракта FLT+DIST Monomachine SFX-60 MkII (OS 1.32B)

Фильтр (кольцо коэффициентов + каскад func_000340 + фильтровая огибающая
BOFS/WOFS), дисторшн и огибающие тракта ядра DSP1 (DSP56303) — из декомпиляции
прошивки. Сборка по КОРРЕКТНОЙ карте ячеек (CONTROL_MODS_MAP_RU §3, пак 14;
вердикт сверки GITHUB_SYNC_VERDICT_2026-10-03 §4). Фильтр приходит
в дист — слышимая ступень 4k+клип стоит после фильтра.

mnm_16: РЕЗОНАТОР ИЗ ТРАКТА УБРАН. func_000397 (сканер 8 дробных тапов с
демпфированной ОС, HPQ/LPQ) — начинка ДЕЛЕЙ-машины, ОТДЕЛЬНОГО модуля машины
(правка владельца). В тракте FLT+DIST его нет; бит-точный материал сохранён
в пакете mnm_15, сверка с векторами пака 8 — при портировании делея.

**mnm_19 (2026-10-04): ФИКСЫ ПО КРИТИКЕ ИМПОРТА (разбор Nova).** Три
подтверждённых дефекта устранены, четвёртый — опровергнут по фактам:

1. **СТЕРЕО-КАДР — ИСПРАВЛЕН (дефект был реален).** processL/processR
   двигали ОБЩИЙ cnt_ — при вызове парой L,R счётчик рос вдвое быстрее,
   кадр стрелял на середине стереокадра, оба буфера забивались дырами
   (inBufL_ на чётных, inBufR_ на нечётных индексах). Новый API:
   `pushStereo(inL, inR, &outL, &outR)` — один счётчик на пару, оба буфера
   пишутся на одном индексе. Моно-API оставлен ТОЛЬКО для моно-шин
   (документировано в шапке). Процессор переведён на pushStereo.
   ВАЖНО: outL == outR при L == R НЕ ожидается — стадия 2 асимметрична
   по дизайну прошивки (банки a/b = X:$30–$3F / X:$20–$2F с раздельным
   стейтом). Тесты: DC-установившийся режим покадрово постоянен;
   pushStereo(L) == processL(L) канал-в-канал.
2. **СЛОВО РУЧКИ DIST Y:$404 — ПОДАЁТСЯ ХОСТОМ.** setDistWord(w) →
   ступень $079F–$07D1 (x0 = max(0, 2w−1.0); folding активен только при
   w ≥ $400000, т.е. v ≥ 64). В плагине добавлен 17-й параметр DIST
   (линейное слово; дефолт $400000 = нижняя граница folding).
   Делитель X:$40B — setDistDivWord() (сток: дыра = 0).
3. **БАНКИ ДИСТА В МИКС НЕ СУММИРУЮТСЯ — И ЧЕСТНО ЗАФИКСИРОВАНО.**
   distOutRaw() отдаёт банки (bankA = X:$B0–$D3 после pass2, bankB =
   X:$72–$93) и пины (y1/x0/r2/kDrive/curveW/K1/K2) хосту, но суммирование
   в аудио-микс НЕ добавлено: потребитель банков вниз по тракту НЕ
   трассирован — веса были бы додумкой. На стоковой OS банки немы
   (X:$40B = дыра → y1 = $FFFFFF = −ε — измерено exp72c).
4. **ЗАКОН ДЕЛИТЕЛЯ УТОЧНЁН (ошибка старых комментариев).** Частное DIV
   живёт в формате A0 (беззнаковая дробь, y1_A0 = 8·2^24/D), в знаковом
   mpy читается как signed Q23: D=0/8 → $FFFFFF = −ε → K1 ≈ 0 (банки
   немы); D=16 → $800000 = −1.0 → K1 = −kDrive; D=32 → $400000 = 0.5 →
   K1 = kDrive/2. Прежнее «K1 = kDrive при D = 16» — неверно
   (K1 = +kDrive недостижим: $800000 знаково = −1.0). Пины в тестах.

4. **Кривая ColdFire ручка→слово DIST — ЗАКРЫТО.** ColdFire кладёт слово

5. **Банковая ступень DIST P:$07BD–$07D1 — ЗАКРЫТО (проведено).** Полная

   знаковом mpy $FFFFFF = −1 → на стоковой OS (X:$40B = 0 — дыра) банки
   диста немы (K1 = $FFFFFF ≈ −ε); K1 = kDrive точно при D = 16. Конвейер:
   store ПРЕДЫДУЩЕГО acc (параллельные перемещения), asl #8 в pass1,
   acc-переток через границу pass1→pass2 (пин p2[0] = $0000E6).
6. **Q-интерполятор P:$0629–$0649 — ЗАКРЫТО (атрибуция).** Это интерполятор
   коэффициентов EQ-биквада (таблицы $141A98/$142158/$142F06) по сглаженному
   индексу от Y:$4DA — домен TONE. Сами биквады func_000350 вне скоупа
   голоса (полнота хвоста — пак 8); слышимый путь панча (гейн EQ $0857 +
   фактор среза $07D4) проведён.

Бонус-фиксы арифметики: mpy56/mac56 получили ре-расширение знака из бита 55

## «Кольцо» — окончательное определение (владелец, mnm_16)

«Кольцо» в этом модуле = КОЛЬЦО КОЭФФИЦИЕНТОВ ФИЛЬТРА — ступень P:$0573–$05A2,
которая из BASE/WDTH через таблицы kDiv1/kDiv2 и 24-шаговое деление считает
пары срезов; выход — модуль-4 кольцо регистров Y:$04–$07
(c[0]=Y:$04 срез, c[1]=Y:$05 eps, c[2..3]=Y:$06/$07 ширина).
Название совпало с FX-машиной RINGMOD, но к ней блок отношения НЕ имеет —
RINGMOD (эффекты) не трогается вообще.

* HOLD в AMP env (в ядре — темпо-счётчик P:$088E–$08D7, связь OPEN);
* хвост окна каскада (регион $97–$AC шире кадра);

**OPEN (честно, изолировано в коде; == §7 DECOMPILATION_NOTES, шесть пунктов):**
1. WOFS-ветка P:$0569–$056B — разводка WOFS в индекс LP не замкнута
   статически; в порту WOFS входит той же математикой, что BOFS (ERRATA +
   мануал + владелец);
2. Трекинг питча P:$054F–$055A — шкала X:(V−$27) и роли bit11/bit9
   Y:(V−$03) требуют прогона на эмуляторе; в порту — как в листинге;
3. Домены tone-путь ↔ кольцо (клампы $700/$63F/$6A3, таблицы $143546 /
   $143F95) — соединены регистрами, цепочка не восстановлена; в порту —
   пропорциональное преобразование (PORT WIRING, modulateWord);
4. Кривая ColdFire «ручка → слово D» DIST и закон аттенюации отрицательной
   половины — ColdFire не дизассемблирован; порт: линейный маппинг knob;
5. Банковая ступень DIST P:$07BD–$07D1 (34 слова ×k·y1, ←7 под
   насыщением; y1 = частное 8/X:(V−$1D)) — реализована измеренным
   скалярным законом 4k+клип; семантика X:(V−$1D) и идентичность банков —
   OPEN;
6. Q-интерполятор P:$0629–$0649 / P:$06F9–$0719 (тройник таблиц
   $141A98/$142158/$142F06, кламп $7FFFA4) — включение результата
   (y:$1d/y:$1e) в кольцо не замкнуто; в порту HPQ/LPQ идут напрямую
   таблицами (материал делея — вне тракта mnm_16).

(asr + лимитер), панч 64 кадра, AHDR, env2 SUS², каскад стабилен,
латентность 1 кадр, note-off закрывает гейты, пины ступени DIST и тона
(mnm_18), стерео-кадр pushStereo + проведение слова DIST (mnm_19).

### Плагин (VST3/Standalone)
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
Первый прогон подтянет JUCE 8.0.4 через FetchContent.

Сетка: кадр = 16 сэмплов (родная сетка машины). Латентность = 1 кадр
(~0.36 мс @44.1к) — свойство прошивки.
