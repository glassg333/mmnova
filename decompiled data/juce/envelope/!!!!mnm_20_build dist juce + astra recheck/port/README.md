# MnmFltDist — JUCE-порт тракта FLT+DIST Monomachine SFX-60 MkII (OS 1.32B)

Фильтр (кольцо коэффициентов + каскад func_000340 + фильтровая огибающая
BOFS/WOFS), дисторшн и огибающие тракта ядра DSP1 (DSP56303) — из декомпиляции
прошивки. Сборка по КОРРЕКТНОЙ карте ячеек (CONTROL_MODS_MAP_RU §3, пак 14;
вердикт сверки GITHUB_SYNC_VERDICT_2026-10-03 §4). Фильтр приходит
в дист — слышимая ступень 4k+клип стоит после фильтра.

## «Кольцо» — окончательное определение (владелец, mnm_16)

«Кольцо» в этом модуле = КОЛЬЦО КОЭФФИЦИЕНТОВ ФИЛЬТРА — ступень P:$0573–$05A2,
которая из BASE/WDTH через таблицы kDiv1/kDiv2 и 24-шаговое деление считает
пары срезов; выход — модуль-4 кольцо регистров Y:$04–$07
(c[0]=Y:$04 срез, c[1]=Y:$05 eps, c[2..3]=Y:$06/$07 ширина).
Название совпало с FX-машиной RINGMOD, но к ней блок отношения НЕ имеет —
RINGMOD (эффекты) не трогается вообще.

**DIV** — репликация DIV-пути кольца, доказанная эмулятором до слова:
делимое = 1<<24 (трасса $0583/$0584: move #$1,a → A = 00000001000000 —
левое выравнивание imm8 в аккумуляторе), после 24 шагов A = 00005E9C000075
→ q0 = 0x75 = 2^24/143188. Пин в test_sanity. История mnm_15/mnm_16:
op_Div-версия расходилась из-за OPEN начального состояния acc — теперь
закрыто: делимое 1<<24, q0 бит-в-бит с ядром (peak каскада 0.9661 —
ядерно-верный). Дополнительно: probe_eps.py 9/9, сетка 128×128 — бит-в-бит
(sweep_ring_grid.py, 30 точек эмулятора).

**Реконструкция / PORT WIRING (помечено в коде):**
* вход env-членов в кольцо (в ядре цепочка регистров между веткой
  P:$0537–$0572 и кольцом не замкнута статически — notes §4.1–4.3);
* HOLD в AMP env (в ядре — темпо-счётчик P:$088E–$08D7, связь OPEN);
* хвост окна каскада (регион $97–$AC шире кадра);
* обвязка плагина (Processor/Editor) переписана начисто после сбоя
  воркспейса 2026-10-04; DSP-блоки — оригинальные.

**OPEN (честно, изолировано в коде; == §7 DECOMPILATION_NOTES, шесть пунктов):**
1. WOFS-ветка P:$0569–$056B — разводка WOFS в индекс LP не замкнута
   статически; в порту WOFS входит той же математикой, что BOFS (ERRATA +
   мануал + владелец);
2. Трекинг питча P:$054F–$055A — шкала X:(V−$27) и роли bit11/bit9
   Y:(V−$03) требуют прогона на эмуляторе; в порту — как в листинге;
3. Домены tone-путь ↔ кольцо (клампы $700/$63F/$6A3, таблицы $143546 /
   $143F95) — соединены регистрами, цепочка не восстановлена; в порту —
   пропорциональное преобразование (PORT WIRING, modulateWord);
4. Кривая ColdFire «ручка → слово D» DIST и закон аттенюации отрицательной
   половины — ColdFire не дизассемблирован; порт: линейный маппинг knob;
5. Банковая ступень DIST P:$07BD–$07D1 (34 слова ×k·y1, ←7 под
   насыщением; y1 = частное 8/X:(V−$1D)) — реализована измеренным
   скалярным законом 4k+клип; семантика X:(V−$1D) и идентичность банков —
   OPEN;
6. Q-интерполятор P:$0629–$0649 / P:$06F9–$0719 (тройник таблиц
   $141A98/$142158/$142F06, кламп $7FFFA4) — включение результата
   (y:$1d/y:$1e) в кольцо не замкнуто; в порту HPQ/LPQ идут напрямую
   таблицами (материал делея — вне тракта mnm_16).

**Состав против старого бандла (по вердикту §4, минимальный корректный набор):**

## Сборка

### Ядро без JUCE (самопроверка)
```
g++ -std=c++17 -O2 -I Source -o test_sanity Tests/test_sanity.cpp && ./test_sanity
```
Ожидаемо: ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ (0 провалов), 39 чеков; якоря таблиц,
пин div24 (q0=0x75), 7 пинов кольца против эмулятора, сетка 128×128
(asr + лимитер), панч 64 кадра, AHDR, env2 SUS², каскад стабилен,
латентность 1 кадр, note-off закрывает гейты.

### Плагин (VST3/Standalone)
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```
Первый прогон подтянет JUCE 8.0.4 через FetchContent.

Сетка: кадр = 16 сэмплов (родная сетка машины). Латентность = 1 кадр
(~0.36 мс @44.1к) — свойство прошивки.
