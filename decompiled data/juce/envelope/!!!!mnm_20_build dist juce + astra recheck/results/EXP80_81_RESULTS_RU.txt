1. КТО ПИШЕТ X:$40B (прямая проверка блока смены машины)
====================================================================
Дизасм P:$00E8–$00F6 (r6 = $428 у диспетчера машин):
  00F0: move #$20,x0          ; $20 — левое выравнивание imm8 → x0 = $200000
  00F1: move x0,x:(r6-$1d)    ; → X:$40B = $200000 (0.25 Q1.23)
  00F3: move #>$1,x0
  00F4: move x0,x:(r6-$19)    ; → X:$40F = 1
  00F5: move b,x:(r6-$20)     ; → X:$408 = индекс машины (Y:$429)
  00F6: jsr  (r2)             ; init машины (X:$10016B+idx)
Живой прогон свитча на оракуле (watch X:$40B/$40F/$408/$40C):
  машина 1:  WRITE x:$40B = 200000 (PC $00F1), x:$40F = 1, x:$408 = 1
  машина 14: то же, x:$408 = E
  машина 19: то же, x:$408 = 13
Init машин ($144CC9/$145AB5/$144E81) X:$40B НЕ пишут.
Вывод: X:$40B НЕ «дыра» — константа init-а смены машины. Харнес трасс
(stарый) стартовал с $0100 и свитч не исполнял → в трассах лежал 0 →
ложный вывод «дыра → div0 → банки немы» (исправлен в track_harness.py).

3. ПИНЫ СТУПЕНИ ДИСТА ПРИ OS-ДЕФОЛТЕ X:$40B = $200000 (exp81/81b)
====================================================================
Пошаговая трасса $079F–$07BD (DIST=0):
  $079F y0 = X:$40B = $200000
  $07A0 a = $000008000000 (move #$8,a → A1 = 8, ПРАВОЕ слово!)
  $07A2-$07A4: 24× div y0,a → A = E00000000040 (A1 = остаток, A0 = частное)
  $07A5 y1 = a0 = $000040 (64)          ← НЕ frac(8/D)=$400000, а 8·2^24/D
  $07B7 x1 = curve[r2=0] = $7FFFFF
  $07B9 b = $1FFFFFC00000 (K2-acc), a,y0 → y0 = kDrive = $021333
  $07BA a = y1·y0 = $000001099980
  $07BC a,y0 → y0 = K1-слово = $000001 (A1), x0 = вход банки
Сетка DIST (D = $200000):
  v=0:   y1=$000040 kDrive=$021333 K1=$000001 K2=$1FFFFF
  v=96:  y1=$000040 kDrive=$218E66 K1=$000010 K2=$0B504F
  v=127: y1=$000040 kDrive=$7C1878 K1=$00003E K2=$0B504F
  v=-64: как v=0
ЗАКОН (исправленный):
  y1 = 8·2^24 / D (частное 24-шагового DIV, слово A0)
  K1 = word(y1·kDrive) → при D=$200000 банк A ≈ НЕМ (K1 ≤ $3E при любом v)
  K2 = word(curve·D)  → банк B жив: 0.25·curve на стоке
  div0 (D=0): A сатурируется в $00FFFFFFFFFFFF → y1 = $FFFFFF ≈ −1.0 →
  K1 ≈ −2·kDrive — банк A инвертирует сигнал (баг порт-версий ≤ mnm_19)
Старые пины exp72d (D=8, div0) остаются валидными как модульные (D — вход).
