EXP70 (2026-10-03) — ЖИВАЯ ТРАССА БЛОКА $04A8 / ЯЧЕЕК EFX НА БИТ-ТОЧНОМ ЭМУЛЯТОРЕ
================================================================================

A. ЧИТАТЕЛИ (полная трасса эффективных адресов, 3 кадра, с форсажем фазы $421=1):
   Y:$418 (EQF)  -> только $04B4 (env2, атака)
   Y:$419 (EQG)  -> только $04CC/$04C9 (env2, спад)
   Y:$41A (SRR)  -> только $04DE/$04C9 (env2, сустейн/сравнение)
   Y:$41B (DTIM) -> только $04E5 (env2, релиз)
   Y:$41F (DWID) -> только $0B1E (рампа T5)
   Y:$41C (DSND) -> только $0284 (пролог, знак ветки делэя)
   Y:$41E (DBAS) -> только $02C8 (пролог, база длины делэя)
   X:$40B        -> $079F (делитель гейна EQ) — пишет ИНИТ машины ($00F1, константа $20)
   X:$40F        -> $05A9/$05E8/$06C2/$078E/$0833/$08FD — пишет ИНИТ ($00F4, константа 1)
   ВЫВОД: эквалайзер/дециматор в кадре эти слова НЕ читают. Единственный
   потребитель $418-$41B — гейт конца цепи ($04A8 + T5).

B. ГЕЙТ-ФОРСАЖ $421 (DWID=96, EQF..DTIM=64):
   $421=1 (атака): level 0x16F978 -> 0x0261A9 -> 0x00081D -> ~0 (общая ячейка
                   $4FF: level' = (level·DWID)² + SHAPE_A[EQF] — коллапс)
   $421=2 (релиз): 0x16B70F -> 0x0242C8 -> 0x0005BB -> 0 за 3 кадра
   $421=4 (спад):  фаза 4 -> 5, уровень -> сустейн
   $421=5 (сустейн): level = SRR²·DWID²: SRR=32 -> 0x004800; 64 -> 0x048000;
                   127 -> 0x45C6B7 (= 0.545) — совпадение с формулой бит-в-бит

C. T5/T6 (трасса адресов $0B1E-$0B49, по словам):
   $0B1E читает y:(r6+$1f) = Y:$41F (DWID)
   $0B20/$0B23 читают Y:$4FF (уровень env2)
   $0B28 пишет Y:$4FF (стейт рампы = (level²·DWID²))
   $0B31/$0B32 пишут рампу Y:$10-$1F (16 слотов, без ступенек)
   $0B45/$0B46 пишут выход: X:(X:$FF)+ и Y:$0000-$001F
   $0B48 пишет моно-эхо: (L+R)/2 -> X:(X:$2C9)+ (эхо-шина X:$300+)
   T6 умножает каждый слот: (сухая шина X:$00-$1F + резонанс L2 Y:$20-$3F) × mod[k]

D. ГРАБЛИ ХАРНЕСА (для воспроизведения):
   1) ключи страницы АБСОЛЮТНЫЕ: e.Y[0x41F]=v<<16, НЕ e.Y[P+0x41F] (двойной сдвиг
      молча обнуляет ручки — первый прогон exp70 из-за этого показал «свипы не работают»);
   2) без события $421/$428 фазовые ветки не исполняются -> трасса читателей пуста;
   3) в харнесе пака 7/8 X:$FF=0 -> выходное кольцо T6 совпадает с банком X:$00-$1F
      (само-фидбек) — для аудио-измерений учитывать.
