ПАК 14 (2026-10-03): КАРТА УПРАВЛЯЮЩИХ МОДУЛЯЦИЙ + УНИВЕРСАЛЬНЫЙ МЕТОД + ИСПРАВЛЕНИЕ АТРИБУЦИИ $04A8

ЧТО ЭТО
1) docs/CONTROL_MODS_MAP_RU.md — ГЛАВНЫЙ ДОК: под какими именами/ячейками хранятся
   управляющие модуляции фильтра (ATK/DEC/BOFS/WOFS = резонанс стадии 2), FM-машин
   (1FEN/1VEN/2ENV, 1ENV/2ENV/3ENV), где AMP-энвелоуп (AHDR $088E-$08D7, $400-$403),
   и финальная атрибуция блока $04A8 = ГЕЙТ/УРОВЕНЬ КОНЦА ЦЕПИ (узел LEVEL:
   усиление финального микса, выход -> выходное кольцо + моно-эхо-посыл).
   Плюс итоговая сверка CC -> ячейка -> реальная роль в DSP.
2) docs/UNIVERSAL_METHOD_RU.md — универсальный метод извлечения блоков без гадания:
   оракул-эмулятор -> живая трасса эффективных адресов -> диф-свип -> привязка к
   сигналу -> хост/UI -> бит-в-бит порт. С граблями (двойной сдвиг P+, фазовые
   ветки без событий, греп vs трасса).
3) results/ — живые доказательства (exp70): трасса читателей, гейт-форсаж $421=1/2/4/5
   с числами, T5/T6 по словам, JSON с полными прогонами.
4) tools/ — шаблоны трассировки (exp70*.py), готовые к переиспользованию на любом
   блоке/ячейке.
5) dsp/mnm/ — актуальные порты гейта и хвоста: MnmEnv2.hpp (6120/0), MnmTail.hpp
   (8296/0), MnmEnv2Tables.h. Атрибуция в комментариях MnmEnv2.hpp устарела
   («рампы тапов») — семантика верна, см. CONTROL_MODS_MAP_RU.md §1.4.

ГЛАВНЫЕ ИЗМЕНЕНИЯ ПРОТИВ ПАКОВ 10-12
- «env2 = конверт рамп тапов делэя» -> ГЕЙТ/УРОВЕНЬ КОНЦА ЦЕПИ (усиление финального
  микса + эхо-посыл). Живая трасса: выход Y:$4FF потребляется рампой T5, рампа
  умножает микс T6; к тапам/длине делэя связи нет.
- $421 = one-shot ФОРСАЖ ФАЗЫ (хост пишет номер фазы), режимы: полный/закрытие/
  сустейн SRR²/релиз. Числа в results/EXP70_RESULTS_RU.txt.
- EQF/EQG/SRR/DTIM ($418-$41B) в кадре читает ТОЛЬКО гейт (трасса + греп сходятся).
- X:$40B/$40F — константы ИНИТа машины ($20 / 1), не коэффициенты ручек.
