## 1. ГДЕ КАКАЯ МОДУЛЯЦИЯ (имена → ячейки → код → порт)

### 1.1 AMP-энвелоуп (AHDR) — «AMPLIFICATION ENVELOPE» роутинга

| Что | Значение |
|---|---|
| Ручки (AMP-страница) | ATK HOLD DEC REL — **$400 $401 $402 $403** (CC56–59) |
| Код | **P:$088E–$08D7** |
| Событие | TRIG_EVENT **$428**: 1 = note on (уровень НЕ сбрасывается — нативный ретриг), 2 = note off → фаза 3 (REL), 3 = KILL → фаза 4 |
| Фазы | ATK: level += SHAPE_A[$141800][ATK], конец по переполнению → дата-лимитер $7FFFFF (НЕ −1.0) → HOLD (порог от темпа $423) → DEC/REL: ×(−SHAPE_B[$141880][DEC/REL]); DEC=127 → ×1.0 заморозка; фаза 4 (KILL) — фикс слово $20 → индекс 1 → ×0.904016/кадр |
| Связь с резонансом | фаза 4 → KILL-гейт стадии 2 ($0AC0–$0AC4): множитель интегратора = 0, хвост резонанса глохнет мгновенно; note-off (фаза 3) хвост НЕ глушит |
| Порт | **пак 7** `MnmAmpEnv.hpp` + `MnmAmpEnvTables.h` (plugin-level, бит-в-бит) |

### 1.2 Управляющие модуляции ФИЛЬТРА

### 1.4 Узел LEVEL = блок $04A8 («env2» паков 10–12) — финальная атрибуция

**Что это: гейт/уровень КОНЦА цепи (узел LEVEL роутинга).** Усиление финального
микса трека = сухая шина (после машины → фильтра → диста → AMP env → VOL/PAN)
+ резонансный хвост стадии 2. Не конверт тапов (паки 10–12 ошибались), не
«второй фильтр» — гейт последнего каскада перед выходом.

| Часть | Адрес | Факт (живая трасса exp70c: адреса подтверждены) |
|---|---|---|
| Фаза | X:$400 | 0/иное = полный уровень; 1 атака; 4 спад; 5 сустейн; 2 релиз |
| Гейт-форсаж | Y:$421 | one-shot: хост пишет НОМЕР ФАЗЫ — машина прыгает в неё, ячейка самоочищается ($04AD–$04B1); хост гасит флаг в буфере после каждой отсылки страницы (coldfire $048386–$048396, трио $420/$421/$428) |
| Атака | Y:$418 (EQF, CC80) | level += SHAPE_A[$141800][$418>>16]; читатель $04B4 |
| Спад | Y:$419 (EQG, CC81) | level ×(−SHAPE_B[$141880][$419>>16]) до сустейна; читатели $04C9/$04CC |
| Сустейн | Y:$41A (SRR, CC82) | level = ($41A)²; читатель $04DE |
| Релиз | Y:$41B (DTIM, CC83) | level ×(−SHAPE_B[$41B>>16]) без конца; читатель $04E5 |
| Выход уровня | Y:$4FF | пишется $04BE/$04C1/$04D5/$04E0/$04EE/$04F3 |
| Рампа T5 | $0B1E–$0B33 | читает DWID **$41F** ($0B1E) и уровень $4FF ($0B20/$0B23); строит 16-слотовую рампу без ступенек **Y:$10–$1F** от уровня к (уровень·DWID)²; стейт пишется обратно в $4FF ($0B28) |
| Микс T6 | $0B33–$0B49 | (сухая шина X:$00–$1F + резонанс L2 Y:$20–$3F) × mod[k] каждый слот |
| Куда подаёт усиленный сигнал | — | (1) выходное кольцо X:(X:$FF)+ и Y:$0000–$001F → блок-микшер → мастер; (2) моно-эхо-посыл (L+R)/2 → X:(X:$2C9)+ → эхо-шина X:$300+ → мастер-делэй |

Живые числа (эмулятор, $418–$41B = 64, DWID = 96):
- $421 = 2 (релиз): уровень 0.18 → 0.018 → 0.0004 → 0 за 3 кадра — коллапс в тишину
  (покадровый квадрат (level·DWID)² в общей ячейке $4FF);
- $421 = 5 (сустейн): уровень = SRR²: SRR=0 → 0; 32 → 0.0039·DWID² = 0x4800;
  64 → 0.0625·DWID² = 0x48000; 127 → 0.545 = 0x45C6B7 — совпало с формулой бит-в-бит;
- $421 = 1 (атака): level = стейт + SHAPE_A[EQF], далее квадрат — при DWID<127
  равновесие около нуля (−110 дБ при 64/64/96); при DWID=127 уровень держится.

Порт: **пак 10** `MnmEnv2.hpp` (6120/0) + **пак 11** `MnmTail.hpp` (T5+T6, 8296/0).

## 2. КАК ИЗВЛЕЧЬ ДЛЯ JUCE (готовое)

1. Взять порты из паков (все — заголовки C++ без зависимостей + таблицы из pmem):
   `MnmAmpEnv.hpp` (пак 7), `MnmFilterStage2.hpp`+`MnmFilterCurves.h` (пак 5),
   `MnmFmDyn.hpp` (пак 3), `MnmEnv2.hpp` (пак 10), `MnmTail.hpp` (пак 11),
   `MnmDistDrive.hpp` (пак 12/13).
2. Модель времени: кадр = 16 сэмплов @ 44.1 кГц = 0.3628 мс; конвертный тик — раз
   в кадр; таблицы SHAPE_A/$141800, SHAPE_B/$141880 — уже в заголовках.
3. Триггеры: $428 = 1/2/3 (note on/off/kill) — вход в MnmAmpEnv; $421 = форсаж фазы
   env2 (one-shot); $420 = панч.
4. Порядок на кадр: машина → env2 → AMP env → VOL/PAN → стадия 1 → EQ/DIST →
   стадия 2 → T5 рампа → T6 микс (гейт) → выход + эхо-посыл.
5. Проверка идентичности: векторы из паков (emulator-oracle) — прогнать
   `tools/test_*.cpp`, ожидается mismatches=0. Правила адаптации и 9 фиксов
   сломанных реализаций — пак 11 `JUCE_ADAPT_AND_FIX_RU.md` + `MnmEnvLegacyFix.h`.
