`OPEN` / `РЕКОНСТРУКЦИЯ` / `PORT WIRING` — вольных додумок нет.

## 3. Архитектура (сверка с мануалом и машиной)

Мануал OS 1.32 (FILTER PAGE): «combined resonant 24dB low/band/high-pass
filter… BASE controls the base filter cut-off… WDTH controls the filter gap
width… HPQ/LPQ… individual Q-control». FILTER ENVELOPE: ATK/DEC/BOFS/WOFS —
«BOFS sets the value that will be added to the filter BASE [from the
envelope], WOFS … to the filter WDTH».

Реализация в модуле (все части доказаны, кроме отмеченного):

```
BASE, WDTH (слова страниц) ──[env-модуляция BOFS/WOFS: 4·$700·env·|p−0.5|²]──┐
                                                                             ▼
[кольцо P:$0573-$059A] div1[BASE·$4AF], div2[WDTH·$80], DIV-путь → f, eps, width-пары
        │ (Y:$04-$07 — модуль-4 кольцо коэффициентов)
        ▼
[func_000340 ×2 (L/R)] гибрид FIR+SVF, halfband 2× ($F528BD/$4A4DF0)   ← БИТ-В-БИТ
        │
        ▼
[func_000397 + HPQ/LPQ] гребёнка 8 дробных тапов + демпфированный фидбек ← БИТ-В-БИТ
        │
        ▼
[DIST P:$079F-$07D1] x0=max(0,2D−1); k=0.98379·x0²+0.01621; ступень 4k + клип ±1.0
        │   кривая c=kDrive[idx] → множитель коэффициента среза следующего кадра
        ▼
[AMP env P:$04A8-$04F5] гейт громкости выходящего звука
```

Соответствие ролям (подтверждено владельцем машины):
* два фильтра (НЕ одиночный резонатор): каскад 1 — пара срезов
  (BASE = низкий срез, BASE+WDTH = верхний), резонанс каскада 2 даёт Q
  раздельно (HPQ/LPQ);
* огибающая фильтра двигает оба среза через BOFS/WOFS (биполярные, центр 64);
* DIST без огибающих; управление — аттенюацией входа (ниже 0) и перегрузом
  (выше 0); интегрирован с фильтром (мануал) — кривая c затемняет срез;
* AMP AHDR — единственная громкостная огибающая-гейт на выходе.

## 4. OPEN-пункты (честный список; в коде помечены)

1. **WOFS-ветка P:$0569–$056B.** В листинге результат `mac y1,x1,b` после
   `clr b ifmi` перезаписывается `move y:(r6+$10),b` — регистровая разводка
   WOFS в индекс LP по этому листингу не замыкается. В порту WOFS входит той
   же математикой, что BOFS (ERRATA: |V-$1A+$C00000|·$700 «для BOFS/WOFS»;
   мануал: WOFS = env-добавка к WDTH; владелец: энвелоуп на hi cut есть).
2. **Трекинг P:$054F–$055A.** Вклад `mac x1,y0` в домен A1 =
   (pitchAcc·16)>>24; шкала X:(V-$27) на входе ветки и точные роли
   bit11/bit9 (Y:(V-$03)) требуют прогона на эмуляторе. Реализовано как в
   листинге; хост может подать любое слово через `setPitchTrackingWords`.
3. **Согласование доменов tone-путь ↔ кольцо.** Tone-индекс (клампы $700/
   $63F/$6A3, таблица $143546) и кольцо (·$4AF, таблица $143F95) соединены в
   ядре через регистры, полная цепочка которых не восстановлена статически.
   Порт: env-члены пересчитаны в слова кольца пропорционально длинам таблиц
   (`PORT WIRING`, `MnmVoiceFilterDist::modulateWord`).
4. **Точная кривая ColdFire «ручка → слово D» DIST** и закон аттенюации
   отрицательной половины — сторона ColdFire не дизассемблирована (FACTS:
   «НЕ ЗНАЮ… кривые считает ColdFire»). Порт: линейный маппинг в `setKnob`,
   аттенюация изолирована в `inputGain_`.
5. **Банковая ступень DIST P:$07BD–$07D1** (34 слова, ×k·y1, ←7 под
   насыщением; y1 = частное 8/X:(V-$1D)) — реализована измеренным скалярным
   законом 4k+клип; семантика X:(V-$1D) и точная идентичность банков — OPEN.
6. **Q-интерполятор P:$0629–$0649/P:$06F9–$0719** (тройник таблиц
   $141A98/$142158/$142F06, кламп $7FFFA4, пары macsu, деление) — таблицы
   извлечены, но включение результата (y:$1d/y:$1e) в кольцо не замкнуто
   статически; в порту Q идёт напрямую таблицами HPQ/LPQ (что даёт
   доказанные крайние точки резонатора).
7. **Кривая разбега тапов резонатора** между крайними точками (HPQ=0 → 1.0,
   HPQ=127 → 15.8828) — линейная калибровка пака, помечена РЕКОНСТРУКЦИЯ.

## 6. История атрибуций (почему верить текущей версии)

* Итерации ≤14 пака считали P+$14–$17 «ATK/DEC/BOFS/WOFS» → итерация 15
  опровергла (это delay-модуляция) и ошибочно объявила «у фильтра нет
  огибающей вовсе».
* ERRATA (новее) вернула: V-$1C/V-$1B = FilterAttack/FilterDecay;
  V-$1A/V-$19 = BOFS/WOFS — по формуле биполярной центровки P:$053E–$054B.
* Владелец машины (промпт + записи mmnova) независимо подтвердил: энвелоупы
  base/width есть, BOFS/WOFS к ним идут, дист без огибающих, тракт
  фильтр → дист, AMP — гейт выхода.
* Мануал OS 1.32 подтверждает все 8 ручек FLT-страницы и формулировку DIST.

Текущая реализация следует ERRATA + мануалу + словам владельца.

## 7. Как верифицировать дальше

1. Прогон модуля против эмулятора (monomodule уже собирает dsp56300 и грузит
   те же секции syx): сравнить кольцо/огибающую/DIST слово-в-слово на сетке
   кадров 16 (интерфейсы модуля это позволяют: `setFiltWords`,
   `setDistWord`, `MnmFilterEnv::tickBlock`).
2. Закрыть OPEN п.2/3/5/6 трассировкой ядра с фиксацией X/Y-памяти на границах
   P:$0537/$059A/$079F/$07DB (методика svf_trace.py в mmnova).
3. A/B с машиной: свипы BASE/WDTH при BOFS/WOFS в крайних положениях и
   ATK/DEC на минимуме — проверка env-члена и его домена.
