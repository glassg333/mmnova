АРХИВ 5 — ЭНВЕЛОПЫ ФИЛЬТРА (ATK/DEC/BOFS/WOFS): НАЙДЕНО + БИТ-ТОЧНОЕ ЯДРО
Monomachine Nova, OS 1.32B, стадия 2 трекового фильтра (P:$0A5D-$0AD0)
Дата: 2026-09-28

ОТВЕТ НА ВОПРОС «ГДЕ ЭНВЕЛОПЫ ФИЛЬТРА (BOFS)»
----------------------------------------------
Страница FILT: BASE WDTH HPQ LPQ ATK DEC BOFS WOFS (дескрипторы ОС).
Ячейки страницы голоса: P+$14=ATK, P+$15=DEC, P+$16=BOFS, P+$17=WOFS.
Код — стадия 2 фильтра, ядро DSP1, P:$0A5D-$0AD0:
  L1 $0A5D-$0A82  вращение, угол c1 = X:$144AC7[BOFS]
  L2 $0A84-$0A9B  вращение, угол c2 = X:$144AC7[WOFS+BOFS]
  L3 $0A9D-$0AB5  вращение, угол c3 = X:$144B48[(сост. делеЯ P+$CF>>17)]
  DP $0AB7-$0AD0  depth = (2|ATK-0.5)^2; DEC = множитель; KILL при фазе 4
Кривая $144AC7 — та же, что TONE у FM-машин и HP/LP реверба (258 слов).
Выход стадии 2 -> интегратор + гребёнка тапов делеЯ ($0AD1-$0B4C) ->
банк тапов L:$90-$A0. «Фильтр с энвелопами» из мануала = этот резонатор:
он и есть модулятор тапов делеЯ (поэтому старая добыча путала его с делем).

ЧТО СДЕЛАНО (доказано, не на слух)
----------------------------------
MnmFilterStage2.hpp — пословная транскрипция L1/L2/L3/DP в C++ (Q23,
56-бит аккумулятор, data limiter DSP56300). Сверка с эмулятором OS 1.32:
34 конфигурации x 8 кадров = 272 кадра, 37 536 слов, расхождений 0
[100% BIT-EXACT]. Свип покрывает: все 4 ручки x 7 позиций (0,1,32,64,96,
126,127) + 6 форсированных состояний делеЯ (ненулевые индексы кривой L3).

ВАЖНОЕ ИСПРАВЛЕНИЕ СТАРОЙ ДОБЫЧИ
--------------------------------
Модель итерации 18 (exp18) снималась со СТАРЫМ эмулятором — без data
limiter. На актуальном (верифицированном, том же, что дал бит-точные FM):
  - move b,x0 при b=2^47 сатурируется в $7FFFFF (не $800000 = -1.0!);
  - индекс кривой L3 = A0-часть (биты [40..17]) состояния ДЕЛЕЯ P+$CF,
    а не стейта резонатора P+$CC, и не старшие биты.
В порту учтено; старые векторы exp18 устарели (в пак не включены).

ЧЕГО ЭТОТ АРХИВ НЕ ЗАКРЫВАЕТ (честно)
-------------------------------------
1. Хвост $0AD1-$0B4C (DIV-интегратор + гребёнка тапов func_000397) в C++
   не перенесён — он словно верифицирован отдельно (итерация 22,
   OK=8296/BAD=0), перенос — следующий шаг.
2. В плагин ядро ещё не встроено: стадии 2 нужны входы всего тракта
   (аудио-шины и банк), т.е. полный бит-точный кадр голоса (SVF-каскад 1,
   EQ, AMP, DIST, делей). Это и есть следующая очередь работ.
