# mnm_flt_dist_juce — Фильтр (FLT) и дисторшн (DIST) Monomachine для JUCE

Декомпилированные блоки **FILTER** (два фильтра + Q + фильтровые огибающие
BOFS/WOFS) и **DIST** (аттенюация/перегруз, без огибающих) тракта
Monomachine SFX-60 MkII, OS 1.32B — из дизассемблированного ядра DSP56303.

Полная доказательная база (адрес → формула, таблицы, OPEN-пункты):
**DECOMPILATION_NOTES.md** — читать перед правками.

## Что внутри

* `source/` — чистый C++17 **без зависимостей от JUCE** (header-only);
  включается в любой JUCE-проект (или standalone).
* `test/test_sanity.cpp` — самопроверка фактов декомпиляции:
  `g++ -std=c++17 -I../source -o test_sanity test_sanity.cpp && ./test_sanity`
* `reference/` — выписки листинга ядра по всем реализованным регионам +
  отчёт кросс-проверки таблиц.

## Быстрый старт

```cpp
#include "MnmVoiceFilterDist.h"

mnm::MnmVoiceFilterDist fx;
fx.setSampleRate(44100.0);
fx.setFiltWords(
    mnm::wordFromKnob(32),   // BASE  — низкий срез (low cut)
    mnm::wordFromKnob(80),   // WDTH  — ширина створа (верхний срез = BASE+WDTH, hi cut)
    mnm::wordFromKnob(84),   // HPQ   — резонанс верхнего фильтра
    mnm::wordFromKnob(31),   // LPQ   — резонанс нижнего фильтра
    mnm::wordFromKnob(10),   // FLT ATK
    mnm::wordFromKnob(40),   // FLT DEC
    mnm::wordFromKnob(58),   // BOFS  — env→BASE (биполярная, 64 = нейтраль)
    mnm::wordFromKnob(80));  // WOFS  — env→WDTH (биполярная, 64 = нейтраль)
fx.setDistKnob(20);          // DIST −64..+63 (без огибающих)
fx.setAmpWords(mnm::wordFromKnob(0),   // AMP ATK
               mnm::wordFromKnob(0),   // AMP HOLD
               mnm::wordFromKnob(64),  // AMP DEC
               mnm::wordFromKnob(64),  // AMP REL
               mnm::wordFromKnob(0));  // AMP SUS (уровень удержания)
fx.trigger();                // FILTER-trig / нота ON

// в processBlock — по сэмплу (модуль сам буферизует кадры по 16):
float outL = fx.processL(inL);
float outR = fx.processR(inR);
```

Обвязка `juce::AudioProcessor` (MIDI, параметры) — `source/MnmFilterDistJuceExample.h`.

## Важные свойства

* **Сетка кадров 16 сэмплов** (родная сетка машины). Латентность фильтра =
  ровно 1 кадр (~0.36 мс @44.1к) — это свойство прошивки, не «задержка плагина».
* **Таблицы — дословные слова прошивки** (18 таблиц из `dsp1_pmem.bin`,
  SHA-256 и кросс-чек — в DECOMPILATION_NOTES §2 и reference/table_report.json;
  Q-таблицы дозаполнены 2026-10-04: kQTableA 527, kTbl2/kQTableC 1601,
  kQGainTbl 911 — полные регионы в reference/q_tables_full_regions.json).
* Каскад `func_000340` — **бит-в-бит** верифицирован паком filter_phaser_pack
  против эмулятора DSP56300 (svf_recursion_proven.md). func_000397 (тап-сканер)
  — код ДЕЛЕЯ, в пакет не входит (см. «Что НЕ включено»).
* DIST — точный закон ядра: `x0 = max(0, 2D−1)`, `k = 0.98379·x0²+0.01621`,
  ступень `4k` с жёстким клипом ±1.0 (24-бит слово), кривая привода затемняет
  срез. Ручка −64..+63: меньше нуля — ослабляется вход (фильтр слабее
  перегружается), больше нуля — дист усиливается.
* Порядок тракта: вход → аттенюация DIST → ФИЛЬТР (кольцо → каскад ступени 1
  func_000340; Q — через интерполятор $0610/$06E0 → глайд-тройки 16×3 →
  Q-петлю SVF-пары внутри func_000350/000365 — цепь замкнута статически
  (трасса 2026-10-04) и верифицирована прогоном на эмуляторе (svf_trace.py
  E1–E4, 2026-10-05): Q-ячейки КРОСС ($40B=LPQ→фильтр A, $40A=HPQ→фильтр B);
  см. reference/svf_trace_2026-10-05_results.md) → DIST (4k+клип) →
  AMP-гейт → выход. Единственная обратная связь тракта — собственная Q-петля
  SVF; никакого delay-фидбека/тап-сканера в фильтре нет.

## Что НЕ включено (чтобы не перепутать)

* track delay и его два фильтра (без Q и без огибающих) — P:$0939–$0B49;
* тап-сканер func_000397 (дробные тапы ДЕЛЕЯ: вызовы ядра только
  $0938/$0978/$0A5A/$0B13, в коде FLT их нет) и таблицы $1448C6/$144946/$144BC9
  (чтения $0912/$0914/$0990 — delay-территория; ранее ошибочно атрибутировались
  Q фильтра — отозвано);
* «rotation resonator» stage2 (машина delay-модуляции) — P:$0A5D–$0AD0;
* FM-машины и их огибающие freq 1/2/3;
* EQ-полоса (EQF/EQG).

## Честные ограничения

Открытые места декомпиляции (WOFS-ветка $56B, согласование доменов
tone↔кольцо, кривая ColdFire для DIST, банковая ступень $07BD–$07D1)
перечислены в DECOMPILATION_NOTES §4 и изолированы в коде с пометками.
Шкала трекинга закрыта прогоном: вклад ≤0.02 ед. индекса — музыкально ноль.
Q фильтра: ступень «резонанс» из ранних версий УДАЛЕНА (это был тап-сканер
ДЕЛЕЯ); цепь Q замкнута статически (трасса 2026-10-04) и верифицирована
прогоном E1–E4 (2026-10-05): кросс ячеек $40B→A/$40A→B, param4 = kQGain,
глай = два полублока. В пак добавлен ИЗОЛИРОВАННЫЙ модуль Q —
`source/mnm_filter_q.h` (mnmq::QInterpolator: q-слова + глайд-тройки 16×3) —
за флагом `MNM_ENABLE_EXACT_Q` (по умолчанию ВЫКЛЮЧЕН, поведение тракта
не меняет). Подача троек в звук — после порта движков ступеней A/B
(func_000350/000365; текущий порт покрывает ступень 1 func_000340).
ТРАНСКР-места модуля (asl-экстракция полинома, знак SUBR $064B, масштаб
div-ветки) закрываются реплеем векторов E1/E3/E4 — `test/test_q_vs_emu.cpp`.
Всё остальное — дословная декомпиляция или бит-в-бит верификация из
первоисточников.
