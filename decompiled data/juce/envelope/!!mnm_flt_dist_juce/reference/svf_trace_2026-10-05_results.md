# Прогон svf_trace.py на эмуляторе DSP56300 — результаты E1–E4

Дата: 2026-10-05. Метод: бит-точный эмулятор (dsp_emu.py, итерация 12),
verbatim-код ядра P:$04A8–$0B4C, тестовая страница голоса r6=$400,
дампы X/Y на границах P:$05FF/$06CD/$071A/$077A. Стимул — блок-рейт слово
машины: движок A читает l:(r6+$E2) ($06BD/$06BE), движок B — l:(r6+$E6)
($0783–$0785); маркерный прогон (34 L-слова $4DC..$4FD) подтвердил слоты.
Векторы: `svf_trace_results.json` (E1/E2/E3/E4), скрипт: `svf_trace.py`.

Закрывает OPEN-пункты §8.5 трассы Q (`kernel_P05FF-0719_q_feedback_trace.md`).

## E1 — разводка ячеек страницы (закрывает §8.5.3 в DSP-части)

| Ячейка | Роль | Подтверждение |
|---|---|---|
| y:(r6+$8) | BASE → индекс | E1: idxDA 1920 → 2333 при BASE 0.5→0.7 |
| y:(r6+$9) | WDTH → индекс | E1: тот же idxDA при WDTH=0.7 (симметрично) |
| y:(r6+$a) | Q → интерполятор **фильтра B** ($06E0) | E1: движется только q-пара B; на A не влияет |
| y:(r6+$b) | Q → интерполятор **фильтра A** ($0610); X-сторона = DIST ($079F) | E1: движется только q-пара A |
| y:(r6+$4) | param4 → kQGainTbl (предкоррекция gQ) | E4: f1 −0.000009→−0.184 по свипу; q-слова не меняет |
| y:(r6+$10/$11) | «кольцо» — читается расчётом коэффициентов ($056D/$0578), param-масштаб | E1: не пишется ядром (значение живёт без изменений) |

* **КРОСС-ВКЛЮЧЕНИЕ Q подтверждено прогоном**: LPQ-ячейка ($40B) кормит
  фильтр A, HPQ-ячейка ($40A) — фильтр B; перекрёстного влияния нет.
* Писателей ячеек $408–$411 в DSP-листингах (ядро/машины/диспетчер) НЕТ —
  страницу пишет хост (ColdFire). Маршрутизация CC→ячейки — хост-сторона,
  в DSP-листингах не разрешается; для порта фиксируется карта потребителей.
* Карта пака 2 «CC72–79 → $410–$417»: на DSP-стороне $410/$411 — кольцо
  расчёта коэффициентов (param-масштаб), а НЕ ячейки ручек. Потребители
  ручек = $408–$40F (+X:$40B DIST).

## E2 — плечи движков и поведение при Q (частично закрывает §8.5.1)

Блок-рейт отводы: A = l:(r6+$E2)/l:(r6+$E3) ($06C0/$06C1; mono-дубль
$06CB/$06CC → $E4/$E5 — jset #$0,x:(r6+$f) пропускает только повторный
проход, стores исполняются всегда). Отводы B = $078B–$078D → $E6/$E7/$E8.

* **b-ветка движка A (l:$E3) — LP-подобная**: DC-стимул проходит
  (dc=+0.24/−0.99 при DC±0.25), a-ветка (l:$E2) на устоявшемся DC → 0 и
  проходит переменную составляющую (ac=0.61) — HP-подобная. По кодовой
  симметрии func_000365 — те же роли для B.
* **Q-ячейки = 0 — НЕ рабочая точка**: предкоррекции дают q_hp = −gQ
  (≈−0.98) и q_lp → малый предельный цикл (−0.03); при QB=0.95 —
  полномасштабный самоген (1.0) — резонанс. Реальная машина всегда имеет
  хост-слова Q ≥ 0; ячейка Q=0 в порту должна воспроизводить тот же
  предкоррекционный профиль (это и делает mnm_filter_q.h).
* Каскад подтверждён регистрово: движок B вызывается с r0=$74 ($077E) —
  состояния B = per-sample буфер выходов A (L:$74..$83); вход-слово B =
  l:$4E6 ($0783–$0785), его y/x-половины к $078B переписываются парой
  (x1:x0) из x:$82/$83 — эхо последних per-sample выходов A (№14/№15),
  l:$E7/$E8 — финальные a/b движка B.
* Ограничение прогона: блок-рейт финалы B на тестовой рабочей точке
  слабо различимы — роли плеч B взяты по кодовой симметрии; уточнение —
  на векторах с реальными хост-словами (следующий прогон).

## E3 — концы глайд-таблиц (закрывает §8.5.2)

Глай = **два полублока по 8 сэмплов** (не линейный рамп на 16):

* полублок 1 (k=0..7): старт от сида прошлого кадра (l:$4E0-пара),
  шаг = (текущее − сид)·$10 на сэмпл (micro-ramp, слово-шаг = adj>>19);
* полублок 2 (k=8..15): старт от свежих y:$1d/y:$1e, шаг — ротация
  (сид − текущее)·$10;
* f-треть: половина 1 от f-сида (y:$4E1) к f1, половина 2 от f1 к f2;
* сиды следующего кадра: $0694/$0697 (q-пара) и $06B1 (f2).

Замер (ступенька BASE 0.3→0.7): полублок 1 — микрорамп от прошлого
значения; полублок 2 — выход на свежий уровень q (−0.8688 flat).

## E4 — param4 (закрывает §6.4/§8.5 частично)

y:(r6+$4) → kQGainTbl[param4·$200] = gQ предкоррекции (f1 −0.000009 →
−0.184 по свипу 0→1); q-слова не трогает (предкоррекция позже, в глайде).
X:$40B=0 → DIST-ступень молчит (выход y:$4B0 = 0) — консистентно с
«DIST на стоке нем» (Task 4).
