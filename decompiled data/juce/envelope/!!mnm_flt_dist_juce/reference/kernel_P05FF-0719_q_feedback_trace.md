# Трасса включения Q: P:$05FF–$0719 — от таблиц до обратной связи SVF-пары

Дата: 2026-10-04. Источник: `dsp1_kernel_P0000-0B4D.txt` (dsp56k-emulator,
100% корпусная верификация). Все адреса — P-память DSP1.

Уровни достоверности (как в NOTES §4):
**БВБ** = бит-в-бит из листинга; **ТРАНСКР** = дословная транскрипция, пословная
семафорная роль уточняется прогоном; **ИНТЕРП** = помеченная реконструкция
алгебры до прогона эмулятора.

---

## 0. Ответ на вопрос «какой ещё фидбек?»

НИКАКОГО ДРУГОГО. В тракте FLT на участке P:$05FF–$0719 существует ровно одна
обратная связь — **собственная Q-ОС state-variable-пары**: состояния
интеграторов движка умножаются на q-коэффициенты и **вычитаются** из входного
накопителя (`mac -y0,x0,…` внутри func_000350/func_000365). Слово «каскад» в
формулировке «фидбек каскада» = per-sample движок func_000350/func_000365
(состояния в x:$74.. / x:$B4..), а НЕ delay-каскад.

Чем это НЕ является (все пункты уже отозваны/исключены, NOTES §5):
* тап-сканер func_000397 — код ДЕЛЕЯ, в FLT-коде не вызывается;
* таблицы kHpqDamp/kHpqFb/kLpqFb ($1448C6/$144946/$144BC9, чтения
  $0912/$0914/$0990) — delay-территория;
* delay-фидбек/рампы — P:$0939–$0B49;
* ring mod — FX-машина, к FLT/DIST отношения не имеет.

## 1. Вычисление пары q (фильтр A) — БВБ

Вход: слово среза `y:(r7-$6)`. Внимание: `lua (r6)+$DC,r7` (P:$04FE) +
дрейф r7 на +4 (сохранения выходов func_000340: P:$05A7/$05A8/$05BB/$05BC,
`l:(r7)+` ×4) → слот = **y:(r6+$DA)**; x:(r7-$d) фильтра B = **x:(r6+$D3)**.
Писатели этих слотов вне P:$0000–$0B4D (хост/dispatch) — **OPEN** (см. §6).

```
05FF: move y:(r7-$6),x1        ; x1 = слово среза (БВБ)
0600: tfr x1,a
0601: sub #>$5bf,a             ; a = idx − $5BF
0603: clr a ifmi               ; кламп ≥0            → избыток1
0604: move a,y0
0605: sub #>$80,a              ; a = избыток1 − $80
0607: clr a ifmi               ; кламп ≥0            → избыток2
0608: move a,y1
0609: move #>$63f,x0
060B: tfr x1,a
060C: cmp x0,a
060D: tfr x0,a ifgt            ; x1 = min(idx, $63F)
060E: move a,x1
060F: move x1,r0               ; r0 = индекс (без сглаживания)
```

Полином самовозбуждения (компенсация Q на высоком срезе):

```
0610: move y:(r6+$b),a         ; a = Q-слово параметра (слот r6+$B)
0611: mpyi #>$fffdf3,x1,b      ; b = −$200D·idx
0613: maci #>$ffe666,y0,b      ; b −= $199A·избыток1
0615: maci #>$ffa666,y1,b      ; b −= $599A·избыток2
0617: asl #$18,b,b
0618: tfr x1,b b,y0            ; y0 = полином
0619: move a,x0
061A: mac y0,x0,a              ; a = Q-слово·(1+полином)
061B: clr a ifmi               ; кламп ≥0
061C: move a,x0
061D: maci #>$fff912,x0,b      ; b −= $66EE·a   → индекс банка C
```

Сглаживание пары (сохранение в кадр, half-sum = anti-zipper):

```
061F: move x:(r7-$1e),x0       ; старая половина x
0620: move y:(r7-$1e),a        ; старая половина y
0621: move b1,x:(r7-$1e)       ; новая: полином
0622: move x1,y:(r7-$1e)       ; новая: индекс
0623: add x1,a b1,r2           ; a = старая_y + idx;  r2 = целый(полином) ДО сглаживания
0624: asr a                    ; a = (старая_y + idx)/2      — сглаженный индекс
0625: add x0,b
0626: asr b a1,r1              ; b = (старая_x + полином)/2; r1 = целый(сгл. индекса)
0627: move a0,x0               ; x0 = дробь(сгл. индекса)
0628: move b0,x1               ; x1 = дробь(сгл. полинома)
062D: tfr y0,a b1,r3           ; r3 = целый(сгл. полинома)
```

Тройник таблиц (lerp, macsu = знаковый×беззнаковый):

```
0629: move x:(r1+$141a98),y0   ; tA[r1]      (kQTableA)
062B: move x:(r1+$141a99),y1   ; tA[r1+1]
062E: macsu -y0,x0,a           ; a = tA[r1]·(1−frac)
062F: macsu y1,x0,a            ;   + tA[r1+1]·frac
0630: move x:(r1+$142158),y0   ; tB[r1]      (kTbl2)
0632: move x:(r1+$142159),y1
0634: mpysu -y0,x0,b
0635: add y0,b a,y0
0636: macsu y1,x0,b            ; b = tB-lerp
0637: move x:(r3+$142f06),x0   ; tC[r3]      (kQTableC)
0639: move x:(r3+$142f07),y1
063B: mpysu y1,x1,a
063C: add x0,a b,y1
063D: macsu -x0,x1,a           ; a = tC-lerp
063E: move #>$7fffa4,x0
0640: cmp x0,a
0641: tgt x0,a                 ; кламп tC ≤ $7FFFA4
0642: move a,x0                ; x0 = tC
0643: mpy x0,y1,b              ; b = tC·tB
0644: mpy y0,x0,a              ; a = tC·tA
0645: move b,y0
0646: add #>$800000,a          ; округление
0648: move b,y:$1e             ; **q_lp = tC·tB  → y:$1e**   (БВБ)
0649: move a,y:$1d             ; **q_hp = tC·tA  → y:$1d**   (БВБ)
```

Имена «hp/lp» для tA/tB — по терминологии владельца; какая из таблиц какое
плечо SVF кормит — решается трассой выходов (§6, OPEN).

Коэффициенты интеграторов f (пара ±0.25 — классическая коррекция перегиба SVF):

```
064A: mpy x0,x0,b              ; b = tC²
064B: subr a,b                 ; b = tC² − q_hp
064C: sub #>$400000,b          ; b −= 0.25
064F–0654: div24: частное x1 = $800/q_lp     (y0 = q_lp)
0657–0659: b = ($800/q_lp)·(tC²−q_hp−0.25), asl #10
065A–0662: x0 = kQGainTbl[$200·param4] (таблица $143C06, r1 = param4·$200)
0662: mpy x0,y1,b              ; f1 = kQGain·((…−0.25))
0665: move b,y:$1c             ; **f1 → y:$1c**
0666: move x:(r0+$142158),y1   ; tB[r0] — без сглаживания (r0)
0668: move x:(r2+$142f06),a    ; tC[r2]
0670–0673: y:$5 = tC[r2]·tA[r0]; y:$6 = tC[r2]·tB[r0]  — пара БЕЗ сглаживания
0674–0684: b = ($800/q_lp)·(tC²−q_hp+0.25), asl #10
0685–0692: f2 = kQGain·((…+0.25)) → **y:$4**
```

## 2. Потребление q — единственные чтения y:$1d/y:$1e — БВБ

Проверено grep'ом по всему ядру: записи только $0648/$0649 (A) и $0718/$0719
(B); чтения только $0695/$0698 (A) и $0755/$0758 (B). Других обращений к
y:$1d/y:$1e в P:$0000–$0B4D нет.

```
068C: move x:(r1+$143c06),x0   ; x0 = kQGain-слово (gQ)
068F: mpy x0,y1,b y:(r0)+,a    ; f2 = gQ·poly; a = y:$5 (q_hp без сглаживания)
0690: add #>$800000,a          ; округление
0692: move b,y:$4
0693: move l:(r7),x            ; 48-бит слово блока (вход/состояние кадра)
0694: move a,y:(r7)            ; кадр: q_hp_глад + 0.5
0695: move y:$1d,a             ; **a = q_hp**
0696: sub x0,a y:(r0)-,y1      ; **a = q_hp − gQ**   (предкоррекция)
0697: move y1,x:(r7)
0698: move y:$1e,b             ; **b = q_lp**
0699: sub x1,b a,y0            ; **b = q_lp − $800/q_lp** (x1 = частное div24)
069A: tfr x0,a #$10,x0         ; a = gQ; x0 = $10 (=2^4, масштаб шага глайда)
```

`q_hp_B − tC` (x0 = tC из $0736), `q_lp_B − $800/q_lp_B`.

## 3. Глайд-таблицы коэффициентов (16 сэмплов × 3 коэффициента) — ТРАНСКР

Три пары 8-шаговых циклов строят в y-памяти **три stride-3 таблицы по 16
записей**: f-глайд y:$4+3k, q_hp-глайд y:$5+3k, q_lp-глайд y:$6+3k (k=0..15).
Первые половины (k=0..7) — циклы 1/3, вторые (k=8..15) — цикл 2 (r0 продолжает
с $1D/$1E = те же series со сдвигом). Шаг каждой записи = adj-слово·$10.

```
069C: do #<$8,>$6a0            ; тело $069E–$069F ( конец по машинному слову $69F )
069E: mac y0,x0,a a,y:(r0)+    ; a += q_hp_adj·$10; → y:$5+3k
069F: mac x0,y1,b b,y:(r0)+n0  ; b += $10·q_lp_adj; → y:$6+3k (n0=$2)
06A0: move y:(r0)+,x0          ; x0 = y:$1D = q_hp (чтение назад)
06A1: move l:(r7)+,ba          ; слово блока
06A2: sub x0,a y:(r0)-,x1      ; a −= q_hp; x1 = y:$1E = q_lp
06A3: sub x1,b                 ; b −= q_lp
06A4: tfr x0,a a,y0            ; ротация: y0 = шаг 2-й половины
06A5: tfr x1,b b,y1
06A6: move #$10,x0
06A7: do #<$8,>$6ab            ; тело $06A9–$06AA — вторые половины (y:$1D+3k/y:$1E+3k)
06A9: mac y0,x0,a a,y:(r0)+
06AA: mac x0,y1,b b,y:(r0)+n0
06AB: move #$3,n0              ; шаг stride меняется $2 → $3
06AD: move #$1c,r0
06AE: move y:$1c,x1            ; f1
06AF: tfr x1,a y:(r1),b        ; a = f1; b = y:$4 = f2
06B0: move y:(r7),x0
06B1: sub x0,a b,y:(r7)+       ; a = f1 − y:(r7); f2 → кадр
06B2: sub x1,b                 ; b = f2 − f1
...
06B6: move #$10,x0
06B7: do #<$8,>$6ba            ; тело $06B8–$06B9 — f-глайд (r1=$4+n1=$3 → y:$4+3k;
06B8: mac y0,x0,a a,y:(r1)+n1  ;   r0=$1C+n0=$3 → y:$1C+3k — вторая половина f)
06B9: mac x0,y1,b b,y:(r0)+n0
```

Алгебра концов глайда (откуда стартует каждая половина и куда приходит) —
**ИНТЕРП**, закрывается прогоном с дампом y-памяти на границе кадра.

## 4. Обратная связь: func_000350 / func_000365 — БВБ листинг, роли макросов ТРАНСКР

Вызовы: **$06BF/$06CA** (фильтр A, движок func_000350), **$0788/$0799**
(фильтр B, движок func_000365; второй — при бите 0 слова x:(r6+$f)).
Перед вызовом: r0 = r1 = $74 (A) / $B4, $B2 (B) — буферы состояний/вывода;
r4 = $4 — указатель коэффициентов; вход — 48-бит слово кадра.

func_000350: `do #<$10` = **16 итераций = 16 сэмплов кадра**; r4 шагает +3 за
итерацию (внутри полутела паттерн +1/−2/+1) → читает **тройки
(f, q_hp, q_lp) по сэмплам** из глайд-таблиц y:$(4..7)+3k.

```
0350: move x:(r0)+,x0 y:(r4)+,y1   ; x0 = состояние[0]; y1 = f[k]
0351: move #>$fffffe,n4            ; n4 = −2
0353: move b,x1                    ; x1 = вход (b от вызывателя)
0354: do #<$10,>$363               ; 16 сэмплов
0356: asr #$4,b,b
0357: mac x0,y1,b y:(r4)+,y1       ; b += x0·q_hp[k]; y1 = q_lp[k]?? (шаг +1)
0358: asl #$4,b,b
0359: mac y1,x1,b a,x0 y:(r4)+n4,y0 ; b += y1·x1 (вход); x0 = a; y0 = коэф (шаг −2)
035A: mac -y0,x0,b a,l:(r1)+       ; **b −= y0·x0 — ОТРИЦАТЕЛЬНЫЙ MAC = Q-ОС**;
                                   ; a → L:(r1)+ (вывод кадра)
035B: mac x0,y1,a x:(r0)+,x0 y:(r4)+,y1 ; a += x0·y1; x0 = след. состояние
035C: mac x1,y0,a b,x1             ; a += x1·y0; x1 = b
   … (вторая половина тела — парный канал, $035D–$0363, та же mac -y0,x0,b на $0361)
```

`mac -y0,x0,…` / `mac -y1,x1,…` (в func_000365: $036B/$036F) — единственные
отрицательные умножения обоих движков: **накопитель −= коэффициент × текущее
состояние**. Это и есть резонансная петля SVF-пары, в которую включаются
q_hp/q_lp через глайд-таблицы. Постатабличная роль каждого mac
(какой = f-интегратор, какой = q-ОС, какой = выходной отвод) — ТРАНСКР,
закрывается одношаговым прогоном (§6).

После движка: вывод a/b → `l:(r7)+` ×2 ($06C0/$06C1), затем (бит 0 x:(r6+$f))
второй проход на буферах $B4/$B2 ($06C5–$06CC). Далее — фильтр B
($06CD–$0779), его движок ($0788/$0799), ступень DIST ($079F–$07D1).

## 5. Сводная схема включения Q (итог)

```
индекс среза (кадр, y:(r6+$DA) / x:(r6+$D3))            ← писатель: хост (OPEN)
   │  клампы $5BF/$80/$63F; полином −$200D·idx−… (P:$0611–$061D)
   ▼
lerp kQTableA[k·idx] ─┐
lerp kTbl2[k·idx]     ├─ ×lerp kQTableC[k·полином] (кламп $7FFFA4)
   ▼                  ▼
q_hp = tA·tC → y:$1d   q_lp = tB·tC → y:$1e          (БВБ, $0648/$0649)
   │ предкоррекции: q_hp −= kQGain[$200·param4]; q_lp −= $800/q_lp (div24)
   ▼
глайд-таблицы y:$(4..7)+3k, 16 троек (f, q_hp, q_lp) на кадр   (ТРАНСКР)
   ▼
func_000350 (A) / func_000365 (B), 16 сэмплов, r4 += 3
   └─ mac −коэф×состояние  ← **ЕДИНСТВЕННАЯ обратная связь (Q-ОС SVF)**
```

Блок = 16 сэмплов (подтверждено независимо: пакт 11 «кадр 16 сэмплов»,
`do #<$10` движка, 8×2 halfband-интерполятор P:$05D8).

## 6. Что осталось открытым (после этой трассы)

1. Писатели индексных слотов y:(r6+$DA)/x:(r6+$D3) — вне P:$0000–$0B4D
   (хост/dispatch); нужен проход по dsp1_machine_code/dispatch.
2. Алгебра концов глайд-таблиц (стартовые значения = хвосты прошлого кадра).
3. Постатабельные роли mac внутри func_000350/000365 (какой mac = f, какой = Q).
4. Семантика param4 (y:(r6+$4)) и доступ kQGainTbl шагом $200
   ($0660/$068C/$07A6); масштаб r1 = param4·$200.
5. Соответствие tA/tB → плечи hp/lp выходов.
6. Верификация всей цепи прогоном на эмуляторе с дампами X/Y на границах
   P:$05FF/$06C0/$0719/$077A (методика svf_trace.py).
