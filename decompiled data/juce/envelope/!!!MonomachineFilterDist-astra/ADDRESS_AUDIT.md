# Адресный аудит OS 1.32B

Все адреса P ниже — адреса 24-битных слов DSP, не байтовые смещения BIN.
Контрольные суммы и точные границы — `evidence/provenance.json`.

| Адреса P, включительно | Что делает участок | В пакете |
|---|---|---|
| $04FF–$0536 | FILT trigger, attack, переход фаз, decay | да |
| $0537–$056C | BASE/WDTH + BOFS/WOFS + key tracking | да |
| $056D–$05BE | EFX EQF/EQG и вызовы $0340 | нет; вход после этого участка |
| $05BF–$05FE | интерполяция, история левого/правого трактов | да |
| $05FF–$06CC | LP, LPQ, зависимость усиления от DIST; вызовы $0350 | да |
| $06CD–$079E | HP, HPQ; вызовы $0365 | да |
| $079F–$07D1 | headroom/DIST, нелинейное ограничение и компенсация | да |
| $07D2–$0808 | частотно-зависимая коррекция, вызов $037C | да |
| $0809–$0854 | обратное преобразование частоты обработки | да |
| $0855–$088D | дополнительная коррекция HP, вызовы $038A | да |
| $088E–$08D7 | AMP envelope | нет |
| $08D8 и далее | AMP gain/pan, затем остальные эффекты | нет |
| $08FA–$0980 | SRR, интерполяция $0397 | нет |
| $0981 и далее | delay send/feedback/return | нет |
| $0A5D–$0A9C | фильтры задержки из DBAS/DWID | нет |

Подпрограммы включены целиком: `$0350…$0364`, `$0365…$037B`,
`$037C…$0389`, `$038A…$0396`. Названия f350/f365 сохранены по адресу;
готовые «красивые» модели фильтров вместо их арифметики не подставлялись.

## Почему это нужные фильтры

Карта параметров хоста связывает Y:page+$08…$0F с FILT. Чтения `$0C/$0D`
на `$0509/$052B` устанавливают принадлежность атаки/спада к FILT.
Триггер читается из `$20` на `$04FF`. Состояние уровня — X:page+$DB,
фаза — Y:page+$DB, счётчик — X:page+$DA. BOFS и WOFS участвуют
в вычислении индексов частот до расчёта коэффициентов основных фильтров.
HPQ и LPQ читаются из `$0A/$0B`, а не из параметров delay.

Здесь нет отдельно выбранного «резонатора». Две похожие интерполяционные петли
в начале аудиоучастка — стереотракты, а не два различных вида фильтра.
HP/LP различаются последующими вычислениями коэффициентов и вызовами подпрограмм.

DIST читается из Y:page+$04. Headroom находится в X:page+$0B, а LPQ —
в Y:page+$0B: одинаковый offset не означает одинаковый параметр в пространствах X и Y.
DIST влияет на таблицу усиления `$143C06` в участке `$065A…$0662` /
`$0685…$068F`, а также на компенсацию `$1447C6` возле `$07B7`.
На `$07C3` устанавливается SR bit 11: это масштабирование передачи из
аккумулятора. Ограничение 24-битных передач вместе с этим масштабированием
существенно для перегруза. Подмена участка произвольным waveshaper недопустима.

Delay DBAS/DWID располагаются в Y:page+$16/$17, отдельно от `$08…$0F`.
Участки FM-машин и их freq envelopes в перечисленные диапазоны не входят.

## Арифметика, которую нельзя упростить до float

Сохраняются 24-битные слова, 56-битные аккумуляторы, 48-битные пары L,
различие ограниченной передачи `a/b` и сырого `a1/b1`, перенос параллельных
MOVE со значениями до ALU, смешанное signed/unsigned умножение, округление RND
и 24 шага DIV. Короткий MOVE `#$08,a` помещает `$080000` в A1;
это не целочисленная загрузка 8. SUBR вычисляет половину назначения минус источник.
Параметры EFX EQF/EQG не переименовываются в BASE/WDTH.

Арифметический слой — только подмножество для этого среза. Он не реализует
полный DSP56300, все sticky flags, прерывания и произвольные режимы адресации.
Используемые условные переходы и масштабирование реализованы; полный SR
не предназначен для побитного сравнения с эмулятором. Для адресации выбранных
подпрограмм требуется линейный режим, выход за память выставляет fault.

## Происхождение

Исходный BIN и декодированный SYX дают одинаковый контейнер размером
516 024 байта по смещению BIN `$4000`. Из него восстановлены записи DSP.
900 машинных слов выбранного листинга и 12 486 табличных слов сверены с ними.
Ранее также проверен весь используемый kernel-листинг: 2894 слова.
Проверка машинных слов не равнозначна независимой проверке декодирования
всех мнемоник или звукового результата C++.

Предоставленный `Elektron_SFX6-60_OS1.32B.pdf` содержит release notes.
Дополнительно прочитан соседний `monomachine_manual_OS1.32.pdf`: печатные
страницы 27, 30–31 подтверждают принадлежность DIST к перегрузу фильтра,
BASE/WIDTH, HPQ/LPQ и воздействия BOFS/WOFS. Адреса и арифметика определены
по прошивке и исходникам, а не восстановлены из описания в руководстве.
