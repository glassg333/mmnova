## Что делать агенту-интегратору (по порядку)

1. **Track Delay**: скопировать `MnmTrackDelay.hpp` + `mnm_trackdelay_tables.h`
   в `Source/dsp/mnm/`; в `NovaDSP.h` подключить и завести per-track
   `mnm::td::TrackDelayCore`. Канал параметров:
   - FX-страница трека → `Params.eqf/eqg/srr/dtim/dsnd/dfb/dbas/dwid` (<<16);
   - FILT-страница → `Params.filtAtk/filtDec/bofs/wofs` ($514–$517);
   - `lpq` ($513) → гейт/таблицы длины;
   - хостовая длина `lenHost/lenHostHi` (P$2A) — пока формула ColdFire не
     восстановлена, считать: `P$2A ≈ (TIM_sync_ticks)` и калибровать по
     таблице целей из README_trackdelay.md §"длина".
2. **SRR**: в ядре НЕ биткраш — см. README_trackdelay.md §"Сюрпризы" п.1.
   Ручка SRR = сустейн EFX-конверта (SUS = SRR²). Слепок поведения на железе:
   при SRR→0 эхо затухает по кривой DEC сразу после атаки.
3. **Дальше по досье** (`README_machines_queue.md`): m13 (сначала фикс
   параллел-мува эмулятора, рецепт внутри) → m4/m5 → m14 → m1/m2 → m3/m6 → m11.

## Верификация

- Модели-источники: exp18 (384/384), exp22 (8296/8296), exp24 (глайд/взведение),
  func_000397 (iter 14) — всё бит-точное против эмулятора на оригинальном bin.
- Тесты модуля проверяют: SUS=SRR², α=0.1 глайд (словесное округление),
  ±4 слюв, T5-закон (env·DWID)², T4-окно $3FFF, func397 frac=0 passthrough.
- Полная дифференциальная проверка C++ ↔ эмулятор (кадр-в-кадр) — следующий
  шаг интегратора (харнес: `05_emulator/track_harness.py` из пака).
