# Итерация 28 — ядро DSP: роутинг DSND/DBAS/P$2A, глайндвижок, эхо-шина

**Дата:** 2026-09-23. Метод: адресный разбор кода ядра в `decoder_v2/code_full.asm`
(dsp1_pmem.bin) + xref-поиск (`xref.json.gz`) + извлечение таблиц из образа SRAM.
Все адреса — P-пространство DSP (dsp1), если не указано иное.

## 0. ГЛАВНОЕ: поправка к итерации 24

Итерация 24 записала: «DSND (P+$1C) / DFB (P+$1D) / DBAS (P+$1E) — НОЛЬ чтений в
DSP-ядре → send/feedback/база = ColdFire-сторона». **Это неверно.** Ядро читает
DSND и DBAS в глайндвижке $000262–$0002EA (см. §3). Причина промаха итерации 24:
чтения идут через `y:(r6-$0C)`/`y:(r6-$0A)` при r6 = **страница + $28**, а скан
итерации 24 искал смещения от базы страницы. DFB (P+$1D) в ядре по-прежнему не
найден (честно: путь чтения неизвестен).

## 1. Каркас голоса в ядре (уточнение карты страницы)

| Ячейка | Значение | Доказательство |
|---|---|---|
| Y:$123 | указатель текущей страницы **+ $28**; старт $0528 | `move #$528,y:>$123` $0000C8 |
| Y:$124 | счётчик голоса 0..2 | `add #1` $000169, `cmp #$3` $00016F |
| Страницы | Y:$0500 / $0600 / $0700 (3 голоса на DSP) | векторы DMA5 $10/$12/$14 |
| Шаг голоса | Y:$123 += $100 за кадр | $000163–$00016A |
| X:$0500–$052F | **X-тень страницы**: `x:(r6-0x28+k)` ↔ слово k | чтения/записи §3 |
| X:$2C4 | биты 0/1/2 = «страница голоса активна», биты $C/$D = dirty | $0000DD, $0001F3–$000218 |
| P+$24 | текущий DSP-идентификатор машины (сравнивается с y:$120+голос) | $0000E5–$0000E9 |
| P+$28 | TRIG; бит 7 = INIT-флаг (ядро снимает) | $0000E1–$0000E3 |

Диспетчер машин (подтверждает и расширяет итерацию 1):
`x:($10016B+id)` INIT при смене машины (по `y:(r6-$04)` ≠ `y:$120+голос`),
`x:($10018D+id)` CONF **каждый кадр**, `x:($1001AF+id)` PROC — вызов из $0002EB.

## 2. Кодек-кадр, банки, DMA4

- Главный цикл $000087 поллит таймер/ESSI (`jsset #$4,x:$FFFFF4 → $000259`,
  `movep x:$FFFFEB` — фаза кадра) и различает **3 фазы** ($140/$160/$180),
  выбирая одну из трёх rotational-групп банков по 48 слов:
  r1/r2/r3/r0 = ($140,$1A0,$200,$260) / ($180,$1E0,$240,$2A0) / ($160,$1C0,$220,$280);
  указатели сохраняются в X:$2C0–$2C3, фаза — в X:$2C8.
- **DMA4 = вход кодека**: `DSR4=$FFFFB8` (ESSI0 RX!), `DCR4=$CA5140`
  (Drs=11, word, приёмник X-память), `DCO4=$301F` (32 слова/кадр),
  `DDR4` = бегущий банк (X:$2C0-значение + $20, перенос: `cmp #$1A0; sub #$60`),
  $000197–$0001A0. Аудио кадра попадает в банки X:$140–$2BF.
- **Команда хоста $000259** (вход по jsset из $000020): перезаряжает DMA4 на
  приём **47 слов из хоста в X:$2FC** (`DCR4=$4A5A20` prep → `DDR4=X:$2CA` →
  `DCO4=$2F` → `DCR4=$8A52C0`). X:$2FC–$32A — «хост-блок» мастер-микша.
- Копии: $0001C2–$0001E1 раскладывает X:$2FC– и эхо-шину X:$32C– в банки
  X:$160/$1C0/$220; $0001F3–$000218 по битам X:$2C4 выбирает активный банк.

## 3. ГЛАЙНДВИЖОК $000262–$0002EA (сердце роутинга эха)

Вход: команды/кадр ($000124 jmp; $000129/$00012D — биты $C/$D X:$2C4).
Слово-контекст сохраняется в x:$1 ($000262).

### 3.1 Чтения страницы

| Команда | Адрес | Ячейка |
|---|---|---|
| `y:(r6-$0C)` | $000284 | **P+$1C = DSND** |
| `y:(r6-$0A)` | $0002C8 | **P+$1E = DBAS** |
| `y:(r6-$21)` | $000285 | P+$07 |
| `y:(r6-$06)` | $000271/$00029E | P+$22 (старшее слово TEMPO) |
| `y:(r6-$02)` | $0002C6 | P+$26 |
| `y:(r6+$01)` | $000263/$0002B5 | P+$29 |
| `y:(r6+$02)` | $00028A | **P$2A** (хост-ячейка длины) |

### 3.2 Скорости глайда

```
idxA = DSND >> 16        (старший байт DSND, 0..127)
idxB = P+$07 >> 16
x0 = Y:$1449C6[idxA];  x1 = Y:$1449C6[idxB]
rateA = low24(x0 · P$2A >> 8);   rateB = low24(x1 · P$2A >> 8)
(отрицательный результат → замена на $7F: tfr y0,a ifmi)
```

Таблица **Y:$1449C6** (256 слов, извлечена):
- [0] = $FEDCBB (отрицательное, «мгновенно»), [1] = $010F79 (макс. положительная),
  монотонно вниз до [127] = $00000A — кривая «время глайда»: **больше DSND →
  медленнее глайнд**;
- [128..255] — вторая кривая: экспоненциальный подъём $000000 → $7FFFFF
  (форма ~2^(k/16), пик на 256).

### 3.3 Два параллельных глайда (стейт в X-тени)

```
Цель A: X:$502 := P+$22 (тень, $00027E); акк A: X:$504:X$505 (48 бит)
  acc += (X:$502 − X:$503) · rateA          $00029B (mac x0,y1,a)
  перелёт → snap: X:$503 = P+$22            $00029E–$0002A8
  acc -> L:$00, X:$504:X$505                $0002AA–$0002AC

Цель B: X:$507 := P+$29 ($000270); акк B: X:$508:X$509
  acc += (X:$507 − X:$506) · rateB          $0002B2
  перелёт → snap: X:$506 = P+$29            $0002B5–$0002BF
  acc -> X:$508:X$509                       $0002C4–$0002C5
```

### 3.4 Позиция → плавающая длина задержки

```
X:$501 = accB + P+$26 + $B000·DBAS − $5800 + accA     $0002C6–$0002CF
         кламп [0, $5800] (clr if mi; min $5800)       $0002D0–$0002D4
голос < 2: тот же X:$501 пишется и следующему голосу (r6+$FF = X:$627) $0002DB
idx = X:$501 & $7FF        (11 бит — указатель мантиссы)
exp = X:$501 >> 11         (0..11 — порядок)
len = X:$140000[idx] >> 10 << exp                       $0002E2–$0002E5
a   = len · $1D22A >> 3                                 $0002E6–$0002EA
jsr (r1)  ← PROC машины, получает a = длина задержки    $0002EB
```

**X:$140000** — 2048 слов в общей SRAM (мост X/Y ≥ $020000): линейная мантисса
0.5 → 1.0 ($3FFFFF → $7FF4E8, шаг $7FF/слово). Т.е. X:$501 — **22-битный float**
(11 бит мантиссы + порядок): длина задержки = мантисса·2^(exp−10), масштаб
$1D22A/2^23 ≈ 0.2265, итог уходит в PROC (stage-2: гребёнка 17 тапов, итер. 22/24).

Читатели X:$501 (`x:(r6-$27)`, 8 мест): $14594C, $145AE7 (внутри PROC m14!),
$145C09/$145C24, $147336, $1479AB/$1479D4 — машинные PROC'и потребляют длину.

## 4. Эхо-шина и мастер-микш

| Ячейка | Инициализация | Роль |
|---|---|---|
| X:$2C9 | $32C (фазозависимо: $2CC/$32C/$2FC) | указатель записи мастер-микша |
| X:$2CA | $2FC | цель DMA4-блока хоста (47 слов) |
| X:$2CB | $32C | старт эхо-шины (обратное чтение в банки) |

Мастер-микш $000B33–$000B4B: читает `x:(r2)+` = X:$00–$1F (**банк модуляции**),
`l:(r5)+` = L:$10–$1F, `y:(r4)+` = Y:$20+; пишет `a,b` в `X:(r1)+` (X:$FF+,
стейт фидбэка), `Y:(r6)+` (Y:$00–$1F выход) и `b → X:(r3)+` = **эхо-шина**
(16 слов на голос; указатель сохраняется обратно в X:$2C9).
Запись в кольцо: $000B15 — r4 = X:$C5, 16 слов `X:(r0)+ → Y:(r4)+`.
Банк модуляции заполняется на хвосте stage-2 ($0008E7–$000916: таблицы
$1448C6/$144946, `y:(r6+$12)`, mpyri #$80) — вклады голосов (T5, итер. 24).

## 5. ColdFire: уточнение роутера спецификаций ($242058)

Полная расшифровка пар-спецификаций (поправка к README итерации 27, где
путаны имена аргументов):

- Таблицы (12 байт на трек, j = 0..11):
  **$7001FA+t·12+j = группа** (байт выбора), **$700242+t·12+j = смещение**,
  **$70028A+t·12+j = третий байт** (зеркалится в образ DSP2).
- $2403D4: `d3 = $10(a7) = track`, `d2 = $14(a7) = группа` (таблица $240400,
  8 записей), `a1 = $18(a7) = смещение`.
- Группа 2/3/4: ячейка = `$1000A14 + (группа·8 + track·52 + смещение)·4` —
  **одно слово страницы на один указатель** (группа 2 → слова 0–7, 3 → 8–15,
  4 → 16–23; смещение = индекс слова). Т.е. «52·param + spec1» из README-27 —
  это track·52 + смещение-слова.
- Группа 0 → $1000ACC+track·$D0 (fade-in), 1 → флаги $1000B04, 5/6/7 → строки
  $1000E94, ≥8 → дефолт $10013E4.
- Обработчик $242058: 6 итераций × 2 вызова → 12 указателей на трек:
  банк A → `$1001508+t·$30+4k`, банк B → `+0x18+4k`; зеркала в $2C01D2/$2C021A/$2C0262.
- Геттер $242BD0: `index = (argA·7 + argB)·2 + бит` (строки по 14 байт),
  возвращает тройку байтов.
- Значения спецификаций — рантайм-стейт ОС (пишутся сеттерами $2427B4/$242968
  из подсистемы назначения параметров $212xxx); в ROM их нет.

## 6. ColdFire ↔ DSP: одиночное чтение

$24828E (DSP2, $600001) / $248204 (DSP1, $500001): CVR $06 → $86, адрес =
`*($259114) + 1` = X:$701 (константа, init $700 в образе), результат → слово $27
staging-страницы ($1000AF0 / $1000D60). Это единственный найденный «обратный»
канал слово-за-словом; позиция синхросчёта ($29C040, итер. 27) идёт отдельно.

## 7. Статус вопроса 12 (DSND-роутинг) после итерации 28

| Элемент | Статус |
|---|---|
| DSND P+$1C | **ПРОЧИТАН ЯДРОМ**: индекс скорости глайда A (таблица $1449C6) |
| DBAS P+$1E | **ПРОЧИТАН ЯДРОМ**: база позиции (`$B000·DBAS`), $0002C8 |
| P$2A | множитель обеих скоростей глайда + цель stage-2 (итер. 24) |
| DTIM P+$1B | кривая release EFX-конверта (итер. 24) — без изменений |
| DWID P+$1F | send-множитель T5 (итер. 24) — без изменений |
| EQF/EQG/SRR | EFX-конверт (итер. 24) — без изменений |
| DFB P+$1D | чтение в DSP не найдено; путь обратной связи — открыт |
| P+$07/P+$22/P+$26/P+$29 | участвуют (цели/слагаемые) — UI-имена не подтверждены |
| X:$140000 | мантисса длины задержки (2048, 0.5→1.0) — в образе SRAM |
| X:$1449C6 | кривая скоростей глайда (128 вниз + 128 вверх) — извлечена |
| 47-словный блок X:$2FC | канал хоста найден; семантика слов — открыта |
| X:$701 (чтение хостом) | канал найден; содержимое — открыто |
