# Доказательная база итерации 8 (выдержки дизассемблирования)

Все адреса: OS = смещение в section_0_MAIN_OS.bin; $7xxxxx = RAM, секция 4 грузится на 0x700000.
Банк паттернов: база секции 4 = 0x16AE4 (RAM 0x716AE4), слот = 0x1978 (6520) Б, 128 слотов.

## 1. Тригг-маски: 4×16-бит слова в ОБРАТНОМ порядке, LSB-first

Проверка: для всех used-слотов (0..63) и всех дорожек с нотами ноты ⊆ триггам = **100.0%**
(327 дорожек). Прямой порядок слов даёт лишь 69.0% — обратный порядок доказан.
Пример (слот 1, дорожка 0): поле `11 11 04 41 00 41 04 41` → слова [0x1111,0x0441,0x0041,0x0441]
→ в обратном порядке [0x0441,0x0041,0x0441,0x1111] → шаги {0,6,10,16,22,32,38,42,48,52,56,60}
= ровно шаги нот дорожки 0 (`24` на каждом).

## 2. Ноты: +0x2A4 + t*64 (ОС)

OS 0x33B64..0x33B8A (обмен дорожек, полный листинг в disasm_track_swap.asm):
```
033b64: 2002         move.l d2, d0
033b66: ed88         lsl.l #$6, d0          ; d2*64
033b68: 0680000002a4 addi.l #$2a4, d0       ; + 0x2A4

033b74: ...          (d3 -> dst аналогично)

```

## 5. Векторы машин: +0x428+6k, значения ≤3 и ≤11 (ОС)

OS 0x2F3DC..0x2F44E (disasm_field_writer.asm):
```
02f40a: e788         lsl.l #$3, d0          ; слот*6520
02f410: 41f900716f1e lea.l $716f1e.l, a0    ; банк + 0x43A
02f41a: 11801800     move.b d0, (a0, d1.l)  ; [слот*6520 + дорожка]
02f428: 7403         moveq #$3, d2          ; ограничение <=3
02f428: 41f900716f24 lea.l $716f24.l, a0    ; банк + 0x440
02f43c: 41f9...      lea $716F2A, a0        ; банк + 0x446 (в листинге); ограничение <=0xB
```
Вектор +0x446 = ID машины дорожки (≤11); вектор +0x440 = алгоритм/подтип (≤3);
вектор +0x43A = контекст (без ограничения). Векторы 1-3/7-12 (+0x428/+0x42E/+0x434/
+0x44C/+0x452/+0x458/+0x45E/+0x464/+0x46A) переносятся при обмене дорожек —
см. disasm_track_swap.asm 0x33B94..0x33BC4 (байты с +t).

## 10. Wear-leveling масок: 7 копий

Копии триг-масок: +0x000, +0x030, +0x060, +0x120 (+ стёртые +0x090/+0x0C0/+0x0F0).
В 15 слотах (1, 6, 8, 16, 21, 22, 33, 34, 39, 44, 52, 60, 61, 62, 63) копия +0x120
отличается от копий 1-3 = последняя записанная версия (ОС пишет новую копию в первый
свободный слот без стирания старых). Проверка декодом: копия +0x120 даёт лучшее
покрытие нот (0.90 против 0.88 у +0x000) именно на этих слотах.

## 11. Статистика декода

- 64 заводских слота: ноты ⊆ триггам = 100% на 326 дорожках из 327;
  единственное исключение: слот 44, дорожка 4, шаг 56 (нота 0x4F без тригга — след правки).
- Пустые слоты (64..127): 49 уникальных блобов (индивидуальность = хвостовые записи + поля +0x54E).
- Маска A (+0x1B0): 6 уникальных значений (00 — 59 слотов; FF — единичные).
- Маска B (+0x1E0): 15 уникальных значений (0xAAAA... — 46 слотов; вариации `0000aaaa...`,
  `...5555...` — у 18 слотов).
