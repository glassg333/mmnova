# Monomachine OS 1.32B — ядро DSP1: карта голосового тракта (AMP / DIST / FILT)

Дата: 2026-09-18. Метод: дизассемблирование `dsp1_pmem.bin` + **исполнение
настоящего ядра** в эмуляторе dsp56k (`rig/`, см. EMULATOR_PATCHES.md).
Каждый адрес ниже проверен исполнением или дизассемблированием с верифицированным
инструментом (100% совпадение на корпусе).

## 1. Контекст вызова

Главный цикл P:$0066-$01A3 (DSP1, блок = 16 сэмплов, 3 голоса):

```
P:$0117-$0131  выбор входного буфера голоса (r0 = X:$2C0/$2C1/$2C2/$2C3
               = $160/$1C0/$220/$280 по битам X:$2C4) → func_000262 (pre-voice,
               portamento+LFO питча) → jsr (r1) = машина (пишет 16 кадров в r0)
P:$0132-$0142  восстановление m0-m7; r6 = Y:$123-$28 (= V-$28); r7 = $100;
               r5 = X:$2C3;  jmp func_0004A8
P:$04A8-$0B4B  POST-VOICE: AMP env → LFO-модуляции → DIST → FILT → пан/усиление
P:$0B4C        jmp func_000143 (следующий голос)
```

Размер post-voice измерен на rig: **1176 инструкций** на голос-блок.

## 2. Параметровое окно голоса (V = Y:$528 + voice*$100; r6 = V-$28)

ColdFire пишет параметры страниц (ATK HOLD DEC REL DIST VOL PAN PORT / BASE WDTH
HPQ LPQ ATK DEC BOFS WOFS / EFFX 8 / LFO1-3 24) уже отскейленными в Q1.23 в
Y:(V-$28..V-$01). Подтверждено кодом ядра:

| V-offset | роль | доказательство |
|---|---|---|
| X:(V-$28) | состояние AMP env (0/1/2/4/5) | P:$04AC чтение/запись |
| V-$07 | триггер AMP env (1 = note-on → state 1) | P:$04AD-04B1, подтверждено rig |
| V-$08 | триггер LFO (сброс фаз) | P:$04FF-0505 |
| V-$10 | ATK: индекс таблицы Y:$141800 (7 бит, >>16) | P:$04B4-04B8 |
| V-$0F | DEC: индекс таблицы Y:$141880 | P:$04CC-04D1 |
| V-$0E | sqrt(sustain): уровень сустейна = (V-$0E)² | P:$04CA/04DE, подтверждено rig |
| V-$0D | REL: индекс таблицы Y:$141880 | P:$04E5-04EC |
| V-$24 | DIST: индекс кривой привода | P:$07A6-07B7 |
| V-$1C | LFO SPD (индекс Y:$141800) | P:$0509-050D |
| V-$1B | LFO MULT (индекс Y:$141A00) | P:$052B-0534 |
| V-$20 | TONE/cutoff: индекс = V·$800-$80 | P:$0537-053D |
| V-$17 | cutoff-индекс: ·$80 → таблицы-делители | P:$0578-057C |
| X:(V-$19) bit0 | вкл/выкл второй SVF-петли (канал/секция) | P:$05E8-05E9, P:$078F |
| X:(V-$1C) | указатель (в т.ч. на форсант-обработку) | P:$097B-0980 |

## 3. AMP envelope — [EXACT], подтверждено исполнением

P:$04A8-$04F3. Уровень — Y:$04FF (24 бита, сатурация записи).

```
state 1 (attack): level += TBL_RATE[ATK]            ; TBL_RATE = Y:$141800
                  флаг E (сумма >= 1.0) → state 4; запись сатурирует до $7FFFFF
state 4 (decay):  level = level * |TBL_DEC[DEC]|    ; TBL_DEC = Y:$141880 (отриц.)
                  цель = (V-$0E)²; next <= цель → state 5
state 5 (hold):   level = (V-$0E)²
state 2 (release):level = level * |TBL_DEC[REL]|
default:          level = $7FFFFF
```

Контрольный прогон rig (`rig env 0 16 90 16 30`):
```
b=0 state=1 level=0.5000   (ATK=0 → inc 0.5/блок)
b=1 state=4 level=1.0000   (E-флаг, сатурация $7FFFFF)
b=2 state=4 level=0.9639   (×|TBL_DEC[16]| = 0.9636)
...
b=12 state=5 level=0.7087  (= (sqrt(90/127))² — сустейн ровно 90/127)
```

## 4. DIST — каскад привода (P:$07A6-$07D1)

```
D  = Y:(V-$24)                       ; Q1.23, ColdFire скейлит ручку в 0..~0.5
idx= D * $100 >> 23                  ; P:$07AD mpyi #$100 → индекс кривой 0..128
c  = X:($1447C6 + idx)               ; кривая привода 1.0 → 0.35 (129 сл.)
k  = D*D * $7DECCD + $21333          ; P:$07AF-07B5: 0.985461·D² + 0.016230
   ; далее per-sample по 34-словному буферу (X:$70-$91 / X:$B0-$D1):
   state-рекурсия с k и c (P:$07BD-07C2, коэффициенты из окна V+$9C..V+$B1)
   out = sat( 128 * x )              ; P:$07C3-07D1: bset #$b,sr + mpy #$80 —
                                     ; жёсткий клип ±$7FFFFF на сатурации АЛУ
```

Кривая kDriveCurve (P:$1447C6) и формула k — [EXACT]. Связка state-рекурсии с
сигналом закрывается после маппинга ColdFire→V+$9C (см. §7).

## 5. FILT — двухполюсный SVF, два экземпляра

- Петли: func_00037C/00038A (P:$037C-$0397) + развёрнутые копии P:$07E7-$07FB;
  16 итераций = пер-сэмплово; состояния X:$72/$74 (инстанс 1) и X:$B2/$B4 (2).
- Коэффициент среза — из таблицы P:$143546 (≈1700 записей, экспонента):
  значение ≈ 2·sin(π·fc/fs); индекс клампится на $6A3=1699 (P:$07D6).
  Верх таблицы: c=0.9074 → fc ≈ 6.6 кГц — фильтр MNM не открывается до
  Найквиста (известная «тёмность»), это свойство таблицы, не баг.
- Второй срез — та же таблица с P:$1435C6 (P:$0860), индекс до $63F.
- Индексы собираются из параметров через таблицы-делители X:$143F95 (107 сл.)
  и X:$144446 (128 сл.) + 24-битное деление (P:$0583-$0589, do #<$18, div).
- Сглаживание коэффициента раз в блок: `coef += (target-coef)` с округлением
  дельты до 8 дробных бит (P:$056D-$0572) — «зализывание» перестройки.
- Резонанс: HPQ/LPQ через интерполятор таблиц P:$141A98/$142158/$142F06
  (P:$0629-$0668), кламп $7FFFA4.

## 6. Пан/усиление и микширование

- По-сэмпловые рампы усиления: интерполятор 4-tap FIR
  {-0.084146, 0.580566, 0.580566, -0.084146} (P:$05CF-$05D1, func_000340)
  по 16 точкам на канал (X:$0141-$015F / $0151-$015F…), сумма ≈ 0.993.
- LFO-значения читаются из синус-ROM X:$14A000/$14A800 (8192 сл., runtime,
  заливается ColdFire) с фазой голоса (P:$08E5-08EB).
- Финальная петля P:$0B33-$0B48: аудио (X:$0-$1F) × рампа (Y:$20-$3F) →
  accumulate в трек-буфер (r1 = X:$FF = вход r5), rolling-указатель X:$2C9,
  затем `pflush` и jmp func_000143. Семантика add/overwrite — битами X:$2C4.
