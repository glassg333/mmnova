# DPRO-BBOX (m07): как он устроен на самом деле

Источник: `machines_page_A/07_DPRO-BBOX_full.txt` (P:$1474E9-$14764A),
дескриптор (PTCH/STRT/RTRG/RTIM), банк из pmem.

## Главное

BBOX — **не сэмплер с пользовательскими слотами**, а 12 барабанных моделей,
зашитых в прошивку. Банк лежит в P:$103E7B..$11320F (62 356 слов, 24-бит),
границы моделей — таблица пар {start, end} в P:$147632. Модель выбирается
НОТОЙ: `idx = f(V+$01)` (config, $1474ED-$1474FD). С «сырыми» MIDI-нотами
формула даёт индексы 3..9 — значит ColdFire подаёт V+$01 в своём масштабе
(точный — после дизассемблера ColdFire).

Каждая нота = новый хит: фаза = 0, гейт открыт, звук до КОНЦА модели, потом
жёсткий срез (без релиза внутри машины — общий AHD/ADSR трека накладывается
post-цепочкой func_0004A8).

## Сигнальный путь

1. **Питч**: акк = f(нота, PTCH) → таблица X:$140000 (`wt[i]=0.5·2^(i/2048)`,
   2048 ступеней/октава, 11 октав) → `×$1D22A >>3` — та же формула, что у
   kernel'а для всех осцилляторов. PTCH входит множителем `×$2000`
   (ROM: 0..127 → +0..4 октавы при полнодипазонном скейлинге; биtполярность
   возможна кривой ColdFire).
2. **Лестница фаз**: 64 шага на блок 16 кадров = **4× передискретизация**.
3. **Рендер**: чтение банка с линейной интерполяцией; гейт закрывается
   жёстко при выходе позиции за конец модели.
4. **Полифазный FIR-дециматор 4:1** — 10 коэффициентов зашиты прямо в КОДЕ
   машины ($1475D5-$1475F2): `3CE85F F9F156 939958 04D33E 36F789 11B451
   9023EC EE4BAF C652AD 0D1E2D`. Это и есть характерный lowpass-окрас BBOX.
   Внутренний сдвиг/расписание тапов приближено (см. «открытое»).
5. Выход: `asl #7` перед записью, стерео (L=R).

## Ручки (порядок = V+$04+i)

| ручка | функция в ROM |
|---|---|
| p0 PTCH | транспонирование (в питч-акк, ×$2000), дефолт 64 |
| p1 STRT | старт: `pos0 = start + len·STRT/2`, конец не двигается |
| p4 RTRG | число ретригов: `count = min(127,(RTRG+$8000)·$80>>23)`, 0=выкл |
| p5 RTIM | интервал ретригов (см. ниже) |
| p2,p3,p6,p7 | не используются |

**Ретриг** ($147564-$147581): пока счётчик > 0, фаза $7FFFFF уменьшается на
`(RTIM·6+$C00)>>23` за блок; по переходу через ноль — фаза сэмпла в 0, гейт
заново, счётчик−−. Абсолютная калибровка RTIM зависит от скейлинга ColdFire:
при полнодипазонном RTIM декремент = 0..5, что даёт либо «никогда», либо
audio-rate. В референсе реализована непрерывная кривая
`interval = $800000/(RTIM·6+$C00)` блоков (0.99 с → audio-rate) — она
соответствует константам ROM; уточнить можно будет по ColdFire.

## Отличия от текущего порта в Monomachine Nova FX

| аспект | прошивка | Nova (monomachine_bbox.hpp 1.5.2) |
|---|---|---|
| источник звука | 12 зашитых моделей (банк в pmem) | 24 слота, синтезированная сетка |
| выбор модели | нотой (idx = f(note)) | слот / random / chromatic |
| STRT | линейно до ~50% модели | квадратично, кэп 30 мс |
| RTRG | счётчик ретригов 0..127 | счётчик ретригов 0..127 ✓ |
| RTIM | см. выше (блоки, кривая ROM) | мс через `pow((127-rtim)/126,2)` |
| гейн ретрига | нет (гейт просто открывается заново) | `10^(-0.75·i/total)` |
| фейд-ин хита | нет | 0.5 мс фейд |
| интерполяция | линейная ✓ | линейная ✓ (+loop/Хермит как расширение) |
| дециматор | 10-таповый FIR из ROM (окрас) | нет |
| лупы | нет | двухмаркерный луп (расширение) |
| pitch bend | нет (машина его не получает) | есть (расширение) |

Расширения (loop, bend, пользовательские слоты) — легитимная модификация, но
чтобы «звучало как оригинал», база должна быть: банк ROM + 12 моделей по
ноте + STRT-регион + FIR-окрас + жёсткий гейт.

## Данные в пакете

- `data/bbox_drum_bank.bin` — банк целиком, 24-bit BE (62 356 слов);
- `data/bbox_wav/model_00..11.wav` — модели по отдельности, 16-бит/44.1к
  (для прослушки; масштаб >>9);
- `dsp/machines/MnmBBox.h` — движок (модели/смещения зашиты константами);
- загрузчик `loadBBoxBank()` в том же заголовке.

## Открытое

1. Масштаб V+$01 (нота→индекс модели) и V−$0A — ColdFire.
2. Точный шаг RTIM-декремента — ColdFire или трасса на железе.
3. Расписание тапов полифазного фильтра (индексная хореография r1/r2/r3/r5,
   m5=$9, состояния V+$1E..$22) — приближено: коэффициенты подлинные,
   распределение по тапам восстановлено по схеме чтений.
4. Абсолютный уровень выхода ≈ −24 дБ (как получилось из сдвигов ROM);
   в железе добирается ручкой LEVEL/AMP VOL трека.
