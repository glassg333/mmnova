ПАК 6 — MONOMOD (Monomodule) ЭТАЛОН + выжимка знаний. 2026-09-28.

Что это: исходники Monomodule (плагин, который ЗАПУСКАЕТ оригинальную прошивку
Monomachine на эмуляторе DSP56300) + собранный Linux-рендерер + дампы таблиц из
прошивки + эталонное аудио и дампы блоков + документ с раскладкой 52-словного
блока, таймингом хоста, дефолтами всех машин и роутингом.

ЗА ЧТО ЦЕНИТЬ:
- Это генератор истины: любые ручки любой машины -> точные 32 выходных слова,
  как у железа. Спор «кто прав» закрывается навсегда.
- Раскладка 52 слов + дефолты + тайминги = готовая спецификация host-слоя плагина.
- Найден питч-LUT X:$140000 (1024 слова) — закрывает ±1.7 цента из пака 5.
- Найдено расхождение нашей синус-таблицы (не влияет на FM, влияет на SIN/SWAVE/ENS).

С ЧЕГО НАЧАТЬ:
1. KNOWLEDGE_MONOMOD_RU.md  — вся выжимка (читать первым).
2. mnm_render_bin/run_example.sh — эталонный рендер одной командой
   (бинарник собран под Linux x64; на Windows — через WSL, либо пересобрать
   по BUILD_LINUX_RU.txt, там 4 команды).
3. etalon_tables/ — таблицы из прошивки (синус, ratio, питч-LUT).
4. etalon_audio/ — эталонные WAV (FM+ STAT/PAR/DYN, SAW, REVERB) + дампы блоков.
5. monomod/ — полные исходники (включая Elektron_SFX6-60_OS1.32B.syx и патч эмулятора).

Состав проверен: ratio-таблица нашего порта совпала с прошивкой 24/24 бит-в-бит;
сборка mnm-render под Linux выполнена и прогнана (1.32B, 0.18 с на 1 с аудио).
