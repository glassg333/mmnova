ЧТО ЭТО
-------
Это НЕ код и НЕ патч. Это доказательство-таблица к архиву 3
(mnm_3_NEW_code_FM_all_bitexact_2026-09-28.tar.gz). Код там не менялся,
хэши архива 3 остаются в силе.

Вопрос «как я проверю ручки, не слушая?» закрыт ОДНИМ ПРОГОНОМ:
все 8 ручек x все 3 машины x 7 позиций (0, 1, 32, 64, 96, 126, 127) =
168 сетов. На каждом сету оригинал (эмулятор OS 1.32) и порт (ядра из
архива 3) рендерят одинаковые блоки, результат сравнивается слово-в-слово.
