ЧТО СДЕЛАНО (по-человечески)
----------------------------
Главное: FM STAT теперь тоже БИТ-В-БИТ, как раньше были сделаны PAR и DYN.

1) Ядро FM STAT переписано пословно с прошивки (листинг P:$145D21-$145EC8,
   343 инструкции): фазовые аккумуляторы, интерполяция синуса, дифы,
   TONE-фильтры, гейты уровней, обратная связь, ротаторы, выход.
   Доказано на эталонных векторах, снятых с эмулятора оригинальной
   прошивки OS 1.32:
       ВЫХОД: 12800 из 12800 слов совпали (25 наборов ручек x 16 блоков)
       СТЕЙТ: 40000 из 40000 слов совпали (фазы, фильтры, ротаторы)
       ИТОГ: 0 расхождений. Это не «на слух похоже» — это слово-в-слово.

2) В наборе появился ШЕСТОЙ файл: dsp/mnm/MnmFmStat.hpp (новое ядро).

3) Обёртка (MnmFm.hpp) обновлена:
   - все три машины (Stat/Par/Dyn) рендерят через бит-точные ядра;
   - TONE теперь работает ВНУТРИ ядер (как в железе, фильтр $144AC7 из
     прошивки), а внешняя ступень тона в обёртке открыта —
     раньше тон применялся дважды, это исправлено;
   - float-ядро STAT удалено за ненадобностью.

4) FM PAR и FM DYN — без изменений с утра (они уже были бит-в-бит:
   PAR 7168/7168, DYN 8192/8192 слов на своих векторах).

ПОСЛЕ УСТАНОВКИ — ЧЕК-ЛИСТ (всё механически, без ушей)
------------------------------------------------------
Шаг 1. Если ещё не ставил патч экрана — 01_SCREEN_PATCH_PluginEditor.md
       (цифры под ручками 1FRQ/2FRQ/3FRQ: без него экран врёт, звук верный).
Шаг 2. Собери плагин.
Шаг 3. Проверки:
       - 1FRQ на 127 -> на экране 8.00; на 0 -> 0.03 (= 1/32);
       - 2VOL ниже 64 -> оператор 2 молчит (гейт, как в железе);
       - 1ENV ниже 64 -> оператор 1 молчит (гейт);
       - частота честно опускается питч-словом до 0 (кэрриер стоит).
Шаг 4. (по желанию) Перепроверить бит-точность самому:
       cd research
       g++ -O2 -std=c++17 -I../dsp/mnm test_fm_stat.cpp -o test && ./test
       -> должно напечатать «100% BIT-EXACT, mismatches = 0»

КАК ДОКАЗЫВАЛОСЬ (коротко, подробно в 02_PROOF_FM_STAT.md)
----------------------------------------------------------
- С эмулятора прошивки OS 1.32 (dsp_emu.py, тот самый, на котором
  проверялись m1/m2/m3/реверб) сняты эталонные выходы: 25 наборов ручек
  (включая края: гейты 63/64/65, края таблицы частот, 1FB max, TONE 0 и
  127, питч-слово 0) x 16 блоков, по 32 слова на блок + весь стейт машины.
- C++ ядро прогнано на тех же входах, сравнение слово-в-слово.
- Первый прогон после транскрипции нашёл одну ошибку (сдвиг на 2 сэмпла
  из-за двусмысленности дизассемблера в адресе конца DO-цикла $145EB5 —
  в машинном коде конец $145EBA, а в мнемонике $145EBB). Исправлено,
  после чего 0 расхождений на всех 52800 словах.
