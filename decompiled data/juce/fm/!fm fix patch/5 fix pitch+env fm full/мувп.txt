Что такое movep
MOVEP = MOVe Peripheral data — инструкция семейства Motorola DSP56300 (в Monomachine два таких DSP). Обычный move двигает данные между памятью X/Y и регистрами ядра. А периферия (serial-порт, кодек, host-интерфейс) отображена в отдельное I/O-пространство X:$FFC0–$FFFF, и обращение к этим регистрам — это именно movep: 24 бита за такт между ядром и периферийным регистром.

В блочном цикле ОС она — самая первая инструкция, и не случайно:

000087: movep  x:<<$ffffeb,a   ; 084E2B  ← читает слово из приёмного регистра ESSI (RX)

000088: cmp    #>$180,a

00008A: beq    int_000092      ; $180 → раскладка 6×MONO

00008B: cmp    #>$160,a

00008D: beq    int_00009f      ; $160 → 3×STEREO

00008E: cmp    #>$140,a

000090: beq    int_0000ac      ; $140 → 3×STEREO+AB

000091: bra    int_000087      ; невалидно → крутиться и ждать заголовокЭто дверь, через которую ColdFire-хост сообщает DSP раскладку блока — слово $140/$160/$180, от которого зависит вся маршрутизация шин. x:<< — I/O short addressing: 6-битное поле в машинном слове, адрес = $FFE0+поле; в слове $084E2B поле $0B → $FFEB, W=0 — направление «из периферии в регистр». В порте это смоделировано честно: регистр — ячейка X-памяти $FFFFEB, сама инструкция — тот же 24-битный тракт:

if (mnem == "movep") { doMoves(toks, 0); return 0xFFFFFFFFu; }  // ядро, строка 773
