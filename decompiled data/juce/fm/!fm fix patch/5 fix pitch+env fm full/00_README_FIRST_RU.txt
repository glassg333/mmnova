ПАК 9 — РОУТИНГ / БЛОЧНЫЙ МИКШЕР (OS 1.32B)
============================================

ЧТО ЭТО
Бит-в-бит порт блочного цикла ОС вокруг кадра голоса: режимы
роутинга (6*MONO / 3*STEREO / 3*STEREO+AB / MIX), пер-трековые
флаги роутинга, микшер шин, суммирование MIX, копия эхо-регионов,
пути ввода с кодека. Кадр голоса (пак 8) и FM-ядра (паки 3/4/7)
используются как есть.

БЫСТРЫЙ СТАРТ
-------------
Сборка и самотест (один прогон):

  g++ -O2 -std=c++17 -I dsp/mnm -o test_block_routing test_block_routing.cpp
  ./test_block_routing vectors/routing_vectors.txt

Ожидается:
  checks=360756 mismatches=0  [100% BLOCK-ROUTING BIT-EXACT]

Регрессия пака 8 (кадр голоса) на этом же дереве:
  g++ -O2 -std=c++17 -I dsp/mnm -o test_voice_frame test_voice_frame.cpp
  ./test_voice_frame <путь к voice_frame_vectors.txt из пака 8>
Ожидается: checks=392824 mismatches=0.

ГЛАВНОЕ В КРАТЦЕ
----------------
1. Блок = 3 суб-блока на DSP; суб-блок k = трек k (машина y:$120+k,
   страница y:$528+$100k). Два DSP = 6 треков.
2. Заголовок блока $140/$160/$180 = раскладка шин (таблица — в
   README_ROUTING.md, п.2).
3. Флаги роутинга трека = слово y:(страница−3), биты 0/1/2 = «шина
   кадра в bus1/2/3», бит 8 = MIX-сумма в конце блока, бит A = копия
   эхо-регионов, биты 6/7 = ввод с кодека.
4. Путь бита 3 (replace) в прошивке мертвый: ветвление без bsr на
   функцию с rts = пустой стек. В порт включен как есть.
5. Самотест: один прогон, 22 сета, 360 756 проверок, 0 расхождений.
