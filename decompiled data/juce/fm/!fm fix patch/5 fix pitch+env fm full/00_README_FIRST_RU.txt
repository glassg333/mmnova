ЧТО ЭТО ТАКОЕ «КАДР ГОЛОСА»
  Каждые ~1/48 тика ядро ОС прогоняет звук одного трека через фиксированную
  цепочку: пролог (питч-цепь) -> машина (у нас FM, ядро из паков 3/4/7) ->
  хвост $02EC-$0B4C: env2 -> копия истории -> каскад-1 (halfband 2x oversample
  SVF, ручки BASE/WDTH) -> EQ (EQF/EQG) -> энвелоп AMP -> гейн (VOL^2, пан,
  16-шаговый рамп) -> резонанс HPQ/LPQ -> трековый делэй -> стадия 2 фильтра
  с энвелопой (пак 5) -> выход трека. Теперь ВСЯ эта цепочка в плагине.

КАРТА ЯЧЕЕК СТРАНИЦЫ (r6 = $400 в хвосте, абсолютные адреса)
  $404 EQF | x$40B EQG | $405 VOL | $406 PAN | $408 BASE | $409 HPQ
  $40C фильтр-ENV ATK | $40D фильтр-ENV DEC | $40E WDTH | $410/$411 оффсеты
  $413 LPQ | $414-$417 стадия-2 ATK/DEC/BOFS/WOFS | $418-$41B env2
  $423 TEMPO | $428 TRIG (1=on, 2=rel, 3=kill) | $429 слово питча | $42A tick
  Машинные ручки FM: $42C-$433 (raw<<16), TUNE = $433.
  Выход кадра: кольцо гейна Y$20-$3F (32 слова) + буфер микса Y$4DC-$4FF.

ЗАДАокументированные особенности (в порту воспроизведены 1:1)
  1. move ab,l: — эмулятор пишет B->X / A->Y (железо: A->X / B->Y); 4 места
     ($0470, $0483, $08F0, $0911). Порт повторяет эмулятор, чтобы сходиться
     с векторами пословно; при желании железной семантики поменять 4 строки.
  2. Панорамные sin/cos-таблицы $14A000/$14A800 в харнесе инжектируются
     математически (round(sin/cos(2*pi*i/8192)*2^23-1)) — порт использует те
     же таблицы (kSine8192 из пака 3 + mnm_cos_table.h).
  3. Ячейки X$2C0-$2C9 (указатели мастера) в харнесе обнулены, X$2C9
     зафиксирован на $300 — воспроизведено в VoiceFrame::frame().
  4. y:$120-$124 — указатели диспетчера машин; для FM-слота патчатся
     константы INIT/CONF/PROC ($145D12/$145D1D/$145D21).
