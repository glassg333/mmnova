text

000AB7: move y:(r6+$14),b   ; ATK
000AB8: sub  #>$400000,b    ; ATK − 0.5
000ABA: abs  b              ; |ATK−0.5|
000ABB: asl  b              ; ×2
000ABE: mpy  x0,x0,a        ; depth = (2·|ATK−0.5|)²
Глубина — парабола с минимумом ровно в центре ручки (64), растёт в обе стороны. Плюс при ATK ≥ 64 прошивка меняет окна местами:

text

000A22: move y:(r6+$14),a   ; ATK
000A23: sub  #>$400000,a    ; ATK − 0.5
000A25: bmi  $0A29          ; < 64 → окна как есть
000A27: move #$62,r0        ; ≥ 64 → окна X:$62/X:$40 обменяли
000A28: move #$40,r1
DEC — множитель затухания резонатора, BOFS/WOFS — стартовые углы цепей (кривая $144AC7).

«При чём тут делей» — вот при чём, и это не моя путаница
Стадия 1 (BASE/WDTH/HPQ/LPQ) — чистая, env-free, делэй не трогает. Но стадия 2 вшита в обратную связь делэя: её выход пишется в банк тапов L:$92–$9F, и сама ОС выставляет эти ячейки наружу как фильтр делэя — mn_midi.csv: CC86 «EFX Delay FLT Base», CC87 «EFX Delay FLT Width». То есть «фильтр с энвелоупами» и «фильтр эха» в прошивке — один блок. Тут модель «эффекты рядом, по отдельности» не работает.

А вот где работает: DSND — да, отдельный блок. Ядро ячейку DSND (P+$1C) не читает ни разу — это хостовая моно-громкость посыла, T6 пишет в эхо-шину X:$2C9 сумму (L+R)/2 ($0B45: add a,b; asr).
