# ПАК 8 — ПРОТОКОЛ ДОКАЗАТЕЛЬСТВА (полный кадр голоса)

Дата: 2026-09-29. Правило №18: один пакетный прогон эмулятора, один прогон теста.
**Итог: 392824 проверки, 0 расхождений — [100% VOICE-FRAME BIT-EXACT].**

## Метод

Живой трек-кадр OS 1.32B ($0100–$0B4C) на бит-точном эмуляторе DSP56300 с
диспатчем машины m8 (FM-STAT) на треке 0 (пак-7 контракт: INIT единожды,
CONF перед каждым кадром, захват A на входе PROC). Для каждого сета:
свежий эмулятор → INIT → CONF → **SEED** (полное X/Y $000–$700) → кадры.
Захват кадра: те же окна X/Y (3584 слов) + выход машины Y$100–$121.

Порт в C++: транслитерированный поток инструкций кадра (2636 инструкций)
исполняется ядром точной семантики DSP56300 (порт dsp_emu.py); на
диспетчерском `jsr (r1)` вызывается нативное бит-точное FM-ядро (пак 3/7)
с двусторонней синхронизацией scratch/page-состояния.

Проверка: для каждого кадра сравниваются ВСЕ ячейки, изменившиеся с seed
(дельта-формат эквивалентен полному сравнению: ячейка отсутствует в обеих
дельтах ⇔ совпадает с seed с обеих сторон).

## Сет-грид (155 сетов, 936 кадров, один прогон tools/exp66_tail_frames.py)

1. BASE × WDTH: 7×4 = 28 сетов × 4 кадра
2. HPQ × LPQ: 5×5 = 25 × 4
3. EQF × EQG: 5×4 = 20 × 4
4. фильтр-ENV ATK/DEC ($40C/$40D) × BOFS/WOFS ($410/$411): 12+9 × 8
5. стадия-2 ATK/DEC × BOFS/WOFS ($414–$417): 9+9 × 8
6. env2 ($418–$41B) + kill/phase ($420/$421): 9+3+2 × 8
7. ячейки делэя $438–$43F + длинный хвост: 16+1 × 8/16
8. VOL × PAN: 9 × 4
9. гейтовые последовательности (16 кадров, on/off/rel): 2 × 16
10. дефолты: 1 × 8

## Законы, подтверждённые в кадре (поверх паков 3/5/7)

- Регистры секций: r6 = $400 во всём хвосте (func_000132: r6 = y:$123 − $28),
  r7-маршрут $4DC → $4E8 → $4FA → $55C; хвост самодостаточен по регистрам
  (машина оставляет r6=$428/r7=$120, func_000132 переустанавливает).
- Копия истории ($04F5): 17 итераций × 2 слова читают выход машины
  Y$100–$121 (r7 = $100→$122) в X$97–$A7 / X$D7–$E7.
- Каскад-1: коэфф-калькулятор ($0537–$059F: BASE→div-индекс $141CA7·1199>>23,
  WDTH→width-таблицы) → func_000340 (FIR+SVF гибрид) L/R с mono-гейтом
  (x:$40F.0) → halfband-полифаза ($F528BD/$4A4DF0) → комплексно-поворотный
  расчёт (пары $141A98/$142158/$142F06, mpyuu+dmac, 24× div) → func_000350/365.
- EQ ($0789–$0858): EQF/EQG через $143C06; гейн-путь ($08D8–$08FA): VOL²,
  пан sin/cos ($14A000/$14A801), 16-шаговый рамп в кольцо Y$20–$3F.
- Резонанс ($0859–$0938): HPQ/LPQ-таблицы, прогрессия тапов L:$80–$90,
  сканер func_000397 (гребёнка дробных тапов), эхо-гейт T1[LPQ]·TEMPO.
- Стадия-2 + хвост ($0A5D–$0B4B): фильтр-энвелопа BOFS/WOFS (пак 5),
  финальная прогрессия делэя ($0AD1–$0B12), скан ($0B13), микс выхода.

## Документированные divergence (в порту воспроизведены = оракул)

- `move ab,l:` пишет B→X / A→Y (железо: A→X / B→Y); 4 места: $0470, $0483,
  $08F0, $0911. Порт повторяет эмулятор для пословного совпадения с векторами.
- Панорамные таблицы $14A000/$14A800 — математическая инжекция харнеса
  (round(sin/cos·(2^23−1))), порт использует те же таблицы.
- `lsr b a1,r0` в эмуляторе — динамическая 3-операндная форма
  (r0 := a1 >> (B&63)); поведение воспроизведено.
