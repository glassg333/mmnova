# ФИЛЬТР-ЭНВЕЛОП (ATK/DEC/BOFS/WOFS) — числа и сведённые факты (пак 12)

Мануал (стр. 30–31): «BOFS задаёт величину, которая ДОБАВЛЯЕТСЯ к BASE;
WOFS — к WDTH; управляются ATK и DEC» — это модель ОС. В DSP (OS 1.32B,
$0A22–$0AD0) она реализована как система вращающих цепей + банк коэффициентов
резонанса фильтра. Ниже — что доказано кодом и что измерено дифференциальным
экспериментом на бит-точном эмуляторе (exp69b, живая FM-нота m8).

## 1. Ячейки — ИСПРАВЛЕННАЯ карта (главный источник прошлых путаниц)

| Ячейка | Параметр | Доказательство |
|---|---|---|
| $410 | FLT BASE (CC72) | чтение P:$056D → индекс div1 |
| $411 | FLT WDTH (CC73) | P:$0578 → div2/width1/width2 |
| $412 | FLT HPQ (CC74) | P:$08FA → $1448C6/$144946 |
| $413 | FLT LPQ (CC75) | P:$0985 → $144BC9 |
| $414 | FLT ATK (CC76) | P:$0A22 (свап), P:$0AB7 (глубина) |
| $415 | FLT DEC (CC77) | P:$0ABF (множитель) |
| $416 | FLT BOFS (CC78) | P:$0A5D/$0A85 (углы c1/c2) |
| $417 | FLT WOFS (CC79) | P:$0A84 (c2 = кривая[WOFS+BOFS]) |

ОШИБКИ СТАРЫХ ДОКОВ, исправлены: «BASE=$408, WDTH=$40E, HPQ=$409»,
«$404 = EQF», «EQG = y:$40B» (на деле X:$40B — делитель гейна EQ),
«машинные параметры = $404–$40B» (на деле $42C–$433: база машин = P+$28).

## 2. Механизм (адреса — обоснование)

- **Свап окон** $0A22–$0A34: ATK−0.5 ≥ 0 (ручка ≥ 64) → обмен банков
  X:$40–$63 ↔ X:$62–$83. ATK=64 — точка симметрии.
- **L1** $0A5D–$0A82: угол **c1 = curve[$144AC7][BOFS]**; вход — аудио
  X:$20–$3F, выход Y:$62–$81; стейты $4D3/$4D4.
- **L2** $0A84–$0A9B: угол **c2 = curve[$144AC7][WOFS+BOFS]** (сумма!);
  вход = выход L1, выход — банк Y:$20–$3F; стейт $4D5.
- **L3** $0A9D–$0AB5: угол c3 = curve[$144B48][(фаза делэя $4CF>>17)];
  вход — шина машин, выход пишет в ТОТ ЖЕ банк Y:$62–$81 (перекрывает L1
  для следующего кадра).
- **DP** $0AB7–$0AD0: банк тап-коэффициентов резонанса
  `a[i] = 2·DEC·L2out[i] + depth·L3out[i]` → X:$51–$61 (b-банк X:$40–$50);
  **depth = (2·|ATK−0.5|)²** ($0AB7–$0ABE). X:$51 = a[0] (НЕ «depth» —
  поправка к карте итерации 18).
- **KILL** $0AC0–$0AC4: фаза AMP-энвелопа (X:$4D8) == 4 → `DEC := 0` —
  в банке тапов остаётся только depth·L3.

Кривая $144AC7 (углы): [0]=0.0022, [32]=0.0147, [64]=0.0942, [96]=0.4758,
**[128]=0.912 (макс)**, [160]=0.643, [192]=0.831, [254]=0.911. BOFS/WOFS —
это «тон резонанса», пик кривой на 128.

## 3. Дифференциальный замер (exp69b, живой FM, BASE=64 WDTH=96 LPQ=120)

Свип каждого knob'а против базы ATK=96 DEC=96 BOFS=WOFS=96, 40 кадров,
диф ВСЕХ ячеек X/Y $000–$6FF:

| Свип | ячеек изменилось | вывод |
|---|---|---|
| DEC 96→0 | **1 (сама ячейка)** | DEC НЕ слышим в этом конфиге |
| WOFS 96→0 | **1 (сама ячейка)** | WOFS НЕ слышим в этом конфиге |
| ATK 96→0 | 91 | глубина + свап окон |
| ATK 96→64 | 58 | глубина → 0, свап off |
| BOFS 96→0 | **173 (весь микс!)** | BOFS — главная слышимая ветка |

Интерпретация: DEC умножает вклад L2 (2·DEC·L2out), WOFS задаёт угол L2 —
обе ветки мертвы, пока цепь L2 не возбуждена (в этом конфиге L2out = 0).
В принудительных конфигурациях пака 5 (форс-стейты делэя) свип DEC двигал
окно стадии-2 бит-в-бит — возбуждение L2 конфиг-зависимо. Честный вывод:
**DEC/WOFS слышимы только при возбуждённой цепи L2; ATK и BOFS слышимы
всегда**. Проверка на железе: повернуть DEC при зафиксированной ноте —
если хвост резонанса не меняется, конфиг попадает в «спящую» ветку.

## 4. KILL: фаза 4 — это СОБЫТИЕ KILL, а не REL (исправление)

Код AMP-энвелопа $088E–$089C:

| TRIG_EVENT ($428) | фаза после | смысл |
|---|---|---|
| 1 | 0 | note on → ATK |
| 2 | 3 | note off → REL ($08CA, ручка REL $403) |
| 3 | **4** | **KILL** → фаза 4, фиксированный спад $20 (0.904/кадр) |

Гейт стадии-2 ($0AC0) сравнивает фазу с **4** ⇒ резонансный хвост глушится
**событием KILL (TRIG=3)** — мгновенно, до следующей ноты. Обычный note-off
(фаза 3) хвост НЕ глушит: резонанс звенит сквозь релиз AMP (замер exp69:
TRIG=2 → фаза 3, банка жива; TRIG=3 → фаза 4, DEC-вклад банка обнулён).
Формулировка «при снятии ноты» из старых доков — неточная: гашение = KILL
(TRIG=3) либо естественное затухание, а ручка REL ($403) управляет только
AMP-энвелопом.

## 5. Сводка «где начинают, чем кончают»

- ATK (глубина): 0 = (2·1)²… стоп: depth=(2·|ATK/128−0.5|)² → ATK=64 → 0
  (резонанс спит), ATK=0/127 → 0.996 (максимум с двух сторон ручки).
- DEC (множитель L2-ветки): 0 → вклад L2 нулевой; 127 → ×0.992/кадр.
- BOFS/WOFS: углы цепей из кривой $144AC7; BOFS=WOFS=0 → 0.0022 (почти
  прямые), BOFS≈128-зона → 0.91 (резкое вращение = слышимый резонанс).
- KILL (TRIG=3): DEC-вклад банка тапов → 0 в течение одного кадра.
