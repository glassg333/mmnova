# DIST: АТТЕНЮАЦИЯ И НАСКОК — полный разбор с числами (пак 12)

OS 1.32B, ядро DSP1. Кадр = 16 сэмплов @ 44.1 кГц = 0.3628 мс. Терминология:
фильтр имеет **резонанс** (не «резонатор»); AMP-энвелоп фазой 4 глушит
резонансный хвост (KILL-гейт $0AC0–$0AC4).

DIST — ручка 5 AMP-страницы, **ячейка $404, CC60**, в UI биполярная
**−64…+127** (мануал, стр. 27–28: отрицательная половина = увеличение
headroom, положительная = перегруз). В странице — знаковое слово `v<<16`.

DIST состоит из ДВУХ механизмов: статичного (ручка → коэффициенты фильтра/EQ)
и динамического (драйв-энвелоп = «наскок» на каждую ноту).

---

## 1. НАСКОК — драйв-энвелоп ENV3 (P:$04FF–$0536)

Стейт-машина кадра, уровень `x:$4DB`, фаза `y:$4DB`, счётчик `x:$4DA`.

Фазы (по коду $0506–$0536):

| Фаза | Код | Что происходит |
|---|---|---|
| 0 ATK | $0506–$0516 | `level += kDistAtk[$40C>>16]`; при достижении 1.0 — **дата-лимитер пишет $7FFFFF (+1.0)**, фаза := 1 |
| 1 HOLD | $0517–$052A | 1 кадр, множитель темпа = 0 → безусловный переход в DEC того же кадра |
| 2 DEC | $052B–$0536 | `level −= kDistRel[(VOL²+$7FFF)>>16]`; VOL≤127 → индекс 0 → **шаг 1/64 за кадр**; кламп `<0 → 0` |

- РЕТРИГ: ячейка `$420 == 1` → полный сброс уровня/фазы ($04FF–$0505).
- ИСПРАВЛЕНИЕ против mnm_dist.h (пак 11): точка перелома атаки = **$7FFFFF
  (сатурация дата-лимитером), не −1.0**. Измерено: atk=0 → f0: 0.5, f1:
  $7FFFFF фаза 1, f2: −1/64, ноль на f65 — ровно 64 кадра спада.

### Числа атаки (шаг за кадр = kDistAtk[$141800], индекс = старшая половина $40C)

| $40C (индекс) | шаг/кадр | кадров до 1.0 | время «наскока» |
|---|---|---|---|
| 0 | +0.5 | 2 | ~0.7 мс (мгновенно) |
| 8 | +0.2563 | 4 | 1.5 мс |
| 16 | +0.13135 | 8 | 2.9 мс |
| 32 | +0.03450 | 29 | 10.5 мс |
| 64 | +0.002381 | 420 | 152 мс |
| 96 | +0.000164 | 6100 | 2.2 с |
| 127 | +0.0000120 | 83000 | ~30 с («никогда») |

Спад всегда **64 кадра = 23.2 мс** (от +1.0 до 0, линейно 1/64). Итого звук:
«наскок» = подъём драйва за `atk`-время, плато 1 кадр, спад 23.2 мс.

Важно: DSP-сторона не видит, что хост кладёт в `$40C` при отрицательном DIST
(слово до $141800 читается как нули — атака мгновенная). Для 0..127 закон
выше бит-в-бит (векторы vectors_dist_exp69.txt, 450 кадров, 0 расхождений).

### Индекс тона (P:$0537–$0556) — куда бьёт наскок

```
idx = wrap24( param4·$800 − $80 + panFactor − level·1792·panFactor )
panFactor = a1-срезы от |PAN_L($40E) + (−0.5)|²·4   (при $40E=0 → 1.0)
```
Бит-в-бит замер: level=0.5 → idx = 0xFFFC00 = **−1024 = −128 − 0.5·1792**;
level=1.0 → −1920. Верхний кламп $700 есть, нижнего нет — отрицательные
индексы уходят в таблицы как есть. Драйв СКВОЗЬ скользит индекс тона вниз.

## 2. АТТЕНЮАЦИЯ — статичный путь ручки ($07A6–$07B5 + читатели)

```
$07A6  a = $404 (DIST, знаковое)
$07A7  asl a          → 2·DIST
$07A8  add #$800000   → 2·DIST + 1.0
$07AA  clr a ifmi     → max(0, 2·DIST+1)     ← отрицательная половина гасится
$07B7  x1 = $1447C6[r2],  r2 = mpyi((2·DIST+1) a1-срез · 256)   ← ПИЛА по ручке
       масштаб = (2·DIST+1)²·0.98316 + 0.01574   ($07AF–$07B5)
$065A/$0685  вторая кривая $143C06, индекс из 2·DIST (тот же a1-срез)
$0857–$0865  гейн EQ = 1 − tbl[$1435C6][clamp(idx_тона, 0, 1599)]
```

- Диапазон аттенюации EQ: tbl[0]=0.0008 → гейн 0.999; tbl[1599]=0.913 →
  гейн **0.087 (−21 дБ)**. Индекс тона управляется EQF-словом хоста ($408),
  PAN ($40E) и наскоком (−1792·level) — «дисторшн — интегральная часть
  фильтра» (мануал) ровно в этом смысле.
- Кривая $144C6: 1.0 → 0.3536 (√2/4) с масштабом (2·DIST+1)²·0.98316+0.01574.
- Индекс $143C06/$1447C6 — ПИЛА: a1-срез (2·DIST+1) заворачивается каждые 64
  единицы ручки (замер: DIST 0→idx 0, 16→128, 32→0, 64→252) — неотбражаемая
  «гранулярность» и есть характер перегруза.

### Слышимый замер (мастер-микс T6, VOL=80, FM-нота, RMS кадров 24–43)

| DIST | сухой RMS | LPQ=127 RMS |
|---|---|---|
| −64 | −7.96 дБ | −7.29 дБ |
| −32 | −7.86 дБ | −8.68 дБ |
| −16 | −8.25 дБ | −6.93 дБ |
| 0 | −5.46 дБ | −5.46 дБ |
| 32 | −5.46 дБ | −5.46 дБ |
| 64 | −7.76 дБ | −7.91 дБ |
| 127 | −7.76 дБ | −7.91 дБ |

Максимум уровня на DIST≈0…32 (пила idx≈0), спад к обоим краям — согласуется
с пилой индекса. Пик упирается в 1.0 (мастер клипуется) — относительные
различия достоверны, абсолютные — с оговоркой.

**checks=450 mismatches=0 [100% DIST-DRIVE BIT-EXACT]** против эмулятора
