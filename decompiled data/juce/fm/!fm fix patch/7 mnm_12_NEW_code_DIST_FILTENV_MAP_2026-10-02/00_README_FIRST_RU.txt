OS 1.32B, бит-точная база = паки 3/5/7/8/10/11. Терминология: резонанс фильтра
(не «резонатор»); KILL-гейт фазы 4 глушит резонансный хвост.

ГЛАВНЫЕ ЧИСЛА
  наскок: атака 2 кадра (idx 0) … ~30 с (idx 127); плато 1 кадр; спад ВСЕГДА
          64 кадра = 23.2 мс (1/64 за кадр); индекс тона = −128 − level·1792
  аттенюация: гейн EQ = 1 − tbl[clamp(idx,0,1599)]; диапазон 0…−21 дБ;
          отрицательная половина DIST гасит драйв-член (max(0, 2·DIST+1))
  фильтр-энвелоуп: depth=(2·|ATK−0.5|)², DEC = множитель L2-ветки, углы из
          кривой $144AC7 (пик 0.912 на индексе 128); KILL (TRIG=3, фаза 4) →
          DEC:=0 за один кадр; note-off (TRIG=2, фаза 3) хвост НЕ глушит
