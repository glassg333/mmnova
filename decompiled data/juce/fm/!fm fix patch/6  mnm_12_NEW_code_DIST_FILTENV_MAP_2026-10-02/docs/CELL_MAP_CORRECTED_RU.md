# КАРТА ЯЧЕЕК СТРАНИЦЫ ГОЛОСА — СВЕДЁННАЯ (пак 12)

Страница трека 0 = Y:$0400 (треки 1/2 = $0500/$0600; у каждой машины своя
база: машинный r6 = P+$28, поэтому машинные параметры 0–7 = $42C–$433).
Кадр фильтра идёт с r6 = P ($400). CC-карта = официальный MIDI Appendix.

## Исправленные ошибки прежних редакций (причина «данные видны, факты не сведены»)

1. «$404 = EQF» → **$404 = DIST** (CC60). Секция $0789–$0859 = драйв/EQ-гибрид,
   читает именно DIST — «дисторшн контролирует headroom фильтра и EQ» (мануал).
2. «BASE=$408, WDTH=$40E, HPQ=$409» → **FLT = $410–$417** (трасса чтений).
   Свипы «BASE/WDTH/HPQ» в exp66/exp68 крутили служебные ячейки тона/PAN —
   выводы про «эхо/делэй» от этих свипов недействительны (свипы ATK/DEC/
   BOFS/WOFS и DBAS/DWID/DSND — действительны, ячейки были верные).
3. «Кривые $143C06/$1447C6 = машинный параметр 0» (поправка итерации 21) →
   **это кривые DIST** ($404): «поправка» опиралась на устаревшую карту
   «параметры = $404+», что противоречит итерации 13 (машины читают свои
   параметры с базы P+$28) и MIDI-карте (CC60 = AMP Dist).
4. «Ячейки env2 $418–$41B скрыты от UI» → **это EFX-ручки EQF/EQG/SRR/DTIM**:
   форма конверта env2 (атака/спад/сустейн/релиз рамп тапов делэя) задаётся
   первыми четырьмя ручками EFX-страницы. Ни ядро, ни машины больше нигде
   $418–$41B не читают.
5. «Фаза 4 AMP-энв = REL» → **фаза 4 = состояние KILL (TRIG_EVENT=3)**;
   note-off = фаза 3 (REL), хвост резонанса звенит сквозь релиз.
6. «X:$51 = depth» → **X:$51 = a[0]** (первый тап-коэффициент
   2·DEC·L2out+depth·L3out); depth в память не пишется.
7. «$143C06 = кривая DIST, индекс DIST·$100, монотонная» → индекс = a1-срез
   (2·DIST+1)·256 — **пила** (заворот каждые 64 единицы ручки).

## env2 — итоговая атрибуция (уточнение пака 10)

env2 (P:$04A8–$04F4, выход Y:$4FF) = конверт рамп тапов делэя
(рампы Y:$10–$1F ← DWID²·env2², $0B1E–$0B22). Его ATK/DEC/SUS/REL индексы =
ячейки **$418/$419/$41A/$41B = EQF/EQG/SRR/DTIM**. Бит-в-бит порт (6120/0,
пак 10) остаётся в силе — верны были законы чтения, а не их атрибуция.
«ENV 2 = энвелоуп второго фильтра хай-хэта» — неверно: второго фильтра нет.
