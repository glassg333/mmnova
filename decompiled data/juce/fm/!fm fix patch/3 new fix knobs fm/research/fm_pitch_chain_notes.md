# Цепочка питча кернела — заметки по разбору (2026-09-28)

## Что измерено на оригинальной ОС (эталон Monomodule, dsp56300)

1. **Диспетчер трека** (P:$00E1-$00F6): r6 = y:$123 = блок+40 (слово 40 = NoteTrig);
   `y:(r6+$1)` = слово 41 (питч) грузится в B; `x:(r0+$10016B)` при r0 = индекс
   машины = указатель PROC машины; вызов `jsr (r2)`.
2. **На входе PROC** (захвачено пошагово): A = 48-битный acc (линейное слово
   частоты: точно ×2 на октаву, ~f×2^24), ОДИНАКОВЫЙ для STAT/PAR/DYN.
   B на входе = мусор диспетчера (не питч).
3. **Машина** ($145D21..): `mpysu x0,y0,a; dmac ss x0,y1,a` — умножение acc на
   $BE37C (×2), затем на слово таблицы соотношений Y:$141A80[n1], n1 из ручки
   2FRQ (r6+$8) законом ((K<<16)+$8000)*24<<1>>24; asl#3 → глайд-рамп оператора.
4. **Золотая таблица**: fm_pitch_golden.json — 3x2x128 acc. Свойства:
   - acc(69, tune440) = 0x1B7CD1771 = 7 378 638 705 (~440×2^24);
   - acc точно ×2 на октаву (0x416061E6 → 0x82C0C3CC → 0x105818798 → …);
   - интонация ОС ≈ −0.8 цента от РТ (тюн-слово −1 ед + пол LUT);
   - индекс питча кернела = слово41 + тюн + ~341.33 ед (+2 полутона);
   - idx ≤ 0 → кламп kFmAccFloor = 122 172 277 (acc питч-индекса 0).
5. **Тюн**: слово 38 = u16 65536×f/440 с клампом 65535 (при 440 Гц = −1);
   смещение частоты = 2^(тюн_ед/2048) (подтверждено рядом 400/440 Гц).

## Конверсия кернела P:$02DD-$02EA (глайд, чтение LUT)

```
asr  #$b,a,b          ; b = idx >> 11  (октава)
and   #>$7ff,a        ; a = idx & 2047 (индекс, 2048 записей = 1 октава)
move  a,r2
move  b,x0
move  x:(r2+$140000),a ; a = LUT24[idx&2047]  (X:$140000, Q2.22, 1.0=$400000)
asr   #$a,a,a          ; a = LUT>>10 (~4096)
asl   x0,a,a           ; a <<= октава (динамический сдвиг!)
move  #>$1d22a,y0
move  a,x0
mpy   y0,x0,a          ; a = x0*y0<<1
asr   #$3,a,a          ; acc = a * $1D22A / 4
```
LUT24 в прошивке (dsp1_pmem.bin X:$140000..1407FF): floor($400000 × 2^(i/2048)),
2048 записей, LUT[2047] = $7FF4E8. ВАЖНО: у эталона Monomodule верхняя половина
LUT обнулена (его стаб скипает часть инита кернела, $100139 чистит внешнюю
память) — сверку конверсии делать по dsp1_pmem.bin, не по peek эталона.

Перед $02DD (глайд, $02C0-$02CC): сумма слово30 (питч-мод, покой 64<<16;
вклад w30×$B000×2/2^24 − $5800 = 0 в покое) + слово38 (тюн) + X:$1×$2AB×2
(X:$1 = 0 в эталоне) − $5800; далее аккумулятор глайда X:(r6−$20..$26).

## Почему формула не бит-в-бит, а таблица

Цепочка acc = conv(idx) с полами LUT/сдвигов даёт разброс ±1 ед. внутри
инверсии (Δ = idx_eff − слово41 − тюн ∈ {340,341,342}) — точная
целочисленная цепочка кернела длиннее (глайд-аккумулятор, порядок полов).
Поэтому в MnmFmPitch.h зашиты сами acc (золотая таблица): бит-в-бит при
тюне 440, а тюн/бенд масштабируют якорь экспонентой (у ОС квант 0.586 цента,
расхождение ≤ ~0.3 цента из-за полов LUT ОС).
