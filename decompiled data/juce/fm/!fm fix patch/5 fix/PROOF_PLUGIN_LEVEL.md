# ПАК 7 — ПРОТОКОЛ ДОКАЗАТЕЛЬСТВА (уровень плагина FM)

Дата: 2026-09-29. Правило №18: один пакетный прогон эмулятора, один прогон теста.
**Итог: 9556 проверок, 0 расхождений — [100% PLUGIN-LEVEL BIT-EXACT].**

## Метод

Живой трек-кадр OS 1.32B ($0100–$0B4C) на бит-точном эмуляторе DSP56300 с
диспатчем машины m8 (FM-STAT) на трек 0 (треки 1/2 — пустые). На каждую
конфигурацию: свежая страница, машинный INIT ($145D12), CONF ($145D1D,
идемпотентен — в живой ОС вызывается при изменении параметров), затем кадры
$0100–$02EC (внутри $02EB ядро делает jsr на PROC — машина исполняется) и
$02EC–$0B4C (энвелоп, гейн-кольцо, SVF).

Захват на кадр: регистр A на входе PROC ($145D21, ПОЛНЫЙ 48-бит a1:a0),
уровень/фаза/счётчик энвелопа (Y/X[P+$D7/$D8]), гейн-цели (X/Y[P+$FA]),
выход машины (Y:$100–$121).

## Сет-грид (один прогон, tools/exp64_fm_pluginlevel.py)

1. Питч-закон: w41 {0, 10240, 11776, 21674} × TUNE {0,1,32,64,96,127} ×
   w30 {64, 0, 127} = 72 сета × 3 кадра.
2. Энвелоп: ATK/HOLD/DEC/REL сетки × последовательности гейта
   (on→off→retrig, on→kill, длинный hold 72 кадра) = 8 сетов, 184 кадра.
3. Гейн: VOL {0,64,127} × PAN {0,32,64,127} = 12 сетов × 4 кадра.

## Законы, восстановленные и верифицированные

### Питч ($0262–$02EA) — 72/72 бит-в-бит
```
tuneDelta = (tuneRaw * 683) >> 7                    # TUNE-слово страницы
modDelta  = ((w30<<16) * $B000 >> 23) - $5800       # покой w30=64 -> 0
word      = clamp(glide + tuneDelta + modDelta, 0, $5800)
frac, ip  = word & 2047, word >> 11
x0        = ((tbl$140000[frac] << 24) >> 10 << ip) >> 24
acc48     = ($1D22A * x0) >> 2                      # ПОЛНЫЙ a1:a0
```
Таблица $140000 = 2^(i/2048) в Q22 (2048 слов из дампа). Слово питча = октавы·2048.
Машина умножает $0BE37C на ВЕСЬ 48-битный аккумулятор (mpysu/dmac по a1:a0) —
дробное a0 даёт родной алиасинг MNM FM, теперь бит-в-бит.

### Энвелоп AMP (P:$088E–$08D7) — 184 кадра бит-в-бит
- TRIG: 1 → фаза ATK (уровень НЕ сбрасывается — родной ретриг),
  2 → REL, 3 → KILL.
- ATK: level += tblA[ATK]; при сумме ≥ 1.0 дата-лимитер пишет $7FFFFF
  (НЕ wrap в −1.0 — снято трассировкой!), фаза := HOLD, счётчик := 1.
- HOLD: t0 = (HOLDword ≥ $10000 ? HOLDword : 0); x1 = (t0·TEMPO)>>23;
  порог = x1·$791FD0·4; DEC когда (счётчик+1)<<24 > порог.
- DEC/REL: idx = (слово + $FFFF) >> 16; level = −level·tblB[idx] >> 23.
- KILL: слово $20 → idx 1 → 0.904016/кадр (−60 дБ ≈ 16 мс) — измерено.
- DEC=127 → tblB[127] = −1.0 → уровень заморожен.

### Гейн-путь (P:$08D8–$08FA) — 48 кадров, цели бит-в-бит
```
VOL²q = (VOL<<16)² >> 23;  v = (level·VOL²q) >> 23
idx   = ((PAN<<16)·$408E05) >> 34
L_t   = (v · cos$14A800[idx+1]) >> 23      # +1 как в коде
R_t   = (v · sin$14A000[idx]) >> 23
рамп: out[i] = (prev<<24 + i·(2^20·(target−prev))) >> 24, i = 0..15
```
PAN 0 → L = cos[1] = 1.0, R = sin[0] = 0 (жёстко влево). Волют-закон = VOL².

### Выход машины — 184 кадра × 32 слова бит-в-бит
Ядра MnmFmStat/Par/Dyn (паки 3/4, без изменений логики) с ПОЛНЫМ 48-битным A
воспроизводят живой выход машины слово-в-слово, включая инвариант дублей
(a,a,b,b) — обоснование фикса 16-сэмплового кадра.

## Задокументированный дефект эмулятора (в порт НЕ переносился)
`move ab,l:aa` в питоновском dsp_emu сохраняется как B→X / A→Y (реальный
DSP56300: A→X / B→Y). Из-за свопа рампа гейна в эмуляторе стартует с чужого
канала (пила −41 дБ на 2.756 кГц). Порт = семантика железа: канал рампится от
своего предыдущего значения. Цели гейна от свопа не зависят — сверены точно.
