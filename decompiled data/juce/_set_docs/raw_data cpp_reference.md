### Формулы (по шагам сэмпла)

1. LFO-амплитуда: `lfoGain = sin(2π·rate·t) · oscVolume`, где `oscVolume → depth·0.5`
   (osc sin [C.cpp:42-43]; частота [C.cpp:135]; амплитуда [C.cpp:136]; применение [C.h:117-118]).
2. Задержка: `d_ms = max(1, 20·lfoGain + centreDelay)` [C.h:124]; в сэмплы: `d_smp = d_ms·sr/1000` [C.h:125].
3. Вычитающая feedback: `x = input − lastOutput` [C.h:138]; запись в линию и чтение с линейной
   интерполяцией [C.h:140-142] (DelayLine Linear [C.h:158]).
4. `lastOutput = wet · feedback` [C.h:145] (сглаженный feedbackVolume [C.h:160]).
5. Микс: `out = dry·(1−mix) + wet·mix` (правило linear [C.cpp:45], пропорция [C.cpp:137]).

### Официальный совет по конфигурациям [C.h:46-49]

- Классический хорус: centreDelay ≈ 7–8 мс, низкий feedback, низкая depth.
- Флэнжер: меньший centreDelay + «a lot of feedback».
- Вибрато: mix = 1.

### Формулы

1. Нормализованный центр: `normCentre = mapFromLog10(centre, 20, min(20000, 0.49·sr))` [P.cpp:78].
   mapFromLog10 = (log10(v)−log10(min))/(log10(max)−log10(min)) [MF.h:423-431].
2. На каждом 4-м сэмпле (осциллятор тикает с sr/4 [P.cpp:115-119]):
   `lfo = clamp( sin(2π·rate·t)·(depth·0.5) + normCentre, 0, 1 )` [P.h:136-138],
   амплитуда `oscVolume → depth·0.5` [P.cpp:149].
3. Частота среза: `fc = mapToLog10(lfo, 20, min(20000, 0.49·sr)) = 20·(hi/20)^lfo`
   [P.h:140-141]; mapToLog10 = 10^(v·(log10max−log10min)+log10min) [MF.h:402-411].
4. Коэффициент TPT: `g = tan(π·fc/sr); G = g/(1+g)` [FT.cpp:120-121].
5. Ядро каждого каскада: `v = G·(x−s); y = v+s; s = y+v` [FT.cpp:93-95];
   выход all-pass: `2y − input` [FT.cpp:101] (режим выбирается в [FT.cpp:97-103]).
6. Вычитающая feedback: `x = input − lastOutput` [P.h:158];
   `lastOutput = out·feedback` [P.h:176].
7. Микс: правило linear [P.cpp:51].

## 4. Reverb (Freeverb)

Схема на КАЖДЫЙ канал: 8 comb-фильтров ПАРАЛЛЕЛЬНО → 4 all-pass ПОСЛЕДОВАТЕЛЬНО;
стерео — те же тюнинги + spread 23 сэмпла на правом канале [R.h:104-119];
кросс-подача wet1/wet2 [R.h:174-175]. Полный класс [R.h:50-328].

### Параметры (дефолты — как в структуре Parameters)

| Параметр | Диапазон | Дефолт | Строки |
|---|---|---|---|
| roomSize | 0..1 (1 — большой) | 0.5 | [R.h:64] |
| damping | 0..1 | 0.5 | [R.h:65] |
| wetLevel | 0..1 | 0.33 | [R.h:66] |
| dryLevel | 0..1 | 0.4 | [R.h:67] |
| width | 0..1 | 1.0 | [R.h:68] |
| freezeMode | 0..1 (≥0.5 — freeze) | 0.0 | [R.h:69-70], [R.h:210] |

### Тюнинг задержек (сэмплов @44100 Гц)

| Comb 0..7 | 1116, 1188, 1277, 1356, 1422, 1491, 1557, 1617 | [R.h:104] |
|---|---|---|
| AllPass 0..3 | 556, 441, 341, 225 | [R.h:105] |
| stereoSpread | +23 сэмпла на правый канал | [R.h:106] |
| Масштаб под sr | size = sr·tuning/44100 | [R.h:111, 117] |

### Формулы

1. Гейны при setParameters [R.h:83-94]: `wet = wetLevel·3`; `dry = dryLevel·2`;
   `wetGain1 = 0.5·wet·(1+width)`; `wetGain2 = 0.5·wet·(1−width)`;
   `gain = frozen ? 0 : 0.015` [R.h:91]. Сглаживание 0.01 c [R.h:121-126].
2. Отображение параметров [R.h:212-229]: `feedback = roomSize·0.28 + 0.7`;
   `damping = damping·0.4`; при freeze: damping = 0, feedback = 1 [R.h:218-219].
3. Comb [R.h:255-266]:
   `output = buf[i]; last = output·(1−damp) + last·damp; buf[i] = input + last·feedback;`
   `i = (i+1) mod size;` вернуть `output`.
4. AllPass [R.h:299-307]:
   `temp = input + buf[i]·0.5; buf[i] = temp; i=(i+1) mod size;` вернуть `buf_old − input`
   (см. строки [R.h:301-306]).
5. Выход стерео [R.h:174-175]: `L = outL·wet1 + outR·wet2 + L·dry`,
   `R = outR·wet1 + outL·wet2 + R·dry`. Вход: `(L+R)·gain` [R.h:152].
