# decoder_v2 — новая система расшифровки прошивки (итерация 18)

Полная статическая-analysis система для dsp1_pmem.bin (1 343 588 слов):
весь firmware декодируется за **~1.2 секунды** с **100% покрытием кода**.

## Результаты верификации (quality)

| Регион             | Эталон (verified listing) | Найдено кода | Пропуски | Объяснение пропусков | recall-code |
|--------------------|---------------------------|--------------|----------|----------------------|-------------|
| Ядро $0-$B4D       | 2344 адреса               | 2264         | 80       | 80 = данные          | **100.00%** |
| Машины $144CC9+    | 10285 адресов             | 9486         | 911      | 911 = данные         | **100.00%** |

Ключевой факт: эталонный листинг машин (`dsp1_machines_fx.txt`) — линейный
дамп, который ложно декодирует ~911 слов таблиц как инструкции (`macr`).
decoder_v2 разделяет код и данные **точнее эталона**: все реальные инструкции
найдены, все пропуски — доказанно данные.

## Как работает (4 прохода)

1. **PASS 1** — лёгкое декодирование КАЖДОГО слова (valid/mnemonic/ext_count)
   в numpy-массивы (0.9 с на 1.34M слов).
2. **PASS 2** — рекурсивное восстановление кода от точек входа (ядро $0000,
   монитор $100000, 62 записей диспетчера машин INIT/CONF/PROC
   $10016B/$10018D/$1001AF) с жёсткими границами регионов + **мультираундовые
   сиды после каждого rts/jmp** (блоки, доступные только через indirect
   переходы: 19+13+8+6+6+4+3+3 = 62 дополнительных блока). Рендер —
   эталонным dis56300 (100% совпадение с dsp56k).
3. **PASS 3** — глобальная карта кросс-ссылок XREF: call/jump/branch/do_end/
   mem_x/mem_y/imm/imm_rN/**disp_rN** (чтение таблиц смещением `(r4+$141800)` —
   главный паттерн доступа к таблицам в этой прошивке!).
4. **PASS 4** — сканер данных: поинтерные таблицы (614), числовые ряды
   (ramp/curve/const), **индекс баз таблиц** (469 адресов с указанием
   читающих инструкций).

## Находки, которые даёт XREF сразу

- Читатели EQ/гейн-таблиц Ф3: `$143546` ← ядро $07D9 (EQ-секция) и машина
  $1451CD; `$1435C6` ← ядро $0860 + машины $145C31/$1479E5/$145A52/$147347;
  `$143C06` ← ядро $0660/$068C (зона расчёта коэффициентов SVF!).
- Кривые стадии 2: `$144AC7` ← 13 ссылок (imm), `$144B48` ← $0AA9 (disp_r2).
- Sin/cos `$14A000` ← 22 ссылки; `$14A800` и часть таблиц лежат ЗА концом
  образа ($148063) — второй банк памяти, в дамп не попал.
- Новые поинтерные таблицы монитора: $1013EF, $101A31, $101AE6.
- 6 indirect-сайтов (jmp (rN)/jsr (rN)) — кандидаты на runtime-диспетчеризацию.

## Ограничения

- Диспетчеризация через регистры (jmp (r0), jsr (r4)) не отслеживается
  статически — такие цели помечены как indirect-сайты (6 шт).
- Синонимы: DSP-код второй прошивки (dsp2_pmem.bin) не анализировался —
  инструмент переносится заменой путей.
