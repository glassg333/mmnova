   не синthesis). Ни одно не совпадает по смыслу с тремя режимами.

## Рабочие гипотезы (требуют подтверждения)

- `dyn` = **динамический** FM (частота модулятора меняется во времени / огибающей);
- `stat` = **статический** FM (фиксированные параметры модулятора);
- `par` = **параллельный** FM (несколько модуляторов на одну несущую параллельно,
  в противовес последовательным цепочкам операторов, как в DX7-алгоритмах).

Это ГИПОТЕЗЫ, не данные. На них код писать нельзя — будет выдумка.
