Официальные цитаты из мануала Elektron Monomachine OS 1.32 (стр. 29–31)

1. ДВЕ НЕЗАВИСИМЫЕ ОГИБАЮЩИЕ НА ТРЕК:

Тот ответ из гугла был прав: AMP огибающая строго управляет громкостью, а на фильтре стоит своя отдельная огибающая (Filter Envelope).

«The filter envelope is trigged every time a FILTER-trig is received. The FILTER-trig can be controlled individually from the sequencer...»

ATK / DEC на странице FILTER регулируют атаку и спад огибающей фильтра. BOFS и WOFS задают, сколько этой огибающей добавляется к частоте BASE и к ширине WDTH.

2. ТОЧНЫЙ ЗАКОН ЧАСТОТЫ СРЕЗА (8 ШАГОВ = 1 ОКТАВА):
«Both the BASE and the WDTH parameters rise one octave for eight steps. This exact locking of the filter to octaves is useful if you want to use high filter Q settings to be used for pitch.»

Это чистый экспоненциальный закон с шагом: std::pow(2.0, steps / 8.0)! Диапазон 0..127 дает ровно 15.875 октав охвата!

3. ПРИВЯЗКА К НОТЕ (KEYTRACKING) И РЕЗОНАНСЫ:
«The filter normally tracks the pitch of the note played. The high pass filter starts cutting two octaves under the base pitch when the BASE parameter is set to zero.»

При BASE = 0 частота среза High-Pass фильтра находится ровно на 2 октавы ниже сыгранной ноты (Note_Freq / 4.0).
HPQ управляет резонансом среза High-Pass (вокруг точки BASE).
LPQ управляет резонансом среза Low-Pass (вокруг точки BASE + WDTH).

Каноническая математика фильтра Elektron Monomachine

// 1. Огибающая фильтра (Filter Envelope, фазы Attack и Decay):
float filtEnvVal; // 0.0 .. 1.0 от параметров ATK и DEC страницы FILTER
// 2. Модуляция BASE и WIDTH через BOFS и WOFS (биполярные -64..+63, где 64=0):
float bofsAmt = (p.bofs - 64) * 2.0f; // эффективный сдвиг в шагах
float wofsAmt = (p.wofs - 64) * 2.0f;
float effBase = std::clamp(p.base + filtEnvVal * bofsAmt, 0.0f, 127.0f);
float effWdth = std::clamp(p.wdth + filtEnvVal * wofsAmt, 0.0f, 127.0f);
// 3. Расчёт частот среза по закону "8 шагов = 1 октава":
// При BASE=0 срез HP на 2 октавы ниже ноты (noteFreq * 0.25):
double fHpHz = (noteFreq * 0.25) * std::pow(2.0, effBase / 8.0);
double fLpHz = fHpHz * std::pow(2.0, effWdth / 8.0);
// 4. Демпфирование (Q) для двух секций (константа DSP56303 $F528BD = -0.084694564):
double qHp = std::clamp(2.0 - 0.084694564 - (p.hpq / 127.0) * 1.88, 0.05, 2.0);
double qLp = std::clamp(2.0 - 0.084694564 - (p.lpq / 127.0) * 1.88, 0.05, 2.0);
