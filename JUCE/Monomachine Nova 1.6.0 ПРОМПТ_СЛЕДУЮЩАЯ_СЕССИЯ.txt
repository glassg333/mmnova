# Промпт для следующей сессии (Monomachine Nova 1.6.0 «mnm modes»)

Скопируйте этот файл агенту вместе со ссылкой на репозиторий. Здесь состояние работы,
правила и точные адреса, из которых надо продолжать. Подробный разбор — в
`ДОКЛАД_1.6.0_АУДИТ_И_ПЛАН.md`.

## Где что лежит

* `JUCE/1.6.0 mnm modes/Monomachine_Nova_{Synth,FX}` — актуальная версия (1.5.2 + фикс сборки,
  bbox от 1.5.1, новый ДСП «mnm», версия 1.6.0).
  Исходники Synth и FX **идентичны**, кроме `Source/NovaConfig.h` (макрос `NOVA_SYNTH`).
  Правьте одну копию и копируйте в другую.
* `JUCE/1.4.0-1.5.0 prompts/Monomachine-Nova-1.5.2` — здесь **исправлена ошибка сборки**
  (отсутствующее поле `selectedStep` в классе `ArpPage`, `Source/PluginEditor.cpp`).
* `decompiled data/!decryptor 56300 - …` — листинги/таблицы/дескрипторы (источник истины).
* `decompiled data/!firmware bin and syx original/elektron_sfx6-60_os1.32b.bin` — прошивка.

## Правила работы (не нарушать)

1. Не менять ручки/органы управления, если об этом не просили.
2. **ПКМ нигде не крутит параметр** — только альтернативные действия (списки, модуляции,
   окно огибающей, список ДСП-режимов).
3. bbox — вариант 1.5.1. Не добавлять лупы/кнопки, о которых не просили.
4. Новые алгоритмы добавляются как **новые записи в списке**, значение по умолчанию `mnm`,
   старые остаются как `old` (см. `Source/models/DspModes.hpp`).
5. Старые состояния не должны молча включать новый ДСП (схема состояния — `schema`, сейчас 8).
6. Хорус, который уже одобрен, не трогать; альтернатива — только отдельным режимом.
7. Предупреждения компилятора не отключать.
8. Максимум нововведений в ДСП до следующей компиляции, минимальные точечные правки.

## Что уже сделано (1.6.0)

* Ядро `mnm`: `Source/dsp/mnm/` — `MnmTables.hpp` (таблицы 1:1 из образа прошивки),
  `MnmKernel.hpp` (AMP-огибающая, TONE/LP, насыщение, SRR, огибающая фильтра),
  `MnmFm.hpp` (FM+STAT/PAR/DYN), `MnmDelay.hpp` (m32-подобная линия дилея).
* Список режимов: `mode_synt`, `mode_amp`, `mode_filt`, `mode_dist`, `mode_dly`, `mode_route`,
  `mode_cho`; кнопка «DSP MODE» рядом с секцией SYNT, ПКМ на ручке → список нужного узла.
* Тесты ядра: `tests/MnmCoreTests.cpp` (CTest: `MnmCoreTests`).
* Проверка сборки: `g++ -std=c++17 -fsyntax-only` по всем .cpp обеих плагин — чисто.

## Ближайшие задачи

1. ColdFire-сторона: раскладка страничных параметров в `V−$28…V−$01`
   (`coldfire_main.bin`, `sec0_full.bin`) → после этого станут точными формулы фильтра и INTL/DPTH.
2. Фильтр: сопоставить BASE/WIDTH банкам `P:$144AC7` и ввести резонанс по `$4A4DF0`.
3. Машины осцилляторов по листингам (SAW/PULS/SID/DPRO/VO6) как режим `mnm` у SYNT.
4. FX-машины (REV/PHA/FLA/RING/DYN/m33) как `mnm`-реализации в FX-плагине.
5. Альтернативный хорус отдельным режимом (текущий не трогать).
6. Разобраться со вторым банком/направлением ручек, помеченных как «не подтверждено»
   (DTIM, шкалы глубины FM, банк WIDTH фильтра).
