# Дополнительная сборка через GitHub Actions

Это необязательный шаблон. Он не запускался при подготовке архива.

1. Создай свой репозиторий и помести СОДЕРЖИМОЕ папки одного проекта в корень: CMakeLists.txt, Source, .github и остальные файлы.
2. В репозитории должна быть разрешена работа Actions. Не публикуй личные файлы/сэмплы без необходимости.
3. Открой Actions → Build VST3 → Run workflow (или отправь commit в main).
4. Workflow скачает JUCE 8.0.9, запустит Windows x64 и macOS universal сборки.
5. Если задания успешны, скачай их artifacts. Windows-результат нельзя использовать на macOS и наоборот.
6. Подпись и notarization не настроены. Это не готовый коммерческий installer.

Если репозиторий содержит оба проекта в подпапках, сначала адаптируй пути CMake и artifacts в workflow.
Использование hosted runners зависит от правил и квот твоего GitHub-аккаунта.
