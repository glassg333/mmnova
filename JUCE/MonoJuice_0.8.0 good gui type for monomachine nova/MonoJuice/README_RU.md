# MonoJuice 0.8.0

**Пять последовательных FX-слотов, любой порядок и повторы. Тёмный pixel GUI.**

В каждом слоте: EMPTY / PITCH / CHORUS / GRANULAR / COMB / SPECTRE. В COMB теперь **ODIN2 и ParallelComb**, в SPECTRE — **CLASSIC 0.5 и EXTENDED**. Добавлены общая обратная связь с выхода на вход, выходной CLIPPER и DC BLOCK.

## Что попробовать первым

- **COMB → Preset 1–5**: ODIN2, высокая резонансность, положительная/отрицательная обратная связь A/B, DRIVE, полностью обработанный выход.
- **COMB → Preset 6–10**: ParallelComb, короткие резонансы, явное изменение их настройки огибающей входа и LFO. Настройки ориентированы на упругие, «резиновые» движения, а не статический delay.
- **SPECTRE → CLASSIC 0.5 → Preset 1**: прежний default SPECTRE. Это отдельный процессор из 0.5, а не просто обнуление ручек EXTENDED.
- Общий **FEEDBACK** сначала оставьте на 0. **CLIPPER и DC BLOCK** у нового экземпляра включены. Увеличивайте feedback при небольшой громкости.

Названия в обоих банках — **Preset 1…Preset 10**. Подробности: `PRESETS_RU.md`. Тембровые названия описывают настройки, а не гарантируют имитацию конкретного материала на любом источнике.

## Сборка JUCE / Projucer / Visual Studio

Это архив исходников, **не готовый Windows VST3**.

1. Распакуйте весь архив в новую папку, например `C:\AudioDev\MonoJuice_08`.
2. Откройте **MonoJuice.jucer** в Projucer. Проверены JUCE/Projucer **8.0.6**.
3. Укажите путь к `JUCE\modules` в Global Paths.
4. Выберите VS2022 или VS2019, выполните Save Project and Open in IDE.
5. Соберите Release / x64. Нужны Desktop development with C++, Windows SDK; стандарт **C++17**.
6. Копируйте bundle `MonoJuice.vst3` целиком из `Builds\VisualStudio2022\x64\Release\VST3\` в каталог плагинов.

Не переносите только Processor/Editor в старый проект: нужны все новые DSP-заголовки. Собственных CPP по-прежнему четыре; остальной DSP header-only. SDK JUCE, ROM loader, VST host и MATLAB runtime не включены и не нужны для обработки.

**Linux VST3/Standalone собраны. Реальные Projucer-экспорты VS2022/2019 проверены. MSVC/Windows здесь не запускался.**

Альтернатива:

```sh
cmake -S . -B build/plugin -DJUCE_PATH=/path/to/JUCE -DNOVA_BUILD_TESTS=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build/plugin --config Release --parallel 1
```

Системному JUCE Debian нужны codec development-библиотеки и `-DNOVA_SYSTEM_CODECS=ON`. Для экономии RAM: `-DNOVA_LOW_MEMORY_BUILD=ON`, serial build. Это снижает оптимизацию большого GUI-модуля, не DSP. Официальному Windows SDK JUCE этот codec-флаг не нужен.

## Слоты и команды

- Строка идёт слева направо. Нажмите SLOT для редактирования; выбор редактируемого слота не меняет звук.
- ON/OFF независим от выбора типа. EMPTY — прямое соединение без latency.
- MOVE меняет местами **полные банки** двух слотов, включая модели, переключатели и невидимые ручки. Истории затронутых FX очищаются.
- INIT FX: в COMB загружает Preset 1 для ODIN2 или Preset 6 для ParallelComb, не меняя скрытый банк другого COMB-ядра. В SPECTRE возвращает CLASSIC/default. У остальных FX — прежний сброс выбранного типа.
- CLEAR FX очищает историю текущего эффекта, сохраняя параметры.
- RANDOM работает только с текущим FX; сохраняет TYPE, ON/OFF, порядок, другие типы/слоты и master-параметры. В COMB сохраняет выбранную модель, в SPECTRE — выбранный режим. EMPTY — без рандомизации.
- Пресеты не включают ON автоматически. Они очищают историю. CUSTOM означает отличие параметров от фабричного набора.
- Двойной щелчок по ручке — её default. Значение можно ввести с клавиатуры.

## COMB: две модели и новый слой обработки

### Общие ручки

| Ручка | Диапазон и действие |
|---|---|
| DRIVE | 0…36 dB. Усиление перед нелинейным `tanh`-возбуждением резонатора. При 0 слой возбуждения прозрачен |
| WET MIX | 0…100%. Общий dry/wet всего COMB, поверх внутреннего mix выбранной модели |
| OUTPUT | −30…+12 dB. Уровень wet COMB, не мастер-громкость плагина |
| MOTION | 0…24 st. Глубина синусоидальной модуляции настройки |
| RATE | 0.03…20 Hz. Частота этой модуляции |
| ENV TUNE | −36…+36 st. Изменение настройки огибающей входа: знак задаёт направление |
| ENV DECAY | 5…2000 ms. Отпускание огибающей; attack около 3 ms |

Огибающая общая для двух каналов, берётся из максимальной абсолютной амплитуды входа до DRIVE: `min(1, 4 × peak)`. Поэтому на тихом и громком материале движение разное. LFO/огибающая меняют частоты ODIN либо множитель времени ParallelComb. Управление обновляется каждые 16 сэмплов, независимо от host block size; исходное сглаживание ядер сохранено.

**Это новые функции MonoJuice вокруг исходных ядер**, не заявление, что такой envelope/LFO был в оригинальных VST. DRIVE находится снаружи внутреннего oversampling ParallelComb; 16× не означает oversampling всего нового слоя.

### ODIN2

Восстановлена модель из FX5 0.5:

- FREQ A/B: 40…16000 Hz; RES A/B: 0…99.5%.
- NEG A/B: знаки обратной связи каждого фильтра.
- A ONLY / A > B / A + B: один A, последовательная или параллельная обработка.
- BALANCE действует только в A + B. В A ONLY ручки B неактивны.
- ODIN MIX — внутренний mix прежней модели.

Первая страница: фильтры и DRIVE/WET MIX/OUTPUT. Вторая: MOTION/RATE/ENV TUNE/ENV DECAY. Новый default COMB совпадает с ODIN Preset 1: 337/541 Hz, RES 96/94%, A > B, отрицательный B, DRIVE 9 dB, WET MIX 100%, OUTPUT −15 dB.

Ядро сохранено из старого native-порта: линейная интерполяция, прежнее сглаживание, ограничение resonance и истории. При нейтральном новом слое оно совпало с 0.5 на всех проверенных маршрутах и полярностях.

### ParallelComb

Сохранён Uhhyou ParallelComb 0.2.14, но новый default и пресеты не оставляют доминирующий сухой сигнал:

- Страница 1: TIME 1…4, MULTIPLY, FEEDBACK, FB HPF, LIM RELEASE, SLEW RATE, TIME SMOOTH, L-R LEAN, CROSS.
- Страница 2: FB TO TIME, GATE, GATE RELEASE, DRY, WET, TUNE.
- Страница 3: все семь общих ручек нового слоя.
- MID/SIDE и исходный 16X OS сохранены. Режимы очищают память.

Новые начальные TIME: 1.3 / 2.1 / 3.3 / 5.3 ms, feedback 24%, HPF 65 Hz, DRY = mute, WET −3 dB. В пресетах 6–10 времена также короткие, dry отключён, а огибающая заметно двигает настройку. Старые сохранённые времена/уровни не заменяются при миграции.

Максимальные диапазоны старых ручек сохранены: TIME до 4 секунд, DRY до +24 dB, WET до +60 dB, feedback до 100%. Они всё ещё позволяют сделать delay или экстремальный генератор. Внутренний limiter ParallelComb стоит в feedback, не на полном выходе.

**PANIC!** текущего COMB обнуляет Parallel feedback и резонансы ODIN этого слота и очищает историю. Если звук циркулирует через общую петлю, используйте **PANIC ALL**.

## SPECTRE: CLASSIC 0.5 / EXTENDED

### CLASSIC 0.5 — по умолчанию

В `SpectreClassic.h` восстановлены process, prominence mask и overlap-add из версии 0.5. FFT/KBD-планы общие с EXTENDED и математически неизменны. CLASSIC реально использует только:

- PROMINENCE 1…100 dB;
- MIX 0…100%, dry выровнен с wet;
- WINDOW 512 / 1024 / 2048 / 4096 / 8192 / 16384 / 32768 / 65536 samples.

Все дополнительные частотные ограничения, расширение/огибающие маски, SHIFT и Freeze **не участвуют** в CLASSIC даже при ненулевых сохранённых значениях. Их ручки скрыты. При одинаковых старых параметрах и входе получено полное совпадение с отдельной контрольной копией 0.5 на восьми окнах.

### EXTENDED

Переключатель сохраняет расширенную модель 0.6/0.7: LOW/HIGH отбора пиков, MAX PEAKS, WIDTH, REJECT LEVEL, ATTACK/RELEASE, SPEC SHIFT и SPEC FREEZE.

- HIGH 0 = Nyquist, PEAKS 0 = все прошедшие пики, REJECT −120 dB = mute.
- LOW/HIGH — границы отбора, не независимые HP/LP. REJECT может вернуть остальной спектр.
- SHIFT — интерполяция реальных MDCT-коэффициентов, не формантосохраняющий pitch.
- Freeze удерживает два pre-mask кадра с фазовым продолжением. Сначала нужен входной материал; пустой захват не создаёт wet-аудио.

Сам переключатель CLASSIC/EXTENDED сохраняет значения, но очищает истории. Десять новых пресетов SPECTRE выбирают CLASSIC и нейтрализуют расширения. RANDOM в CLASSIC также возвращает расширения в нейтраль; RANDOM в EXTENDED использует их.

## Общий FEEDBACK, CLIPPER и DC BLOCK

В нижней панели OUTPUT LOOP:

```
внешний вход + return → пять FX → mono downmix (если mono)
                    → DC BLOCK → CLIPPER → выход хоста
                                       └→ задержка 1 sample → FEEDBACK → вход
```

- **FEEDBACK −99…+99%**, default 0. Отрицательные значения инвертируют полярность возврата. Петля общая для всех пяти слотов, а не дополнительный локальный feedback одного COMB.
- Возврат берётся с окончательного выхода, после mono downmix, DC и клиппера. Задержка — **один сэмпл, не один аудиоблок**; размер host buffer не меняет эту задержку. Сам рэк может иметь дополнительную задержку/хвост.
- В ветви возврата всегда есть аварийный clamp ±4 для ограничения runaway. Он **не ограничивает полный выход**, если CLIPPER выключен.
- **CLIPPER** — реальная галочка. Жёсткое ограничение выходных сэмплов до ±1, то есть 0 dBFS. Без oversampling; возможен aliasing, inter-sample peaks не ограничиваются. Может намеренно придавать жёсткость звучанию.
- **DC BLOCK** — реальная галочка: независимые DC-блокеры двух каналов, срез 10 Hz. Стоит перед клиппером, затрагивает также ветвь возврата. Последующая нелинейная обрезка асимметричного сигнала может снова создать некоторую постоянную составляющую; это не обещание идеального нуля среднего при любом clipping.
- **PANIC ALL**: общий feedback в 0, очистка всех FX, огибающих и петли. Не меняет локальные параметры, ON/OFF и галочки; живой вход не заглушает.
- **BYPASS ALL** и host bypass отключают петлю и обходят пять FX с выравниванием по PDC. Выходные DC/CLIPPER остаются активными, если их галочки включены. Для полностью необработанного выровненного dry снимите обе галочки. Это описывает вызов processBlockBypassed; если DAW сама маршрутизирует сигнал в обход плагина и не вызывает его DSP, его выходные модули не могут действовать.

На новом экземпляре CLIPPER/DC BLOCK включены. При загрузке старого состояния отсутствовавшие master-модули выключаются для сохранения старого звука.

**Важно:** даже feedback меньше 100% может самовозбуждаться, если общий gain цепи больше единицы. Клиппер ограничивает сэмплы, а не субъективную громкость или безопасность слуха. Начинайте тихо; длинную генерацию останавливайте PANIC ALL.

## PITCH / CHORUS / GRANULAR

PITCH и GRANULAR не менялись. Ядро CHORUS (`ChorusCore.h/.cpp`, `ChorusTables.h`) побайтно сохранено; менялась только обёртка (см. CHANGELOG). Режим **V1** — прежний внутренний MIX (звук до фикса, default); режим **V2** — исправленный внешний MIX со сглаживанием ~20 мс.

- PITCH: SHIFT ±24 st, FINE ±100 ct, WINDOW 20…160 ms, MIX. Две дробные головки. Это новая native-топология, не восстановленная аппаратная машина.
- CHORUS: DEL/DEP/SPD/MIX/FB/WID/LP/INP 0…127, прежний fixed-point DSP из BIN. В V2 MIX=0 — всегда чистый вход при любом INP; в V1 (default) MIX=0 даёт прежний подогретый dry `in × (INP/64)²`. MIX=127 в обоих режимах звучит бит-в-бит как раньше. Новые master-модули могут изменить итоговый выход, но не код CHORUS.
- GRANULAR: 8 секунд истории, до 48 зёрен на слот; SIZE, DENSITY, POSITION, SPRAY, PITCH, JITTER, WIDTH, MIX, FEEDBACK, METAL, TONE, REVERSE; FREEZE и METAL CLOUD. Длинный/металлический feedback сохранён. Это новая топология на исследованных примитивах, не аппаратная машина.

## LFO: модуляция всех эффектов + SYNC

В каждом слоте один биполярный LFO (−1…+1), общий для любого загруженного эффекта. Матрица: у каждого из 65 числовых параметров своя ручка глубины **D-…** в единицах самого параметра (диапазон ±span ручки, default 0). Итог = ручка + глубина × LFO, дальше действуют штатные клампы эффекта.

- RATE 0.01…20 Hz (free), SHAPE: 0 SINE, 1 TRI, 2 SQUARE, 3 SAW, 4 S&H.
- SYNC ON — темп DAW: DIV в долях 8 / 4 / 2 / 1 / 1/2 / 1/4 / 1/8 / 1/16 / 1/32. Фаза привязана к ppq-позиции транспорта и замирает на стопе; без плейхеда (standalone) — внутренний клок 120 BPM.
- Глубины нулевые по умолчанию: свежий слот звучит бит-в-бит как без LFO, накладных расходов нет. INIT сбрасывает глубины текущего эффекта, но оставляет RATE/SHAPE/SYNC/DIV; RANDOM и пресеты LFO не трогают.
- Хорус: в V1 модулируются все 8 внутренних параметров напрямую каждый сэмпл; в V2 семь параметров идут через сглаживание ~20 мс, а D-MIX двигает внешний микс каждый сэмпл. Остальные эффекты обновляются каждые 16 сэмплов, ступеньки сглаживают их собственные фильтры.
- COMB: глубины обеих моделей и colour-слоя на месте; активны для текущей модели. LFO слота не зависит от встроенного MOTION-LFO colour-слоя (их можно вкладывать: D-MOTION/D-RATE).

## State, задержки и ресурсы

**739 зарегистрированных параметров:** 134 числовых (65 базовых + 65 глубин LFO + 4 управления LFO) + 13 остальных на слот, плюс BYPASS / MASTER_FB / OUT_CLIP / OUT_DC. Старые ID сохранены, прежние ODIN ID вновь зарегистрированы. Состояние version 3, tag `NOVA_FX5_STATE`.

Миграция:

- FX5 0.5 с ODIN-настройками → ODIN2, его старые значения, нейтральный новый слой.
- 0.6/0.7 с ParallelComb → ParallelComb, старые значения, нейтральный новый слой.
- Старый SPECTRE без активных расширений → CLASSIC; с ненейтральными расширениями/Freeze → EXTENDED для сохранения сессии. Можно вручную переключить CLASSIC.
- Старые CHORUS-only и FX3 state поддержаны.
- Сессии без C_MODE открывают хорусы в V1 (звук до фикса); глубины LFO отсутствуют → 0 (модуляции нет).
- Master feedback 0, выходные модули OFF при отсутствии этих полей в старом состоянии.

Истории, Freeze-захваты, хвосты, фазы модуляции и возвращаемый аудиосэмпл не сериализуются. Сохраняются настройки, а не звучащая память. Загруженный Freeze при необходимости нужно выключить и захватить заново.

ID `MnOn/NvF5` сохранён: это обновление MonoJuice/FX5, не отдельный плагин для параллельной установки. Сделайте backup, уберите старый bundle из scan path, затем пересканируйте DAW. Windows/конкретная DAW не проверялись.

PDC — сумма выбранных CHORUS и SPECTRE, даже если они OFF. CHORUS: 16/87/139 samples при 44.1/48/96 kHz; SPECTRE — выбранный WINDOW. COMB сообщает 0 transport latency, как раньше; реальные задержки его внутренних фильтров остаются частью эффекта. MOVE/TYPE/WINDOW/смены моделей очищают память и не являются бесшовными. Предпочтителен остановленный транспорт.

Все буферы предвыделяются, включая неактивные модели. Только ParallelComb-буферы пяти слотов — около 117 MiB при 48 kHz; классический и расширенный SPECTRE требуют дополнительную память. 16×, большие окна и пять повторов повышают CPU/RAM; гарантии отсутствия xrun нет.
