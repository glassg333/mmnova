# MonoJuice 0.8.0 — выполненные проверки

17 сентября 2026, Linux x86-64, GCC, CMake/Ninja, JUCE/Projucer 8.0.6. Журналы — TestsResults. Windows/MSVC не запускался.

## Восстановленные модели

- **CLASSIC SPECTRE против native 0.5:** все восемь окон 512…65536, 392 480 stereo frames / 784 960 выходных значений, точное совпадение. В CLASSIC намеренно установлены ненейтральные расширенные параметры и Freeze: они не влияют на его выход. Контрольная копия содержит полный старый процессор и собственные FFT/KBD-планы.
- **ODIN против native 0.5:** 44.1/48/96 kHz × три маршрута × четыре комбинации NEG A/B = 36 профилей по 5000 stereo frames. При нейтральном новом слое все значения совпали.
- **ParallelComb через новый нейтральный слой:** совпал с прежним ParallelCombModel без различий при 1× и 16× на 48 kHz, по 12 000 stereo frames.
- Прежний RackTests повторяет 12 сравнений самого ParallelCombModel с неизменённым upstream DSPCore; max error 0 / relative RMS 0. Этот тест относится к ядру, не к новому drive/envelope слою.

Это сравнения исходного native DSP, **не запуск исходных VST-бинарников**, не MATLAB и не аппаратный Monomachine A/B.

## Новые пресеты и рандомизация

Native FactoryTests:

- 20 новых пресетов × 44.1/48/96 kHz = 60 секундных профилей.
- Выход конечный, ненулевой, различные аудио-fingerprints; peak <4 при тестовом сигнале. Это не гарантия максимального уровня на любом входе.
- RANDOM всех пяти типов, с обеими моделями COMB/SPECTRE: 7 вариантов × 4 seeds × 3 sample rates = 84 профиля. В тесте нет NaN/Inf и тишины; peak левого канала <8, оба канала проверены на конечность.
- Повторный seed воспроизводит параметры.
- COMB Preset 6–10 сравниваются с собой при отключённых MOTION/ENV TUNE. Энергии разности: 1666.61 / 1556.87 / 196.658 / 966.758 / 1445.72. Новое управление настройкой реально меняет аудио.

Энергия разности — не dB и не доказательство субъективного «материала». Слуховая оценка на пользовательском источнике не проводилась. Подготовлен RMS-matched A/B 0.7/0.8, чтобы не подменять оценку тембра просто увеличением громкости.

## Общая петля и выход

Native проверки:

- При EMPTY и feedback ±50% импульс следует аналитическому ряду `x[0] × (±0.5)^n` — задержка возврата один sample.
- Независимые stereo-каналы; mono-возврат берётся после downmix.
- С включённым клиппером вход 2 ограничивается до 1, следующий sample при 50% feedback — 0.5. Значит, возвращается post-clip выход, не необрезанный внутренний сигнал.
- Hard clip точно ограничивает до ±1; при OFF вход 3 действительно проходит как 3, без скрытого полного выходного лимитера.
- DC BLOCK удаляет постоянные +0.25/−0.4; после секунды при 48 kHz остаток <1e−8. При OFF сигнал проходит точно.
- Пять резонансных ODIN, master feedback 90%, DC+clip: конечный выход в ±1 на тестовом сигнале.
- BYPASS разрывает общую петлю, reset очищает возврат.
- При повторных Rack::set каждые 127 сэмплов результат совпадает с непрерывным рендером: общая петля и COMB-модуляция не зависят от границ блока.

Клиппер — sample-peak, не true-peak; без oversampling. DC до клиппера не гарантирует нулевого среднего после любой асимметричной обрезки. Аварийный предел ±4 действует только на feedback return. Без выходного клиппера полный выход не ограничен 0 dBFS.

## Настоящий JUCE AudioProcessor / editor

- **389 зарегистрированных параметров**, полный round-trip, выбранный слот.
- MOVE всех 65 numeric и 12 прочих параметров каждого слота, без изменения master.
- Миграция ODIN 0.5, ParallelComb 0.6/0.7, старого CLASSIC/активного EXTENDED, CHORUS-only, FX3; старые отсутствующие master-модули не включаются автоматически.
- Нейтральный новый COMB-слой при миграции; malformed state игнорируется.
- 100 factory loads: 20 пресетов × 5 слотов, проверка всего банка/изоляции, state и номера пресета.
- 35 RANDOM slot/model-вариантов, изоляция, реальное изменение, повторяемый seed.
- INIT COMB сохраняет скрытый банк другого ядра; локальный PANIC изолирован; PANIC ALL меняет master feedback и очередь очистки, но не чужие параметры.
- **60 секундных аудиопрофилей через настоящий processBlock**: 20 пресетов × три частоты, master feedback 35%, DC/clip ON, размеры блоков 1/7/63/127/512/1024. Выход ненулевой и в ±1.
- Mono layout и обработка.
- **326 проверенных slider attachments:** 325 числовых slot-параметров + master FEEDBACK, включая обе модели и все страницы.
- 100 загрузок через GUI preset menu, реальная кнопка RANDOM, привязки обеих выходных галочек.
- EMPTY отключает RANDOM.
- Настоящие PNG 960×860, тёмный фон; визуально просмотрены COMB, CLASSIC и PARALLEL MOTION. Новый нижний блок не перекрывает FX-ручки.
- Message-thread PDC: CHORUS + SPECTRE 4096 при 96 kHz = 4235 samples даже без нового processBlock.

## Сборки и регрессии

Linux VST3 и Standalone собраны и слинкованы. CTest plugin: 5/5 PASS — OriginalChorusGolden, FXChain, FX5Rack, MonoJuiceFactory, JUCEWrapper. Native CTest: 4/4 PASS.

ASan + UBSan + leak detection: полный новый native FactoryTests прошёл, `ASAN_OPTIONS=detect_leaks=1:quarantine_size_mb=64`. Это не sanitizer всего JUCE/GUI. В тест входят обе модели, Classic oracle, пресеты, random audio и новая master-петля.

Старые CHORUS/FX3/Rack регрессии повторены: golden, неизменённый адаптер, пять повторов каждого типа, 32 ON/OFF-маски при трёх частотах, 120 перестановок пяти разных FX. Native new/new[] watchdog в проверенном Rack::set/process цикле — 0. Он не покрывает UI-команды, APVTS, системный malloc или каждый возможный путь хоста.

Реальный Projucer --resave: VS2022, VS2019, Linux Makefile. Проверены существующие Source paths и C++17. **Экспорт Visual Studio не является компиляцией MSVC.** Только test-only upstream oracle требует C++20.

Распакованный исходный ZIP отдельно собран и проверен native CTest. Manifest содержит SHA-256 каждого файла; исходники финального ZIP совпадают с проверенной распаковкой.
