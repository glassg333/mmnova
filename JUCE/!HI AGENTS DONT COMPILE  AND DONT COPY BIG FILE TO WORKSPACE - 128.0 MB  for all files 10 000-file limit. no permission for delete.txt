## СБОРКА (всё проверено 2026-09-25 с чистого /tmp)
- Стенды: `bash /home/user/batches/hdtest/build_bench.sh <дерево> [bench|asan]`
  (дерево = .../Monomachine_Nova_Synth или _FX). bench ~3 мин чистый, asan ~46 c после чистки /tmp.
  RAM 1984MB swap 0: перед ASAN чистить /tmp; -g только точечно, потом -g0.
- pphash (бит-эталон плагина): пересобрать obj/b_PP.o и obj/b_pphash.o, слинковать pphash
  (рецепт линка = бенч с b_pphash.o вместо b_main.o; см. архив), прогнать:
  **БАЗЛАЙН: PPHASH ec101520ac42bb83** (детерминирован). ЛЮБОЕ изменение плагина обязано
  держать этот хеш, пока фича не должна менять звук (пустые FX-слоты).
- Хорус-стенд: `g++ -O2 -std=c++17 -DNDEBUG -I Source/dsp main_chorus.cpp ChorusCore.cpp ChorusNative.cpp`
  → BIT-EXACT PASS + silence PASS обязаны.
- После смены PluginProcessor.h ИЛИ dsp-хедеров: rm obj/* ЦЕЛИКОМ.
- Пайпы едят статусы (grep -c 0 → exit 1). Проверки не писать через |.
