СБОРКА VST3 ОДНИМ КЛИКОМ
========================

Файлы:
  build_vst3.bat   — запуск (перетащи папку проекта на него или просто открой)
  build_vst3.ps1   — сам скрипт
  build_config.json — появится после первого запуска, хранит все настройки и пути

Окно настроек (открывается при запуске):
  - перетащи папки проектов (прошлые уже в списке, можно выбрать галочками);
  - «Собирать»: VST3 / Standalone (.exe) / LV2 / VST2 — что включено в .jucer (Plugin Formats).
    AU и другие форматы для macOS на Windows собрать нельзя (нужен Mac с Xcode).
  - «Куда копировать» — папка для VST3 (например C:\Program Files\Common Files\VST3\!build);
  - «Standalone/LV2 в» — папка для остального (пусто = подпапка !build рядом с VST3);
  - галочка «одним файлом» — плоский Имя.vst3 без папки-бандла;
  - галочка «удалить Builds навсегда после сборки» (мимо корзины, ~600 МБ);
  - галочка «пропускать ManifestHelper» — не собирать/не запускать juce_vst3_helper (быстрее, Ableton не нужен);
  - галочка «при ошибке открыть файл с ошибками» — logs\errors_*.txt откроется в Блокноте,
    ошибки уже в буфере обмена; в итоговом окне есть кнопки «Скопировать ошибки» / «Открыть отчёт».
  Кнопка «Только снести Builds» — удалить папки сборки без компиляции.

Что делает по шагам:
  Builds удалить навсегда -> Projucer --resave -> MSBuild .sln /t:выбранные форматы Release|x64
  -> проверить, кто держит старый файл (Ableton и т.п.) -> заменить -> снова удалить Builds.

Из консоли (без окна):
  powershell -NoProfile -STA -ExecutionPolicy Bypass -File build_vst3.ps1 -NoPicker -Path "E:\mm\Monomachine-Nova-1.6.3" -Formats VST3,Standalone -Flat -NoManifest
