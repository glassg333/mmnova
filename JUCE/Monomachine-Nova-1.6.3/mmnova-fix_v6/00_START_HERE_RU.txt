==============================================================================
 Monomachine Nova 1.6.3 -- правка v6 (BBOX по-старому, чистка режимов)
==============================================================================

ЧТО ЭТО
-------
Один скрипт, который приводит дерево Monomachine-Nova-1.6.3 (Synth + FX)
к состоянию v6. Дерево 1.6.3 уже содержит правку v5 (реальный фильтр основным
режимом) -- v6 ставится поверх неё.

ЧТО МЕНЯЕТ (коротко)
--------------------
1. BBOX -- рабочий кит снова СТАРЫЙ: крепкий кик, клэп, колокол (Cow Bell),
   лазер/zap (Blipp) и остальные старые голоса. Из нового кита взяты только те,
   что понравились: Snare Drum 1 (слот 2), Tom 1 (слот 3), Tom 2 (слот 4).
2. RTIM -- вернулась СТАРАЯ формула 5...255 мс, но инвертированная:
   rtim 127 = самый частый повтор. Интервал повтора больше НИКОГДА не 0,
   поэтому на 100...127 звук не пропадает и эффект не "выключается".
3. Клик на перезапуске сэмпла убран сглаживанием ПО СЭМПЛАМ (16 сэмплов,
   спад доходит ровно до нуля к перезапуску) -- миллисекундных фейдов нет.
4. STRT (start position) стал мягче: 1/8 активной длины вместо 1/4,
   короткие удары больше не срезаются так сильно.
5. Хорус и все FX -- как в 1.6.0: линейный INP (p[7]/64), без домешиваний
   x1.5 (хорус) и x3.0 (ревер), без комментариев "FIXED".
6. Меню режимов почищено: осталось ДВА режима -- mnm (основной) и old (резерв).
   Альтернативные движки dist2 / fm2 / bbox2 удалены вместе с кодом
   (файлы MnmDist2.hpp / MnmFm2.hpp / MnmBbox2.hpp -> *.bak-v6).
   Новые режимы теперь есть только у фильтра: FILT mnm = реальный фильтр из дампа.
7. Попутно закрыт найденный баг: ревер (FX-машина 13) переполнял стек на блоке
   больше 32 сэмплов и ронял плагин -- теперь буферы под размер блока хоста.

КАК ПРИМЕНИТЬ (Windows)
-----------------------
1. Распакуй архив, открой PowerShell/cmd в папке с fix_filter_v6.py.
2. Сначала посмотри, что будет сделано (файлы не меняются):

     python fix_filter_v6.py "E:\mm\Monomachine-Nova-1.6.3" --check

3. Затем применить:

     python fix_filter_v6.py "E:\mm\Monomachine-Nova-1.6.3"

   Оригиналы сохраняются рядом как *.bak-v6. Повторный запуск безвреден.
4. Проверить результат (ничего не меняет):

     python verify_fix_v6.py "E:\mm\Monomachine-Nova-1.6.3"

   Ожидаемый итог: "ИТОГ: ВСЁ НА МЕСТЕ".
5. Дополнительно можно прогнать статический верификатор режимов:

     python verify_dsp_mode_patch.py "E:\mm\Monomachine-Nova-1.6.3\Monomachine_Nova_Synth\Source"
     python verify_dsp_mode_patch.py "E:\mm\Monomachine-Nova-1.6.3\Monomachine_Nova_FX\Source"

   Ожидаемый итог: "PASS static patch verification".
6. Visual Studio -> Build -> Rebuild Solution (Release x64).

ЧТО ПОСЛУШАТЬ
-------------
* BBOX, ручка RTIM: провести от 0 до 127 на синусе и на кике -- повторы должны
  учащаться, доходить до частого "пулемёта" и НЕ пропадать/не щёлкать.
* BBOX, RTRG: 1 -- один повтор примерно на -15 дБ (аккуратный кик с ударом мимо),
  127 -- длинная затухающая серия.
* Кит: слот 1 -- старый кик, слот 2 -- снейр из нового, слоты 3-4 -- новые томы,
  слот 8 -- колокол, слот 24 -- лазер/Blipp (как в старом ките).
* Хорус (FX-CHO): MIX=0 -> сухой, MIX=127 -> полный wet, громкость не скачет.
* Меню DSP mode в каждом разделе: только "mnm" (основной) и "old" (резерв).

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
* "ЭТО ДЕРЕВО ЕЩЁ НЕ ПРОШЛО ПРАВКУ v5" -- ты указал дерево без правки v5
  (например 1.6.2). Сначала fix_filter_v5.py, потом fix_filter_v6.py.
* Если скрипт пишет "ПРОБЛЕМЫ" -- пришли вывод целиком, разберём.
* Откат: файлы *.bak-v6 рядом с изменёнными -- просто переименуй обратно.
