# Исторические FM MODE тесты до cleanup 30.09.2026

Это точные копии прежних test sources, где MODE SYNT ещё содержал experimental
slots с raw IDs 6..8. Они сохранены без правки как архив validation-материала.

Обе ветки Synth/FX имели byte-identical варианты этих шести файлов; поэтому
сохранена одна копия каждого имени. Актуальные test sources в `tests/` изменены
для шести selectable FRQ/BPM modes и schema 36. Эти исторические копии не
являются текущим контрактом UI/state migration.
