# Omega 8 / CODE — сводка декода (сессия r1..r13)

Источники: `manual/omegaCODE_clean.txt` (OCR-мануал), фабричные патчи `patches/`
(512 шт.), `firmware/` (дампы ОС), скриншоты редактора `ui_official/` +
`ui_decode_screens/`, карта `omega8_map.json` (conf: 3 = сверено с
редактором/скринами, 2 = вероятно, 1/0 = гипотеза).

## 1. Формат патча / файла
- Патч = **176 байт**: 0..159 параметры, **160..175 имя** (ASCII, ровно 16,
  хвост — пробелы; байт >=128 в имени не встречался, но name() в плагине
  режет всё не-ASCII на всякий случай — это источник «японских иероглифов» в
  старых сборках, если байты >127 трактовались как UTF-8).
- `.syx`: `F0` + **8-байтная заголовочная строка** (напр. `00 00 4d 08 ...`)
  + N×176 (+`F7`). `.mid` (SMF): sysex в треке, после F0 — VLQ-длина.
- **MULTI-дамп** (`Omega8FactoryMulti.syx`, 10250 байт): одно сообщение,
  тот же заголовок, дальше **4-байтные повторяющиеся записи** (`xx 7f 00 01`)
  — НЕ 176-байтные патчи. MULTI/Prepared не распарсен (кандидат r14+).
- Аналогичный заголовок и у банков A/B (ROM) — см. `analysis/bank_loader.py`.

## 2. Ключевые конвенции (сверено!)
- **OSC1_FREQ(30) / OSC2_FREQ(31)**: шкала **0..63 полтонов ОТ ноты**
  (map conf3: «panel scale 0..63; =24 editor»). Фабричные байты кратны 12
  (0/12/24/36 = октавы). **Центра 64 НЕТ** — сдвиг `-32`, бывший в r1..r10,
  был багом (всё звучало на 2.6 октавы ниже → «атонально/как эффекты»).
- **OCTAVE(2)**: нибблы: hi = октава (4 = MID, raw-шаг 1 = ниббл = 16),
  lo = fine (0..15, знак «>8 → -16», ×0.1 полутонов) — conf2.
- **OSC2_FINE(78)**: c64: 64 = центр, 40 = «fat detune» (у нас −0.75 полут.),
  65 = +1. conf2.
- **GLIDE_TIME(0)** i7 conf3 (editor: time=42 у REVELATION);
  **GLIDE_FLAGS(1)** conf2: **bit6 (0x40) = ON**, bit2 (0x04) = legato/reg.
  Фабрика: {64:246, 68:152} vs {0:71, 4:22} — 81% «включённых». **Открытый
  вопрос: не исключена инверсия** (81% патчов со скольжением = подозрительно;
  GLIDE-тумблер на панели для быстрой проверки).
- **FILT_TYPE(43)**: 0 SEM-LP, 1 BP, 2 HP, 3 BR, 4 MINI(Moog24), 5 AUX1,
  6 AUX2 (=CS80 всегда, мануал p.21). «303/2600/Juno» — карты в AUX-слоты
  (физика), байтом не кодируются.
- **WAVE_BITS(74)**: бит0=tri, бит1=saw, бит2=pulse (0 показывает saw);
  **WAVE2(75)**: 0=pulse,1=tri,2=saw; **SUB_WAVE(4)**: {0=OFF,1..6}
  (1/4=pulse50, 2=sine, 3=tri, 5=saw, default=saw).
- **MASTER_TUNE(77)**: c64 (64 почти всегда, 508/512).
- **XMOD_DPTH(41)**: 0 в 393/512; NOISE(39): 0 в 376/512.
- **PAN (Multi, мануал p.15)**: «The Multi preset stores its own Pan Position,
  Pan Rate and Pan Depth **for each voice**» → **per-voice летающая панорама =
  оригинал** (не баг). Массивы: RATE 136..143, POS 144..151 (64=центр),
  DEPTH 152..159 — 8 штук (по числу голосов). Панельные галочки P1..P4 =
  первые 4. PAN_WAVE(120) {0:tri...} conf1, PAN_SYNC(116)=0 SELF,
  PAN_KEY(119)=0 OFF (editor).
- **CONT_DEST (25)** = OFF, FRE1, FRE2, 1&2F, LEV1, LEV2, PW1, PW2, 1&2P,
  FILT, RESO, LEVN, XMOD, EA1, EA3, EXT, LF1R, LF2R, LF1D, LF2D, 1&2D, 1&2R,
  PAND, PANR, PAN — дословно = мануал p.17-18. LFO-список мануала (14, с VOL)
  — VOL-байта нет, не добавлен.
- **Арп**: мануал p.236 «Arpeggiator (Omega)», CC116=TEMPO, CC117=START/STOP.
- **«8 ламп программ»**: скрин black_omega8 — ряд из 8 LED под LCD кода;
  энкодер (Q-dial) = выбор патча; ▲▼ = банк на главной странице (мануал
  «Change Patch Banks: press UP/DOWN»); ◀▶ = курсор/шаг. Секвенса программ
  в мануале НЕТ; Prepared Multi (свой патч на голос) — п.1 MULTI.
- **AGC**: мануал p.21: у Mini-фильтра при высоком резонансе включается AGC
  (компенсация уровня) — в плагине: `1/(1+agcQ·res²)`.
- **Голосовые состояния**: гипотеза юзера подтверждена реализацией в r11:
  патч захватывается на ноту, BLEND/смена пресета активные ноты не трогают.

## 3. Открытые вопросы (см. PROMPTS.md)
1. Полярность GLIDE bit6 (conf2).
2. Категория-бейдж банка (MINI/OBLP/OBBR/OBHP на bank_mode.jpg) — байт не найден.
3. CONT1/CONT2 источник (MODW/TRAK на скрине cell_123123) — байты 81..85 conf0.
4. Байт-заголовок 8 байт: расшифровать поля (команда/банк/кол-во?).
5. MULTI/Prepared: 4-байтные записи, разложить на 8 голосов.
6. UNK6/UNK17/UNK18/PRIOR/VMODE/MTRG — enum-смыслы (частично: VMODE=CYCL,
   MTRG=OFF по редактору).
7. Таблица «FILTER TYPE NUMBERS FOR THE F TABLES» (мануал p.583) против
   value-кодов в патче (0-based vs 1-based) — совпало сдвигом на 1.

## 4. Статистика, на которой поймали баги
- FRE1: {24:256, 0:104, 12:70, 36:30,...} — кратность 12 подтверждает шкалу.
- OCTAVE lo-нибблы: {0:254, 1:118, 13:60, 15:24,...} — fine не ноль вполовину.
- GLIDE кросс-таблица: ON+t>=20: 222, ON+t==0: 82, OFF: 96.
- Имён с байтами >=128: 0 в фабрике (проверь RAM-банки C/D своих дампов).

## 5. Что в плагине соответствует декоду (r12/r11)
176-байтовый лоадер → карта смещений → движок (12-ТЕТ, FREQ без -32,
per-voice latch, AGC) → UI (TYPE=43, волны=74/75, PAN-массивы, дест-комбо).
