# r18.1 — звук r10 (питч), морф @50% без клика, AUX2 без взрыва, матрица по оригу

Ревизия `r18.1-20260930`. Проверка: `findstr /c:"r18.1-20260930" Source\PluginProcessor.h`
→ в логе `omega8 build rev r18.1-20260930`. Папка: `omega8v18`.

Задача пользователя: «посмотри, что можно вернуть из 10, и пересмотри UI»
(r10 = эталон: громче, менее фильтрован, чистый тон, стабильный питч).

## 1. ПИТЧ — возврат ровно к r10 (`FREQ − 32`)

В r15/r16 сдвиг `−32` сняли по фабричной статистике (FRE1=24 у 256/512 патчей).
Живой тест показал обратное: без `−32` **весь** звук на 32 полутона выше —
«звучит очень тонко», «октавы сбиты», «слишком фильтрован» (высокий регистр
+ тот же фильтр = темнее и тоньше).

Теперь: `semi = FREQ − 32` (оба осциллятора; FINE-2 как в r10/r18).
**Измерено** (t18f2, DFT 16384, параб. интерполяция, 44.1 кГц):

| FREQ | OCT | нота | ожидается | измерено |
|------|-----|------|-----------|----------|
| 32 | MID | A4 | 440.000 | 440.085 |
| 44 | MID | A4 | 880.000 | 880.168 |
| 20 | MID | A4 | 220.000 | 220.582 |
| 33 | MID | A4 | 466.164 | 465.696 |
| 32 | hi5 | A4 | 880.000 | 880.168 |

Ошибка = разрешение/парабола бинов, не сдвиг. LFO→питч (±24 st × amt), glide,
bend — без изменений (как в r10).

## 2. МОРФ @50% — «кликает / переключается очень резко»

Переход через 50% = enum-прыжок байтов (FILT_TYPE, dest) + смена фильтра.
Xfade на таком прыжке был 30 мс — холодный фильтр даёт транзиент дольше.
**r18.1: xfade 30 → 120 мс.** Нота не ретриггерится (xfade затухает/взводит
восьмиголосые состояния, не амплитуду ноты).

t18g: одиночный прыжок A→B через 50% (+12 st, SEM→MINI):
`max/base = 1.00` (в r18 до фикса кривой было 1.86, jerk 4.13).
В реальном банке «пики» морфа = реальные различия уровней патчей A/B
(морф ведёт к более громкому патчу) — это не клик, у r10 там был резкий
скачок.

## 3. AUX2 (CS80) — «взрывается, как другие режимы раньше»

**Причина не резонанс** (AGC не помогала бы) — **численный расход SVF**:
tan-форма этого SVF расходится при `f/sr ≥ 0.30` (сетка dbg8: 0.25·sr —
стабильно при любом Q; 0.30·sr и выше — inf, даже при Q=0.5). HP-стадия
каскада: `hpFreq = 20·600^(HPF/127)` = до 12 кГц = 0.27·sr → HPF вправо
с ~6 кГц и выше = inf → полный клип (это и был «взрыв»).

Фиксы:
1. `Svf::set`: кламп частоты `0.45·sr → 0.24·sr` (Svf в движке использует
   только AUX2 — другие фильтры не затронуты);
2. AGC каскада: `fOut *= 1/(1 + 2.5·res²)` (резонансный пик HP→LP не
   вылезает на клип);
3. Q HP-стадии: `0.5+8·HPR → 0.5+4·HPR` (мягче, как у r10 one-pole).

Измерено (res=127, HPF=127, CUTOFF=60): `peak 1.000 → 0.018`, inf/nan нет,
`DC = −1.9e-6`.

**не было** — конструктор вызывал её один раз с `false`. Окно растёт,

```cpp
else if (b == &matrixBtn)

    if (matrix != nullptr) matrix->setVisible (matrixOpen);   // r18.1

```

### 4b. Раскладка = оригинал (2 колонки, как на скрине)

Старая r18-раскладка (3 самодельные колонки) заменена на оригинальную:

```
┌ ЛЕВО: PARAMETERS ────────────────────────────────┬ ЦЕНТР ──────────────────┬ ПРАВО ──────────┐
│ uni  octav | lvl  osc1 | WAVE1(иконки) | pwm     │ ENVELOPES               │ GLIDE / PAN     │
│ voice tune | lvl2 osc2 | WAVE2         | pwm2    │ dyn/dly/Atk/Dec/        │ glide  (бит6)   │
│ prior sync | noise 36  | SUB           | fine    │ Dk2/Sus/Rel x env1-3    │ mode   (бит2)   │
│ vmod sub   | envlamt invt| in win      │ track   │ PER-VOICE PAN x8        │ time          │
│ mtrg filter| cutoff hpf │ reso hpr     │ mode    │ pos(c64)/rate/dpth      │ pan wave/sync/key│
│ xmod|dpth (dest + dpth 3-знач)                      │                      │               │
│ LFO1/LFO2/ENV3: dest1..3 + amt + rate + wave        │                      │               │
│ MOD MATRIX: modwhl/dyn/bender/press/c1/c2           │                      │               │
│            x dest1 + amt + dest2 + amt              │                      │               │
└────────────────────────────────────────────────────┴───────────────────────┴───────────────────┘
```

Новые механики ячеек:
- **bit-ячейки**: `glide` (бит 0x40 байта 1) и `mode` (бит 0x04) —
  дропдап OFF/ON / REG/LEGAT переключает **бит**, остальное в байте не
  трогаем (в r18 «glide» писал весь байт и убивал mode);
- **enumVals**: `voice` = {0,1,16} (нелинейные значения, по карте);
- **octav**: дропдап по hi-нибблу (L-3..H++), lo-fine (0.1 окт)
  сохраняется;
- **xmod dest** = {OSC1, PW, VCF} (по карте dest42; в r18 было «FREQ/CUTOFF»);
- **pwm/win** = `raw·100/128 %` (67 → 52% — как в редакторе, в r18 было raw %);
- **tune** = `100 + (v−64) %` (64 → 100%);
- иконки волн: WAVE1 = битмаска (клик = toggle бита, как в r18),
  WAVE2 = 0/pulse·1/tri·2/saw, SUB = pulse/sine/tri (5 = saw — все приглушены);
- pan-блоки: `PAN_WAVE/PAN_SYNC/PAN_KEY` + per-voice pos/rate/dpth (x8) —
  перенесены в правый блок; dyn/dly в ENVELOPES (как на скрине).

## 6. Что НЕ менялось (сознательно)

- Фильтры: SEM = Oberheim12 (r17, бит-в-бит OberhVar.h), MINI = Moog24
  (MoogPop), AUX1 = OB-Xa/OB-X/TB303, AUX2 = SVF-каскад (исправление выше).
  MINI в r10 был другой ZDF-лестницей — если после возврата питча MINI
  всё ещё «не тот» — следующим шагом ставим лестницу r10 (источник в
  `…/juce try/omega8v10 …/Source/OmegaEngine.h`).
- Уровни: volGain 1.4·v², ×0.45, softClip 0.85 — как в r10/r18. E2E OBMoog:
  peak 0.105..0.234 (уровень r10-диапазона), DC ≤ 4.4e-4.
- LFO2→FRE1 amt=1 в тест-патче даёт ±0.19 st медленного дрейфа (≈0.06 Гц) —
  это в патче (LFO rate 23), было и в r10; не баг движка.

## 7. Открытый вопрос (r19)

В r10 остался «детун на 2-3 ноты» (константный сдвиг, не дрейф).
Нужно одно слово: в r10 нота была **ниже** (плоская) или **выше** (острая)
от ожидаемой — тогда центр FREQ сдвигаем на ±2-3 raw-единицы.
