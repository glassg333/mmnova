# Omega8 v27.1 — JUCE VST3

Проект эмуляции Studio Electronics Omega 8 / Omega CODE. Плагин читает оригинальные
176-байтовые патчи и банки SysEx (`.syx`, а также SysEx-потоки из `.mid`), синтезирует
8 голосов и предоставляет A/B-морфинг, арпеджиатор, матрицу модуляций и MULTI/SEQ.

**Версия исходников:** `omega8v27`, build revision `r27.1-20261004`.
Технические заметки и полный список исправлений — в [`VERSION.txt`](VERSION.txt).

## v27: что исправлено

- Возвращено поведение морфа v20: отключены в коде блочное сглаживание `morphSm` и
  гистерезис `morphSide` из v26. Непрерывные байты патча лерпятся напрямую, enum/flags
  переключаются на границе 50%. Частота осцилляторов сглаживается на сэмпл, а состояния
  фильтров сбрасываются только при смене `FILT_TYPE`, не при каждом блоке/enum-переходе.
- `MW=BLEND` — отдельный глобальный APVTS/host-параметр `mwBlendOn`, а не значение A/B и
  не бит байта 36; смена пресета и морф не переключают этот флаг. Колесо добавляется к
  положению морфа только при включённой галке. Отдельные `MODW_D1/D2` — patch-маршруты,
  они продолжают морфироваться как enum; если маршрут выключен в обоих концах, он остаётся
  выключенным. В заводской паре A001/B045 источники MODW, напротив, ненулевые.
- Исправлена причина провала уровня на морфе A001 `REVELATION 1-8` → B045 `PIGALLE PARTY`:
  `ENV1/2/3_DK2` со значениями 0 и 127 — оба sentinel «вторая фаза выключена», не числа
  для линейного интерполирования. Если любой конец выключен, DK2 теперь переключается
  дискретно на границе 50%; активное время интерполируется лишь между двумя активными
  значениями. Неизвестный байт 36 также не синтезирует промежуточные флаговые значения.
- Исправлены `MASTER_TUNE` / Accu-Tune, центр частоты OSC1/OSC2, `OSC2_FINE` и декодирование
  `OCTAVE`. Низший ниббл OCTAVE сохраняется в данных, но не добавляется к pitch: прежняя
  приблизительная интерпретация как шага 0.1 приводила к расстройке заводских патчей.
- Восстановлены смещения `ENV1/2/3_SUS` и `ENV1/2/3_DK2`; реализована стадия Decay 2.
  Передние ручки `S` управляют Sustain, а `DKY2` — второй стадией decay.
- Подключены ранее неработающие параметры: `DYN1/3`, `INVT`, `OSC2_MODE`, `OSC2_ENV1`,
  `OSC2_SYNC`, `PAN_WAVE/KEY/SYNC`, `LFO1/2_SYNC`, `CONT1/2_SRC`, `UNISON`, `VOICE_QTY`,
  `VMODE`, `MTRG`, Legato Glide и `XMOD_DEST=O+V`. Аудит также убрал ошибочное сложение
  CC16/CC17 с любым выбранным CONT-источником: TRAK/DYNA/MODW/PEDL/PRES теперь эксклюзивны.
- Арпеджиатор снова работает как host-параметры при любом положении морфа; MIDI CC 116–118
  обрабатываются отдельно от байтов SysEx. Секвенсор использует темп хоста.
- Слоты `AUX1` и `AUX2` имеют селекторы карт. `AUX2` по умолчанию — CS-80, но карту можно
  выбрать, включая `TS-808` и `WAH`.
- У `TS-808` нет отдельной физической ручки DRIVE: это та же ручка **RESO**, которая при
  активной карте автоматически подписывается **DRIVE**; **CUTOFF** подписывается **TONE**.
  Для `WAH` подписи становятся **WAH FREQ** и **WAH Q**. Иными словами, ищите DRIVE на
  месте RESO в секции FILTER, когда выбрана карта AUX1/AUX2 TS-808.
- Страница 2 показывает все 128 пресетов четырьмя диапазонами по 32 и позволяет грузить
  выбранный патч в слот A или B. Страница 3 даёт меню выбора патча для MULTI и SEQ.
  Передние лампы в Single/Morph выбирают одну из восьми программ текущего блока и не
  включают MULTI сами по себе. `RESET ALL` выключает MULTI/SEQ.
- Удалены дублирующие JUCE ComboBox A/B: выбор слота теперь открывается кликом по строке
  номера/имени пресета (стрелки «влево/вправо» сохранены). Кнопка `GLOBAL` стоит после
  контролов ARP, ниже них.

## Управление

### A/B и морфинг

- `Preset A` и `Preset B` — номера патчей `0..127` (на панели отображаются как `001..128`).
  Клик по строке номера/имени открывает меню выбора; стрелки на панели выбирают соседний патч.
- `Patch Morph A->B` — автоматизируемый морф `0..100%`: непрерывные параметры плавно
  интерполируются; типы/режимы переключаются на 50%.
- Ручки редактируют доминирующий слот: A ниже 50%, B на 50% и выше (совпадает с границей enum-морфа).
- Галка `MW=BLEND` — одна глобальная настройка, по умолчанию выключена; она не хранится
  отдельно в A/B и не меняется от смены патча/морфа. При включении ModWheel складывается
  с морфом, но сам host-параметр морфа не перезаписывается.

### Фильтры и карты расширения

Тип фильтра выбирается из `SEM LP/BP/HP/BR`, `MINI`, `AUX1`, `AUX2`. Селекторы карт AUX1 и
AUX2 находятся в секции фильтра; AUX2 стартует с CS-80. Варианты карт: `OB-Xa 24`,
`OB-X 12`, `TB-303`, `ARP2600`, `CS-80`, `WAH`, `TS-808`.

- `TS-808`: `CUTOFF` → Tone low-pass, `RESO` → Drive/перегруз.
- `WAH`: `CUTOFF` → частота/центр, `RESO` → Q; LFO1 даёт автоматический sweep.
- `CS-80`: каскад HPF → LPF; ручки HPF/HPR управляют high-pass секцией.

### Матрица и MULTI/SEQ

- Страница 1 (`PARAMETERS`): редактирование голосовых параметров, огибающих, LFO, pan и
  XMOD. Параметры страницы связаны с DSP, включая Sync и источники CONT1/CONT2.
- Страница 2 (`BANK`): диапазоны `001–032`, `033–064`, `065–096`, `097–128`; выбор целевого
  слота `A` или `B`.
- Страница 3 (`MULTI/SEQ`): до 8 частей с патчем/уровнем/панорамой/включением/шагом.
  Клик по имени патча открывает список всего банка. SEQ следует BPM хоста.
- 8 индикаторов: в Single/Morph — быстрый выбор программы внутри текущей группы из восьми;
  в MULTI/SEQ — выбор состояния части/шага.

## Важные смещения патча

| SysEx offset | Параметр |
|---:|---|
| 2 | OCTAVE (высший ниббл задаёт октаву; low nibble не влияет на pitch) |
| 30 / 31 | OSC1_FREQ / OSC2_FREQ; `36` — нейтральный центр |
| 49–53 | ENV1: ATK, DEC, SUS, DK2, REL |
| 54–58 | ENV2: ATK, DEC, SUS, DK2, REL |
| 59–63 | ENV3: ATK, DEC, SUS, DK2, REL |
| 77 / 78 | MASTER_TUNE / OSC2_FINE |
| 83 / 84 | CONT1_SRC / CONT2_SRC |
| 112–115 | DYN1 / DYN2 / DYN3 / OSC2_MODE |
| 116–120 | PAN_SYNC / DLY2 / DLY3 / PAN_KEY / PAN_WAVE |
| 121 / 125 | LFO1_SYNC / LFO2_SYNC |
| 129–132 | PAN_CLK extension / OSC2_SYNC / OSC2_ENV1 / INVT |

MIDI CC 116, 117 и 118 — отдельные номера MIDI-контроллеров для функций арпеджиатора и
OSC2 Sync; это **не** смещения байтов патча.

## Состояние проекта и банков

- Встроенный банк A загружается при старте; `LOAD BANK` принимает `.syx` / `.mid`.
- Хост сохраняет APVTS-параметры, положение морфа, состояние MW=BLEND, `arpSync`, SEQ и
  MULTI-части. При наличии внешнего банка сохраняется путь к нему.
- `RESET ALL` возвращает морф к A, глушит голоса, сбрасывает MW/ARP и отключает части
  MULTI/SEQ; Accu-Tune устанавливает `MASTER_TUNE=64`.

## Сборка (Windows)

1. Откройте `Omega8.jucer` в Projucer JUCE 8.0.12 и сохраните проект.
2. Откройте экспортёр Visual Studio 2022, выберите `Release | x64`, соберите цель
   `Omega8 - VST3`.
3. Вариант с CMake (если JUCE доступен рядом с проектом или задан `JUCE_DIR`):

```bat
cmake -B build -G "Visual Studio 17 2022" -DJUCE_DIR=C:/JUCE
cmake --build build --config Release
```

## Проверки и ограничения

- Ошибки MSVC из пользовательского лога (`proc.partEng[i]` — такого поля нет) исправлены:
  редактор вызывает `proc.killPartVoice(i)`, который направляет запрос в движок.
- GCC 14.2 syntax-only compile `PluginProcessor.cpp` (including `PluginEditor.h`) against
  JUCE 8.0.12 passed with `-Wall -Wextra`; legacy deprecation/unused-parameter warnings
  were suppressed. This is not a Windows VST3 link/build.
- Regression test на удерживаемой ноте A001 → B045 проверяет все 101 позиции морфа в
  `Engine`: после фикса DK2 RMS больше не проваливается в ноль; прямой 2-секундный B045
  также звучит. Это DSP/headless-проверка, а не прослушивание собранного VST.
- Предыдущая формулировка «морф прошёл без щелчков» была слишком сильной: измерения RMS
  не доказывают отсутствие переходного щелчка. Щелчки в DAW/VST считаются не проверенными,
  пока не выполнена целевая сборка и прослушивание.
- Windows VST3-линковку нужно подтвердить вашим MSBuild/Projucer-билдером. Полная Linux
  plugin/standalone-сборка здесь не запускалась; для неё отсутствует ALSA development header.
- `WAH`, `TS-808` и некоторые новые routing-поведения — DSP-эмуляции/интерпретации по
  доступному мануалу, дампам и UI-декоду; A/B-сверка с физическим Omega 8 здесь не проводилась.
